# Primitive Bad-Pair Finite-Basis Prompt

Prompt:

```text
Please answer self-containedly and mathematically.  We are working on Sawin's
finite rack-domination problem:

    For every finite bijective set-theoretic YBE solution X, does there exist
    a finite rack Y such that ker rho_n^Y <= ker rho_n^X for every n?

Current frontier:

The contextual route is reduced to the finite extraction dichotomy /
Residual-Rigid Harmful Collapse Exclusion:

    harmful contextual collapse must either be finitely rack-absorbed or yield
    an independently constructed strict active descent.

Residual endpoint extraction is closed.  For every finite M, the residual
endpoint quotient E_M collapses an actual bad pair under the no-detector
hypothesis, and no quotient or totalization through E_M can restore
orbit-injectivity.

Target B, independent active extraction, is logically possible but currently
acts like an added hypothesis: it requires non-rack finite data
M,Z,r_Z,pi_{a,b}:X->Z not factoring through E_M, with total bijective YBE,
contextual compatibility, braid equivariance, properness, and global
orbit-injectivity.

The most actionable direction is Target A: direct finite rack absorption.

Target A can be phrased as a finite cover problem.  For a finite contextual
rack detector D, let B_D be the set of kernel-fiber bad pairs not separated by
D.  Products satisfy

    B_{D_1 x D_2}=B_{D_1} cap B_{D_2}.

So one finite detector exists iff finitely many detectors D_1,...,D_k separate
all bad pairs collectively.

Concrete proposed theorem:

    Primitive bad-pair finite-basis theorem.

    There exists a finite set of primitive bad-pair patterns such that every
    bad pair contains, reduces to, or factors through one of them in a
    context-stable YBE-compatible way; moreover each primitive pattern is
    separated by a finite contextual rack detector.

Then the product of the finitely many primitive-pattern detectors gives direct
finite rack absorption.

Task.

1. Formulate the primitive bad-pair finite-basis theorem precisely.  What is a
   "primitive bad-pair pattern"?  Possible notions include:

       bounded arity bad cores,
       bounded braid-complexity kernel moves,
       context-stable clopen cores in K=hat{L_X} x X x hat{L_X},
       primitive reachable holonomy loops,
       primitive K_n(P_X)-moves in fibers over P_X^n,
       minimal bad pairs under some YBE-compatible order.

   Choose the strongest plausible formulation and state it exactly.

2. Test bounded arity.  Is there any YBE-specific reason every harmful bad
   pair should contain a bounded-arity harmful core?  If not, give an explicit
   obstruction pattern involving arbitrarily many observer strands.

3. Test bounded braid complexity.  Can elements of K_n(P_X) acting
   nontrivially on X^n be reduced, up to contextual detection, to bounded
   braid words?  If not, identify examples or mechanisms where kernel word
   length must grow with n.

4. Test finite-index contextual Myhill-Nerode.  Can orbit-relevant contextual
   behavior have finite index beyond the already-failing residual endpoint
   quotient E_M?  What extra state would be needed, and why would it be
   rack-realizable?

5. Test context-stable clopen cores.  Can bad pairs be covered by finitely
   many detector-separated clopen cores in the profinite contextual alphabet?
   If compactness does not prove this, what YBE-specific mechanism might?

6. Test uniform reachable holonomy separation.  Can every actual
   kernel-fiber monodromy be separated by finitely many finite rack-valued
   holonomy detectors?  What fails if holonomy is only pointwise separable or
   profinite?

7. Test special structure of K_n(P_X).  Since P_X is a finite rack and
   K_n(P_X) has finite index in B_n for each n, is there any uniform finite
   basis for its action on fibers over P_X^n?  Does the family over all n
   have a Markov/operadic/local generation property useful for detection?

8. If the primitive finite-basis theorem fails, extract the failure data.
   Does failure naturally produce non-rack holonomy or finite coordinatewise
   active data for Target B?  Or can failure remain purely profinite and
   non-coordinatewise?

9. State the strongest valid result after the audit.  Should Target A be
   pursued via bounded arity, bounded braid complexity, finite-index
   Myhill-Nerode, context-stable clopen cores, reachable holonomy, or
   K_n(P_X) finite-basis structure?

Guardrails.

- Do not rely on residual endpoint quotients E_M; they already collapse
  actual bad pairs under the harmful hypothesis.
- Do not assume compactness, Higman, Stone duality, ordinary automata, or
  pointwise residual finiteness gives a finite detector.
- Do not treat ordinary YBE quotients as domination-reducing unless
  orbit-injectivity/kernel reflection is proved.
- Do not treat holonomy or groupoid data as solving the problem unless it
  becomes finite rack-valued detection or total bijective YBE active data.
- Keep Target A distinct from Target B: Target A must produce an actual finite
  contextual rack detector.

Goal.

Determine whether a primitive bad-pair finite-basis theorem is plausible, and
identify the most concrete sublemma to attack next.
```
