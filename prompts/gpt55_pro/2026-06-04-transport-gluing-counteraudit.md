Definitions. A finite rack Y dominates a finite bijective set-theoretic Yang-Baxter solution X if

    ker(B_n acting on Y^n) <= ker(B_n acting on X^n)

for every n.

Let pi:X->Z be a finite YBE quotient with crossing-closed fibres F_a=pi^{-1}(a). Assume Z is rack-dominated and each internal block solution F_a is rack-dominated. For a != b, write r_Z(a,b)=(c,d). Assume the mixed row

    r_X:F_a x F_b -> F_c x F_d

is product-like: either direct,

    r_X(x,y)=(phi_{a,b}(x), psi_{a,b}(y)),

or swapped,

    r_X(x,y)=(phi_{a,b}(y), psi_{a,b}(x)).

Assume every one-variable transport map phi,psi is an isomorphism of the relevant internal block YBE solutions.

A previous proposed proof claimed that these hypotheses imply X is rack-dominated by:

1. forming the finite groupoid generated by the transport isomorphisms;
2. choosing representative fibres and gauges;
3. replacing every mixed transport by identity to get a split YBE solution T;
4. dominating T by the quotient rack and block racks;
5. reconstructing X by an injective B_n-equivariant sequential code.

Here is a concrete stress test showing that step 3 is false literally.

Let

    X = {0,1} x Z/3

with

    r((a,x),(b,y)) = ((a,y),(b,x+1 mod 3)).

The quotient by the first coordinate is the identity solution on two colours. The two colour fibres are crossing-closed, and the internal solution on each fibre is the cyclic rack crossing

    (x,y) -> (y,x+1).

Every mixed row is product-like and its one-variable transport maps are isomorphisms of this internal cyclic-rack solution. However the transport groupoid has loop monodromy x -> x+1 of order 3.

If we follow the proposed split construction literally, keeping the internal cyclic row on same-colour pairs and replacing only the mixed cyclic transport by identity, we get a table T:

    T((a,x),(a,y)) = ((a,y),(a,x+1))       for same colours,
    T((a,x),(b,y)) = ((a,y),(b,x))         for a != b.

This T is not a YBE solution. On the triple

    ((0,0),(0,0),(1,0))

one gets

    sigma_1 sigma_2 sigma_1 = ((0,0),(0,1),(1,1)),
    sigma_2 sigma_1 sigma_2 = ((0,0),(0,0),(1,1)).

So transport-isomorphism does not justify simultaneous identity-normalization.

This example is not a counterexample to rack domination. It is closed by a finite cyclic detector: in one-based position i, set

    u_i = x_i - i mod 3.

Then every braid generator acts on the u-coordinates by the cyclic rack crossing

    (u_i,u_{i+1}) -> (u_{i+1}+1,u_i).

Thus the example is braid-equivalent on fibre coordinates to the 3-point cyclic rack, with the colour coordinate an inert observer.

C. A finite counterexample satisfying the stated hypotheses but not rack-dominated.

Please do not restate the old identity-gauge proof unless it addresses the non-YBE split T above. The key issue is whether every finite transport monodromy action arising from such product-like isomorphism rows can be absorbed by a fixed finite detector tower in all braid arities.
