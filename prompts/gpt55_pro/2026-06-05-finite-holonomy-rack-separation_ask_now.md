# Finite Holonomy-Rack Separation Prompt

Status: ask_now / prepared for GPT-5.5 Pro on 2026-06-05.

Prompt:

```text
Please answer self-containedly and mathematically. Do not give only a bounded
computation. The goal is to decide whether the finite holonomy-rack separation
lemma can close the remaining residual branch of Sawin's finite rack-domination
problem.

Background.

Sawin asks: for every finite bijective set-theoretic Yang-Baxter solution X,
does there exist a finite rack Y such that

    ker rho_n^Y <= ker rho_n^X       for every n?

Write

    r_X(x,y)=(L_x(y),R_y(x)).

Known guardrails:

1. Product observers Lambda_n=L_{x_1}...L_{x_n} and the right analogue are
   genuine inert observers, but they do not reduce the problem.  For any finite
   solution Z, X=E x Z with E a nontrivial identity solution is everywhere
   singular and has ker rho_n^X=ker rho_n^Z.

2. Product-Hurwitz separability is a valid sufficient theorem, but finite
   residual separability of the universal suffix Hurwitz racks U_L(X), U_R(X)
   is an extra hypothesis.

3. The prefix-path rack vertexization theorem is valid.  Let S=S_L^1 and
   p_0=1, p_i=L_{x_1}...L_{x_i}.  If there are a finite rack Y, maps
   psi:S x X -> Y, and inert observers iota_n such that, for r_X(x,y)=(u,v),

       psi(p,u) = psi(pL_x,y),                                  (V1)
       psi(pL_u,v) = psi(pL_x,y) triangleright psi(p,x),        (V2)

   and (Psi_n,iota_n) is injective for every n, where

       Psi_n(x_1,...,x_n)=(psi(p_0,x_1),...,psi(p_{n-1},x_n)),

   then ker rho_n^Y <= ker rho_n^X for every n.

4. An active factor must be domination-reducing, not merely an ordinary
   quotient.  A proper finite solution Z is a domination-reducing active factor
   of X if there are B_n-equivariant maps Pi_n:X^n -> Z^n and inert maps
   eta_n:X^n -> I_n such that (Pi_n,eta_n) is injective for every n.  This
   implies ker rho_n^Z <= ker rho_n^X.  Ordinary solution quotients usually
   give the opposite containment.

Universal prefix vertex rack.

Let V_L(X) be the rack generated by symbols

    a_{p,x}       (p in S_L^1, x in X)

with relations, for every p,x,y and r_X(x,y)=(u,v),

    a_{p,u} = a_{pL_x,y},                              (VL1)
    a_{pL_u,v} = a_{pL_x,y} triangleright a_{p,x}.     (VL2)

This is the universal rack making prefix labels braid-equivariant.

Define finite-rack residual equivalence on S_L^1 x X by

    (p,x) ==_fin (q,y)

if every homomorphism from V_L(X) to a finite rack identifies a_{p,x} and
a_{q,y}.

If orbit observers are allowed, finite prefix vertexization is equivalent to
orbitwise finite-rack separation:

    whenever w != w' lie in the same B_n-orbit in X^n,
    some coordinate i has

       (p_{i-1}(w),w_i) not ==_fin (p_{i-1}(w'),w'_i).

The remaining lemma would be:

    In every residual rigid finite solution X with no proper domination-
    reducing active factor, ==_fin is orbit-faithful.

Equivalently:

    Every finite-rack residual collapse of prefix vertices either descends to a
    proper inert active factor, or is harmless for braid-orbit separation.

Task.

1. Try to prove this finite holonomy-rack separation lemma for residual rigid
   cores.  Use the prefix path groupoid with arrows p --x--> pL_x and the YBE
   square relations

       (p,x)(pL_x,y)=(p,u)(pL_u,v).

2. If it is false, give the sharpest possible obstruction.  Ideally provide:
   - a finite YBE table pattern or construction;
   - a finite semigroup/Rees matrix pattern where ==_fin has a prefix-dependent
     collapse that does not descend to a coordinate active factor;
   - or a proof that such a collapse can exist in V_L(X) while still being
     compatible with the YBE relations.

3. Analyze whether the finite-rack residual congruence ==_fin can be computed
   by a finite closure process on S_L^1 x X using:
   - VL1;
   - rack operation functionality;
   - injectivity of rack translations;
   - self-distributivity;
   - finite quotient separation.
   Does this closure decide finite vertexization, or is there a genuinely
   profinite rack obstacle?

4. Determine whether a prefix-dependent finite-rack collapse necessarily
   produces a smaller domination-reducing active factor after adding an inert
   complement.  If yes, prove it.  If no, isolate the obstruction precisely.

5. Relate the answer to Rees sandwich data in the minimal ideal of S_L.  Does
   the holonomy groupoid retain enough row/column/sandwich information to force
   finite rack separation, or can Rees sandwich ambiguity survive all finite
   rack quotients?

Important:

- Do not claim product observers alone prove domination.
- Do not use ordinary quotients as active factors unless the kernel-reflecting
  direction ker rho_n^Z <= ker rho_n^X is proved.
- Do not identify V_L(X) with the suffix Hurwitz rack U_L(X) without proving
  the needed reversal/opposite symmetry.
- If the result is conditional, state the exact missing finite/profinite lemma.
- A useful answer should either prove the lemma, refute it with a realizable
  obstruction, or turn it into a smaller finite checkable criterion.
```
