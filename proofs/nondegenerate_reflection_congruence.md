# Nondegenerate Reflection Congruence

This note records a canonical quotient attached to any finite bijective
Yang-Baxter solution.  It is the smallest braided congruence that must be
collapsed in order to make the quotient two-sided nondegenerate, hence the
largest two-sided nondegenerate quotient of the original solution.

## Setup

Let `X` be a finite bijective YBE solution, and write

```text
R_X(x,y) = (lambda_x(y), rho_y(x)).
```

A braided congruence on `X` is an equivalence relation `E` such that both
`R_X` and `R_X^{-1}` descend to `X/E`.

The quotient `X/E` is left-nondegenerate if, for every class `[x]`, the map

```text
[y] -> [lambda_x(y)]
```

is injective, and therefore bijective because `X/E` is finite.  It is
right-nondegenerate if the analogous maps

```text
[x] -> [rho_y(x)]
```

are injective.

## Definition

Define an increasing sequence of braided congruences `E_k`.

Start with

```text
E_0 = Delta_X.
```

Given `E_k`, let `E_{k+1}` be the braided congruence generated by `E_k` and
the following quotient-degeneracy pullbacks:

```text
y ~ y'       if lambda_x(y) E_k lambda_x(y') for some x in X,

x ~ x'       if rho_y(x) E_k rho_y(x') for some y in X.
```

Since `X` is finite, this chain stabilizes.  Let

```text
E_nd = E_N
```

for the stable value.  Call `E_nd` the nondegenerate-reflection congruence.

## The Quotient Is Nondegenerate

Let

```text
bar X = X/E_nd.
```

Suppose in `bar X` that

```text
lambda_[x]([y]) = lambda_[x]([y']).
```

By definition, this means

```text
lambda_x(y) E_nd lambda_x(y').
```

Because `E_nd` is a fixed point of the construction, the left pullback rule
forces

```text
y E_nd y'.
```

Thus `[y]=[y']`.  Therefore every left translation in `bar X` is injective,
hence bijective.

The same argument with `rho` proves right-nondegeneracy.  Therefore

```text
X/E_nd
```

is a finite two-sided nondegenerate YBE solution.

## Universal Property

Let `F` be any braided congruence such that `X/F` is two-sided
nondegenerate.  Then

```text
E_nd <= F.
```

Indeed, `E_0 <= F`.  Assume inductively that `E_k <= F`.

If

```text
lambda_x(y) E_k lambda_x(y'),
```

then also

```text
lambda_x(y) F lambda_x(y').
```

In the quotient `X/F`, this says

```text
lambda_[x]([y]) = lambda_[x]([y']).
```

Left-nondegeneracy of `X/F` gives `[y]=[y']`, so `y F y'`.

Similarly, if

```text
rho_y(x) E_k rho_y(x'),
```

then right-nondegeneracy of `X/F` gives `x F x'`.

Since `F` is already a braided congruence, it contains the braided congruence
generated by `E_k` and all these new pullback pairs.  Hence

```text
E_{k+1} <= F.
```

By induction, `E_nd <= F`.

Thus every map from `X` to a finite two-sided nondegenerate quotient factors
through

```text
X -> X/E_nd.
```

Equivalently, `X/E_nd` is the largest two-sided nondegenerate quotient of
`X`.

## Finite Certificate

The construction is an explicit finite closure procedure.

1. Start with equality.
2. Pull back already identified outputs under every `lambda_x` and every
   `rho_y`.
3. Close under the four operations defining braided congruence: the two
   coordinates of `R_X` and the two coordinates of `R_X^{-1}`.
4. Iterate until stable.

If the stable congruence is proper, `X` has a nontrivial canonical
nondegenerate quotient.  If the stable congruence is universal, then the
only two-sided nondegenerate quotient is the one-point quotient.  In that
case call `X` degeneracy-perfect.

## Consequences For Counterexample Search

If `X` is braided-simple and degenerate, then `E_nd` is nontrivial.  Indeed,
degeneracy gives either

```text
lambda_x(y) = lambda_x(y') with y != y',
```

or

```text
rho_y(x) = rho_y(x') with x != x',
```

so a nontrivial pair is added at the first pullback stage.  Braided
simplicity then forces

```text
E_nd = X x X.
```

Thus a braided-simple degenerate candidate is automatically
degeneracy-perfect.

For a general finite degenerate `X`, the first canonical step is to compute
`E_nd`.

If `E_nd` is proper, then the quotient `X/E_nd` is nondegenerate and therefore
finite-rack dominated by the known derived-rack/guitar theorem.  The
remaining problem is not to find a base detector, but to decode the hidden
layer over

```text
X -> X/E_nd
```

using the relative contextual, species-gauge, or stratified decoder-tower
machinery.

If `E_nd` is universal, then no nontrivial nondegenerate quotient is
available.  These degeneracy-perfect solutions are the sharper primitive
search class for a possible fixed finite counterexample.

This does not prove Sawin domination, and it does not produce a
counterexample.  It canonicalizes the first quotient layer and narrows the
next search target to:

```text
degenerate non-involutive solutions with universal E_nd,
especially braided-simple or subdirectly irreducible ones,
```

or hidden layers over a proper `E_nd` quotient that evade every finite
stratified decoder tower.
