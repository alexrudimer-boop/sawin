# Q3 Small-Rack Compression

Date: 2026-06-04

This note records the exact compression of the rack-size-three detector

```text
Q_3 = product of all rack isomorphism classes of size <= 3.
```

It is useful for the bounded-deletion obstruction in
`proofs/dummy_color_deletion_descent.md`, especially when `a_X(2)=2` and the
next detector is `Q_3`.

## Racks of Size at Most Three

In the convention

```text
R(a,b) = (a ▷ b, a),      L_a(b)=a ▷ b,
```

the rack identity is

```text
L_{a▷b} = L_a L_b L_a^{-1}.
```

Up to isomorphism, the racks of size at most three are:

```text
T_1.

T_2:      L_0=L_1=id.
C_2:      L_0=L_1=(01).

T_3:      L_0=L_1=L_2=id.
E_+:      L_0=L_1=id,    L_2=(01).
E_-:      L_0=id,        L_1=L_2=(12).
C_2^(3):  L_0=L_1=L_2=(12).
D_3:      a ▷ b = 2a-b mod 3.
C_3:      L_0=L_1=L_2=(012).
```

This matches the repository enumeration

```text
small_rack_representatives(3)
```

with sizes

```text
1, 2, 2, 3, 3, 3, 3, 3, 3.
```

## Exact D3 Formula

Let `D_3(n)` be the kernel of the braid action on `Q_3^n`.  Let

```text
ell_ij : P_n -> Z
```

be the standard pure-braid abelianization coordinate, normalized by
`ell_ij(A_rs)=1` when `(i,j)=(r,s)` and `0` otherwise.  Define the row-sum
linking vector

```text
w_i(beta) =
  sum_{j<i} ell_{j,i}(beta) + sum_{j>i} ell_{i,j}(beta).
```

Let

```text
delta_n : B_n -> GL_n(F_3)
```

be the three-color dihedral rack representation, where `sigma_i` acts on
coordinates `i,i+1` by the block

```text
[ 2 2 ]
[ 1 0 ]
```

over `F_3`.

Then, for `beta in B_n`,

```text
beta in D_3(n)
```

if and only if all four conditions hold:

```text
beta in P_n,
ell_ij(beta) = 0 mod 2        for every i<j,
w_i(beta) = 0 mod 3           for every i,
delta_n(beta) = I_n.
```

Equivalently,

```text
D_3(n)
 =
ker(B_n -> S_n)
cap ker(ell mod 2)
cap ker(w mod 3)
cap ker(delta_n).
```

## Proof Sketch

The trivial racks `T_2` and `T_3` give the ordinary permutation action
`B_n -> S_n`, so invisibility to all racks of size at most three forces
purity.

For a constant-action rack with common left translation `pi` of order `e`, a
pure braid `beta` sends the color on strand `i` to

```text
pi^{w_i(beta)}.
```

Thus `C_3` imposes `w_i(beta)=0 mod 3`, while the constant transposition racks
impose `w_i(beta)=0 mod 2`.  The latter is implied by pairwise
`ell_ij(beta)=0 mod 2`.

The degenerate racks `E_+` and `E_-` impose the pairwise mod-two linking
conditions.  For `E_+`, view color `2` as a marker and colors `0,1` as a bit.
If `S` is the marker set, then for a pure braid the non-marker bit on strand
`j` changes by

```text
sum_{i in S} ell_ij(beta) mod 2.
```

Thus triviality for every coloring is equivalent to every `ell_ij(beta)` being
even.  The rack `E_-` gives the same condition with the corresponding active
two-color subset.

The rack `D_3` is exactly the linear representation `delta_n`; invisibility to
that rack is exactly `delta_n(beta)=I_n`.  Combining the classified rack list
proves the formula.

## Compressed Obstruction Group

For the bounded-deletion obstruction with cutoff `Q_3`, define a finite image
generated by pure generators `A_ij`.

For each `1 <= i < j <= n`, use the generator tuple

```text
g_ij =
(
  e_ij in F_2^{binom(n,2)},
  e_i+e_j in F_3^n,
  delta_n(A_ij) in GL_n(F_3),
  rho^X_n(A_ij),
  (rho^X_{|T|}(d_T A_ij))_{2 <= |T| <= h}
).
```

Here `d_T A_ij` is `A_{rank_T(i),rank_T(j)}` if both `i,j` survive in `T`,
and is the identity otherwise.

Let `Omega^{(3)}_{X,h,n}` be the group generated by the `g_ij` and their
inverses.  Then the `Q_3` bounded-deletion obstruction is

```text
E^{(3)}_{X,h,n}
 =
{ g_X :
  (0,0,I,g_X,(I)_T) occurs in Omega^{(3)}_{X,h,n} }.
```

This equals the original `E_{X,h,n}` whenever the relevant detector cutoff is
`Q_3`.  A nontrivial `g_X` is exactly a pure braid that is invisible to `Q_3`,
visible on `X^n`, and invisible after every deletion to at most `h` strands.

The helper

```text
bounded_deletion_support_q3_compressed_audit(X,h,n)
```

implements this witness-preserving compressed closure.  It avoids all action
on `Q_3^n`; the detector side is just

```text
F_2^{binom(n,2)} x F_3^n x GL_n(F_3).
```

The companion helper

```text
bounded_deletion_support_stabilizer_audit(X,h,n,3)
```

uses a disjoint-union permutation-group stabilizer instead.  It does not retain
braid words, but it can prove exact vanishing in larger arities.

For affine-linear solutions over `F_2`, the helper

```text
bounded_deletion_support_affine_q3_compressed_audit(M,t,d,h,n)
```

uses the same `Q_3` detector data, but stores the full `X^n` action and all
deleted `X` actions as augmented affine maps over `F_2`, not as permutations
of `X^n`.  This is an exact representation of the braid action when
`X=F_2^d` and

```text
R(x,y) = M(x,y)+t.
```

It is therefore a convention check and a non-enumerating compressed finite
matrix model for the affine branch.  It still closes the generated finite
image by breadth-first search, so large matrix images can remain too large
for exhaustive closure; in that case the stabilizer helper gives a separate
exact arity check when the underlying finite set is still small enough.

The generated affine pressure audit

The note `proofs/fixed_q3_affine_rack_obstruction.md` records the opposite

```text
X=F_5,
R(x,y)=(-x+2y,x).
```

For this rack, `a_X(2)=2`, but the exact compressed audit gives

```text
E^{(3)}_{X,2,3} != 1.
```

This does not refute Sawin, since `X` is itself a finite rack.  It only shows
that the affine endpoint cannot keep the detector fixed at `Q_3`; it must use
the true cutoff `a_X(h)+1`.

## Scope

This compression does not prove a bounded-deletion theorem for all
affine-linear finite YBE solutions.  It proves a sharper finite computation:
whenever the relevant cutoff is `Q_3`, exact rack-invisibility is finite
linear/matrix data.  The remaining affine branch is therefore the finite
matrix problem of proving that `E^{(3)}_{X,h,n}=1` for some `h=h(X)` and all
`n`, or finding nontrivial compressed obstructions for unbounded `h,n`.
