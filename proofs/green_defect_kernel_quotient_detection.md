# Green defect-kernel quotient detection

Date: 2026-05-29

This note performs the next reduction after
`proofs/green_first_output_defect_criterion.md`.  It does not prove the Master
Local-Minimal Residual Theorem.  It proves that every Green kernel-block or
Schutzenberger observer row has a canonical finite quotient on which the row
is exactly rack-Artin.  Therefore all Green/Schutzenberger motion outside a
finite normal defect kernel is already detected by the existing Artin
detector-lift theorem.

The remaining Green obstruction is no longer an arbitrary row mismatch.  It is
the endpoint product of first-output defects inside one finite normal subgroup.

## Setup

Fix one regular Green class `C` and one group-valued observer

```text
U_C.
```

Here `U_C` is either the Schutzenberger action group of `C`, or a finite
kernel-block permutation quotient of such an action.  These groups are fixed
by the interval data and are among the factors allowed in the corridor
detector product `H(pi,Q)`.

For each completed retained Green/corridor row write

```text
(a,q) |-> (q^a,a^q).
```

Let

```text
g(e) in U_C
```

be the observer label of an edge-germ `e`.  The coordinate-action relation
gives the product identity

```text
g(a) g(q) = g(q^a) g(a^q).          (1)
```

Define the first-output defect of the row by

```text
d_C(a,q) = g(q^a) g(q)^-1 in U_C.
```

Let

```text
Def_C = << d_C(a,q) : (a,q) a completed retained row >>_{U_C}
```

be the normal subgroup generated by all first-output defects of this observer.
It is finite because `U_C` is finite.

## The quotient theorem

Set

```text
bar U_C = U_C / Def_C.
```

Then every completed row becomes the exact side-opposite rack-Artin row in
`bar U_C`:

```text
bar g(q^a) = bar g(q),
bar g(a^q) = bar g(q)^-1 bar g(a) bar g(q).
```

Proof.  By definition,

```text
d_C(a,q)=g(q^a)g(q)^-1 in Def_C.
```

After quotienting by `Def_C`,

```text
bar g(q^a) bar g(q)^-1 = 1,
```

so `bar g(q^a)=bar g(q)`.  Project the product identity `(1)` to the quotient:

```text
bar g(a) bar g(q) = bar g(q^a) bar g(a^q).
```

Substitute `bar g(q^a)=bar g(q)`:

```text
bar g(a) bar g(q) = bar g(q) bar g(a^q).
```

Multiplying on the left by `bar g(q)^-1` gives

```text
bar g(a^q) = bar g(q)^-1 bar g(a) bar g(q).
```

Thus the projected row is exactly

```text
(A,B) |-> (B, B^-1 A B),
```

the side-opposite form of the Artin detector-lift row.  QED.

## Consequence: quotient motion is already rack-detected

The detector-lift criterion applies to the projected observer `bar U_C`.
Therefore terminal projected Green/Schutzenberger endpoint labels are
evaluations of recursive Artin longitudes in the fixed finite group `bar U_C`.

Equivalently, identity finite-`bar U_C` longitude data kills all projected
endpoint motion:

```text
Lambda_{bar U_C,n}(beta)=Lambda_{bar U_C,n}(1)
    => projected U_C endpoint is identity.
```

This introduces no braid-index dependence.  The group `bar U_C` is computed
from the finite interval-level observer `U_C` and its finite list of row
defects.  It is therefore a legal fixed detector factor.  If a proof keeps the
original factor `U_C` inside `H(pi,Q)`, the same conclusion follows by
projecting finite-`U_C` longitude data through the quotient homomorphism
`U_C -> bar U_C`.

## The only remaining Green obstruction

The quotient theorem shows that all non-defect Green/Schutzenberger motion is
Artin-longitudinal.  Hence the remaining obstruction lies inside the finite
normal defect kernel `Def_C`.

More explicitly, while sweeping a braid word, the elementary row defects
transport and multiply to an endpoint element

```text
D_C(beta) in Def_C.
```

The remaining A-side target is:

```text
D_C(beta) in V_beta(Def_C)
```

for every residual braid `beta`, uniformly in braid index.

It is enough to display this endpoint as a product of Artin permutation defect
values

```text
phi(beta(w) p_beta(w)^-1)
```

inside the fixed finite group `Def_C`, because
`proofs/artin_defect_longitudinalization_sieve.md` proves that such values
always lie in `V_beta(Def_C)`.

If this defect-kernel longitudinalization is proved, the
Green/Schutzenberger component closes:

1. `U_C/Def_C` is killed by the quotient theorem and detector-lift.
2. `Def_C` is killed by the defect-endpoint longitude display.
3. Kernel-block quotients are handled as homomorphic images of the same
   Schutzenberger argument when no local-only edge-germs occur.
4. The atom-inner component is already closed once atom descent and totality
   are known.
5. The remaining lower endpoint/unit holonomy is the separate unit-endpoint
   target isolated elsewhere in the repository.
6. Product assembly then places all fixed factors into one finite group
   `H(pi,Q)`, and the sharp obstruction theorem gives `Q x A_{H(pi,Q)}`.

## Counterexample consequence

A B-route can no longer use a generic Green or Schutzenberger row mismatch.
Every such mismatch is absorbed by the finite defect kernel.

To become outcome B, one must produce an explicit local-minimal interval and
a normalized-law sequence `beta_j` such that, eventually for every finite
group `G`, the finite-`G` recursive longitude data is identity, while a
defect-kernel endpoint

```text
D_C(beta_j) in Def_C
```

remains nonidentity and moves a residual tuple.  A bounded row mismatch, a
nontrivial finite quotient defect, or a detector miss at one braid index is
not enough.
