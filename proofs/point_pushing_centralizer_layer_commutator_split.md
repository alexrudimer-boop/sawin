# Point-Pushing Centralizer-Layer Commutator Split

Date: 2026-05-30

This note refines the centralizer-layer generator branch from
`proofs/point_pushing_active_module_generator_split.md`.

It does not prove outcome A or B.  It separates the centralizer-layer case
into an abelian layer and a stem layer inside the normal closure of the newest
point-pushing generator.

## Setup

Let a noncentral abelian-chief first failure have irreducible monolith

```text
M ~= F_p^r
```

and let

```text
C = C_H(M).
```

Assume we are in the centralizer-layer generator branch: the newest
point-pushing generator image `t` maps trivially to the action shadow
`H/C`, so

```text
t in C.
```

Let

```text
N = <<t>>_H.
```

By `proofs/point_pushing_bounded_normal_generator_tail.md`,

```text
M <= N.
```

Since `C` is normal in `H` and contains `t`, every conjugate of `t` lies in
`C`, so

```text
N <= C.
```

Therefore `M <= Z(N)`.

## Theorem

Exactly one of the following holds.

1. **Abelian centralizer layer.**

   ```text
   [N,N]=1.
   ```

   The normal generation of `M` occurs inside an abelian `H`-stable layer
   generated by conjugates of the bounded-order element `t`.

2. **Centralizer stem layer.**

   ```text
   M <= [N,N].
   ```

   Then `N` is a stem central extension over the module:

   ```text
   M <= Z(N) cap [N,N].
   ```

## Proof

The subgroup `N` is normal in `H`, so `[N,N]` is normal in `H`.  Because
`M` is the unique minimal nontrivial normal subgroup of the monolithic
quotient `H`, the intersection

```text
M cap [N,N]
```

is either `1` or `M`.

If `M cap [N,N]=M`, then `M<=[N,N]`.  Since `N<=C_H(M)`, we also have
`M<=Z(N)`, giving the centralizer stem layer.

Suppose instead that

```text
M cap [N,N]=1.
```

If `[N,N]` were nontrivial, then quotienting `H` by the normal subgroup
`[N,N]` would still leave the vertical monolith `M` nontrivial.  The
first-failure relation image `M` would survive in the smaller quotient,
contradicting the minimal choice of `H`.  Hence `[N,N]=1`, giving the abelian
centralizer layer.

This proves the dichotomy.  QED.

## Consequence For The Fork

The centralizer-layer generator branch is no longer a black box.  It is
exactly one of:

```text
abelian centralizer layer generated by conjugates of bounded-order t,
centralizer stem layer with M <= Z(N) cap [N,N].
```

Thus the noncentral module branch now has two active forms:

1. an active bounded-order linear generator, whose conjugate commutator images
   generate `M`;
2. a centralizer-layer generator, which is either abelian or stem inside
   `N=<<t>>_H`.

The theorem does not close either form, but it removes the possibility of an
unstructured centralizer-layer obstruction.

The follow-up
`proofs/point_pushing_abelian_centralizer_layer_prime_bound.md` further
constrains the abelian centralizer-layer form: `N=<<t>>_H` must be a
`p`-primary abelian layer whose exponent divides `ord(t)|B_X`.  Hence this
subcase has no module-prime escape.

## Audit Hook

The helper

```text
point_pushing_centralizer_layer_commutator_audit(...)
```

checks a finite row by forming `N=<<t>>`, computing `[N,N]`, and labeling the
row as

```text
abelian_centralizer_layer
centralizer_stem_layer.
```

Rows whose generator does not centralize `M`, whose normal closure does not
centralize `M`, or whose normal closure does not contain `M` are rejected as
invalid centralizer-layer data.
