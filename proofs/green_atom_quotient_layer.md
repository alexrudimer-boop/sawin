# Green atom quotient layer

Date: 2026-05-29

This note records the finite rack-like layer extracted from a Green
completed-row audit.  It is a theorem target and guardrail, not a proof of the
Master Local-Minimal Residual Theorem.

## Setup

Let `X` be a finite bijective YBE solution and write

```text
R(x,y)=(u,v).
```

Let

```text
tau_x(y)=pr_1 R(x,y)
```

be the first-coordinate action maps.  The YBE gives the structure relation

```text
tau_x tau_y = tau_u tau_v.
```

Fix a regular Green `R`-class `C` in the finite transformation monoid
generated by the `tau_x`, and form the retained edge-germs

```text
E_C = { (s,x) : s in C, s tau_x in C }.
```

For a supported pair

```text
a=(s,x),       q=(s tau_x,y),
R(x,y)=(u,v),
```

the completed row is

```text
q^a=(s,u),     a^q=(s tau_u,v).
```

The saturated atom relation is generated by

```text
q^a ~ q
```

over all completed rows.  Let `p:E_C -> A_C` be the quotient map.

## Atom-Action Descent

The Green atom layer is usable only if the completed-row operation descends
to atoms:

```text
p(a) triangleright p(q) = p(a^q).
```

This means that `p(a^q)` depends only on the two atoms `p(a),p(q)`, not on
the chosen edge representatives.  The inverse bookkeeping operation must also
descend:

```text
p(a^q) triangleleft p(q) = p(a).
```

When both operations are well-defined and every atom pair is supported, define
a finite atom crossing

```text
R_A(A,Q) = (Q, A triangleright Q).
```

Then `R_A` is bijective.  Indeed, for fixed `Q`, the map
`A -> A triangleright Q` has inverse `B -> B triangleleft Q`, and the first
coordinate of `R_A(A,Q)` is `Q`.

In this right-rack convention, the YBE is exactly the right
self-distributive law

```text
(A triangleright B) triangleright C
  =
(A triangleright C) triangleright (B triangleright C).
```

The YBE for `R_A` follows from the supported completed-row cube identities.
At edge level, applying the two braid words `121` and `212` to a retained
three-edge path gives the same labelled output because the original table
satisfies YBE; the coordinate-action relation keeps the monoid endpoints
consistent.  Passing to atoms is legitimate precisely because the operation
descends.  Thus a total descended atom layer is a finite right-rack-like YBE
solution of the form

```text
(A,Q) |-> (Q, A triangleright Q).
```

Equivalently, after taking the side-opposite convention, it is a finite rack
layer.  This layer is therefore not itself a normalized-law obstruction.

## Executable Helper

The helper

```text
atom_action_summary(audit)
```

records:

- the number of atoms;
- the number of completed rows;
- supported and undefined atom pairs;
- forward `triangleright` conflicts;
- inverse `triangleleft` conflicts.

The helper

```text
atom_descent_closure_summary(audit)
```

computes the least coarsening of the saturated atom partition that makes the
forward action and inverse bookkeeping action well-defined.  If its
`proves_stable_atom_action` flag is true, then the original atom partition
already supplies a total well-defined atom action.  If it coarsens, the
coarsening is a precise obstruction object rather than an informal descent
failure; see `proofs/green_atom_descent_closure.md`.

The companion helper

```text
atom_descent_quotient_rack_audit(audit)
```

applies the same rack-law check after passing from saturated atoms to the
least descent-closed coarsening.  If the original atom partition coarsens but
the descent-closed quotient is a total rack layer, the atom-level part is
still controlled by a finite rack detector; the remaining theorem burden is
to show that the lost lower information is killed by endpoint/unit
longitudes, or to turn that lost information into a normalized-law
counterexample.

The helper

```text
atom_quotient_solution(audit)
```

constructs the finite atom crossing `R_A` when descent is conflict-free and
total.  It raises an error if the atom action is not well-defined on every
atom pair.

The helper

```text
atom_quotient_rack_audit(audit)
```

checks the rack laws directly:

- right-rack-like crossing shape, first output equal to the second input;
- bijectivity of every right translation `A -> A triangleright Q`;
- right self-distributivity;
- the equivalent finite YBE table check.

Thus generated reports no longer rely only on a black-box YBE check for the
atom quotient; they record the exact rack identity the proof must establish.

## Consequence For The Master Branch

This note separates the Green obstruction into two layers.

First, the saturated atom layer should be rack-like.  If this is proved
symbolically, it can be handled by the same finite-rack/finite-group
longitude mechanisms already recorded for known rack branches.

Second, any remaining obstruction must live below the atom quotient, in
section or unit holonomy.  That lower layer is exactly where
`proofs/unit_composite_longitude_criterion.md` and
`proofs/unit_section_product_detector.md` apply: residual endpoint units must
lie in the longitude-value subgroup of one fixed finite product of unit
groups, or a counterexample must produce a normalized-law sequence escaping
every finite group.
