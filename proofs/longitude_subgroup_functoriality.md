# Longitude subgroup functoriality

Date: 2026-05-29

This note records a small but useful algebraic fact used whenever detector
groups are replaced by quotients, products, normalized holonomy groups, or
unit groups of finite transition monoids.  It is not a proof of the Master
Local-Minimal Residual Theorem; it is a theorem-level hygiene lemma that
keeps the finite-longitude subgroup criterion stable under fixed finite group
maps.

## Statement

Let

```text
f : G -> H
```

be a homomorphism of finite groups.  For a braid `beta in B_n`, define

```text
V_beta(G) =
  < phi(L_i(beta)) : phi:F_n -> G, 1<=i<=n > <= G.
```

Then

```text
f(V_beta(G)) <= V_beta(H).
```

If `f` is surjective, then equality holds:

```text
f(V_beta(G)) = V_beta(H).
```

## Proof

For every assignment `phi:F_n -> G`, the composite

```text
f phi : F_n -> H
```

is an assignment into `H`.  Hence each value
`f(phi(L_i(beta)))` is one of the generators allowed in `V_beta(H)`.  Since
`f` is a group homomorphism, the image of the subgroup generated by all
`G`-values is contained in the subgroup generated by all `H`-values.

If `f` is surjective, every assignment `psi:F_n -> H` lifts
generator-by-generator: choose `g_k in G` with `f(g_k)=psi(x_k)`.  The free
property of `F_n` gives an assignment `phi:F_n -> G` lifting `psi`.  Thus
every generator `psi(L_i(beta))` of `V_beta(H)` lies in `f(V_beta(G))`, so
the two subgroups are equal.

## Consequence

The finite-longitude subgroup criterion is compatible with fixed finite group
maps:

- if a label `h in H` is the image of a label `g in V_beta(G)`, then
  `h in V_beta(H)`;
- if a normalized holonomy group is a quotient of a totalized product-label
  group, membership can be proved upstairs and pushed downstairs;
- if detector factors are multiplied into a direct product, projection to
  each factor preserves the corresponding longitude-value subgroup;
- if a semigroup observer is replaced by its unit/permutation group and then
  by a quotient of that unit group, the unit-holonomy longitude gate is
  stable under that quotient.

This matters for the remaining local theorem because the candidate detector
`G(pi,Q)` is assembled from fixed finite factors: product-label groups,
normalized holonomy groups, Green kernel-block groups, Schutzenberger groups,
unit groups of transition monoids, quotient detector factors, and already
known branch factors.  The lemma lets a proof move labels through those fixed
maps without changing the braid index and without introducing an
`n`-dependent detector.

## Executable Certificate

The code introduces:

```text
FiniteGroupHomomorphism(source,target,mapping)
homomorphic_longitude_subgroup_audit(f,n,beta)
pushforward_longitude_subgroup_witness(f,witness)
pushforward_longitude_subgroup_witness_audit(f,n,beta,witness)
```

The audit computes `V_beta(source)`, maps it into `target`, computes
`V_beta(target)`, and reports containment and equality.  Regression tests
check both:

- a surjective quotient `C_6 -> C_3`, where equality holds;
- a non-surjective homomorphism `C_2 -> C_4`, where the image is a proper
  subgroup of `V_beta(C_4)` for the two-strand pure generator.

The witness pushforward helpers are the certificate-level version of the same
lemma.  Given a displayed word in longitude values in the source group, they
apply `f` to every entry of every assignment and verify that the resulting
target witness evaluates to the homomorphic image of the source value.  This
lets quotient and normalized-holonomy steps carry explicit endpoint
certificates rather than relying on subgroup enumeration.
