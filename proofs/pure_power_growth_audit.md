# Pure-power growth audit

## Purpose

This note isolates the simplest normalized-law counterexample route.

For any `N`, the word

```text
x^lcm(1,...,N)
```

is eventually a law for every fixed finite group.  Embedded as
`A_{i,q}^{lcm(1,...,N)}`, it would give a B-style obstruction only if one
fixed finite YBE solution `X` had pure-generator action orders on `X^q` with
new prime-power divisors appearing as `q -> infinity`.

Thus the pure-power route needs unbounded order of the permutation

```text
rho_{X,q}(A_{i,q})
```

as `q` grows.  This is only a candidate-search criterion, not a theorem.

## Generated report

The generated JSON report is `proofs/pure_power_growth_audit.json`.

Current bounded results:

- all size-2 whole YBE solutions, `q <= 6`: maximum pure-generator order `2`;
- all size-3 whole YBE solutions, `q <= 6`: maximum pure-generator order `3`;
- all linear YBE maps on `F_2^2`, `q <= 5`: maximum pure-generator order `3`.

So the easiest exponent-power B route does not appear in these families.

## Moving subgroup warning

This does not rule out law-word counterexamples.  The subgroup generated by all
pure generators can grow while the individual generators have bounded order.
For the known size-3 affine commutator candidate, which is in an eliminated
nondegenerate branch and is not B, the pure-generator subgroup profile is:

```text
q=2: size 3, exponent 3
q=3: size 24, exponent 12
q=4: size 648, exponent 36
q=5: exceeds 5000 under the audit cap
```

This confirms the broader escape hatch: a true B candidate could still use
moving finite action groups and non-power law words.  It also shows why
bounded subgroup closure must not be treated as proof evidence for the global
theorem.  The exact exponents for the closed rows make the exponent-law
barrier explicit: a pure-power word whose exponent is divisible by the row's
subgroup exponent is forced to act trivially on that fixed image.

## Consequence

The counterexample search should prioritize non-power normalized laws and
bi-free local-minimal intervals.  Pure powers remain a possible theoretical
route only if a symbolic construction proves unbounded pure-generator order;
no such behavior is visible in the current small or affine-linear audits.
