# Profinite Stabilizer Separation Boundary

Date: 2026-06-05

Correction added after the next audit: the profinite stabilizer criterion
below is correct, but `V_L(X)` itself does not retain the full prefix arrow
`p --x--> pL_x`.  Relation `(VL1)` collapses `a_{p,x}` to `a_{1,p(x)}`.
Thus the associated group that matters for this particular prefix rack is more
economically written as `As(W_L(X))`, where `W_L(X)` is generated by normalized
prefix labels `b_z`, `z in X`.  The full prefix path groupoid retains Rees
sandwich data; the rack `V_L(X)` only sees its evaluated label part.  See
`proofs/normalized_prefix_profinite_barrier.md` for the corrected endpoint.

This note records the sharpened obstruction after the finite holonomy-rack
separation audit.  The finite prefix holonomy groupoid retains the Rees
sandwich data lost by the local group `eSe`, but retaining the data is weaker
than proving finite rack quotients can separate it.  The exact remaining issue
is profinite subgroup separability in the associated group of the universal
prefix vertex rack.

## Associated Group Of The Prefix Vertex Rack

Let

```text
A=S_L^1 x X,
alpha=(p,x),
a_alpha=a_{p,x}.
```

Let

```text
R=V_L(X)
```

be the prefix vertex rack generated by `a_{p,x}` with relations, for
`r_X(x,y)=(u,v)`,

```text
a_{p,u} = a_{pL_x,y},
a_{pL_u,v} = a_{pL_x,y} triangleright a_{p,x}.
```

The associated group is

```text
G=As(R)=< e_r, r in R | e_{b triangleright a}=e_b e_a e_b^{-1} >.
```

Since `R` is generated by the finite set `A`, `G` is generated by the elements
`g_{p,x}=e_{a_{p,x}}`.  The corresponding finite presentation is

```text
G =
< g_{p,x}
  | g_{p,u}=g_{pL_x,y},
    g_{pL_u,v}=g_{pL_x,y} g_{p,x} g_{pL_x,y}^{-1}
>.
```

The group `G` acts on `R` by rack translations.  For a prefix vertex
`alpha in A`, write `bar alpha in R` for its represented rack element and

```text
H_alpha = Stab_G(bar alpha).
```

## Profinite Criterion For Finite Rack Residual Equivalence

For two prefix vertices `alpha,beta in A`, define

```text
alpha ==_fin beta
```

if every homomorphism from `R` to a finite rack identifies `bar alpha` and
`bar beta`.

If `bar alpha` and `bar beta` lie in different `G`-orbits, they are separated
by a finite trivial rack recording the finitely many generator orbits.  Thus

```text
alpha not ==_fin beta.
```

If they lie in the same `G`-orbit, choose `g in G` with

```text
bar beta = g . bar alpha.
```

Then

```text
alpha ==_fin beta
iff
g in closure_prof(H_alpha)
iff
g in intersection_{N normal finite index in G} H_alpha N.
```

Thus finite-rack residual collapse is exactly a nonseparable coset problem:

```text
g notin H_alpha
but
g in closure_prof(H_alpha).
```

## Proof Sketch

Let `f:R -> Q` be a finite rack quotient.  It induces

```text
phi_f:G -> Inn(Q),
```

where `Inn(Q)` is finite.  If `g in H_alpha ker(phi_f)`, write `g=hn` with
`h in H_alpha` and `n in ker(phi_f)`.  Then

```text
f(g . bar alpha)=phi_f(g).f(bar alpha)
              =phi_f(h).f(bar alpha)
              =f(h . bar alpha)
              =f(bar alpha).
```

If this holds for every finite quotient of `G`, then every finite rack quotient
identifies `alpha` and `beta`.

Conversely, if `g notin H_alpha N` for some finite-index normal subgroup
`N normal G`, construct a finite augmented rack

```text
Q_N = disjoint union_j G/(H_j N),
```

where `a_j` runs over the finitely many `G`-orbits of `R` represented by
generators and `H_j=Stab_G(a_j)`.  The finite group `G/N` acts on `Q_N`, with
augmentation

```text
partial(hH_jN)=h e_{a_j} h^{-1} N.
```

The rack operation is

```text
(gH_iN) triangleright (hH_jN)
    = (g e_{a_i} g^{-1} h) H_jN.
```

The map

```text
R -> Q_N,
g . a_j -> gH_jN,
```

is a finite rack quotient and separates `a` from `g.a` whenever
`g notin H_a N`.

## Orbitwise Failure Of Vertexization

For a word

```text
w=(x_1,...,x_n),
p_0(w)=1,
p_i(w)=L_{x_1}...L_{x_i},
alpha_i(w)=(p_{i-1}(w),x_i),
```

finite prefix vertexization fails exactly when there exist `n`, a braid
`beta`, and a word `w` such that

```text
w' = rho_n^X(beta)w != w
```

and for every coordinate `i`,

```text
alpha_i(w) ==_fin alpha_i(w').
```

In associated-group language, for each `i` there is a transporter `g_i in G`
with

```text
bar alpha_i(w') = g_i . bar alpha_i(w)
```

and

```text
g_i in closure_prof(H_{alpha_i(w)}).
```

The obstruction is genuinely profinite when some `g_i` is not in the actual
stabilizer:

```text
g_i notin H_{alpha_i(w)}
but
g_i in closure_prof(H_{alpha_i(w)}).
```

## Why Finite Closure Is Insufficient

The finite closure rules on `S_L^1 x X` are sound:

```text
VL1;
rack-operation functionality;
injectivity of rack translations;
self-distributivity.
```

They compute ordinary equational consequences of the rack presentation, or
finite approximations to those consequences.  In group language, they detect
membership in the actual stabilizer `H_alpha`.

Finite-rack residual equivalence detects membership in

```text
closure_prof(H_alpha).
```

The gap

```text
closure_prof(H_alpha) \ H_alpha
```

is invisible to any finite local closure process on the finite vertex set
`S_L^1 x X`, unless the process includes the profinite oracle "identify two
vertices if no finite rack quotient separates them."

Therefore the finite holonomy-rack lemma is not a finite semigroup/Rees
statement.  It requires subgroup separability of orbit-relevant stabilizers in
`As(V_L(X))`.

## Prefix-Dependent Collapse And Active Factors

For each prefix `p`, define

```text
x ~_p y
iff
(p,x) ==_fin (p,y).
```

A coordinate active factor requires a prefix-independent relation on `X`, or
more generally a coherent finite YBE state quotient.  If `~_p` varies with
`p`, the collapse is holonomy-dependent and does not automatically descend to
a coordinate quotient.

An inert complement cannot repair this inside a single braid orbit: inert
observers are constant on the orbit, so separation of two points in that orbit
must come from the active coordinates themselves.  A prefix-dependent collapse
can produce a domination-reducing active factor only if the relevant prefix
state can be encoded coherently as a smaller finite YBE active state.  That is
an additional condition, not a consequence of `(VL1),(VL2)`.

## Rees Sandwich Data

Let `S=S_L^1`, and let a minimal ideal be represented by a Rees matrix
semigroup

```text
I = M(G_0; I_0, Lambda; P),
```

with multiplication

```text
(i,g,lambda)(j,h,mu) = (i, g P_{lambda j} h, mu).
```

If

```text
L_x=(i_x,g_x,lambda_x),
L_y=(i_y,g_y,lambda_y),
e=(i_0,1,lambda_0),
```

then

```text
eL_xL_y e
= (i_0,
   P_{lambda_0 i_x} g_x P_{lambda_x i_y} g_y P_{lambda_y i_0},
   lambda_0),
```

whereas

```text
eL_xeL_y e
= (i_0,
   P_{lambda_0 i_x} g_x P_{lambda_x i_0}
   P_{lambda_0 i_y} g_y P_{lambda_y i_0},
   lambda_0).
```

Thus the local group loses the intermediate row, column, and sandwich entry

```text
(lambda_x, i_y, P_{lambda_x i_y}).
```

The prefix arrow

```text
p --x--> pL_x
```

keeps this data.  If `p=(i,g,lambda)`, then

```text
pL_x = (i, g P_{lambda i_x} g_x, lambda_x).
```

However, retaining Rees data in the finite holonomy groupoid does not imply
finite rack quotients separate it after rackification.  A loop detecting
different sandwich data can still lie in the profinite closure of a
prefix-vertex stabilizer.

## Smaller Sufficient Theorems

One finite sufficient certificate is a quotient

```text
phi:G=As(V_L(X)) -> Gbar
```

such that the induced finite coset rack separates every orbit-relevant pair of
prefix vertices.  Then the corresponding finite rack gives a prefix
vertexization and hence

```text
ker rho_n^Y <= ker rho_n^X
```

for all `n`.

A simpler sufficient condition is a finite rack `Y` and a map

```text
psi:S_L^1 x X -> Y
```

satisfying `(V1),(V2)` such that for every prefix `p`, the map

```text
x -> psi(p,x)
```

is injective.  Then the prefix labels recover each word from left to right, so
`Psi_n` is injective for every `n`.

## Current Missing Lemma

The residual branch now closes exactly under the following profinite
stabilizer-separation lemma.

```text
For every residual rigid X with no proper domination-reducing active factor,
every orbit-relevant stabilizer H_alpha <= As(V_L(X)) is profinitely closed on
the cosets needed to separate braid-orbit points.
```

Equivalently:

```text
No bad holonomy coset
g in closure_prof(H_alpha) \ H_alpha
appears in an orbit-relevant coordinate.
```

This is the current precise obstruction.
