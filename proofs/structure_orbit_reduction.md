# Structure orbit reduction

Date: 2026-05-28

This note records a small but useful invariant for both proof and
counterexample work.

## Positive structure monoid

For a finite braided set `X`, define the positive structure monoid

```text
M_X = < X | x y = u v whenever R(x,y)=(u,v) >.
```

Every defining relation preserves word length.  On degree `n`, the congruence
generated by these relations is exactly the orbit relation generated by
applying adjacent braid generators and their inverses:

```text
(...,x,y,...) <-> (...,u,v,...)
when R(x,y)=(u,v).
```

Because every local table `R` is bijective on `X x X`, the reverse rewrite is
the action of the inverse braid generator.  Therefore the degree-`n`
structure congruence classes are precisely the `B_n`-orbits on `X^n`.

## Consequence for A and B

This invariant is not enough to prove domination.  It records where the
motion can happen, not which braid element gives which permutation inside a
class.  The residual problem is exactly the holonomy problem:

```text
beta fixes the structure class but may permute points inside it.
```

Thus a B counterexample cannot be only a product invariant: the moved tuple
and its image must lie in the same finite degree structure orbit.  Conversely,
an A proof must show that the proposed finite detector groups kill all
possible holonomy inside every such orbit, uniformly in the degree.

This reframes the Green/kernel-block program.  The finite Green data should
detect the recurrent holonomy inside structure orbits.  If it does not, the
escaping object should be visible as a finite-state automaton group acting
nontrivially on deeper and deeper structure-orbit levels.

## Executable layer

The module `structure_orbits.py` implements:

- `adjacent_rewrites(X, word)`;
- `structure_orbit(X, word)`;
- `level_structure_orbit_partition(X, n)`;
- `braid_action_preserves_structure_orbits(X, n, beta)`;
- `structure_orbit_holonomy_summary(X, n)`;
- `structure_orbit_factorization_summary(X, n)`.

The holonomy helper computes the finite braid-action group on each degree-`n`
structure orbit separately.  It reports orbit sizes, internal group sizes,
internal group exponents, and which orbit group closures were truncated by a
configured diagnostic cap.  The factorization helper computes the global
fixed-degree image in `Sym(X^n)`, records its size and exponent when it
closes, and compares its projections with the separate orbit-holonomy
groups.  Since braid action preserves structure orbits, the global image
injects into the product of these orbit factors; the helper checks that the
closed projections are onto the factor groups.

The tests verify:

- identity solutions have singleton structure orbits;
- the trivial rack has multiset structure orbits;
- braid words preserve the structure partition in a nontrivial rack example;
- the trivial rack has a size-`3` structure orbit with internal `S_3`
  holonomy;
- for the trivial rack at `n=3`, the global image has size `6`, while the
  product of the two nontrivial orbit factors has size `36`; the projections
  are onto both orbit groups.

The generated report `proofs/structure_orbit_holonomy_audit.md` records the
orbit-holonomy profiles for the identity solution, the trivial rack, the
dihedral quandle, and the size-3 affine commutator diagnostic.  It also
records the correlated global image.  For the size-3 affine commutator
diagnostic at `n=4`, the orbit factors have sizes `216`, `648`, and `648`,
but the global image has size `648`, not the full product
`216 * 648 * 648`.

The normalized-law B route has also been localized to this structure-orbit
language in `proofs/structure_orbit_law_obstruction.md`.  If the standard
pure braid generators have orbit-local image groups `H_{q,O}` that escape
the finite-group varieties generated by all groups of bounded size, then the
standard law-braid embedding gives a moved tuple inside a single structure
orbit while finite-group Artin longitudes are eventually trivial.  The helper
`structure_orbit_law_separation()` is the bounded diagnostic for this target.

These are exact finite-degree checks.  They are not global proof evidence by
themselves, but they make the obstruction target sharper: future normalized
law candidates must exhibit undetected holonomy within these finite
structure classes and inside the correlated global braid-action image.
