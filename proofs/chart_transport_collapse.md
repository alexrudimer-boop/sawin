# Chart-transport collapse

Date: 2026-05-29

This note records a proof-side simplification for the remaining endpoint
longitudinalization target.  It does not prove the Master Local-Minimal
Residual Theorem.  It proves that transported or chart-conjugate copies of an
elementary endpoint generator do not need separate longitude proofs.

The detector group remains the fixed interval-level product

```text
H(pi,Q) = product_s H_s.
```

No factor introduced here depends on braid index `n`.

## Longitude subgroup normality

For a finite group `G` and braid `beta in B_n`, recall

```text
V_beta(G) =
  < phi(L_i(beta)) : phi:F_n -> G, 1 <= i <= n >.
```

Lemma.  `V_beta(G)` is a normal subgroup of `G`.

Proof.  Let `h=phi(L_i(beta))` be a generator of `V_beta(G)` and let `c in G`.
Define a new assignment

```text
phi^c(x_j) = c phi(x_j) c^-1.
```

Then

```text
phi^c(L_i(beta)) = c phi(L_i(beta)) c^-1 = c h c^-1.
```

Thus every conjugate of every generator is again an allowed generator.  Hence
the subgroup generated by those values is normal.  QED.

The executable witness form is
`conjugate_longitude_subgroup_witness(...)`: it replaces every assignment in a
literal `V_beta(G)` witness by its conjugate assignment and checks that the
evaluated value is `c u c^-1`.

## Chart-transport collapse

Let `C_el` be the finite elementary corridor groupoid used in the
elementary-longitudinalization target.  Its generators include elementary
coordinate-kernel seed arrows, one-step YBE transports and inverse transports,
retained Green/Schutzenberger chart-change arrows, and finite endpoint/unit
refinements.

Suppose the generating arrows of `C_el` are partitioned into finite
chart-conjugacy orbits.  Choose one representative `e_0` in an orbit, and
suppose its endpoint label in a fixed factor `H_s` satisfies

```text
u_{e_0}(beta,z,x) in V_beta(H_s).
```

If `e` is a transported copy of `e_0`, its label has the form

```text
u_e(beta,z,x) = c u_{e_0}(beta,z,x) c^-1
```

for a finite chart-change element `c in H_s`.  The element `c` may depend on
`beta`, `z`, `x`, the output coordinate, or finite corridor state.  This
dependence is harmless because the target group `H_s` is fixed.

By normality of `V_beta(H_s)`,

```text
c u_{e_0}(beta,z,x) c^-1 in V_beta(H_s).
```

Therefore

```text
u_e(beta,z,x) in V_beta(H_s).
```

QED.

## Loop consequence

The witness calculus already records that `V_beta`-membership is stable under:

- multiplication and inverse inside a fixed finite group;
- fixed finite group homomorphism pushforward;
- embedding factor witnesses into a fixed direct-product detector.

Together with chart-transport collapse, this means a loop certificate is
forced by one endpoint-longitude certificate for each finite chart-conjugacy
orbit of elementary generators.

The remaining burden is therefore not:

```text
prove every transported generator separately.
```

It is:

```text
prove one representative elementary generator in each finite chart-conjugacy
orbit has endpoint label in V_beta(H_s).
```

## Normal-closure correction

A previous possible weakening was to replace `V_beta(G)` by the normal closure

```text
<< V_beta(G) >>_G.
```

That is not a weaker target, because `V_beta(G)` is already normal.  Hence

```text
<< V_beta(G) >>_G = V_beta(G).
```

The certificate target remains ordinary `V_beta(G)` membership.  The useful
point is that ordinary membership already absorbs all finite chart conjugation.

## Updated obstruction seed

A genuine B route cannot be:

```text
the endpoint expression is conjugated by a finite chart change.
```

That is killed by this note.  It also cannot be a separate failure for a
transported copy once the orbit representative is certified.

The remaining possible seeds are:

1. a representative elementary generator orbit with no `V_beta(H_s)` witness;
2. a residual endpoint not represented by the finite elementary corridor
   groupoid;
3. a failure of faithfulness of the finite residual readout;
4. atom descent closure that is non-total or non-rack-like and does not route
   to an already handled branch.

Thus the chart-dependent generator noise is removed, but the final
descent-separation theorem remains open.
