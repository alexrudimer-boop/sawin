# Triangular recovery derived-series fork

Date: 2026-05-31

This note follows `proofs/triangular_recovery_unit_observer.md` and
`proofs/triangular_recovery_detector_lift_fork.md`.  It does not close the
remaining nonlinear branch.  It refines the finite `U_tri` endpoint problem by
splitting the unit group into derived quotients and a stable perfect residual.

## Setup

The triangular recovery observer gives one fixed finite group

```text
U_tri = < triangular recovery row permutations >.
```

A residual endpoint is a finite product of these row permutations.  The direct
membership target is still:

```text
endpoint in V_beta(U_tri).
```

The previous detector-lift route tries to prove this by identifying endpoint
labels with recursive Artin longitude labels.  The derived-series route gives
an independent finite certificate language for the same target.

The direct supplied-expression wrapper is recorded in
`proofs/triangular_recovery_longitude_expression_certificate.md`.  It checks
the middle route explicitly:

```text
recovery endpoint = product of evaluated recursive longitudes in U_tri.
```

The derived-series route below is useful when that expression is not supplied
directly but can be built quotient by quotient.

Let

```text
U_tri^(0) = U_tri,
U_tri^(r+1) = [U_tri^(r), U_tri^(r)],
P_tri = stable final derived subgroup.
```

## Derived-stage lift certificate

The wrapper

```text
triangular_recovery_derived_series_lift_audit(
    interval, n, beta, factor_row_indices,
    stage_lifted_witnesses,
    final_witness,
)
```

specializes the generic
`unit_composite_derived_series_lift_audit(...)` to the monoid generated by the
triangular recovery rows.

At stage `r`, the current residual endpoint lies in `U_tri^(r)`.  A supplied
witness must:

1. use only assignments in `U_tri^(r)`;
2. evaluate to the endpoint modulo `U_tri^(r+1)`.

Equivalently, the correction

```text
current_endpoint * witness_value^-1
```

must lie in `U_tri^(r+1)`.  Iterating through the derived series leaves a final
endpoint in `P_tri`.  A final witness in `P_tri` then proves that the original
endpoint is a product of evaluated recursive longitudes in `U_tri`.

Thus:

```text
triangular_recovery_derived_series_lift_audit(...).
    proves_recovery_endpoint_by_derived_lift
```

is a finite, checkable A-certificate for one triangular recovery endpoint.

## Solvable unit groups

[Conditional] If `U_tri` is solvable, then `P_tri=1`.  In that case, supplied
derived-stage lifts through all abelian quotients close the endpoint, because
the final residual is forced to be the identity.

This is useful but not yet a uniform proof: the remaining theorem would still
have to construct the stage witnesses for every local-minimal
bi-free universal-corridor interval and every braid index.

## Perfect residual fork

When `P_tri` is nontrivial, the wrapper

```text
triangular_recovery_perfect_residual_audit(
    interval, n, beta, residual_endpoint,
)
```

specializes `unit_perfect_residual_longitude_audit(...)` to the same
triangular recovery observer.  It checks whether the terminal residual
endpoint lies in

```text
V_beta(P_tri).
```

If it does, the derived-stage witnesses plus the perfect-residual witness
close the endpoint in `V_beta(U_tri)`.

If instead the Artin permutation is the identity, `V_beta(P_tri)` is trivial,
and a nonidentity endpoint remains in `P_tri`, then the finite audit has found
the exact nonsolvable seed needed for the B-route.  It is still not
`[Resolution: B]`: the seed must be upgraded to an all-prefix normalized-law
sequence that is invisible to every finite group while moving an explicit
residual tuple.

## Current remaining obstruction

[Open] After this refinement, the triangular recovery obstruction is:

```text
a local-minimal bi-free universal-corridor interval whose fixed finite
triangular recovery unit group U_tri has an endpoint composite for which no
uniform certificate has been supplied by:

  1. active Artin detector-lift rows;
  2. an explicit endpoint-longitude expression;
  3. derived-series quotient lifts plus a P_tri witness; or
  4. a normalized-law sequence upgrading a P_tri finite detector miss.
```

To prove `[Resolution: A]`, supply one of the first three certificates
uniformly for every remaining interval.

To prove `[Resolution: B]`, construct an explicit remaining interval and turn
a stable perfect-residual finite miss into the required normalized-law
sequence.
