# Finite semigroup holonomy route

## Purpose

This note records a small symbolic narrowing lemma for the Green/corridor
route.  It does not prove the master local-minimal residual theorem.  It says
where a possible residual obstruction must live: any residual motion that is a
permutation on a finite fibre block must be visible in a finite group
component of the relevant transition semigroup.  A purely aperiodic reset
component cannot be the final source of a nontrivial residual braid action.

## Aperiodic permutation lemma

Let `M` be a finite transformation monoid on a finite set `S`.  Call an
element `m in M` aperiodic if `m^N=m^(N+1)` for some `N>=0`; call `M`
aperiodic if every element is aperiodic.

Lemma.  If `M` is aperiodic, then every permutation element of `M` is the
identity permutation of `S`.

Proof.  Let `p in M` be a permutation.  Since `M` is aperiodic, choose
`N>=0` with `p^N=p^(N+1)`.  Compose on the left by `p^{-N}` inside the
permutation group generated by `p`.  This gives `id=p`.  Therefore no
nonidentity permutation can lie in an aperiodic finite transformation monoid.

Equivalently, if a finite transition monoid contains a nontrivial permutation
of a fibre block, then the cyclic subsemigroup generated by that element has
a nontrivial group period.  The obstruction is group holonomy, not pure
aperiodic collapse.

The permutation elements of a finite transformation monoid form a finite
group.  Closure is inherited from the monoid, and if `p` is a permutation
element then a positive power of `p` is the identity permutation, so the
inverse `p^{-1}` is another positive power of `p` and lies in the same
monoid.  This group is the concrete "unit" part extracted by the executable
helper `monoid_permutation_group()`.

The companion note `proofs/unit_holonomy_longitude_gate.md` connects this unit
part to the Artin-longitude detector.  For a finite transition monoid `M`, the
unit group `U(M)` is a valid fixed finite detector factor.  If every
group-like residual label lies in the subgroup generated by all values of the
recursive Artin longitudes in `U(M)`, then identity finite-`U(M)` longitude
data kills those labels.  Nonunit reset labels cannot be the residual
permutation part.

The stronger factorization gate is recorded in
`proofs/unit_factorization_gate.md`: a product of total maps of a finite set is
a permutation only if every factor is a permutation.  Therefore a branch word
containing a nonunit/reset label cannot later become the residual permutation
moved by a braid.  The actual B obstruction must already be visible in unit
or group-like holonomy.

## Relevance to the local theorem

The residual maps `delta_{n,z}(beta)` are permutations of the finite fibres
`X_z`.  Suppose a local branch has been represented by finite transition
monoids built from context maps, Green edge germs, or corridor transports.
If all group holonomy factors in those monoids are killed by finite-group
Artin-longitude data, the remaining aperiodic part cannot still induce a
nontrivial residual permutation.  Thus the A-route can focus on proving that
all recurrent branch choices factor through fixed finite holonomy groups
attached to the interval, such as:

- full symmetric groups on the Green kernel-block quotients;
- left and right Schutzenberger groups of regular Green classes;
- finite product-label groups in product-permutation branches;
- known affine, cyclic, semidirect, coboundary, or pairwise-linking factors.

After these group coordinates are killed, any residual transition that lies
only in the aperiodic radical must act trivially on each fibre block because
the residual action is a permutation.

## What remains open

The missing master-theorem assertion is the all-`n` factorization step:
for every local-minimal interval, prove that the residual braid action on
each fibre block decomposes into the fixed finite holonomy groups above plus
aperiodic transition data.  The fixed groups must depend only on the interval
and the quotient detector `Q`, not on the braid index.

If this factorization is proved, the aperiodic lemma prevents any purely
reset-like hidden motion after finite-G longitude data kills the holonomy
groups.  The detector group is then the direct product of the fixed holonomy
groups.

If outcome B is true instead, the counterexample cannot be a branch whose
residual motion is purely aperiodic.  It must produce moving group holonomy
escaping every fixed finite detector group, for example through an
orbit-local normalized-law sequence as in
`proofs/structure_orbit_law_obstruction.md` or through nontrivial closed
product labels as in `proofs/product_closed_label_obstruction.md`.

## Executable guardrail

The helper module `src/ybe_domination/semigroup_holonomy.py` implements:

- powers of finite transformations;
- cyclic aperiodicity checks;
- finite-monoid aperiodicity checks;
- extraction of permutation elements;
- extraction of the finite permutation group of a transformation monoid;
- a unit-factorization audit excluding nonunit factors from permutation
  composites;
- a unit-longitude subgroup audit for proposed group-like labels;
- an audit recording nonidentity permutation elements.

The tests in `tests/test_semigroup_holonomy.py` verify the intended
guardrail examples: a reset map is aperiodic, a nontrivial swap is not, an
aperiodic reset monoid has only the identity permutation, and a group
component exposes its nonidentity permutation subgroup.

The companion Green helper
`bounded_atom_trivial_loop_group_summaries()` applies the same distinction to
bounded completed-context corridors.  It ignores atom-trivial loops that are
not total bijections of the finite context word set, and extracts the finite
permutation group generated by the group-like loops.  This is a diagnostic
implementation of the slogan above: reset-like context collapse is not a
residual obstruction unless it produces nontrivial group holonomy.
