# Point-pushing recursive conjugacy

Date: 2026-05-30

This note strengthens the suffix-shuttle normal form.  It shows that the
marked point-pushing generators are not independent: every generator is a
suffix shift of the first one, and the first one satisfies a one-step
conjugacy recursion.

This does not prove outcome A or B.  It reduces the bounded-`mu` problem to
one recursively defined finite-state family.

## Statement

For a finite bijective YBE solution `X`, write

```text
s_i^{(n)} = rho_{X,n}(sigma_i)
```

and

```text
a_n = rho_{X,n}(A_{1,n}) in Sym(X^n).
```

Here

```text
A_{1,n}=sigma_{n-1} ... sigma_2 sigma_1^2 sigma_2^{-1} ... sigma_{n-1}^{-1}.
```

Then:

1. Base case:

   ```text
   a_2 = (s_1^{(2)})^2.
   ```

2. Recursive conjugacy, for `n>=3`:

   ```text
   a_n
   =
   s_{n-1}^{(n)}
   (a_{n-1} x id_X)
   (s_{n-1}^{(n)})^{-1}.
   ```

   Here `a_{n-1} x id_X` acts on the first `n-1` coordinates and leaves the
   last coordinate fixed.

3. Suffix-shift formula: for every `1<=i<n`,

   ```text
   rho_{X,n}(A_{i,n})
   =
   id_{X^{i-1}} x a_{n-i+1}.
   ```

## Proof

The base case is immediate from

```text
A_{1,2}=sigma_1^2.
```

For `n>=3`, compare the standard pure braid words:

```text
A_{1,n}
=
sigma_{n-1} sigma_{n-2} ... sigma_2 sigma_1^2
sigma_2^{-1} ... sigma_{n-2}^{-1} sigma_{n-1}^{-1}
```

and

```text
A_{1,n-1}
=
sigma_{n-2} ... sigma_2 sigma_1^2
sigma_2^{-1} ... sigma_{n-2}^{-1}.
```

Thus, inside `B_n`,

```text
A_{1,n}=sigma_{n-1} A_{1,n-1} sigma_{n-1}^{-1},
```

where `A_{1,n-1}` is inserted on the first `n-1` strands.  Applying the YBE
braid representation gives the recursive conjugacy formula.

For the suffix-shift formula, relabel the suffix strands

```text
i,i+1,...,n
```

as

```text
1,2,...,n-i+1.
```

The word

```text
A_{i,n}
=
sigma_{n-1} ... sigma_{i+1} sigma_i^2
sigma_{i+1}^{-1} ... sigma_{n-1}^{-1}
```

is exactly the shifted copy of `A_{1,n-i+1}` on this suffix, and it does not
touch the first `i-1` strands.  Applying the braid action gives

```text
rho_{X,n}(A_{i,n})
=
id_{X^{i-1}} x a_{n-i+1}.
```

QED.

## Consequence For The Point-Pushing Image

For `k>=1`, with `n=k+1`,

```text
P_k(X)=<rho(A_{1,n}),...,rho(A_{k,n})>
```

is generated by the suffix shifts

```text
a_{k+1},
id_X x a_k,
id_{X^2} x a_{k-1},
...,
id_{X^{k-1}} x a_2.
```

Thus all of the marked groups `P_k(X)` come from the single recursive family
`(a_n)_{n>=2}`.

## Consequence For The Mu Problem

The exact remaining problem from
`proofs/point_pushing_mu_boundedness_dichotomy.md` can be restated as:

```text
Is the marked group generated by the suffix shifts of the recursive family
a_n detected by D_k(S_m) for one m=m(X), uniformly in k?
```

A B obstruction must now exhibit unbounded `mu` growth in the suffix-shift
group generated by this recursive conjugacy family.  It cannot require
independent arbitrary generators at each arity.

## Audit Hook

The helper

```text
point_pushing_recursive_conjugacy_audit(...)
```

checks, for one finite braid index `n`, that:

- `a_n` agrees with the recursive conjugacy formula;
- every `A_{i,n}` action agrees with the suffix shift of `a_{n-i+1}`.

It is a convention guard and finite diagnostic; the proof above is symbolic.
