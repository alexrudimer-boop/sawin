# Abelian Contextual Separability Test

This note extracts the first computable layer of the contextual augmented
action obstruction.  If a color-changing contextual transition survives all
finite contextual augmented quotients, then it must already be invisible to
the abelianized contextual Wirtinger group and to the abelianized loop-coset
test.

## Contextual Wirtinger Abelianization

Let `hat P` denote the raw contextual states used in the contextual augmented
action.  The contextual Wirtinger group is

```text
G_X=< g_p, p in hat P |
      g_p=g_{p'} for same-strand equalities,
      g_r=g_p g_q g_p^{-1} for every forced product p*q=r >.
```

Its abelianization

```text
G_X^ab=H_1(G_X;Z)
```

is the finitely generated abelian group with generators

```text
[p]        p in hat P
```

and relations

```text
[p]=[p']        for same-strand equalities,
[r]=[q]         for every forced compatible product p*q=r.
```

Indeed, the forced rack relation

```text
g_r=g_p g_q g_p^{-1}
```

becomes `[r]=[q]` after abelianization.  Thus `G_X^ab` is computed by finite
integer linear algebra.

## Abelian Operator Separation

Let `p,p' in hat P`.  If

```text
[g_p] != [g_{p'}] in G_X^ab,
```

then `p` and `p'` are separated by a finite contextual augmented rack.

### Proof

The difference `[g_p]-[g_{p'}]` is nonzero in the finitely generated abelian
group `G_X^ab`.  Finitely generated abelian groups are residually finite, so
there is a finite abelian quotient

```text
pi:G_X->A
```

such that

```text
pi(g_p) != pi(g_{p'}).
```

In the induced finite augmented quotient rack, the operator coordinates of the
two contextual states are different.  Hence the corresponding augmented colors
are separated.

Therefore no transition surviving all finite contextual augmented quotients
can have distinct abelian operator classes.

## Abelian Transporter Separation

Now suppose `p,p'` lie in the same component of the contextual action graph
`C_X`.  Let

```text
v=[p],        w=[p']
```

be their vertices after same-strand quotienting.  Choose a path

```text
ell:v->w
```

with label

```text
tau=lab(ell) in G_X.
```

Let

```text
Lambda_v <= G_X
```

be the loop subgroup at `v`, generated by labels of closed loops based at
`v`.  Let

```text
Lambda_v^ab
```

be the image of `Lambda_v` in `G_X^ab`.

If

```text
[tau] notin Lambda_v^ab,
```

then `p` and `p'` are separated by a finite contextual augmented rack.

### Proof

The quotient

```text
G_X^ab/Lambda_v^ab
```

is finitely generated abelian.  Since `[tau]` is nonzero in this quotient, it
survives in some finite abelian quotient `A`.  Equivalently, there is a finite
quotient

```text
pi:G_X->A
```

such that

```text
pi(tau) notin pi(Lambda_v).
```

In the induced finite action quotient, the vertices `v` and `w` are identified
iff some loop at `v` has the same image as the path from `v` to `w`, i.e. iff

```text
pi(tau) in pi(Lambda_v).
```

This condition fails, so the induced finite action separates the contextual
positions over `v` and `w`.  Hence the augmented colors are separated.

If `p` and `p'` lie in different connected components of `C_X`, they are
already separated at the finite action-graph level.

## Abelian Contextual Separability Criterion

Consider a color-changing pair

```text
p=(A,a,B),        p'=(A',b,B'),        a != b,
```

with the relevant congruence relation `a E b` in the surrounding obstruction
argument.

A finite abelian contextual quotient separates `p` and `p'` if at least one of
the following holds:

```text
[g_p] != [g_{p'}] in G_X^ab;
```

or `p,p'` lie in different connected components of `C_X`;

or, for a path label `tau:p->p'`,

```text
[tau] notin im(Lambda_p->G_X^ab).
```

Therefore, any fixed contextual transition surviving every finite contextual
augmented quotient must satisfy both abelian tests:

```text
[g_p]=[g_{p'}] in G_X^ab,
```

and, whenever a transporter path `tau` is chosen,

```text
[tau] in im(Lambda_p->G_X^ab).
```

## Consequence

The profinite obstruction, if present, is not visible in

```text
H_1(G_X;Z)
```

and is not visible in the abelianized loop-coset test.  Any genuine contextual
separability failure must be nonabelian:

```text
tau in closure_prof(Lambda_p) \ Lambda_p,
```

while already satisfying

```text
[tau] in Lambda_p^ab.
```

Thus the next positive target is subgroup separability for the YBE-origin loop
subgroups after the abelian obstruction vanishes.  The matching negative
target is a finite `X` for which `G_X` has a genuinely nonabelian nonseparable
loop subgroup, with the nonseparable transporter corresponding to a
color-changing contextual transition realized by cofinal quotient-trivial
Brunnian motions.
