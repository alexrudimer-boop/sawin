# Universal Hurwitz Rack Obstruction

Date: 2026-06-05

This note records the sharpened endpoint for product-Hurwitz separability.  The
product-Hurwitz theorem is valid, but the residual-core separability claim is
not proved.  It is exactly a finite separation hypothesis for universal
Hurwitz racks.

## Product-Hurwitz theorem status

Use the right-rack convention

```text
r_Y(a,b)=(b,a triangleright b).
```

For

```text
r_X(x,y)=(u,v)=(L_x(y),R_y(x)),
```

the YBE product identities are

```text
L_u L_v = L_x L_y,
R_v R_u = R_y R_x.
```

The left product-Hurwitz labels are maps

```text
c_t:X -> Y      (t in S_L^1)
```

satisfying

```text
c_{L_v t}(u) = c_t(y),                                      (LH1)
c_t(v) = c_{L_y t}(x) triangleright c_t(y).                 (LH2)
```

For suffix products

```text
s_{n+1}=1,
s_i=L_{x_i}s_{i+1},
```

the label word

```text
C_n(x_1,...,x_n)=
    (c_{s_2}(x_1), c_{s_3}(x_2), ..., c_{s_{n+1}}(x_n))
```

is `B_n`-equivariant.  If

```text
(C_n, Lambda_n, J_n)
```

is injective for all `n`, with `Lambda_n` and `J_n` inert, then

```text
ker rho_n^Y <= ker rho_n^X
```

for all `n`.

The right product version, with prefix products in `S_R^1`, is dual.

## Singular padding no-go theorem

Let `Z` be any finite bijective YBE solution.  Let `E` be a finite identity
solution with `|E|>=2`:

```text
r_E(e,f)=(e,f).
```

Then

```text
L_e^E(f)=e,
R_f^E(e)=f,
```

so all coordinate maps of `E` are singular.  For

```text
X=E x Z
```

with product solution

```text
r_X((e,z),(f,w))=((e,L_z^Z(w)),(f,R_w^Z(z))),
```

the solution `X` is everywhere singular and

```text
rho_n^X = id_{E^n} x rho_n^Z,
ker rho_n^X = ker rho_n^Z
```

for every `n`.

Thus the class of everywhere-singular solutions with nonconstant product
observers is kernel-universal for all finite bijective YBE solutions.  Product
observers alone do not form a smaller branch of Sawin's problem.

## Universal left Hurwitz rack

Define `U_L(X)` to be the rack generated by symbols

```text
[t,x]      (t in S_L^1, x in X)
```

subject to the relations, for all `x,y,t`, with

```text
u=L_x(y),  v=R_y(x),
```

```text
[L_v t,u] = [t,y],                                          (UL1)
[t,v] = [L_y t,x] triangleright [t,y].                      (UL2)
```

Every left product-Hurwitz labelling `c_t:X -> Y` into a rack `Y` is exactly a
rack homomorphism

```text
phi:U_L(X) -> Y
```

with

```text
c_t(x)=phi([t,x]).
```

Similarly, define `U_R(X)` with generators

```text
[p,x]      (p in S_R^1, x in X)
```

and relations

```text
[p,u] = [R_x p,y],                                         (UR1)
[R_u p,v] = [p,x] triangleright [R_x p,y].                 (UR2)
```

Product-Hurwitz separability is therefore equivalent to the existence of a
finite quotient of either `U_L(X)` or `U_R(X)` whose induced label code is
injective after adjoining the allowed inert observers.

## Graph obstruction before the rack operation

There is a finite obstruction visible from `(LH1)` alone.  Let `H_L(X)` be the
graph with vertex set

```text
S_L^1 x X
```

and edges

```text
(t,y) ~ (L_{R_y(x)} t, L_x(y))
```

for all `x,y,t`.  Relation `(LH1)` forces `c_t(y)` to be constant on connected
components of `H_L(X)`.

Dually, let `H_R(X)` have vertex set `S_R^1 x X` and edges

```text
(p,L_x(y)) ~ (R_x p,y).
```

If `H_L(X)` is connected, every left product-Hurwitz labelling is constant.  If
`H_R(X)` is connected, every right product-Hurwitz labelling is constant.

Therefore, if both graphs are connected and `X` has a nontrivial two-strand
braid orbit, neither left nor right product-Hurwitz separability can hold.  In
that case all inert observers are constant on the two-strand orbit, and the
universal Hurwitz labels cannot distinguish the two words.

This is finite and directly checkable.

## Corrected endpoint

The residual-core statement should not be recorded as a theorem.  The exact
missing lemma is:

> For every finite residual rigid core outside the known positive branches,
> either `U_L(X)` or `U_R(X)` has a finite quotient `Y` such that the induced
> product-Hurwitz code is injective on every braid orbit in every arity.

If orbit observers are allowed, this is precisely orbit-wise injectivity of the
universal Hurwitz code.  It remains a finite residual separation hypothesis,
not a consequence of product identities, product semigroups, or minimal-ideal
local groups alone.

## Relation to escape-rack separation

The minimal-ideal escape-rack construction is generally two-sided: its strand
label depends on data of the form

```text
eta(x;A,B)
```

with both left and right minimal-ideal objects `A,B`.  Product-Hurwitz labels
are one-sided, depending only on `(t,x)` or `(p,x)`.

Thus the two routes are not equivalent.  Escape-rack labels compress to
product-Hurwitz labels only under a one-sided determinacy condition: the
escape label must be determined, up to the escape quotient, by the one-sided
prefix or suffix state and the current symbol.

Product-Hurwitz separability implies strand separation for its own rack `Y`,
because inside a braid orbit the inert observers are constant, so the rack
label word must separate.  It does not automatically imply separation for the
specific minimal-ideal escape rack unless `Y` is realized as its quotient or
factor.
