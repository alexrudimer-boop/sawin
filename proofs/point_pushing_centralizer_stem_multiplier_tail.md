# Point-Pushing Centralizer-Stem Multiplier Tail

Date: 2026-05-30

This note refines the stem side of
`proofs/point_pushing_centralizer_layer_commutator_split.md`.

It does not prove outcome A or B.  It identifies the centralizer-stem
generator branch as a bounded-generator stem multiplier quotient inside the
normal closure of the newest point-pushing generator.

## Setup

Let a noncentral abelian-chief first-failure quotient have elementary-abelian
monolith

```text
M ~= F_p^r
```

and let `t` be the image of the newest point-pushing generator.  The bounded
normal-generator theorem gives

```text
ord(t) | B_X,
M <= <<t>>_H.
```

Assume we are in the centralizer-stem branch of
`proofs/point_pushing_centralizer_layer_commutator_split.md`.  Thus, with

```text
N = <<t>>_H,
```

we have

```text
N <= C_H(M),
M <= Z(N) cap [N,N].
```

## Theorem

The centralizer-stem branch is a stem central extension

```text
1 -> M -> N -> Q -> 1,
Q = N/M,
M <= Z(N) cap [N,N].
```

Consequently the moved module layer is a quotient of the Schur multiplier of
`Q`.  In presentation form, for a free presentation

```text
F -> Q,
K = ker(F -> Q),
```

the kernel `M` is a quotient of

```text
(K cap [F,F])/[F,K].
```

Moreover the quotient `Q` is normally generated, under the ambient `H`-action,
by the image of the bounded-order element `t`, whose order divides `B_X`.

## Proof

The displayed inclusions already give a central extension:

```text
1 -> M -> N -> N/M -> 1.
```

Since `M<=Z(N)`, the kernel is central.  Since `M<=[N,N]`, the central
extension is stem.

Every stem central extension of a finite group `Q` is obtained as a quotient
of a Schur cover.  Equivalently, using any free presentation `F->Q` with
kernel `K`, the Hopf formula identifies

```text
H_2(Q,Z) ~= (K cap [F,F])/[F,K],
```

and the central stem kernel is a quotient of this multiplier group.
Taking `Q=N/M` gives the claimed multiplier quotient.

Finally, by definition `N=<<t>>_H`, so the image of `t` normally generates
`Q=N/M` under the same ambient conjugation action.  The bounded
normal-generator theorem gives `ord(t)|B_X`, and the order of the image of
`t` in `Q` divides `ord(t)`.  QED.

## Consequence For The Fork

The centralizer-stem generator branch is no longer an arbitrary nonabelian
centralizer layer.  It is a bounded-generator stem multiplier tail:

```text
finite quotient Q=N/M,
M a quotient of H_2(Q,Z),
Q ambient-normally generated by a bounded-order image of t.
```

Together with
`proofs/point_pushing_abelian_centralizer_layer_prime_bound.md`, the
centralizer-layer generator branch has two exact residual forms:

1. a bounded-prime, bounded-exponent abelian centralizer layer;
2. a bounded-generator centralizer-stem multiplier layer.

Both remain open as possible infinite tails; neither is a complete
counterexample without an explicit product-prefix Brunnian family.

The follow-up
`proofs/point_pushing_centralizer_stem_noncyclic_quotient.md` removes the
cyclic quotient subcase: if `N/M` were cyclic, centrality of `M` would make
`N` abelian, contradicting `M<=[N,N]`.
The follow-up `proofs/point_pushing_centralizer_stem_transport_split.md`
then splits the noncyclic quotient by whether the bounded generator image
normally generates `N/M` internally or requires ambient transport conjugates.
