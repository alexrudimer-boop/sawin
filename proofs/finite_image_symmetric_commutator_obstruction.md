# Finite-Image Symmetric-Commutator Obstruction

Date: 2026-06-06

This note sharpens the ordinary Brunnian boundary into a finite-image
criterion.  After a transparent rack detector is fixed, the remaining
obstruction is the all-meridian symmetric commutator in the finite combined
image of the last-strand free group.

This is still a C-type result.  It does not prove Sawin's statement for all
finite degenerate solutions and does not construct a no-rack counterexample.

Update.  The subsequent note
`proofs/chief_factor_finite_image_obstruction.md` refines this finite-image
criterion further: since the combined image lies in
`Sym(Q^n) x Sym(X^n)`, the two projection kernels intersect trivially, and
the remaining obstruction can be analyzed by chief factors inside the
detector-invisible kernel.

## Setup

Let `X` be a finite bijective YBE solution.  Let `Y` be a finite rack and set

```text
Q = Y^0 x T_2.
```

For `n>=2`, let

```text
F_{n-1} = ker(d_n:P_n -> P_{n-1})
```

be the last-strand Fadell-Neuwirth kernel, freely generated by

```text
x_i = A_{in},        1 <= i <= n-1.
```

Let

```text
Phi_n:F_{n-1} -> Gamma_n <= Sym(Q^n) x Sym(X^n)
```

be the combined finite image

```text
Phi_n(beta) = (rho^Q_n(beta), rho^X_n(beta)).
```

Write `p_Q` and `p_X` for the two projections from `Gamma_n`, and set

```text
K_n = ker p_Q,
L_n = ker p_X.
```

For `1<=i<=n-1`, define

```text
N_{i,n} = << Phi_n(x_i) >>_{Gamma_n}.
```

For normal subgroups `N_1,...,N_r` of a group `G`, write

```text
[N_1,...,N_r]_Sigma
```

for the symmetric commutator subgroup generated by all fully parenthesized
iterated commutators with one input from each `N_i`, in arbitrary order.

## Theorem

With the notation above,

```text
Phi_n(Brun_n cap ker rho^Q_n)
 =
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma.
```

Consequently, by the ordinary Brunnian reduction, `Q` dominates `X` if and
only if

```text
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma <= L_n
```

for every `n>=2`.

## Proof

Inside

```text
F_{n-1}=<x_1,...,x_{n-1}>,
```

deleting the `i`-th non-last strand kills `x_i` and relabels the other free
generators.  Thus the ordinary Brunnian subgroup inside `F_{n-1}` is

```text
Brun_n = intersection_i R_i,
R_i = <<x_i>>_{F_{n-1}}.
```

The projection-kernel symmetric commutator theorem for free groups gives

```text
intersection_i R_i = [R_1,...,R_{n-1}]_Sigma.
```

This is the standard theorem for projection maps from a free group obtained
by killing basis elements; it is recorded, for example, as Lemma 5.1 in
Bardakov-Mikhailov-Vershinin-Wu's work on Brunnian braids on surfaces.

The map `Phi_n:F_{n-1}->Gamma_n` is surjective onto its image.  Therefore

```text
Phi_n(R_i)=<<Phi_n(x_i)>>_{Gamma_n}=N_{i,n}
```

and hence

```text
Phi_n(Brun_n)
 =
Phi_n([R_1,...,R_{n-1}]_Sigma)
 =
[N_{1,n},...,N_{n-1,n}]_Sigma.
```

Finally, `ker rho^Q_n` is the preimage of `K_n` under `Phi_n`, so

```text
Phi_n(Brun_n cap ker rho^Q_n)
 =
Phi_n(Brun_n) cap K_n
 =
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma.
```

An element of `Gamma_n` is `X`-invisible exactly when it lies in `L_n`.  This
proves the domination criterion.

## Relative Lower-Central Criterion

Suppose that, for the fixed detector `Q=Y^0 x T_2`, there is a constant `c`
such that for every `n>c+1`,

```text
K_n cap gamma_{c+1}(Gamma_n) <= L_n.
```

Then `X` is dominated by one finite rack.

Indeed,

```text
[N_{1,n},...,N_{n-1,n}]_Sigma
  <= gamma_{n-1}(Gamma_n)
  <= gamma_{c+1}(Gamma_n)
```

for `n>c+1`.  Hence all large-arity `Q`-invisible ordinary Brunnian elements
are `X`-invisible.  Fixed-arity rack cofinality supplies finite racks handling
the finitely many arities `2<=n<=c+1`.  If their product is `Z`, then

```text
(Y x Z)^0 x T_2
```

dominates `X`.

This criterion is weaker than requiring the whole group
`rho^X_n(F_{n-1})` to have uniformly bounded nilpotence class: it only
requires the part invisible to the chosen rack detector to have no deep
lower-central contribution visible in `X`.

## Redundant-Meridian Criterion

With the same notation, suppose that for all sufficiently large `n`, in

```text
Gamma_n / L_n
```

one of the images of the subgroups `N_{i,n}` centralizes the subgroup generated
by all the other images.  Then, after adding finitely many fixed-arity rack
detectors, a finite enlargement of `Q` dominates `X`.

Reason: every generator of the symmetric commutator subgroup uses every
`N_{i,n}`.  If one meridian normal closure centralizes all the others modulo
`L_n`, then every all-meridian symmetric commutator is trivial modulo `L_n`.
Thus

```text
[N_{1,n},...,N_{n-1,n}]_Sigma <= L_n
```

in all sufficiently large arities, and the remaining finitely many arities are
handled by fixed-arity rack cofinality.

## Remaining Boundary

For a positive solution from this boundary, it is enough to prove that for
every finite bijective degenerate solution `X` there exists one finite rack
`Y` such that, with `Q=Y^0 x T_2`,

```text
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma <= L_n
```

for every `n`.

For a negative solution, one must construct an explicit finite degenerate `X`
such that for every finite rack prefix `P_m`, with `Q_m=P_m^0 x T_2`, there
are unbounded arities `n_m` for which

```text
K_{n_m} cap [N_{1,n_m},...,N_{n_m-1,n_m}]_Sigma
  not <= L_{n_m}.
```

Thus the remaining obstruction is a genuinely all-meridian symmetric
commutator in a finite combined image, surviving after every finite rack
prefix has been added.
