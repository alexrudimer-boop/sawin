# Continuation congruence descent gate

Date: 2026-05-29

This note follows `proofs/transport_state_rackification_detector.md`.  It
does not prove the Master Local-Minimal Residual Theorem.  It turns the
remaining descent-separation question into an explicit finite
local-minimality dichotomy.

Transport-state rackification closes every strand-continuing lower row.  The
only remaining danger is lower motion that changes the state carried by the
continuing strand without being visible in the Green/Schutzenberger readout.
The continuation congruence records exactly the finite congruence generated
by those changes.
The final target note
`proofs/descent_separation_transport_rack_closure.md` packages the resulting
make-or-break theorem: universal continuation must be visible in the fixed
Green/Schutzenberger/atom readouts, or it must seed the normalized-law B
route.

## Setup

Work after the atom quotient is in left rack convention:

```text
R_A(a,b) = (a*b, a).
```

For a local interval over this rack base, write

```text
T_{a,b}(x,y) = (u,v),
```

where `x` lies over `a`, `y` lies over `b`, `u` lies over `a*b`, and `v` lies
over `a`.  The row is strand-continuing at `(a,b,x,y)` exactly when

```text
v = x.
```

## Continuation seed relation

For each colour `a`, define a seed relation on its fibre by adding

```text
x ~ v
```

for every row `T_{a,b}(x,y)=(u,v)` with `v != x`.  Let

```text
Theta^cont
```

be the least admissible local congruence family containing all these seed
pairs, computed by transporting product relations through every local table
and inverse local table.

The executable helper is:

```text
continuation_congruence_audit(interval)
```

It records:

- the individual continuation seeds;
- any base rows that are not in left rack form and therefore are not yet in
  the transport-state setting;
- the generated admissible family `Theta^cont`;
- whether the closure is equality, universal, or a proper mixed family.

## Dichotomy

If `Theta^cont` is equality, then no nontrivial seed exists.  Thus every row
is strand-continuing on the nose, and
`proofs/transport_state_rackification_detector.md` applies directly.

If the interval is local-minimal and `Theta^cont` is non-equality, then
local-minimality forces

```text
Theta^cont = universal.
```

Indeed, `Theta^cont` is admissible by construction.  In a local-minimal
interval, every admissible congruence family is either all equality or all
universal.  Since a nontrivial continuation seed rules out equality, only the
universal family can remain.

If `Theta^cont` is proper mixed, then the row is not a valid local-minimal
target interval.  The interval must be refined along this congruence before
the Master Local-Minimal Residual Theorem can be invoked.

## Consequence for descent separation

The descent-separation burden is now sharper.

1. `Theta^cont = equality`: the lower part is strand-continuing and is killed
   by the transport-state rack detector `Inn(A x E)`.
2. `Theta^cont = proper mixed`: the interval is not local-minimal, so it is
   not a legitimate final local obstruction.
3. `Theta^cont = universal`: all hidden continuation changes generate the
   all-universal admissible corridor.  A positive proof must show this
   universal continuation corridor is exactly the Green/Schutzenberger-visible
   motion already included in the fixed detector product.  A negative proof
   must extract from this universal corridor a normalized-law sequence
   invisible to every finite group while moving an explicit residual tuple.

Thus the remaining make-or-break statement is no longer arbitrary descent
separation.  It is the universal-continuation case:

```text
Universal continuation visibility.
In every local-minimal bi-free corridor interval with
Theta^cont = universal, the resulting continuation motion is fully visible in
the fixed Green kernel-block and Schutzenberger readouts, or else it yields the
normalized-law obstruction required for outcome B.
```

## Executable audit hooks

The code records this gate through:

```text
continuation_seed_rows(...)
continuation_seed_pairs(...)
continuation_congruence_audit(...)
```

These helpers reuse the existing exact generated-congruence engine, so the
closure is not a bounded search artifact.  It is the least admissible
congruence family generated by the continuation-change pairs.

The follow-up note `proofs/elementary_continuation_closure.md` adds the
single-seed version:

```text
continuation_seed_pair_closure_audits(...)
continuation_seed_pair_closure_failures(...)
```

In a local-minimal target, every nontrivial continuation seed pair must close
to the universal family by itself.  Thus universal continuation is an
elementary seed problem, not a collective-only phenomenon.
