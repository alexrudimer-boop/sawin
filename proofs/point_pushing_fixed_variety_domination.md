# Point-pushing fixed-variety domination criterion

Date: 2026-05-30

This note follows `proofs/sawin_last_strand_law_reduction.md` and
`proofs/point_pushing_action_image_variety.md`.  It does not prove outcome A
or B.  It records the fixed-variety reformulation that was later demoted to a
superseded guardrail after the last-strand law gap was found.

**Superseded guardrail.**  The equivalence below depends on the false forward
implication `w in Law_k(G) => iota_{k+1}(w) in K_G(k+1)`.  The counterexample
is recorded in `proofs/last_strand_law_gap_audit.md`.  This file is retained
as a necessary-condition/search heuristic, not as an established equivalent
form of Sawin domination.

## Setup

Let `X` be a finite bijective set-theoretic YBE solution.  For `k>=1`, set
`n=k+1` and define the marked point-pushing action image

```text
P_k(X) =
< rho_{X,n}(A_{1,n}), ..., rho_{X,n}(A_{k,n}) >
<= Sym(X^n).
```

For a finite group `G`, let `var(G)` denote the group variety generated by
`G`, equivalently the finite groups satisfying every word law of `G`.

## Superseded Criterion

The tempting criterion was the following equivalence for a fixed finite group
`G`.

1. The sharp detector rack `A_G` dominates `X`:

   ```text
   K_G(n) subset ker rho_{X,n}
   ```

   for every braid index `n`.

2. Every point-pushing action image lies in the fixed variety generated by
   `G`:

   ```text
   P_k(X) in var(G)
   ```

   for every `k>=1`.

The counterexample in `proofs/last_strand_law_gap_audit.md` shows that this
is not an established equivalence.  The proof of `(1) => (2)` used the false
implication

```text
w in Law_k(G)  =>  iota_{k+1}(w) in K_G(k+1).
```

Ordinary laws do not control the stationary-strand Artin derivative
longitudes of the point-pushed braid.

## Valid Remaining Use

Fixed-variety containment is still a sufficient positive route.  If

```text
P_k(X) in var(G) for every k>=1,
```

then every actual point-pushing layer in `K_G` acts trivially: the repaired
kernel-layer criterion gives a moving layer `iota_r(w) in K_G(r)` if
domination fails, and `proofs/sawin_last_strand_law_reduction.md` gives the
necessary condition

```text
w in Law_{r-1}(G).
```

Since `P_{r-1}(X) in var(G)`, this law evaluates trivially on the marked
point-pushing action image, contradicting movement.

The converse is not known.  A fixed-variety escape

```text
P_k(X) notin var(G)
```

is only a source of candidate point-pushing movers.  To become a B proof, the
corresponding point-pushed word must also be proved to lie in the actual
finite-longitude kernel `K_G`.
