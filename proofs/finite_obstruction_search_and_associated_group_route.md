## Contextual Endpoint Rack Presentation

Let:

```text
X={0,...,m-1},
r(x,y)=(L_x(y),R_y(x)).
```

The structure monoid is:

```text
L_X=< ell_x | ell_x ell_y = ell_{L_x(y)} ell_{R_y(x)} >.
```

For a finite quotient `phi:L_X->M`, write:

```text
bar{x}=phi(ell_x).
```

For `a=(a_1,...,a_n)`, define:

```text
p_i^M(a)=bar{a_1}...bar{a_{i-1}},
s_i^M(a)=bar{a_{i+1}}...bar{a_n},

epsilon_i^M(a)=[p_i^M(a),a_i,s_i^M(a)].
```

The contextual endpoint rack `C_M(X)` has generators:

```text
[p,x,s], p,s in M, x in X,
```

and for every `p,s in M`, `x,y in X`, with

```text
(x',y')=r(x,y)=(L_x(y),R_y(x)),
```

relations:

```text
(T) [p,x,bar{y}s]=[p bar{x'},y',s],

(R) [p,x,bar{y}s] triangleright [p bar{x},y,s]
    =
    [p,x',bar{y'}s].
```

This is finite when `M` is finite.  It has:

```text
|M|^2 |X| generators,
2 |M|^2 |X|^2 endpoint relations.
```

Finite rack quotients of `C_M(X)` are exactly finite endpoint detectors:
a map from generators to a finite rack `Q` extends to a rack homomorphism iff
it satisfies `(T)` and `(R)`.

## Universal Rack Shadow Computation

A partition `theta` of `X` is rack-admissible if:

```text
R_y(x) equiv_theta x for all x,y,

x equiv_theta x' and y equiv_theta y'
imply
L_x(y) equiv_theta L_{x'}(y'),

[x] triangleright [y]=[L_x(y)]
is a rack operation.
```

The universal finite rack shadow is:

```text

theta_* = intersection of all rack-admissible partitions.
```

Since `X` is finite, this is computable by enumerating partitions.

## Associated-Group Separation

For a rack `R`, define:

```text
As(R)=< g_x (x in R) | g_{x triangleright y}=g_x g_y g_x^{-1} >.
```

There is a canonical rack morphism:

```text
eta_R:R -> Conj(As(R)),
x -> g_x.
```

Lemma: associated-group separation implies finite rack separation.

Let `e,e' in R`.  Suppose:

```text
eta_R(e) != eta_R(e') in As(R),
```

and there is a finite group quotient:

```text
psi:As(R)->G
```

with:

```text
psi eta_R(e) != psi eta_R(e').
```

Then `e,e'` are separated by a finite rack quotient of `R`.

Proof: the composite:

```text
R -> Conj(As(R)) -> Conj(G)
```

is a rack homomorphism into a finite conjugation rack and separates `e,e'`.

Therefore, for each finite `M`, orbit-relevant finite residuality follows if:

```text
eta_M:C_M(X)->Conj(As(C_M(X)))
```

is injective on `E_M^rel`, and `As(C_M(X))` is residually finite on the
corresponding endpoint group elements.

## Finite Group Detector

For fixed `M`, the group presentation of `As(C_M(X))` has generators:

```text

```

The contextual rack relations induce group relations:

```text
g_{[p,x,bar{y}s]}=g_{[p bar{x'},y',s]},

g_{[p,x',bar{y'}s]}
=
g_{[p,x,bar{y}s]}
g_{[p bar{x},y,s]}
g_{[p,x,bar{y}s]}^{-1}.
```

To search for a finite group detector, enumerate finite groups `G` and assign:

```text

```

Impose the same group relations and the separation:

```text

```

A satisfying assignment gives a finite conjugation-rack quotient separating
the endpoint pair.  This is weaker than the full finite-rack SAT detector but
typically cheaper.
