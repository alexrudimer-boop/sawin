# Deletion-Null Monolith Chief Obstruction

This note upgrades the parabolic-disjoint chief obstruction to an exact
deletion-null Brunnian chief obstruction.

The previous obstruction chief factor was detector-invisible, all-meridian,
monolith-generating, and absent from every bounded parabolic image.  The
stronger statement here is that every nontrivial element of the chief factor
has an actual representative braid that is Brunnian before passing to the
finite image.  All proper deletion shadows of that representative are
literally trivial in the braid group.

## Setup

Let `X` be a smallest finite bijective YBE solution not dominated by any
finite rack.  Let

```text
mu=mu_X
```

be its unique first-fold monolith.

Fix a finite rack prefix `P_m`, choose a finite rack `Y_mu` dominating
`X/mu`, and for a bounded-support cutoff `s` set

```text
Q_{m,s}=(P_m x Y_mu)^0 x T_2 x B_s(X),
```

where `B_s(X)` is the bounded-support detector product from
`proofs/bounded_support_pairwise_obstruction_elimination.md`.

For arity `n`, let

```text
F_{n-1}=ker(d_n:P_n->P_{n-1})
```

be the last-strand free group, with meridian generators

```text
x_i=A_{i,n}.
```

Let

```text
Phi_n:F_{n-1}->Gamma_n
  <= Sym(Q_{m,s}^n) x Sym(X^n)
```

be the combined finite image.  Define

```text
K_n=ker(Gamma_n->rho^{Q_{m,s}}_n(F_{n-1})),
L_n=ker(Gamma_n->rho^X_n(F_{n-1})).
```

For each meridian, set

```text
N_{i,n}=<<Phi_n(x_i)>>_{Gamma_n},
```

and

```text
C_n=[N_{1,n},...,N_{n-1,n}]_Sigma.
```

For `T subset {1,...,n-1}`, write

```text
F_T=<x_i:i in T>,
H_T=Phi_n(F_T).
```

The finite-image Brunnian theorem gives

```text
Phi_n(Brun_n cap ker rho^{Q_{m,s}}_n)
  =
K_n cap C_n.
```

Here `Brun_n` is the ordinary Brunnian subgroup of `B_n`; hence
`beta in Brun_n` has trivial deletion after deleting any one strand, and
therefore after deleting any proper subset by iteration.

## Theorem

For every rack prefix `P_m`, support cutoff `s`, and arity cutoff `N`, there
exists `n>N` and a chief factor

```text
A/B
```

of `Gamma_n` such that

```text
B < A <= K_n cap C_n,
```

the `X`-projection of `A` is nontrivial and generates the monolith `mu`, and
the factor is parabolic-disjoint:

```text
A cap H_T B = B        for every |T|<=s,
```

where `H_T=Phi_n(F_T)`.

Moreover, every nontrivial element of `A` has an actual Brunnian
`Q_{m,s}`-invisible representative.  More precisely, for every

```text
1 != a in A,
```

there exists

```text
beta_a in Brun_n cap ker rho^{Q_{m,s}}_n
```

such that

```text
Phi_n(beta_a)=a.
```

Consequently,

```text
d_I(beta_a)=1
```

for every proper deletion `I subsetneq {1,...,n}`.

Finally, for every `1 != a in A`, the coordinate mismatches produced by
`p_X(a)` generate the monolith `mu`.

## Proof

Since `X` is a counterexample, `Q_{m,s}` cannot dominate `X`.  By the
transparent Brunnian reduction, there are unbounded arities `n` with

```text
Brun_n cap ker rho^{Q_{m,s}}_n
  not subset
ker rho^X_n.
```

For such `n`, the finite-image Brunnian theorem gives

```text
K_n cap C_n != 1.
```

Choose a chief series of the finite group `Gamma_n` refining

```text
1 <= K_n cap C_n <= Gamma_n.
```

Then some chief factor `A/B` lies inside `K_n cap C_n`, so

```text
B < A <= K_n cap C_n.
```

The monolith-generation argument is the same as in
`proofs/parabolic_disjoint_chief_obstruction.md`.  Since

```text
K_n cap L_n=1
```

inside the direct product image, the `X`-projection of any nontrivial element
of `A` is nontrivial.  Since `A<=K_n`, every element of `A` is invisible to
the `Y_mu^0` factor.  Because `Y_mu` dominates `X/mu`, `p_X(A)` acts
trivially on `(X/mu)^n`.  Thus all coordinate mismatches lie inside
`mu`-classes.  Any nontrivial `a in A` moves some `X^n`-state, so the
mismatch congruence generated by its coordinate changes is nontrivial and
contained in `mu`.  Since `mu` is the global monolith, that congruence equals
`mu`.

The parabolic-disjointness condition is also inherited from
`proofs/parabolic_disjoint_chief_obstruction.md`: because `Q_{m,s}` contains
`B_s(X)`, bounded-support annihilation gives

```text
K_n cap H_T=1        for every |T|<=s.
```

If `a in A cap H_TB`, write `a=hb` with `h in H_T` and `b in B`.  Since
`A,B<=K_n`, one has `h=ab^{-1} in K_n cap H_T=1`, so `a in B`.  Hence

```text
A cap H_TB=B.
```

It remains to prove the deletion-null representative statement.  Take

```text
1 != a in A.
```

Since `A <= K_n cap C_n`, we have

```text
a in K_n cap C_n.
```

By the finite-image Brunnian theorem,

```text
K_n cap C_n
  =
Phi_n(Brun_n cap ker rho^{Q_{m,s}}_n).
```

Therefore there exists

```text
beta_a in Brun_n cap ker rho^{Q_{m,s}}_n
```

with

```text
Phi_n(beta_a)=a.
```

Because `beta_a` is Brunnian, every one-strand deletion of `beta_a` is
trivial.  Deleting any proper subset is an iteration of one-strand deletions,
so

```text
d_I(beta_a)=1
```

for every proper deletion `I`.

This proves the theorem.

## Consequence

A smallest counterexample must have an extremely rigid cofinal obstruction.
For every detector prefix and every support cutoff, there are unbounded
arities with a chief factor

```text
A/B <= K_n cap C_n
```

such that:

```text
every nontrivial a in A has an actual Brunnian Q-invisible representative;
every proper deletion of that representative is literally trivial;
p_X(a) acts inside mu-fibres and generates mu;
A/B is disjoint from every bounded parabolic image.
```

Thus the obstruction is not merely large support, pairwise normal-closure
noise, or same-image deletion coherence.  It is an exact same-image,
deletion-null, all-meridian chief factor whose nontrivial elements lift to
ordinary Brunnian braids in the original braid group.

The positive target is now:

```text
rule out first-fold monoliths generated by deletion-null
detector-invisible chief factors.
```

The negative target is:

```text
construct one fixed finite X whose first-fold monolith is generated
cofinally by deletion-null monolith-generating chief factors against every
finite rack prefix.
```
