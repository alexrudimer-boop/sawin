# YBE Brunnian derivative gate

Date: 2026-06-03

The previous coskeletal checkpoint left a possible negative route: high-arity
Brunnian deletion `2`-classes invisible on bounded skeletons.  The next
pressure test rules out the most tempting but too-naive source of such
classes.

A Brunnian pure braid or point-pushing element may give a nontrivial vertical
bisection.  If it enters through ordinary one-strand point-pushing, however,
its two-deletion shadow is a section-gauge coboundary.  Thus Brunnian pure
braid subgroups are not by themselves a source of nonzero relative deletion
`Br^2_I`.

## Derivative Gate

Write a finite bijective solution as

```text
r(x,y) = (lambda_x(y), rho_y(x)).
```

For a deletion of one strand `p`, let `V_p^I` be the group of vertical
bisections over that deletion face.  For a double deletion `{p,q}`, let
`V_{p,q}^I` be the corresponding double-deletion vertical bisection group.
There is a restriction map

```text
partial_q: V_p^I -> V_p^{I \ {q}}
```

and a transport map

```text
tau_q: V_p^I -> V_{p,q}^I
```

viewing a one-deletion vertical bisection as a two-deletion bisection after
also deleting `q`.  Define the nonabelian deletion derivative

```text
nabla_q b = tau_q(b) inf_q(partial_q b)^-1.
```

If a `1`-cochain `u` has `u_p^I=b` and all other components trivial, then the
square gauge coboundary on `(p,q)` is

```text
(delta u)_{p,q}^I = nabla_q b.
```

So every two-deletion defect arising as the deletion derivative of a
one-strand point-push is gauge.

If `b` is Brunnian relative to `q`, meaning `partial_q b=1`, then

```text
nabla_q b = tau_q(b).
```

The transported bisection `tau_q(b)` may be nontrivial in
`V_{p,q}^I`, but it is still the gauge coboundary `(delta u)_{p,q}^I`.

For an actual Brunnian pure braid `beta in P_I`, deleting `p` kills `beta`,
so its action is a one-deletion vertical bisection `b_beta in V_p^I`.  If
deleting every other `q` also kills `beta`, then `partial_q b_beta=1`, hence

```text
tau_q(b_beta) = nabla_q b_beta = (delta u)_{p,q}^I.
```

Thus high Brunnian pure-braid elements live naturally in deletion degree `1`;
their first deletion derivatives are degree-`2` coboundaries.

The YBE-side coherence identity is the nonabelian derivative chain rule:

```text
nabla_r(nabla_q b) = nabla_q(nabla_r b),
```

after the low-dimensional Peiffer and cube transport defects have been
killed.  This is the deletion cube identity for the coboundary `delta u`.
YBE locality therefore makes point-pushing derivatives satisfy the cocycle
equation, but it also identifies them as gauge.

## Residual Target

The true obstruction target is the residual quotient

```text
R_{p,q}^I =
V_{p,q}^{I,Br} /
< nabla_q V_p^{I,Br},
  nabla_p V_q^{I,Br},
  M_{p,q}^I,
  Pi^sharp V_{p,q,B}^{I,Br} >.
```

Here `V_{p,q}^{I,Br}` is the subgroup of double-deletion vertical bisections
killed by every proper survivor deletion.  The first two denominator terms
are one-strand derivative contributions, hence gauge.  The term `M_{p,q}^I`
is the bounded mutual two-strand subgroup generated by motions involving only
the two deleted strands and their bounded local labels.  The last term is the
fixed-base pullback part.

A genuine high-arity Brunnian relative deletion `2`-class can occur only if
some

```text
a in V_{p,q}^{I,Br}
```

has nontrivial image in `R_{p,q}^I`.  Equivalently, no decomposition

```text
a = nabla_q b_p nabla_p b_q m_{p,q} Pi^sharp(theta)
```

exists with

```text
b_p in V_p^I,
b_q in V_q^I,
m_{p,q} in M_{p,q}^I,
theta in V_{p,q,B}^I.
```

So the exact pressure-test conclusion is:

```text
Brunnian pure braid survives
```

is too weak.  The actual negative certificate must be

```text
[a] != 1 in R_{p,q}^I.
```

Conversely, a positive Fadell-Neuwirth theorem can now target the
decomposition formula above.  If every double-deletion vertical bisection
decomposes into one-strand derivatives, bounded mutual two-strand terms, and
fixed-base pullback after finite operator-label enrichment, then all
arbitrarily high Brunnian relative deletion `2`-classes vanish.
