# Monolith Chief-Factor Pairwise-Core Visibility

This note corrects a tempting but false split of the monolith-chief
obstruction into "pairwise visible" and "central pairwise invisible" cases.

In the exact finite-image boundary used here, the central elementary abelian
all-meridian case is still pairwise-core visible.  The reason is purely
group-theoretic: for normal meridian closures, the all-meridian symmetric
commutator lies in every pairwise commutator subgroup.

Thus a central elementary abelian monolith-chief factor may still be a
high-Brunnian `p`-module mechanism, but it is not invisible to pairwise
commutator tests of the form

```text
K cap [N_i,N_j].
```

## Setup

Use the notation of
`proofs/cofinal_monolith_chief_factor_obstruction.md`.

Let `X` be a smallest finite counterexample, let

```text
mu=mu_X<=F_1(X)
```

be its unique first-fold monolith, and for a finite rack prefix `P_m` set

```text
Q_m=(P_m x Y_mu)^0 x T_2,
```

where `Y_mu` dominates `X/mu`.

For arity `n`, let

```text
Phi_{m,n}:F_{n-1}->Gamma_{m,n}
  <= Sym(Q_m^n) x Sym(X^n)
```

be the combined finite image.  Write

```text
K=K_{m,n},
L=L_{m,n},
N_i=N_{i,m,n},
C=C_{m,n}=[N_1,...,N_{n-1}]_Sigma.
```

Also define the pairwise core

```text
D_{m,n} = intersection_{i<j} [N_i,N_j].
```

## Lemma: The All-Meridian Layer Lies In Every Pairwise Commutator

Let `N_1,...,N_r` be normal subgroups of a group `G`, with `r>=2`, and let

```text
C=[N_1,...,N_r]_Sigma.
```

Then for every pair `i!=j`,

```text
C <= [N_i,N_j].
```

This is the pairwise-depth lemma already recorded in the finite-image ledger.
For completeness, the reason is that every generator of the symmetric
commutator is an iterated commutator with one input from each `N_k`.
Because all `N_k` are normal, every such iterated commutator involving both
`N_i` and `N_j` lies in `[N_i,N_j]`.  Therefore the subgroup generated by all
of them lies in `[N_i,N_j]`.

Consequently,

```text
C <= D_{m,n}.
```

## Theorem

For every finite rack prefix `P_m` and every cutoff `N`, there is an arity
`n>N` such that

```text
K_{m,n} cap D_{m,n} != 1.
```

Moreover, there is a chief factor `A/1` of `Gamma_{m,n}` with

```text
A <= K_{m,n} cap C_{m,n} <= K_{m,n} cap D_{m,n},
```

and for every pair `i!=j`, every nontrivial element of `A` lies in

```text
K_{m,n} cap [N_{i,m,n},N_{j,m,n}].
```

The `X`-projection of `A` is nontrivial, acts inside `mu`-fibres, and its
coordinate mismatches generate the monolith `mu`.

## Proof

By `proofs/cofinal_monolith_chief_factor_obstruction.md`, for every prefix
`P_m` and every cutoff there are unbounded arities with

```text
H=K_{m,n} cap C_{m,n} != 1.
```

Choose a minimal nontrivial normal subgroup

```text
A <= H
```

of the finite group `Gamma_{m,n}`.  Then `A/1` is a chief factor and

```text
A <= K_{m,n} cap C_{m,n}.
```

By the pairwise-depth lemma,

```text
C_{m,n} <= [N_{i,m,n},N_{j,m,n}]
```

for every pair `i!=j`.  Hence

```text
A <= K_{m,n} cap [N_{i,m,n},N_{j,m,n}]
```

for every pair, and in particular

```text
A <= K_{m,n} cap D_{m,n}.
```

Since the projection kernels satisfy

```text
K_{m,n} cap L_{m,n}=1,
```

the `X`-projection of any nontrivial element of `A` is nontrivial.

Because `A<=K_{m,n}`, every element of `A` is invisible to `Q_m`; in
particular it is invisible to the `Y_mu^0` factor.  Since `Y_mu` dominates
`X/mu`, the `X`-projection of `A` acts trivially on `(X/mu)^n`.  Therefore
all coordinate mismatches produced by `p_X(A)` lie inside `mu`-classes.

The `X`-projection is nontrivial, so the mismatch congruence is nontrivial.
It is contained in `mu`; since `mu` is the global monolith, it must equal
`mu`.

This proves the theorem.

## Consequence

There is no separate pairwise-invisible central elementary abelian branch at
the level of exact all-meridian monolith-chief factors.

The remaining finite-image obstruction may still be central elementary
abelian in structure, but it is simultaneously pairwise-core visible:

```text
K_{m,n} cap intersection_{i<j}[N_{i,m,n},N_{j,m,n}] != 1
```

in unbounded arities, and its `X`-projection generates the unique first-fold
monolith.

Thus the next positive target is stronger and cleaner:

```text
rule out cofinal detector-invisible pairwise-core monolith motion.
```

The next negative target is:

```text
construct one finite X whose unique first-fold monolith is generated
cofinally by detector-invisible pairwise-core chief factors.
```
