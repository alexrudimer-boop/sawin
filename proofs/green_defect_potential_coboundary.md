# Green defect potential coboundary

Date: 2026-05-29

This note sharpens the remaining Green/Schutzenberger defect-kernel target
after `proofs/green_defect_kernel_quotient_detection.md`.  It does not prove
the Master Local-Minimal Residual Theorem.  It proves that the elementary
first-output defects in a fixed Green/Schutzenberger observer are finite
nonabelian coboundaries on the retained edge-germ graph.

The remaining theorem is therefore not that the defect kernel is mysterious
holonomy.  The remaining theorem is the finite Artin-transport principalness
of this potential.

## Setup

Fix a regular Green class `C` and one group-valued observer

```text
U_C,
```

either the Schutzenberger action group or a finite kernel-block permutation
quotient.  For each completed retained row

```text
(a,q) |-> (q^a,a^q),
```

write `g(e) in U_C` for the observer label of an edge-germ.  The row satisfies

```text
g(a) g(q) = g(q^a) g(a^q).
```

The first-output defect is

```text
d(a,q)=g(q^a) g(q)^-1.
```

Let

```text
Def_C = << d(a,q) >>_{U_C}
```

be the normal subgroup generated by all first-output defects.

## Defect graph

Build a graph whose vertices are retained edge-germs seen by the observer and
whose elementary directed arrows are

```text
q -> q^a
```

for completed rows.  For connectivity, allow reverse traversal of such an
arrow with inverse label.

On each connected component choose one base edge-germ `e_0`.  Define the
basepoint-normalized potential

```text
eta_C(e) = g(e) g(e_0)^-1.
```

This potential depends on the chosen basepoint, but its coboundaries do not.
If a different basepoint `e_1` is chosen in the same component, then the new
potential is obtained from the old one by right multiplication by the fixed
element `eta_C(e_1)^-1`.

## Theorem

For every edge-germ `e` in the component,

```text
eta_C(e) in Def_C.
```

Moreover every first-output defect is the potential coboundary

```text
d(a,q)=eta_C(q^a) eta_C(q)^-1.        (1)
```

Proof.  Let `e` be in the component of `e_0`.  Choose any path from `e_0` to
`e` using elementary arrows and reverse elementary arrows.  A forward step
`q -> q^a` has ratio

```text
g(q^a) g(q)^-1 = d(a,q) in Def_C.
```

A reverse step has the inverse ratio, also in `Def_C`.  The product of ratios
along the path telescopes to

```text
g(e) g(e_0)^-1.
```

Thus `eta_C(e) in Def_C`.  This also shows that the value is independent of
which path was used, since it is the displayed direct ratio of endpoint
labels; closed paths telescope to `1`.

Now apply the definition:

```text
eta_C(q^a) eta_C(q)^-1
  = g(q^a) g(e_0)^-1 (g(q) g(e_0)^-1)^-1
  = g(q^a) g(q)^-1
  = d(a,q).
```

This proves `(1)`.  QED.

## Consequence for the remaining Green target

The previous target was:

```text
D_C(beta) in V_beta(Def_C),
```

where `D_C(beta)` is the transported endpoint product of first-output defects.
The theorem replaces the elementary defect terms by finite potential
differences:

```text
d(a,q)=eta_C(q^a) eta_C(q)^-1.
```

Therefore the remaining A-side burden is the following finite row-level
condition:

```text
the Def_C-valued potential is principal for the Artin detector transport.
```

Concretely, for each completed row one must prove that the potential
difference, with the correct transported context, is a product of Artin
permutation defect values in the fixed finite group `Def_C`.  The
Artin-defect sieve then places every transported defect endpoint in
`V_beta(Def_C)`.

If this Artin-transport potential condition is proved, the
Green/Schutzenberger part closes:

1. `U_C/Def_C` is already detected by the defect-quotient theorem and the
   detector-lift criterion.
2. The defect-kernel endpoint is killed by the Artin-defect display in
   `Def_C`.
3. Kernel-block factors follow as fixed finite homomorphic images when no
   local-only edge-germs occur.
4. Atom-inner factors are already closed once atom descent and totality are
   known.
5. Product assembly puts all fixed factors into one `H(pi,Q)` independent of
   braid index.

## Counterexample consequence

A B-route cannot use a bare nontrivial defect or a bounded row mismatch.  The
elementary defects are always coboundaries of the finite potential above.

The smallest visible B-target is now a nonprincipal `Def_C`-potential
transport cocycle that survives a normalized-law sequence.  Such a proof
would still need an explicit finite YBE solution, symbolic YBE verification,
base-kernel membership, moved residual tuples, and a normalized-law sequence
invisible to every finite group.

## Executable audit hooks

The code records the proved coboundary part through:

```text
green_defect_kernel_potential_audit(...)
schutzenberger_defect_kernel_potential_audits(...)
kernel_block_defect_kernel_potential_audits(...)
```

The audit computes the connected components of the defect graph, chooses a
base edge in each component, assigns `eta(e)=g(e)g(e_0)^-1`, verifies that
all potentials lie in the finite defect kernel, and checks every row identity

```text
d(a,q)=eta(q^a)eta(q)^-1.
```

It does not prove the remaining Artin-transport principalness condition; it
only verifies the finite nonabelian coboundary reduction.
