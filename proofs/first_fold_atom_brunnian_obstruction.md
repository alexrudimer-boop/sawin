# First-Fold Atom Brunnian Obstruction

This note sharpens the nondegenerate-reflection filtration obstruction for a
smallest counterexample.  It localizes any obstruction to a minimal congruence
atom contained in the first immediate degeneracy fold.

## First-Fold Congruence

Let `X` be a finite bijective YBE solution, and write

```text
R_X(x,y) = (lambda_x(y), rho_y(x)).
```

Define `F_1(X)` to be the braided congruence generated by all immediate
left- and right-degeneracy pairs:

```text
y ~ y'       whenever lambda_x(y)=lambda_x(y') for some x in X,

x ~ x'       whenever rho_y(x)=rho_y(x') for some y in X.
```

If `X` is degenerate, then `F_1(X) != Delta_X`, because some left or right
translation is not injective.

A first-fold atom is a minimal nontrivial braided congruence

```text
mu <= F_1(X).
```

Such atoms exist whenever `F_1(X)` is nontrivial, since the congruence lattice
of a finite algebra is finite.

## Theorem

Let `X` be a smallest finite bijective YBE solution, by cardinality, not
dominated by any finite rack.  Then `X` is degenerate.  Let

```text
mu <= F_1(X)
```

be a first-fold atom.

For every finite rack prefix `P_m`, let `Y_mu` be a finite rack dominating the
proper quotient `X/mu`, which exists by minimality of `X`.  Define

```text
Q_m = (P_m x Y_mu)^0 x T_2.
```

Then there exist arbitrarily large `n`, a braid

```text
beta in Brun_n cap ker rho^{Q_m}_n,
```

and a word `x in X^n` such that, with

```text
x' = rho^X_n(beta)(x),
```

one has:

```text
x' != x,
x_i mu x'_i for every i,
```

and the nontrivial coordinate mismatches generate `mu` as a braided
congruence:

```text
< (x_i,x'_i) : x_i != x'_i >_br = mu.
```

Thus every first-fold atom of a smallest counterexample is generated
cofinally by actual Brunnian detector-invisible coordinate mismatches.

## Proof

Since one-sided nondegenerate solutions are already finite-rack dominated by
the known derived-rack/guitar theorem, a smallest counterexample `X` must be
degenerate.  Hence `F_1(X)` is nontrivial, and first-fold atoms exist.

Let `mu <= F_1(X)` be one.  The quotient `X/mu` is proper because
`mu != Delta_X`.  By minimality of `X`, the quotient is finite-rack dominated;
choose a rack `Y_mu` such that

```text
ker rho^{Y_mu}_n <= ker rho^{X/mu}_n
```

for every `n`.

Fix a finite rack prefix `P_m` and put

```text
Q_m = (P_m x Y_mu)^0 x T_2.
```

If `Q_m` dominated `X`, then `X` would be dominated by a finite rack,
contrary to assumption.  Therefore `Q_m` does not dominate `X`.

By the standard transparent Brunnian reduction, failure of domination gives
some `n` and some

```text
beta in Brun_n cap ker rho^{Q_m}_n
```

such that `rho^X_n(beta)` is nontrivial.  Choose `x in X^n` moved by `beta`,
and set

```text
x' = rho^X_n(beta)(x).
```

Because `Q_m` contains `(P_m x Y_mu)^0`, coloring all strands nontransparent
shows

```text
beta in ker rho^{Y_mu}_n.
```

Since `Y_mu` dominates `X/mu`,

```text
beta in ker rho^{X/mu}_n.
```

Therefore every coordinate mismatch lies inside `mu`:

```text
x_i mu x'_i        for every i.
```

The mismatch set is nonempty because `x' != x`.  Let

```text
nu = < (x_i,x'_i) : x_i != x'_i >_br
```

be the braided congruence it generates.  Then

```text
Delta_X != nu <= mu <= F_1(X).
```

Since `mu` is minimal among nontrivial braided congruences contained in
`F_1(X)`, this forces

```text
nu = mu.
```

It remains to see that the witnesses can be taken in arbitrarily large
arity.  Suppose, for this fixed prefix `P_m`, that all Brunnian
`Q_m`-invisible `X`-visible witnesses occur in arities `n <= N`.  For each
`2 <= k <= N`, fixed-arity rack cofinality gives a finite rack `Y_k` with

```text
ker rho^{Y_k}_k <= ker rho^X_k.
```

Set

```text
Q'_m = Q_m x product_{k=2}^N Y_k^0.
```

For `n <= N`, any Brunnian braid invisible to `Q'_m` is invisible to `Y_n`
after coloring all strands nontransparent, hence is `X`-trivial.  For
`n > N`, the kernel of `Q'_m` is contained in the kernel of `Q_m`, and by
assumption there are no large-arity Brunnian `Q_m`-invisible `X`-visible
witnesses.  Thus every Brunnian `Q'_m`-invisible braid is `X`-invisible.

The Brunnian reduction would then imply that `Q'_m` dominates `X`, a
contradiction.  Hence the witnesses for `Q_m` occur in unbounded arities.

This proves the theorem.

## Consequence

A smallest counterexample must contain a first-fold atom `mu <= F_1(X)` with
all three properties:

```text
mu is generated by immediate left/right degeneracy folds;
X/mu is finite-rack dominated;
mu is generated cofinally by actual Brunnian rack-prefix-invisible
coordinate mismatches.
```

So the search target is no longer an arbitrary degenerate or
degeneracy-perfect solution.  It is:

```text
find a finite X and a first-fold atom mu <= F_1(X)
that supports cofinal Brunnian detector-kernel monodromy,
```

or prove that first-fold atoms cannot be generated by such cofinal Brunnian
detector-invisible mismatches.
