# Two-strand cyclic detector

Date: 2026-05-29

This note records a small all-solution fact: no Sawin counterexample can live
purely on two strands.

## Statement

Let `X` be any finite bijective set-theoretic YBE solution.  Let

```text
r = ord(R_X : X^2 -> X^2).
```

Then the finite cyclic group

```text
G = C_r
```

detects the two-strand action of `X` through the sharp Artin-longitude rack
`A_G`.  Equivalently,

```text
ker rho_{A_G,2} subset ker rho_{X,2}.
```

## Proof

The exact two-strand finite-group period from
`proofs/two_strand_symmetric_gate.md` says that

```text
ker rho_{A_G,2} = 2 exp(G) Z <= B_2 ~= Z.
```

For `G=C_r`, `exp(G)=r`, so

```text
ker rho_{A_{C_r},2} = 2r Z.
```

The two-strand action of `X` is generated by the crossing permutation `R_X`,
whose kernel is

```text
r Z.
```

Since `2r Z subset r Z`, every braid invisible to `A_{C_r}` acts trivially on
`X^2`.

Thus a two-strand crossing-order obstruction can defeat a proposed detector
group `G` when `r` does not divide `2 exp(G)`, but it can always be repaired
by replacing that detector with the finite cyclic group `C_r`.

## Consequence For Outcome B

Outcome B requires braid indices `q_j -> infinity` and eventual invisibility
to every finite group.  This note explains why: on `B_2`, the finite cyclic
detector `C_r` always sees the crossing order of a fixed finite solution.
Therefore a genuine counterexample must use higher-strand residual holonomy
or a normalized-law mechanism whose obstruction cannot be reduced to the
order of a single crossing permutation.

## Relation To The Direct Symmetric Route

The direct shortcut `A_{Sym(X)}` is stronger than this cyclic two-strand
detector.  It passes the two-strand gate exactly when

```text
r divides 2 exp(Sym(X)).
```

If this divisibility fails, `two_strand_symmetric_detector_failure_certificate`
returns the explicit braid `sigma_1^(2 exp(Sym(X)))` and a moved tuple,
killing the direct `A_{Sym(X)}` shortcut.  But the cyclic detector above still
shows that such a failure is not a Sawin counterexample by itself.

## Executable Form

The helper

```text
two_strand_cyclic_detector_certificate(X)
```

returns `r`, the cyclic detector order `r`, the finite-longitude period `2r`,
and the Boolean kernel-containment check.  Regression tests compare it with
`two_strand_group_detector_failure_certificate(...)` on a three-point rack:
`C_2` fails, while `C_3` covers the two-strand action.
