# Prefix point-pushing surface

Date: 2026-06-03

The group-Hurwitz compression pressure test points to the first concrete
point-pushing arities

```text
Q_X(3) <= G_X(4),       Q_X(4) <= G_X(5).
```

This note makes those finite surfaces executable for the prefix-edge
transducer route.

## Standard Generators

The audit uses the same standard meridians as the route note:

```text
alpha_{i,n+1}
 =
sigma_n ... sigma_{i+1} sigma_i^2
 sigma_{i+1}^{-1} ... sigma_n^{-1}.
```

Equivalently, it uses the repository helper

```text
pure_braid_generator(i,n+1).
```

Thus `Q_X(3)` is generated by

```text
alpha_{1,4}, alpha_{2,4}, alpha_{3,4},
```

and `Q_X(4)` is generated by

```text
alpha_{1,5}, alpha_{2,5}, alpha_{3,5}, alpha_{4,5}.
```

## Prefix Surface Check

For each generator, the audit computes its permutation on `X^{n+1}` and also
computes the same action after prefix-path encoding

```text
Phi_{n+1}(x_1,...,x_{n+1})
  = ((P_0,x_1,P_1), ..., (P_n,x_{n+1},P_{n+1})).
```

The two actions must agree under the prefix-path bijection.  This is the
finite check that the prefix transducer really sees the same marked
point-pushing action at the first obstruction surface.

## What The Surface Can And Cannot Prove

The audit records:

- standard generator braid words;
- generator orders;
- point-pushing subgroup size and exponent, when not truncated;
- prefix-path injectivity;
- equality of tuple action and prefix-path action.

This is not an all-arity theorem.  It is the finite starting point for either:

```text
positive route:
  construct a fixed finite group-Hurwitz compression whose quotient maps
  these marked generators compatibly and whose vertical kernels have
  bounded exponent;

negative route:
  find a degenerate finite table where every such compression leaves
  incompatible or unbounded vertical data already visible from Q_X(3),
  Q_X(4), and continuing in the tower.
```
