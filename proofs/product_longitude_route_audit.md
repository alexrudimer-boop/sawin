# Product longitude route audit

## Purpose

This note records the executable fork used for the product closed-label
branch.  It does not prove the all-`n` product theorem.  Instead it prevents
three different proof obligations from being confused:

1. a single common assignment into the product-label group;
2. a single longitude value witnessing each closed label separately;
3. membership of each closed label in the subgroup generated by all longitude
   values.

Only the third condition matches the sharp finite-group obstruction theorem in
full generality.

## Fixed-word data

Fix a product interval, a branch `swapped` or `direct`, a colour tuple `z` of
length `n`, and a residual braid word `beta` whose base colour path and product
dependency are both closed.  Let

```text
H_prod
```

be the finite totalized product-label group generated by the branch labels.
Let

```text
h_j(beta) in H_prod
```

be the closed product labels recorded by
`product_closed_label_permutations(interval, branch, z, beta)`.  Let

```text
L_1(beta),...,L_n(beta)
```

be the recursive Artin longitudes.

The helper

```text
product_closed_label_longitude_route_audit(...)
```

enumerates all assignments `phi:F_n -> H_prod` for this fixed finite group and
fixed word.  It records:

- the number of assignments satisfying
  `phi(L_j(beta))=h_j(beta)` for every coordinate at once;
- whether each nonidentity `h_j(beta)` is hit by one longitude value
  `phi(L_i(beta))`;
- whether each nonidentity `h_j(beta)` lies in the subgroup
  `V_beta(H_prod)` generated by all such values.

Thus the audit displays the strict route ladder:

```text
common assignment
    => per-label single-longitude witnesses
    => longitude-subgroup membership
    => finite-G product detection for this fixed word.
```

The first implication is useful only as intuition, not as a valid theorem
target.  The last implication is the one used by the sharp obstruction theorem:
if `Lambda_{H_prod,n}(beta)=Lambda_{H_prod,n}(1)`, then every value in
`V_beta(H_prod)` is identity, so every closed product label lying in
`V_beta(H_prod)` is identity.

## Regression fixture

The two-colour identity-base cyclic fixture gives the smallest recorded
separation.  For the swapped product interval, colour tuple `(0,1,0)`, and
braid word

```text
sigma_1 sigma_2^2 sigma_1,
```

the route audit has:

```text
common_assignment_count = 0,
nonidentity coordinates = (0,1,2),
all_single_witnessed = true,
all_in_longitude_subgroup = true,
subgroup_only_rows = (),
failed_rows = ().
```

This proves that the common-assignment shortcut is too strong while the
finite-group product detector is still plausible.  The example is not outcome
B because its nontrivial closed labels are already forced to vanish by identity
longitude data in `H_prod`.

## Theorem-level obligation

For outcome A, the product branch should prove the following symbolic lemma:

> For every local-minimal product interval, every braid degree `n`, every
> closed base tuple `z`, and every residual braid `beta`, each closed product
> label `h_{z,j}(beta)` lies in `V_beta(H_prod)`, possibly after replacing
> `H_prod` by a fixed finite product with already-known detector factors.

The detector group is then fixed by the interval and independent of `n`.

For outcome B, a bounded failure of the route audit is still only a candidate.
The counterexample must upgrade such a failure to a normalized-law obstruction
sequence defeating every finite group, not just `H_prod`.
