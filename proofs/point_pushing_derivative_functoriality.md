# Point-pushing derivative functoriality

Date: 2026-05-30

This note records the functorial structure of the exact derivative detector
from `proofs/point_pushing_marked_quotient_criterion.md`.  It does not prove
outcome A or B.  It makes the symmetric and product-prefix reductions
compatible with the repaired `D_k(G)` criterion.

## Setup

For a finite group `G` and `k>=1`, let

```text
D_k(G)=<d_1^G,...,d_k^G> <= Sym((G x G)^{k+1})
```

be the marked Artin derivative detector image.  The generator `d_i^G` is the
active detector action of the pure braid `A_{i,k+1}`.

## Coordinate Equivariance

Let

```text
f:G->H
```

be a finite group homomorphism.  Apply `f` coordinatewise to detector states:

```text
F((m_1,u_1),...,(m_n,u_n))
 =
((f(m_1),f(u_1)),...,(f(m_n),f(u_n))).
```

The active Artin detector updates use only multiplication and inversion in the
group.  Since `f` preserves multiplication and inversion, every pure generator
satisfies

```text
F d_i^G = d_i^H F.
```

The same identity holds for every word in the marked generators.

## Surjections

If `f:G->H` is surjective, then `F:(G x G)^{k+1}->(H x H)^{k+1}` is
surjective.  Therefore every relation among the marked generators in `D_k(G)`
is also a relation among the marked generators in `D_k(H)`:

```text
w(d_1^G,...,d_k^G)=1
  =>
w(d_1^H,...,d_k^H)=1.
```

Hence there is a surjective marked homomorphism

```text
D_k(G)->D_k(H),
qquad
d_i^G |-> d_i^H.
```

Thus derivative detectors respect quotient groups.

## Embeddings

If `f:G->H` is injective, identify `G` with its image in `H`.  The subset

```text
F((G x G)^{k+1}) <= (H x H)^{k+1}
```

is invariant under the marked generators `d_i^H`, by coordinate
equivariance.  Restricting the `H`-detector action to this invariant subset
and conjugating through `F` gives exactly the `G`-detector action.  Therefore
there is a surjective marked restriction homomorphism

```text
D_k(H)->D_k(G),
qquad
d_i^H |-> d_i^G.
```

In particular, if `G` is a finite group of order `m`, the left-regular
embedding `G->S_m` gives

```text
D_k(S_m)->D_k(G)
```

for every `k`.  Therefore the symmetric-detector reduction remains valid in
the exact marked-quotient language: if one finite `G` has marked quotients
`D_k(G)->P_k(X)` for all `k`, then `S_m` also has marked quotients
`D_k(S_m)->P_k(X)` for all `k`.

## Direct Products

Let

```text
G=G_1 x ... x G_r.
```

The state space `(G x G)^{k+1}` is canonically the product of the state spaces
`(G_s x G_s)^{k+1}`.  Under this identification, each marked generator is the
coordinatewise tuple

```text
d_i^G=(d_i^{G_1},...,d_i^{G_r}).
```

Consequently `D_k(G)` is the marked subdirect product of the `D_k(G_s)`
generated by these diagonal marked generators.  Equivalently,

```text
w(d_1^G,...,d_k^G)=1
```

if and only if

```text
w(d_1^{G_s},...,d_k^{G_s})=1
```

for every factor `s`.

This is exactly the derivative-detector form of the product-prefix
diagonalization: relations in `D_k(P_j)` are simultaneous derivative
relations for all finite groups in the prefix

```text
P_j=G_1 x ... x G_j.
```

## Consequence

The repaired exact fork is stable under all detector-format changes used in
the archive:

1. finite quotient groups give quotient derivative detectors;
2. finite subgroup embeddings give restriction quotients in the opposite
   direction;
3. symmetric groups are cofinal by the left-regular embedding;
4. product-prefix detectors impose exactly simultaneous derivative relations.

So the remaining A target may use either one fixed finite group or one fixed
symmetric group, and the B target may use product-prefix derivative relations,
without falling back to the false ordinary-law shortcut.
