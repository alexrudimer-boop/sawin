# Uniform Contextual Tower Obstruction

Date: 2026-06-05

This note records the sharpened endpoint for the finite-state contextual tower.
The tower is valid and stronger than `C_L(X)`, but it does not close Sawin
without a uniform finite/profinite lemma.

The exact missing statement is:

```text
If X is residual rigid and has no proper domination-reducing active factor,
then there exists one finite quotient M of L_X such that C_M(X) is orbitwise
residually separating for all arities.
```

This is not pointwise residual separation.  It requires one finite state
quotient and one finite rack detector for all `n`.

## Finite-State Tower

Let

```text
L_X =
< lambda_x, x in X
  | lambda_x lambda_y=lambda_u lambda_v whenever r_X(x,y)=(u,v) >
```

be the positive left structure monoid.  For a finite quotient

```text
theta:L_X -> M,
```

write `lambda_x^M=theta(lambda_x)`.

Define `C_M(X)` as the rack generated by

```text
d_{a,x,b}        (a,b in M, x in X)
```

with relations

```text
d_{a,u,lambda_v^M b}=d_{a lambda_x^M,y,b},                       (M1)
d_{a lambda_u^M,v,b}
 =
d_{a lambda_x^M,y,b} triangleright d_{a,x,lambda_y^M b}.          (M2)
```

For a word `w=(x_1,...,x_n)`, define

```text
P_i^M=theta(lambda_{x_1}...lambda_{x_i}),       P_0^M=1,
Q_i^M=theta(lambda_{x_{i+1}}...lambda_{x_n}),   Q_n^M=1.
```

Then

```text
Theta_n^M(w)=
(d_{P_0^M,x_1,Q_1^M}, ..., d_{P_{n-1}^M,x_n,Q_n^M}).
```

The local labels around `r_X(x,y)=(u,v)` are

```text
A=d_{a,x,lambda_y b},
B=d_{a lambda_x,y,b},
A'=d_{a,u,lambda_v b},
B'=d_{a lambda_u,v,b}.
```

Relations `(M1),(M2)` give `A'=B` and `B'=B triangleright A`, so
`Theta_n^M` is braid-equivariant.

## Fixed-M Domination

For fixed finite `M`, define

```text
alpha ==_{M,fin} beta
```

if every homomorphism from `C_M(X)` to a finite rack identifies the two
contextual generators.

If there exists finite `M` such that, for every same-orbit pair `w != w'` in
every arity, some coordinate satisfies

```text
(P_{i-1}^M(w),w_i,Q_i^M(w))
not ==_{M,fin}
(P_{i-1}^M(w'),w'_i,Q_i^M(w')),
```

then `X` is dominated by a finite rack.  Since `M x X x M` is finite, take the
product of finite rack quotients separating all generator pairs not identified
by `==_{M,fin}`.  Equivariance of `Theta_n^M` then gives

```text
ker rho_n^Y <= ker rho_n^X
```

for all `n`.

## Uniformity Obstruction

For finite quotients `M' -> M`, there is a natural rack map

```text
C_{M'}(X) -> C_M(X).
```

Thus finer `M` can only improve separation.  Let `B_M` be the set of
same-orbit bad pairs not separated by `C_M(X)` modulo finite-rack residual
equivalence.  Then

```text
M' refines M  =>  B_{M'} subset B_M.
```

Pointwise tower separation says

```text
intersection_M B_M = empty.
```

Sawin needs the stronger statement

```text
there exists finite M with B_M = empty.
```

These are not equivalent.  A model is `B_m={k in N : k>=m}`: the intersection
is empty, but no individual `B_m` is empty.

A bounded bad-witness theorem would close this gap:

```text
There exists N=N(X) such that every bad pair has a bad subconfiguration of
arity <= N.
```

Then only finitely many orbit-relevant pairs would need to be separated, and
the required finite quotients could be multiplied into one `M`.  No such
bounded-witness theorem follows from the current residual-rigid hypotheses.

## Residual Finiteness Of `L_X`

There is a useful positive fact: `L_X` is residually finite as a monoid.

The defining relations are homogeneous of degree `2`, so word length is
well-defined in `L_X`.  For `N>=0`, define a finite quotient `T_N` whose
elements are the classes of words of length at most `N`, plus an absorbing
symbol `infty` for words of length greater than `N`.  Multiplication is

```text
[a][b]=[ab]     if |a|+|b|<=N,
[a][b]=infty    otherwise,
```

with `infty` absorbing.  This is well-defined because the relations preserve
length.

If `A != B` in `L_X`, choose `N >= max(|A|,|B|)`.  Then `A` and `B` remain
distinct in `T_N`.

Thus fixed contexts are finitely separable.  But contexts in arity `n` have
length up to `n-1`, and `n` is unbounded.  The length-truncation quotients do
not produce one finite detector for all arities.

## Profinite Scattering States

Even though `L_X` is residually finite, its profinite completion may contain
limiting states that create bad pairs for every finite quotient.

A tower-level local obstruction has the form: there exist letters
`s,x,u,y` with

```text
r_X(s,y)=(x,y),
r_X(x,y)=(u,y),
u != x,
```

and a profinite state `ahat` in the completion of `L_X` such that

```text
ahat lambda_s = ahat lambda_x = ahat lambda_u.
```

Then for every finite quotient `M`, the image `a_M` satisfies

```text
a_M lambda_s = a_M lambda_x = a_M lambda_u.
```

At that state, the local crossing `(x,y)->(u,y)` is invisible in `C_M(X)`.
The prefix word realizing `a_M` may have to grow with `M`, so this gives an
infinite sequence of bad pairs requiring finer and finer states.

Residual rigidity does not currently rule out such profinite synchronizing
states.

## Full Marked-Word Contextual Rack

Define the full marked-word contextual rack `C_Lword(X)` with generators

```text
e_{A,x,B}        (A,B in L_X, x in X)
```

and relations

```text
e_{A,u,lambda_vB}=e_{A lambda_x,y,B},
e_{A lambda_u,v,B}
 =
e_{A lambda_x,y,B} triangleright e_{A,x,lambda_yB}.
```

Each finite quotient `L_X -> M` induces a rack quotient

```text
C_Lword(X) -> C_M(X).
```

The full rack removes collapse caused by a fixed finite `M`, but it still has
two problems:

```text
pointwise residual finiteness does not give one finite rack for all arities;
a finite rack quotient of C_Lword(X) need not factor through a finite-state
quotient C_M(X).
```

A finite rack quotient `phi:C_Lword(X)->Y` factors through some `C_M(X)` exactly
when its label function

```text
epsilon(A,x,B)=phi(e_{A,x,B})
```

is determined by a finite-index monoid congruence on the two contexts.  Finite
image alone does not imply this Myhill-Nerode finite-state determinacy.

## Fixed-M Profinite Stabilizer Barrier

Let

```text
R_M=C_M(X),
G_M=As(R_M).
```

For a contextual generator `alpha=(a,x,b)`, let

```text
H_alpha=Stab_{G_M}(d_alpha).
```

If `d_beta=g.d_alpha`, then

```text
alpha ==_{M,fin} beta
iff
g in closure_prof(H_alpha)
iff
g in intersection_{N normal finite index in G_M} H_alpha N.
```

Thus the profinite obstruction is

```text
g notin H_alpha
but
g in closure_prof(H_alpha).
```

Residual rigidity does not imply that the groups `As(C_M(X))` are in any
subgroup-separable class, nor that the relevant stabilizers are finitely
generated.

## Active Factor Extraction Still Fails Formally

Contextual tower collapse gives relations among triples `(a,x,b)`, not a
context-independent relation on `X`.

A state-dependent active factor would require a finite bijective YBE solution
`Z` and maps

```text
pi_{a,b}:X -> Z
```

satisfying

```text
r_Z(pi_{a,lambda_y b}(x), pi_{a lambda_x,b}(y))
=
(pi_{a,lambda_v b}(u), pi_{a lambda_u,b}(v)).
```

Then the induced maps `X^n -> Z^n` are braid-equivariant.  If they become
injective after adding inert observers, then

```text
ker rho_n^Z <= ker rho_n^X.
```

But this is a coherent completion of a partial contextual transition rule to a
total finite bijective YBE solution.  A contextual scattering cycle gives no
reason for such a `Z` to exist, and completion can fail.

## Finite Automaton Contexts

Finite monoid quotients are not the most economical finite-state systems.  One
may take a finite right `L_X`-set `P` and a finite left `L_X`-set `Q`, and
define a rack `C_{P,Q}(X)` with generators

```text
e_{p,x,q}.
```

The same contextual relations and equivariance proof apply.

However, any finite `P,Q` action factors through a finite transformation
monoid.  The finite automaton form is more flexible, but it does not remove
the uniformity obstruction.  The required statement is still:

```text
there exists one finite two-sided state system and one finite rack quotient
separating all same-orbit pairs in every arity.
```

## Escape Holonomy

Escape holonomy implies finite contextual rack separation exactly under finite
rack determinacy by states.  There must be a finite state system and a finite
rack `E` with labels

```text
epsilon(p,x,q)
```

satisfying the contextual rack equations.  Then `epsilon` factors through the
corresponding contextual rack.

If escape holonomy distinguishes paths with the same finite state triple or
uses a non-rack crossing law, then it does not factor through the contextual
tower.

## Current Endpoint

The strongest valid theorem is:

```text
If there exist a finite quotient theta:L_X->M and a finite rack quotient
phi:C_M(X)->Y such that phi^n Theta_n^M separates all distinct same-orbit
word pairs in every arity, then ker rho_n^Y <= ker rho_n^X for all n.
```

The exact residual missing lemma is one of:

```text
uniform finite-state contextual separation;
contextual tower failure implies a proper domination-reducing active factor;
escape holonomy is finite-rack-determined by finite two-sided states;
relevant stabilizers in As(C_M(X)) are profinitely closed for some uniform M.
```

At present, none follows from the stated residual-rigid guardrails.
