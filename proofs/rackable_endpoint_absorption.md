# Rackable Endpoint Absorption

Date: 2026-06-04

This note records the same-chat Pro repair to
`proofs/vertical_kernel_endpoint_refutation.md`.

The flip-marker construction refutes the vertical endpoint lemma as stated,
but it is not a Sawin obstruction.  If the formal endpoint labels are upgraded
to actual finite fibre bisections compatible with the Yang-Baxter equation,
then the endpoint bisections themselves form a finite rack detector.  A
nontrivial endpoint in this rackable sense is therefore visible to a finite
rack.

The remaining negative route must find actual endpoint movement that is not
absorbed by such a finite augmented rack factor.

## The Absorbing Rack

Let `F` be a finite endpoint fibre, and let

```text
Phi <= Sym(F)
```

be the finite group generated by the local endpoint bisections.  Let
`C subset Phi` be a finite conjugation-stable set containing the bisections
that occur as local endpoint labels.  The safe choice is `C=Phi`.

Define

```text
R = C sqcup F.
```

For `alpha,beta in C` and `f in F`, define a binary operation `*` on `R` by

```text
alpha * beta = alpha beta alpha^-1,
alpha * f    = alpha(f),
f * z        = z        for every z in R.
```

Here `alpha(f)` is regarded as the corresponding element of the `F` summand.

The left translations are

```text
L_alpha(beta) = alpha beta alpha^-1,
L_alpha(f)    = alpha(f),
L_f           = id_R.
```

They are bijections.  The rack identity is equivalently

```text
L_{x*y} = L_x L_y L_x^-1.
```

It holds in the three cases:

1. for `x=alpha`, `y=beta` in `C`, this is conjugation in `Phi` on `C` and the
   given action on `F`;
2. for `x=alpha in C`, `y=f in F`, both sides are `id_R`;
3. for `x=f in F`, `L_f=id_R`, so the identity is tautological.

Thus `R` is a finite rack, and its associated YBE table is

```text
r_R(x,y) = (x*y,x).
```

This is the rack that absorbs faithful endpoint bisections.

## Faithful Endpoint Realization

Suppose an endpoint-labelled completed-context interval is upgraded so that
the endpoint readout is actual movement of a finite fibre `F`.  For each local
old germ `p`, let

```text
phi_p in Phi <= Sym(F)
```

be the corresponding fibre bisection.  YBE compatibility of triples with two
old colours and one endpoint fibre forces the covariance relation

```text
phi_{p*q} = phi_p phi_q phi_p^-1
```

whenever the old-old crossing sends `q` to `p*q` in the relevant retained
operator label.

This is exactly the statement that

```text
p |-> phi_p
```

is a morphism from the old operator rack to the conjugation rack of `Phi`.
Consequently the rack `R=C sqcup F` reproduces the endpoint motion: when an
old label `phi_p` crosses over a fibre entry `f`, the fibre entry becomes
`phi_p(f)`, and old-old crossings update the operator labels by conjugation.

If a residual branch has full endpoint

```text
u in Phi
```

that acts nontrivially on the actual fibre, choose `f in F` with

```text
u(f) != f.
```

Run the same branch on the rack-coloured configuration whose endpoint fibre
entry is `f` and whose old operator entries are the corresponding
`phi_p in C`.  The final fibre entry is `u(f)`, so

```text
rho^R(gamma) != 1.
```

Therefore a nontrivial faithful rackable endpoint cannot be invisible to all
finite racks.  The finite rack `R` detects it.

## The Marker Obstruction Becomes Harmless

The refutation in `proofs/vertical_kernel_endpoint_refutation.md` used the
involutive flip table on

```text
X = T sqcup {m},
```

where `T` is the set of transpositions in `S_3`.  The endpoint labels were
external `S_3` labels attached to marker crossings.  They produced Brunnian
vertical point-pushing words with nontrivial endpoint and trivial Artin and
bounded deletion shadows.

If those `S_3` endpoint labels are made faithful as actual marker-fibre
movement, the old colours must stop being a pure flip unless the endpoint
bisections commute.

Indeed, suppose one tries to keep old-old and marker-old crossings as flips:

```text
r(t,s) = (s,t),
r(t,f) = (phi_t(f),t),
r(f,t) = (t,f).
```

Apply YBE to `(t,s,f)`.  The two sides move the fibre by

```text
phi_s phi_t(f)
```

and

```text
phi_t phi_s(f).
```

Thus YBE forces

```text
phi_s phi_t = phi_t phi_s.
```

The noncommuting `S_3` endpoint labels used in the refutation cannot be made
faithful while preserving the old flip behaviour.

If the endpoint bisections do not commute, YBE instead forces conjugation
covariance:

```text
phi_{t*s} = phi_t phi_s phi_t^-1.
```

That is precisely the rackable case above.  The repaired object is detected
by a finite rack.

## Explicit S_3 Upgrade

Let `U=S_3`, let `F=U` with the left regular action, and let `C` be either all
of `U` or the conjugation-stable set of transpositions.  The absorbing rack is

```text
R = C sqcup F
```

with

```text
g * k = g k g^-1,      g,k in C,
g * h = g h,           g in C, h in F,
h * z = z,             h in F, z in R.
```

For a base word

```text
(g_1,...,g_K,h)
```

with the last entry in the fibre summand, the last-strand point-pushing
generator `A_{i,K+1}` moves the fibre by the conjugate endpoint

```text
theta_i = P_i g_i P_i^-1,
P_i = g_K ... g_{i+1},
```

using the same formula as the marker refutation.  Since the local labels
generate `S_3`, one can prescribe noncommuting `theta_i` and build the same
Brunnian words

```text
W_2=[x_1,x_2],
W_{K+1}=[W_K,x_{K+1}].
```

These words still have trivial proper deletion shadows, but now their
nontrivial endpoint moves an actual fibre point of the rack `R`.  Hence the
finite rack `R` sees the movement.  The construction is real, but it is
rack-detected by construction.

## Correct Admissibility Filter

Endpoint-only Brunnian classes are not enough for outcome B.  A candidate
negative sequence must be:

1. actual, in the sense that the endpoint is movement of actual residual
   fibres of a finite YBE solution;
2. profinitely Artin-null, so every fixed finite Artin/rack-longitude detector
   eventually sees the identity; and
3. non-rackable, in the sense that the endpoint movement is not captured by
   a finite conjugation/action rack factor of the form above.

The flip-marker refutation fails the first condition before repair, and fails
the third condition after repair.  It is therefore a guardrail against an
overbroad endpoint lemma, not evidence for a Sawin-negative solution.
