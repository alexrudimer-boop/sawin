# Weighted Block-Core Finite-Image Obstruction

Date: 2026-06-06

This note records another C-type sharpening of the finite-image obstruction
for Sawin's finite-rack domination problem.  It does not prove Sawin's
statement and does not provide a cofinal counterexample.  Its contribution is
to preserve the multiplicities of the original meridians after collapsing
them into blocks.

The previous block-core note used the fat-commutator theorem, which forgets
how many original meridians were in each collapsed block.  A genuine
all-meridian obstruction has total commutator length `r=n-1`, not merely
support on three collapsed blocks.  The weighted cores below retain this
length information.

## Definitions

Let `G` be a group and let

```text
N_1,...,N_r triangleleft G.
```

For normal subgroups `H_1,...,H_s triangleleft G` and positive integers

```text
m=(m_1,...,m_s),
```

define the weighted symmetric commutator

```text
[H_1^(m_1),...,H_s^(m_s)]_Sigma^wt
```

to be the subgroup generated by all fully parenthesized commutators of total
length

```text
m_1+...+m_s
```

with exactly `m_j` entries from `H_j`, in arbitrary order.

For a nonempty subset `S subset {1,...,r}`, put

```text
N_S = product_{i in S} N_i.
```

For `2<=s<=r`, define the multiplicity-preserving `s`-block core

```text
Omega_s(G;N_1,...,N_r)
  =
intersection_{P={S_1,...,S_s}}
  [N_{S_1}^(|S_1|),...,N_{S_s}^(|S_s|)]_Sigma^wt,
```

where the intersection ranges over all partitions of `{1,...,r}` into `s`
nonempty blocks.

## Multiplicity-Preserving Containment

Theorem.  Let

```text
C=[N_1,...,N_r]_Sigma.
```

Then, for every `2<=s<=r`,

```text
C <= Omega_s(G;N_1,...,N_r).
```

For `s>=3`,

```text
Omega_s(G;N_1,...,N_r) <= Theta_s(G;N_1,...,N_r),
```

where `Theta_s` is the unweighted block core from
`proofs/block_core_finite_image_obstruction.md`.

Moreover,

```text
Omega_s(G;N_1,...,N_r) <= gamma_r(G).
```

Consequently,

```text
C <= Omega_3(G;N_1,...,N_r)
  <= Theta_3(G;N_1,...,N_r) cap gamma_r(G)
  <= Theta_3(G;N_1,...,N_r).
```

Proof.  A generator of `C` is a fully parenthesized commutator with exactly
one entry from each `N_i`.  Fix a partition

```text
P={S_1,...,S_s}
```

of `{1,...,r}`.  If the individual labels are forgotten and only the block
containing each label is retained, the same commutator has exactly `|S_j|`
entries from `N_{S_j}`.  Therefore the generator lies in

```text
[N_{S_1}^(|S_1|),...,N_{S_s}^(|S_s|)]_Sigma^wt.
```

This holds for every partition, so `C<=Omega_s`.

Each weighted commutator has every block `N_{S_j}` appearing at least once.
Therefore it lies in the corresponding fat-commutator subgroup.  By the
standard fat-commutator theorem, that subgroup equals

```text
[N_{S_1},...,N_{S_s}]_Sigma.
```

Intersecting over all `s`-block partitions gives `Omega_s<=Theta_s`.

Finally, every weighted commutator above has total length

```text
|S_1|+...+|S_s|=r.
```

A fully parenthesized commutator of length `r` lies in `gamma_r(G)`, by
induction on the commutator tree using

```text
[gamma_a(G),gamma_b(G)] <= gamma_{a+b}(G).
```

Thus `Omega_s<=gamma_r(G)`.

## Strictness

The refinement is non-cosmetic.

Let `r=4`, let

```text
G=UT_4(F_p),
```

the group of `4 x 4` upper unitriangular matrices over `F_p`, and set

```text
N_1=N_2=N_3=N_4=G.
```

For every three-block partition, the unweighted three-block subgroup is

```text
[G,G,G]_Sigma = gamma_3(G).
```

Hence

```text
Theta_3(G;G,G,G,G)=gamma_3(G).
```

On the other hand, every weighted three-block commutator has total length
`4`, and with all block subgroups equal to `G` these length-four commutators
generate `gamma_4(G)`.  Hence

```text
Omega_3(G;G,G,G,G)=gamma_4(G).
```

The group `UT_4(F_p)` has nilpotency class three, so

```text
gamma_3(G) != 1,
gamma_4(G) = 1.
```

Therefore

```text
Omega_3(G;G,G,G,G)=1
but
Theta_3(G;G,G,G,G)!=1.
```

The unweighted triple core can contain bounded-depth triple-commutator noise
which cannot come from a true all-meridian obstruction.

## Finite-Image Consequence

Return to the finite-image setup with `r=n-1` and define

```text
Omega_{n,s}^wt
  =
Omega_s(Gamma_n;N_{1,n},...,N_{n-1,n}).
```

Then, for every `3<=s<=n-1`,

```text
C_n <= Omega_{n,s}^wt <= Theta_{n,s}
```

and

```text
Omega_{n,s}^wt <= gamma_{n-1}(Gamma_n).
```

In particular,

```text
C_n <= Omega_{n,3}^wt
  <= Theta_{n,3} cap gamma_{n-1}(Gamma_n).
```

Thus the sufficient triple-block condition

```text
K_n cap Theta_{n,3}=1
```

can be replaced by the strictly weaker weighted condition

```text
K_n cap Omega_{n,3}^wt=1.
```

Even the following smaller target suffices:

```text
K_n cap (Omega_{n,2}^wt cap Omega_{n,3}^wt)=1,
```

because `C_n` is contained in both weighted cores.

Consequently, a detector `Q=Y^0 x T_2` dominates `X` if, for all sufficiently
large `n`,

```text
K_n cap Omega_{n,3}^wt=1
```

or more sharply

```text
K_n cap (Omega_{n,2}^wt cap Omega_{n,3}^wt)=1,
```

with finitely many fixed-arity rack detectors added for the remaining small
arities.

## Relative Weighted Block-Core Criterion

Let `Z` be a braided quotient of `X` already dominated by a finite rack
`Y_Z`, and put

```text
Q=Y_Z^0 x T_2.
```

Let

```text
G^X_n = rho^X_n(F_{n-1}),
E_n = ker(G^X_n -> G^Z_n),
M_{i,n}=<<rho^X_n(x_i)>>_{G^X_n}.
```

Define

```text
Omega_{n,s}^{X,wt}
  =
Omega_s(G^X_n;M_{1,n},...,M_{n-1,n}).
```

Theorem.  If there is a fixed `s>=2` such that

```text
E_n cap Omega_{n,s}^{X,wt}=1
```

for all sufficiently large `n`, then `X` is dominated by one finite rack.

In particular, it is enough to prove

```text
E_n cap Omega_{n,3}^{X,wt}=1
```

for all sufficiently large `n`.  It is also enough to prove the sharper
intersection condition

```text
E_n cap (Omega_{n,2}^{X,wt} cap Omega_{n,3}^{X,wt})=1
```

for all sufficiently large `n`.

Proof.  Let `gamma in K_n cap C_n`, and choose `beta in F_{n-1}` with
`Phi_n(beta)=gamma`.  Since `gamma in K_n`, the `Q` action of `beta` is
trivial.  Because `Q` contains a rack detector dominating `Z`, the `Z` action
of `beta` is trivial.  Hence

```text
rho^X_n(beta) in E_n.
```

Also `gamma in C_n`, so after projecting to `G^X_n`,

```text
rho^X_n(beta) in [M_{1,n},...,M_{n-1,n}]_Sigma.
```

By the multiplicity-preserving containment theorem,

```text
[M_{1,n},...,M_{n-1,n}]_Sigma
  <= Omega_{n,s}^{X,wt}.
```

Therefore

```text
rho^X_n(beta) in E_n cap Omega_{n,s}^{X,wt}=1.
```

Thus `gamma in K_n cap L_n`.  Since

```text
Gamma_n <= Sym(Q^n) x Sym(X^n),
```

the projection kernels satisfy `K_n cap L_n=1`, so `gamma=1`.  Hence
`K_n cap C_n=1` for all sufficiently large `n`, and fixed-arity rack
cofinality handles the remaining finitely many arities.

## Comparison With Previous Criteria

The previous triple-block criterion asked for

```text
E_n cap Theta^X_{n,3}=1.
```

The weighted criterion asks only for

```text
E_n cap Omega_{n,3}^{X,wt}=1.
```

Since

```text
Omega_{n,3}^{X,wt} <= Theta^X_{n,3},
```

this is strictly weaker in general.  Also,

```text
Omega_{n,3}^{X,wt} <= gamma_{n-1}(G^X_n),
```

so the weighted criterion is weaker than the lower-central condition

```text
E_n cap gamma_{n-1}(G^X_n)=1.
```

A true all-meridian Brunnian obstruction is not merely a triple-block
commutator and not merely a lower-central element of weight `n-1`; it is a
support-complete weight-`n-1` element that survives every multiplicity
preserving block collapse.

## Chief-Factor Consequence

Suppose a finite-image failure occurs, so

```text
K_n cap C_n != 1.
```

Then every chief factor detected by this failure is covered not merely by
`Theta_{n,3}`, but by every weighted three-block commutator

```text
[N_{A,n}^(|A|),N_{B,n}^(|B|),N_{C,n}^(|C|)]_Sigma^wt
```

for every partition `{A,B,C}` of `{1,...,n-1}`.

Thus a central high-Brunnian obstruction cannot be a bounded-depth central
triple-commutator artifact.  It must be a prime-order central factor covered
by all multiplicity-preserving three-block commutators of total length `n-1`.

## Remaining Boundary

To prove Sawin's statement by this route, it is enough to prove that for every
finite bijective `X` there is a finite rack detector

```text
Q=Y^0 x T_2
```

such that, for all sufficiently large `n`,

```text
K_n cap Omega_{n,3}^wt=1.
```

A sharper sufficient target is

```text
K_n cap (Omega_{n,2}^wt cap Omega_{n,3}^wt)=1.
```

Equivalently, in the quotient formulation, it is enough to find a dominated
braided quotient `Z` of `X` such that

```text
E_n cap Omega_{n,3}^{X,wt}=1
```

for all sufficiently large `n`, or more sharply

```text
E_n cap (Omega_{n,2}^{X,wt} cap Omega_{n,3}^{X,wt})=1.
```

A cofinal counterexample must therefore produce, for every finite rack prefix
`P_m`, unbounded arities `n_m`, and nontrivial elements

```text
1 != gamma_m in K_{n_m} cap C_{n_m}.
```

Such elements automatically satisfy

```text
gamma_m in K_{n_m} cap Omega_{n_m,3}^wt
```

and even

```text
gamma_m in K_{n_m} cap (Omega_{n_m,2}^wt cap Omega_{n_m,3}^wt).
```

So defeating the unweighted triple core is still insufficient.  A genuine
obstruction must survive every multiplicity-preserving block collapse.
