# Ordinary Brunnian Sharpening

Date: 2026-06-06

This note sharpens the fully deletion-minimal `X`-Brunnian reduction to an
ordinary Brunnian reduction.  It also records one closed positive class:
finite solutions whose last-strand pure braid images have uniformly bounded
nilpotency class.

This is still a C-type result.  It does not prove Sawin's statement for all
finite degenerate solutions and does not produce a no-rack counterexample.

## Ordinary Brunnian Reduction

Let `X` be a finite bijective YBE solution, let `Y` be a finite rack, and set

```text
Q = Y^0 x T_2,
```

where `Y^0` is the transparent extension and `T_2` is the two-element trivial
rack.  Let

```text
Brun_n = { beta in P_n : partial_I beta=1 for every proper I subsetneq {1,...,n} }
```

be the ordinary Brunnian subgroup.

Theorem.  `Q` dominates `X` if and only if

```text
Brun_n cap ker rho^Q_n <= ker rho^X_n
```

for every `n>=2`.

Proof.  The forward implication is immediate.  Conversely, suppose `Q` fails
to dominate `X`.  By `proofs/fully_brunnian_core_reduction.md`, choose a
minimal-arity witness

```text
beta in ker rho^Q_n,
rho^X_n(beta) != 1,
```

whose every proper deletion is both `Q`-invisible and `X`-invisible.  Put

```text
K_m = ker rho^Q_m cap ker rho^X_m.
```

Thus every proper deletion of `beta` lies in the relevant `K_m`.

Let `d_i:P_n -> P_{n-1}` delete the `i`-th strand and let
`s_i:P_{n-1} -> P_n` insert a new trivial strand in the `i`-th position.  The
standard face-section identities are

```text
d_i s_i = id,
d_i s_j = s_{j-1} d_i        for i<j,
d_i s_j = s_j d_{i-1}        for i>j.
```

Insertion preserves `K`: if `gamma in K_m`, then `s_i(gamma) in K_{m+1}`,
because the inserted strand has no crossings and the braid acts as `gamma` on
the other coordinates.  Normality of each `K_m` is automatic because it is an
intersection of representation kernels.

Normalize `beta` by killing one-strand deletions from right to left.  Set
`beta^(n)=beta`.  Given `beta^(j)`, define

```text
a_j = d_j beta^(j),
beta^(j-1) = beta^(j) s_j(a_j)^-1.
```

Maintain the induction invariant:

1. `beta^(j)` has the same `X`- and `Q`-actions as `beta`;
2. every proper deletion of `beta^(j)` lies in the appropriate `K`;
3. all one-strand faces `d_i beta^(j)` with `i>j` are already trivial.

Since `a_j` is a proper deletion of `beta^(j)`, it lies in `K_{n-1}`, so
`s_j(a_j)` lies in `K_n`.  Multiplying by `s_j(a_j)^-1` preserves the `X`- and
`Q`-actions.  Also

```text
d_j beta^(j-1) = a_j a_j^-1 = 1.
```

If `i>j` was already killed, then

```text
d_i s_j(a_j) = s_j d_{i-1} a_j
             = s_j d_{i-1} d_j beta^(j)
             = s_j d_j d_i beta^(j)
             = 1,
```

so the face `d_i` remains killed.  For not-yet-killed faces, the new deletion
is a product of an old deletion in `K` and an insertion of a further proper
deletion in `K`, hence remains in `K`.  This step does not assume arbitrary
deletion-closure of `ker rho^X`; it uses only the maintained tower of proper
deletions of the current witness.

At the end, `alpha=beta^(0)` satisfies `d_i alpha=1` for every `i`, hence
`alpha in Brun_n`.  It differs from `beta` by a product of elements of `K_n`,
so

```text
rho^Q_n(alpha)=1,
rho^X_n(alpha)=rho^X_n(beta) != 1.
```

Thus any domination failure produces an ordinary Brunnian `X`-visible witness
in `ker rho^Q_n`, proving the contrapositive.

## Cofinal Consequence

Let `R_1,R_2,...` enumerate finite rack isomorphism classes and define

```text
P_m = R_1 x ... x R_m,
Q_m = P_m^0 x T_2.
```

If no finite rack dominates `X`, then for every `m` there are `n_m` and
`beta_m` such that

```text
beta_m in Brun_{n_m},
rho^{Q_m}_{n_m}(beta_m)=1,
rho^X_{n_m}(beta_m) != 1.
```

Moreover `n_m -> infinity` by fixed-arity rack cofinality.

## Uniformly Nilpotent Last-Strand Images

Let

```text
F_{n-1} = ker(d_n:P_n -> P_{n-1}).
```

By the Fadell-Neuwirth splitting, `F_{n-1}` is the free group generated by

```text
A_{1n}, A_{2n}, ..., A_{n-1,n}.
```

Theorem.  Suppose there is a constant `c` such that, for every `n`, the group

```text
rho^X_n(F_{n-1})
```

is nilpotent of class at most `c`.  Then `X` is dominated by a finite rack.

Proof.  By fixed-arity rack cofinality, for each `2<=k<=c+1` choose a finite
rack `Z_k` such that

```text
ker rho^{Z_k}_k <= ker rho^X_k.
```

Let `Y_0=prod_{k=2}^{c+1} Z_k` and set

```text
Q = Y_0^0 x T_2.
```

For `n<=c+1`, any braid in `ker rho^Q_n` is in `ker rho^{Y_0}_n`, hence in
`ker rho^X_n` by construction.

For `n>c+1`, let `beta in Brun_n`.  Since `d_n beta=1`, `beta in F_{n-1}`.
Inside the free group

```text
F_{n-1}=<A_{1n},...,A_{n-1,n}>,
```

the deletion `d_i beta=1` means `beta` becomes trivial after killing the
generator `A_{in}`.  Hence

```text
beta in intersection_i <<A_{in}>>.
```

For a free group `F_r=<x_1,...,x_r>`,

```text
intersection_i <<x_i>> <= gamma_r(F_r),
```

where `gamma_r` is the `r`-th lower central subgroup.  One proof is the
Magnus expansion: a nonzero term of degree `<r` omits some variable and
therefore survives after killing that omitted variable.

Thus `beta in gamma_{n-1}(F_{n-1})`.  Since `n-1>c`, the image of this element
under `rho^X_n` is trivial because `rho^X_n(F_{n-1})` has nilpotency class at
most `c`.

Therefore all ordinary Brunnian elements in arity `n>c+1` are `X`-trivial,
and arities `n<=c+1` are handled by the finite rack product above.  The
ordinary Brunnian reduction shows that the finite rack `Q=Y_0^0 x T_2`
dominates `X`.

The dominator supplied by this theorem is `Q`, not necessarily the unextended
product `Y_0`.

## Remaining Boundary

A genuine counterexample must now supply, for every finite rack prefix `Q_m`,
an unbounded sequence

```text
beta_m in Brun_{n_m},
rho^{Q_m}_{n_m}(beta_m)=1,
rho^X_{n_m}(beta_m) != 1.
```

By the uniformly nilpotent criterion, such an `X` must have last-strand pure
images `rho^X_n(F_{n-1})` with unbounded nilpotent complexity capable of
detecting elements in `gamma_{n-1}(F_{n-1})`.
