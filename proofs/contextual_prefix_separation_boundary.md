# Contextual Prefix Separation Boundary

Date: 2026-06-05

This note records the audit of the two-sided contextual prefix rack `C_L(X)`.
The contextual rack is a genuine improvement over the normalized one-sided
prefix rack `W_L(X)`, but it still leaves a new finite/profinite separation
lemma rather than closing Sawin's problem.

## Validity Of `C_L(X)`

Let

```text
S=S_L^1
```

be the finite monoid generated by the left maps `L_x`, with identity adjoined.
Define `C_L(X)` as the rack generated by

```text
c_{p,x,q}        (p,q in S, x in X)
```

with relations, for `r_X(x,y)=(u,v)`,

```text
c_{p,u,L_v q} = c_{pL_x,y,q},                              (C1)
c_{pL_u,v,q} = c_{pL_x,y,q} triangleright c_{p,x,L_y q}.   (C2)
```

The only product identity needed is

```text
L_xL_y=L_uL_v,
```

which follows from the YBE by comparing first coordinates.

For a word `w=(x_1,...,x_n)`, define

```text
p_i=L_{x_1}...L_{x_i},       p_0=1,
q_i=L_{x_{i+1}}...L_{x_n},   q_n=1.
```

Then

```text
Theta_n(w)=
(c_{p_0,x_1,q_1}, c_{p_1,x_2,q_2}, ..., c_{p_{n-1},x_n,q_n}).
```

For a local crossing at context `(p,q)`, with `r_X(x,y)=(u,v)`, the labels
before the crossing are

```text
A=c_{p,x,L_y q},
B=c_{pL_x,y,q}.
```

After the crossing they are

```text
A'=c_{p,u,L_v q},
B'=c_{pL_u,v,q}.
```

Relations `(C1),(C2)` give

```text
A'=B,
B'=B triangleright A.
```

Thus

```text
(A',B')=(B,B triangleright A),
```

so `Theta_n` is `B_n`-equivariant under the rack convention

```text
r_Y(a,b)=(b,b triangleright a).
```

Away from the crossing, labels are unchanged because `L_xL_y=L_uL_v`.

## Universal Property

For any rack `Y`, maps

```text
psi:S x X x S -> Y
```

satisfying

```text
psi(p,u,L_vq)=psi(pL_x,y,q),
psi(pL_u,v,q)=psi(pL_x,y,q) triangleright psi(p,x,L_yq)
```

are exactly rack homomorphisms

```text
C_L(X) -> Y
```

sending `c_{p,x,q}` to `psi(p,x,q)`.

Thus `C_L(X)` is the universal rack making two-sided contextual prefix labels
braid-equivariant.

## Domination From Contextual Separation

Let

```text
phi:C_L(X) -> Y
```

be a finite rack quotient.  If for every `n`, the induced labels

```text
Theta_n^Y=phi^n Theta_n
```

separate distinct points inside every `B_n`-orbit of `X^n`, then

```text
ker rho_n^Y <= ker rho_n^X
```

for all `n`.

Indeed, if `beta in ker rho_n^Y`, then

```text
Theta_n^Y(rho_n^X(beta)w)=Theta_n^Y(w),
```

and `rho_n^X(beta)w` lies in the same braid orbit as `w`.  Orbitwise
separation forces `rho_n^X(beta)w=w`.

Equivalently, add the finite inert orbit observer `X^n/B_n` and require
injectivity of `(Theta_n^Y,iota_n)`.

## Strictly Stronger Than `W_L(X)`

The one-sided prefix rack collapses because equivariance forces

```text
psi(pL_z,x)=psi(p,L_z(x)),
```

and hence `psi(p,x)=psi(1,p(x))`.

For `C_L(X)`, applying `(C1)` to

```text
r_X(z,x)=(L_z(x),R_x(z))
```

gives

```text
c_{pL_z,x,q}=c_{p,L_z(x),L_{R_x(z)}q}.
```

Thus moving a prefix letter through the marked letter changes the right
context.  Prefix data is transported rather than discarded.

Iterating gives a scattering-normalized form

```text
c_{p,x,q}=c_{1,p(x),Delta(p,x)q},
```

where `Delta(p,x)` is the product of right-escape letters produced by sliding
a word representative of `p` through `x`.  Different representatives of the
same transformation `p` may impose further relations, but the label generally
still depends on residual right context.  It does not generally collapse to
`W_L(X)`.

A concrete finite witness is the trivial rack on `S`, denoted `T_S`.  Define

```text
tau:C_L(X) -> T_S,
tau(c_{p,x,q})=pL_xq.
```

For `(C1)`,

```text
pL_uL_vq=pL_xL_yq.
```

For `(C2)`, the trivial rack operation sends the right side to the label of
`c_{p,x,L_yq}`, again `pL_xL_yq`.  Thus `tau` is a rack homomorphism.

The quotient `tau` records the total product `pL_xq`.  The normalized rack
`W_L(X)` only sees `p(x)`.  Therefore if

```text
p(x)=p'(x')
but
pL_xq != p'L_{x'}q',
```

then `W_L(X)` cannot distinguish the contextual generators, while `C_L(X)`
can already distinguish them through `T_S`.

For actual word labels, however,

```text
p_{i-1}L_{x_i}q_i = L_{x_1}...L_{x_n}
```

for every coordinate `i`.  Therefore `tau Theta_n(w)` is just the product
observer repeated in every coordinate, so `tau` alone does not solve Sawin.

## What `C_L(X)` Still Loses

`C_L(X)` does not retain the raw full prefix arrow

```text
p --x--> pL_x.
```

An ordinary rack crossing forces the first output label to equal the second
input label.  Thus any ordinary rack detector must identify, at the label
level,

```text
(p,u,right context)  with  (pL_x,y,right context),
```

which is exactly `(C1)`.

So the hierarchy is

```text
full prefix path groupoid -> C_L(X) -> W_L(X).
```

The first arrow loses the raw distinction between the first output arrow and
the second input arrow in a crossing.  The second forgets the right context and
collapses to normalized prefix evaluation.

## Associated Group And Profinite Obstruction

Let

```text
R=C_L(X),
G_C(X)=As(R).
```

Since `R` is generated by the finite set

```text
A_C=S x X x S,
```

`G_C(X)` has the finite Wirtinger-type presentation with generators
`g_{p,x,q}` and relations

```text
g_{p,u,L_vq}=g_{pL_x,y,q},                              (G1)
g_{pL_u,v,q}=g_{pL_x,y,q} g_{p,x,L_yq} g_{pL_x,y,q}^{-1}.   (G2)
```

For

```text
alpha=(p,x,q),
bar alpha=c_{p,x,q},
```

let

```text
H_alpha=Stab_{G_C(X)}(bar alpha).
```

Define contextual finite-rack residual equivalence by

```text
alpha ==_{C,fin} beta
```

if every homomorphism from `C_L(X)` to a finite rack identifies the two
contextual generators.

If `bar beta=g.bar alpha`, then

```text
alpha ==_{C,fin} beta
iff
g in closure_prof(H_alpha)
iff
g in intersection_{N normal finite index in G_C(X)} H_alpha N.
```

If `bar alpha` and `bar beta` lie in different `G_C(X)`-orbits, they are
separated by the finite trivial rack of orbits.  No residual finiteness of
`G_C(X)` is assumed.

The orbitwise bad-pair obstruction is:

```text
there exist n, w, beta with w'=rho_n^X(beta)w != w
such that alpha_i(w) ==_{C,fin} alpha_i(w') for every i,
```

where

```text
alpha_i(w)=(p_{i-1}(w),x_i,q_i(w)).
```

Equivalently, for every coordinate, the contextual generators are equal in all
finite rack quotients, possibly because a transporter lies in a profinite
stabilizer closure but not in the stabilizer itself.

## Local Contextual Obstruction

At a local crossing, the labels are

```text
A=c_{p,x,L_yq},
B=c_{pL_x,y,q}.
```

The crossing is invisible to every finite quotient of `C_L(X)` if

```text
A ==_{C,fin} B
and
B triangleright A ==_{C,fin} B.
```

If this occurs with `r_X(x,y)!=(x,y)` and the context `(p,q)` occurs inside a
word, then the braid generator gives an orbit-relevant bad pair.  Replacing
`==_{C,fin}` by equality gives the universal-level obstruction; using
`==_{C,fin}` gives the profinite obstruction.

## Active Factors Are Not Automatic

Failure of contextual separation gives relations among triples

```text
(p,x,q).
```

These relations depend on both left and right context.  They do not define a
coordinatewise relation on `X`, and hence do not automatically define a YBE
quotient of `X`.

Inside one braid orbit, inert observers cannot help because they are constant
on the orbit.  A contextual collapse gives active coordinates only if it can
be promoted to a coherent finite state-dependent YBE factor.

The relevant state-dependent condition is: there exists a finite bijective YBE
solution `Z` and maps

```text
pi_{p,q}:X -> Z
```

such that, for every `r_X(x,y)=(u,v)`,

```text
r_Z(pi_{p,L_yq}(x), pi_{pL_x,q}(y))
 =
(pi_{p,L_vq}(u), pi_{pL_u,q}(v)).
```

Then

```text
Pi_n(w)=
(pi_{p_0,q_1}(x_1), ..., pi_{p_{n-1},q_n}(x_n))
```

is `B_n`-equivariant.  If `(Pi_n,eta_n)` is injective for suitable inert
observers, then

```text
ker rho_n^Z <= ker rho_n^X.
```

But the existence of such a `Z` does not follow from failure of contextual
rack separation.

## Comparisons

There is a natural rack homomorphism

```text
C_L(X) -> W_L(X),
c_{p,x,q} -> b_{p(x)}.
```

Relation `(C1)` maps to `b_{p(u)}=b_{pL_x(y)}` and `(C2)` maps to the defining
relation

```text
b_{pL_u(v)}=b_{p(u)} triangleright b_{p(x)}
```

of `W_L(X)`.  Thus `W_L(X)` is a quotient of `C_L(X)`.

The suffix Hurwitz rack `U_L(X)` has generators `[t,x]` and relations

```text
[L_vt,u]=[t,y],
[t,v]=[L_yt,x] triangleright [t,y].
```

Forgetting the left context in `C_L(X)` superficially matches the first
relation, but the second relation has the rack factors in the opposite order:

```text
[q,v]=[q,y] triangleright [L_yq,x]
```

instead of

```text
[q,v]=[L_yq,x] triangleright [q,y].
```

Therefore `C_L(X)` is not canonically `U_L(X)` and should be treated as a
separate two-sided contextual rack.

Relative to the full prefix path groupoid, `C_L(X)` keeps a marked transition
together with right context but imposes the rack-forced identification `(C1)`.
It is closer to escape-rack/minimal-ideal holonomy than `W_L(X)`, but it is
still a quotient of the full raw path data.

## Rees Sandwich Data

If a minimal ideal has Rees matrix form

```text
M(G_0;I_0,Lambda;P),
```

and

```text
p=(i,g,lambda),
L_x=(j_x,h_x,mu_x),
q=(j_q,k,nu),
```

then

```text
pL_xq
```

contains the sandwich factors

```text
P_{lambda j_x}
and
P_{mu_x j_q}.
```

The one-sided normalized label `p(x)` may lose this data.  The contextual
label `c_{p,x,q}` keeps both `p` and `q` before quotienting, so it can encode
incoming and outgoing sandwich information.  Still, retaining that data
universally does not imply finite rack quotients separate it; profinite
stabilizer obstructions remain.

## Positive Group-Theoretic Cases

The associated group `G_C(X)=As(C_L(X))` is finitely presented of Wirtinger
type.  That alone does not imply residual finiteness or subgroup separability.

Sufficient positive cases include:

```text
C_L(X) finite as a rack;
G_C(X) virtually polycyclic;
G_C(X) virtually free;
G_C(X) virtually special with quasiconvex relevant stabilizers.
```

If `R` is a finite rack, then `As(R)` maps to the finite group `Inn(R)` with
central kernel.  Since `As(R)` is finitely generated, this kernel is finitely
generated abelian; hence `As(R)` is virtually abelian and relevant stabilizers
are separable.

No such group-theoretic property follows merely from the current residual
rigid hypotheses.

## Current Endpoint

The contextual route gives the exact reduction:

```text
If for every n and every distinct same-orbit w,w' in X^n, some coordinate
alpha_i(w) is not ==_{C,fin} alpha_i(w'), then X is dominated by a finite rack.
```

Equivalently, the missing lemma is:

```text
For residual rigid X with no proper domination-reducing active factor, all
orbit-relevant stabilizer cosets in As(C_L(X)) are separated in finite
quotients, and no same-orbit contextual bad pair exists.
```

This is stronger than the `W_L(X)` route, but it is still a new independent
finite/profinite separation barrier, not a completed proof of Sawin.
