## Theorem/Proof Content

The following claims are valid progress.

1. Weighted block-core containment.  For normal subgroups
   `N_1,...,N_r triangleleft G`, define

   ```text
   [H_1^(m_1),...,H_s^(m_s)]_Sigma^wt
   ```

   as the subgroup generated by fully parenthesized commutators with exactly
   `m_j` entries from `H_j`.  For a partition
   `P={S_1,...,S_s}`, define the weighted core

   ```text
   Omega_s(G;N_1,...,N_r)
     =
   intersection_P
   [N_{S_1}^(|S_1|),...,N_{S_s}^(|S_s|)]_Sigma^wt.
   ```

   Then

   ```text
   [N_1,...,N_r]_Sigma <= Omega_s(G;N_1,...,N_r)
   ```

   for every `2<=s<=r`.

2. Relation to the previous block-core target.  The weighted core satisfies

   ```text
   Omega_s(G;N_1,...,N_r) <= Theta_s(G;N_1,...,N_r)
   ```

   and

   ```text
   Omega_s(G;N_1,...,N_r) <= gamma_r(G).
   ```

   Therefore

   ```text
   C <= Omega_3 <= Theta_3 cap gamma_r <= Theta_3.
   ```

3. Strictness.  The example `G=UT_4(F_p)` with
   `N_1=N_2=N_3=N_4=G` is sound: the unweighted triple core is
   `gamma_3(G)`, while the weighted triple core is `gamma_4(G)=1`.  Since
   `gamma_3(G)!=1`, weighted block-core vanishing is strictly weaker than
   unweighted triple-core vanishing in general.

4. Finite-image consequence.  In the finite-image setup with `r=n-1`,

   ```text
   C_n <= Omega_{n,s}^wt <= Theta_{n,s}
   ```

   and

   ```text
   Omega_{n,s}^wt <= gamma_{n-1}(Gamma_n).
   ```

   Hence the sufficient condition `K_n cap Theta_{n,3}=1` can be replaced by

   ```text
   K_n cap Omega_{n,3}^wt=1.
   ```

   Since `C_n` lies in every weighted core, the smaller condition

   ```text
   K_n cap (Omega_{n,2}^wt cap Omega_{n,3}^wt)=1
   ```

   also suffices.

5. Relative weighted quotient criterion.  For a dominated braided quotient
   `Z`, with

   ```text
   E_n=ker(G^X_n -> G^Z_n),
   M_{i,n}=<<rho^X_n(x_i)>>_{G^X_n},
   ```

   if, for fixed `s>=2`,

   ```text
   E_n cap Omega_s(G^X_n;M_{1,n},...,M_{n-1,n})=1
   ```

   for all sufficiently large `n`, then one finite rack dominates `X`.  The
   proof correctly projects `K_n cap C_n` into both `E_n` and the weighted
   `X`-block core, then uses `K_n cap L_n=1`.

6. Chief-factor sharpening.  Any finite-image failure chief factor is covered
   by every multiplicity-preserving three-block commutator of total length
   `n-1`; in particular, a central Type C obstruction cannot be only a
   bounded-depth triple-commutator artifact.

## Heuristic Content

The useful heuristic is that genuine all-meridian Brunnian obstructions retain
total commutator weight `n-1` after block collapse.  Unweighted triple-core
conditions may retain bounded-depth artifacts that cannot come from
all-meridian support.

## Extracted Progress

The next theoretical target is now:

```text
exists Q=Y^0 x T_2 such that, for all sufficiently large n,
K_n cap Omega_{n,3}^wt=1.
```

The sharper sufficient target is:

```text
K_n cap (Omega_{n,2}^wt cap Omega_{n,3}^wt)=1.
```

Equivalently, through a dominated quotient:

```text
E_n cap Omega_{n,3}^{X,wt}=1
```

or the corresponding intersection with `Omega_{n,2}^{X,wt}`.

A negative answer must still produce cofinal nontrivial elements in
`K_n cap C_n`.  It is not enough to produce elements in the unweighted
triple core or in a weighted core unless they are proved to come from the
all-meridian symmetric commutator.
