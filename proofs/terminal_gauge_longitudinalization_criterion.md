# Terminal gauge longitudinalization criterion

Date: 2026-05-29

This note follows `proofs/green_balanced_defect_gauge_decomposition.md`.  It
does not prove the Master Local-Minimal Residual Theorem.  It records the
exact certificate format for the remaining terminal gauge/unit holonomy
target.

The balanced Green decomposition shows that raw Green/Schutzenberger row
defects are Artin-visible commutators times terminal gauge boundaries.  Thus
the remaining local theorem must prove that those terminal gauge boundaries
lie in the longitude-value subgroup of one fixed finite endpoint/unit detector
group.

## Terminal gauge telescope

Let `U` be one fixed finite gauge group.  Along a physical strand or a moving
Green/Schutzenberger chart, suppose the successive chart labels are

```text
g_0, g_1, ..., g_t in U.
```

Define the chronological second-output gauge increments by

```text
s_k = g_k g_{k-1}^-1       for k=1,...,t.
```

Then, with the newest factor on the left,

```text
s_t ... s_1 = g_t g_0^-1.
```

Proof.  Substitute the definition:

```text
g_t g_{t-1}^-1 * g_{t-1} g_{t-2}^-1 * ... * g_1 g_0^-1
  = g_t g_0^-1.
```

This is the terminal gauge endpoint.  In a moving chart, the transported
version is the same statement after the chart transport has already been
included in the supplied labels or gauge increments.

## Longitude certificate criterion

For a residual braid `beta in B_n`, let

```text
S_beta = g_t g_0^-1 in U
```

be the terminal gauge endpoint.

It is enough to give one of the standard endpoint certificates already used
elsewhere in the repository:

1. a recursive-longitude expression

   ```text
   S_beta =
     phi(L_{i_1}(beta))^{epsilon_1}
     ...
     phi(L_{i_r}(beta))^{epsilon_r}
   ```

   for a homomorphism `phi:F_n -> U`;

2. a literal subgroup witness in `V_beta(U)`, whose letters may use different
   assignments `F_n -> U`;

3. an Artin-defect display, which the Artin-defect sieve converts to a
   literal subgroup witness; or

4. in finite abelian gauge quotients, a matrix witness in the subgroup
   generated by `a^{m_ij}` from the recursive-longitude exponent matrix.

Any of these proves

```text
S_beta in V_beta(U).
```

If

```text
Lambda_{U,n}(beta)=Lambda_{U,n}(1),
```

then `V_beta(U)` is the identity subgroup, so the terminal gauge endpoint is
trivial.  Thus the chart labels agree at the terminal and initial endpoints
inside this fixed gauge factor.

## Product detector version

For finitely many fixed gauge factors

```text
U_1,...,U_r,
```

the terminal endpoints assemble into one product endpoint

```text
(S_{1,beta},...,S_{r,beta}) in U_1 x ... x U_r.
```

The direct-product longitude lemma gives

```text
V_beta(U_1 x ... x U_r)
  = V_beta(U_1) x ... x V_beta(U_r).
```

Therefore factorwise terminal gauge certificates assemble into a certificate
in one fixed product detector.  This is the form required by the sharp
obstruction theorem: the detector group is fixed by the interval and has no
braid-index parameter.

## Remaining theorem burden

The criterion does not assert that the required terminal gauge certificates
exist in every local-minimal interval.  It makes the remaining A-route target
precise:

```text
Terminal gauge longitudinalization.
For every local-minimal bi-free universal-corridor interval, every transported
terminal gauge endpoint in the fixed Green/Schutzenberger/kernel-block/unit
gauge factors has one of the certificates above, in factors independent of n.
```

If this theorem is proved, the Green/Schutzenberger part closes:

1. the balanced decomposition removes Artin-visible commutator parts;
2. this criterion kills the remaining terminal gauge endpoints;
3. atom-inner factors are already handled once atom descent/totality gives a
   rack-like atom quotient;
4. endpoint/unit factors assemble into one fixed product detector
   `H(pi,Q)`; and
5. the sharp obstruction theorem gives the local rack factor `Q x A_H`.

If the theorem fails, outcome B still requires more than a fixed-word gauge
miss: the failure must be upgraded to a normalized-law sequence invisible to
every finite group while moving an explicit residual tuple.

The principal finite rack-extension subcase is now isolated in
`proofs/principal_gauge_extension_detector.md`.  When a lower gauge row has
the form `(a,r)*(b,s)=(a*b,c(a,b)s)`, the YBE supplies the nonabelian
rack-cocycle identity for `c`; the finite rack `A x U` then has inner group
`Inn(A x U)`, which is a fixed detector for that principal terminal gauge
holonomy.  The remaining structural burden is nonprincipal terminal gauge.
The follow-up `proofs/transport_state_rackification_detector.md` removes
that burden for every strand-continuing finite gauge row by enlarging the rack
state to `A x E`.  The remaining issue is descent separation: any lower
motion that is not strand-continuing must be visible in the Green or
Schutzenberger readout, rather than treated as endpoint gauge.

## Executable audit hooks

The code records this criterion through:

```text
terminal_gauge_telescoping_audit(...)
terminal_gauge_longitude_expression_audit(...)
terminal_gauge_product_longitude_expression_audit(...)
```

The first helper checks the telescope
`s_t ... s_1 = g_t g_0^-1`.  The expression helpers combine that telescope
with the existing endpoint-longitude expression certificates, including the
single product-detector witness used by
`endpoint_product_longitude_expression_audit(...)`.
