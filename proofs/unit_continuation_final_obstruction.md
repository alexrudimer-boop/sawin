# Unit-continuation final obstruction

Date: 2026-05-29

This note specializes the unit-factorization gate to the last constant-observer
universal-continuation case.  It does not prove the Master Local-Minimal
Residual Theorem.  It removes the nonunit half of the remaining continuation
case and states the exact unit-longitude theorem still needed.

## Final case

The remaining constant-observer case is

```text
Theta^cont = Nabla
K^O = Nabla.
```

Thus second-output continuation changes generate the universal local
congruence, while every currently certified Green, Schutzenberger, atom, or
unit observer is fibrewise constant.

Fix a residual braid

```text
beta in N_n = ker rho_{Q,n}
```

and a base tuple `z`.  The residual action

```text
delta_{n,z}(beta)
```

is a permutation of the finite fibre product `X_z`.

In one completed-context continuation branch, write the coordinate motion as a
word in a fixed finite transition monoid:

```text
f_t ... f_1.
```

Each `f_i` is a total transformation of the relevant finite continuation state
set.

## Lemma: nonunit continuation cannot move a residual permutation branch

If the completed-context branch contributes to the residual action, then its
total composite is a permutation.  Hence every factor `f_i` in that branch is a
permutation.

Proof.  This is the unit-factorization lemma from
`proofs/unit_factorization_gate.md`.  For a total map `f` of a finite set, let
`rank(f)` be the size of its image.  Composition of total maps cannot increase
rank, so if

```text
f_t ... f_1
```

has full rank, every factor has full rank.  On a finite set, full rank is
bijectivity.  Therefore a residual branch whose final composite is a
permutation uses only unit/permutation factors.  QED.

Equivalently:

```text
Nonunit or reset-like continuation changes cannot be the final moving
obstruction.
```

They may appear in coarse observer data, but they cannot be the transformation
word that realizes a nontrivial residual permutation.

## Remaining endpoint group

Let `M_cont` be the fixed finite transition monoid generated by the
completed-context continuation sections in this constant-observer universal
corridor.  Let

```text
U_cont = U(M_cont)
```

be its unit group, i.e. the permutation elements of `M_cont`.

The only possible moving endpoint in this final case is a unit composite

```text
S_beta = f_t ... f_1 in U_cont.
```

The surviving theorem target is therefore:

```text
S_beta in V_beta(U_cont)
```

for every braid index `n`, every residual braid `beta in N_n`, every base
tuple `z`, and every completed-context continuation branch.

This is exactly the endpoint-unit criterion already isolated in
`proofs/unit_composite_longitude_criterion.md`: once a finite monoid observer
is fixed, the A-route must prove the residual unit endpoint belongs to the
longitude-value subgroup of the fixed unit group.  It may do this by any of
the accepted certificate formats:

1. an explicit recursive-longitude expression;
2. a literal subgroup witness in `V_beta(U_cont)`;
3. an Artin permutation-defect display;
4. an abelian matrix witness in a finite abelian quotient, when appropriate.

## Unit-continuation longitude theorem

The final make-or-break statement is:

```text
Unit-continuation longitude theorem.
For every local-minimal interval in the bi_free_universal_corridor_bottleneck
with Theta^cont = Nabla and K^O = Nabla, every residual completed-context
continuation unit endpoint S_beta in U_cont belongs to V_beta(U_cont).
```

If this theorem holds, the remaining case closes:

1. Nonunit continuation factors cannot occur in a moving residual permutation
   branch.
2. Unit continuation endpoints lie in `V_beta(U_cont)`.
3. Identity finite-`U_cont` longitude data kills pure continuation motion.
4. Strand-continuing gauge is already closed by transport-state rackification.
5. Green and Schutzenberger first-output defects have already been reduced to
   Artin-visible commutators plus terminal gauge boundaries.
6. Product-longitude calculus assembles all fixed detector factors into one
   finite `H(pi,Q)`.
7. The desired local implication follows:

```text
Lambda_{H(pi,Q),n}(beta)=Lambda_{H(pi,Q),n}(1)
  => Delta_n(beta)=1.
```

8. The sharp obstruction theorem supplies `Q x A_H`, and congruence-chain
   induction gives a finite rack independent of `n`.

## Exact B seed shape

A counterexample can no longer use any of the following as its decisive
obstruction:

- a non-strand-continuing row by itself;
- a nonunit or reset-like continuation label;
- a raw Green or Schutzenberger row defect;
- a bounded detector miss.

The only remaining B-seed shape in this channel is:

```text
S_beta notin V_beta(U_cont)
```

for a unit-continuation endpoint that can be upgraded to a normalized-law
sequence invisible to every finite group while still moving a residual tuple.
Without that normalized-law upgrade, a finite endpoint miss is not outcome B.
