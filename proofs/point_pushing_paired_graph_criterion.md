# Point-pushing paired graph criterion

Date: 2026-05-30

This note is the finite group-theoretic form of the marked quotient criterion.
It does not prove outcome A or B.  It removes one more layer of language:
the point-pushing detector question is exactly the question whether one paired
subgroup is the graph of a marked quotient map.

## Setup

Fix a finite group `G`, a finite bijective YBE solution `X`, and an arity
`k>=1`.  Put `n=k+1`.

Let

```text
D_k(G)=<d_1,...,d_k> <= Sym((G x G)^n)
```

be the Artin derivative detector image of the point-pushing pure braids

```text
A_{1,n},...,A_{k,n}.
```

Let

```text
P_k(X)=<h_1,...,h_k> <= Sym(X^n)
```

where

```text
h_i = rho_{X,n}(A_{i,n}).
```

Define the paired subgroup

```text
M_k(G,X)=< (d_i,h_i) : 1<=i<=k > <= D_k(G) x P_k(X).
```

Call

```text
V_k(G,X)=M_k(G,X) cap ({1} x P_k(X))
```

the vertical kernel.

## Theorem

The following are equivalent.

1. The marked quotient

   ```text
   D_k(G) -> P_k(X),
   d_i |-> h_i
   ```

   exists.

2. The paired subgroup `M_k(G,X)` is the graph of a homomorphism
   `D_k(G)->P_k(X)`.

3. The vertical kernel is trivial:

   ```text
   V_k(G,X) = {(1,1)}.
   ```

4. There is no word `w in F_k` such that

   ```text
   w(d_1,...,d_k)=1
   ```

   but

   ```text
   w(h_1,...,h_k) != 1.
   ```

## Proof

The projection

```text
pr_D:M_k(G,X)->D_k(G)
```

is surjective because the elements `(d_i,h_i)` project to the generators
`d_i` of `D_k(G)`.  Its kernel is exactly `V_k(G,X)`.

If `V_k(G,X)` is trivial, then `pr_D` is an isomorphism from `M_k(G,X)` onto
`D_k(G)`.  Define

```text
q_k:D_k(G)->P_k(X)
```

by

```text
q_k(d)=p
```

where `(d,p)` is the unique element of `M_k(G,X)` lying over `d`.  This is a
homomorphism because `M_k(G,X)` is a subgroup.  It sends every `d_i` to `h_i`,
and its image contains the generators `h_i`, so it is surjective onto
`P_k(X)`.  Thus the marked quotient exists.

Conversely, if a marked quotient `q_k:D_k(G)->P_k(X)` exists, then every
generator pair `(d_i,h_i)` lies in the graph of `q_k`.  Hence the subgroup
`M_k(G,X)` generated by those pairs is contained in the graph of `q_k`.  A
graph intersects `{1} x P_k(X)` only at `(1,1)`, so the vertical kernel is
trivial.

The equivalence with the word condition is just the presentation of the paired
subgroup by the free group `F_k`: a word `w` gives the pair

```text
(w(d_1,...,d_k), w(h_1,...,h_k)).
```

Thus a nontrivial vertical element is precisely a word trivial in `D_k(G)` but
nontrivial in `P_k(X)`.  QED.

## Consequence For B Certificates

A nontrivial vertical element gives a genuine point-pushing detector-kernel
mover.  If

```text
(1,p) in V_k(G,X),
p != 1,
```

and `w` is a word representing it, then

```text
alpha = iota_{k+1}(w)
```

satisfies

```text
alpha in K_G(k+1)
```

by the derivative detector criterion, while

```text
rho_{X,k+1}(alpha)=p != 1.
```

So for product-prefix groups `P_j=G_1 x ... x G_j`, vertical-kernel witnesses
for `M_{k_j}(P_j,X)` are exactly the point-pushing rows needed in the
normalized-law obstruction construction.

## Consequence For A Certificates

For a fixed finite group `G`, the detector rack `A_G` dominates `X` if and only
if, for every `k>=1`, the paired subgroup

```text
M_k(G,X) <= D_k(G) x P_k(X)
```

has trivial vertical kernel.  Equivalently, every paired subgroup is a graph.

This is often the most concrete finite target:

```text
prove no element (1,p), p!=1, can occur in M_k(G,X), uniformly in k.
```

The group `G` must still be fixed independently of `k` and braid index `n`.

## Audit Hook

The helper

```text
point_pushing_marked_quotient_audit(...)
```

generates the paired subgroup `M_k(G,X)` in finite arity and reports a witness
word as soon as it encounters a nontrivial vertical element.  Its
`vertical_kernel_trivial` field is exactly the finite-arithmetic form of the
criterion above, provided the subgroup enumeration is not truncated.

This helper remains an audit tool only.  A proof of A requires a symbolic
argument for all `k`; a proof of B requires an explicit infinite product-prefix
or symmetric-tail family of vertical-kernel witnesses.
