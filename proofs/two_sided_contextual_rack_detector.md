# Two-Sided Contextual Rack Detector

Date: 2026-06-05

This note records the stronger detector that survives the collapse of the
one-coordinate prefix rack `V_L(X)` to the normalized rack `W_L(X)`.  The
one-sided prefix route remains useful but has two independent barriers:

```text
normalized-prefix orbit faithfulness;
profinite stabilizer separability in As(W_L(X)).
```

The two-sided contextual prefix rack keeps both a left prefix and a right
suffix, and therefore retains more prefix-arrow and Rees sandwich data while
still using an ordinary rack crossing rule.

## Unavoidable One-Coordinate Collapse

Let `S=S_L^1`.  Suppose `Y` is a rack and

```text
psi:S x X -> Y
```

is a prefix coordinate label such that the label word

```text
Psi_n(x_1,...,x_n)
 =
(psi(p_0,x_1),...,psi(p_{n-1},x_n))
```

is `B_n`-equivariant under

```text
r_Y(a,b)=(b,b triangleright a).
```

For a local crossing at prefix `p`, write

```text
r_X(x,y)=(u,v).
```

Before the crossing the labels are

```text
psi(p,x), psi(pL_x,y).
```

After the crossing the labels are

```text
psi(p,u), psi(pL_u,v).
```

Rack equivariance forces

```text
psi(p,u)=psi(pL_x,y).
```

Since `u=L_x(y)`, this is

```text
psi(p,L_x(y))=psi(pL_x,y).
```

Iterating along any expression

```text
p=L_{z_1}...L_{z_k}
```

gives

```text
psi(p,x)=psi(1,p(x)).
```

Thus every one-coordinate prefix rack label factors through evaluation

```text
(p,x) -> p(x).
```

This is not a presentation artifact; it is forced by the rack crossing rule.

## Normalized Prefix Obstructions

For

```text
w=(x_1,...,x_n),
p_0=1,
p_i=L_{x_1}...L_{x_i},
```

define

```text
D_n(w)=(p_0(x_1),p_1(x_2),...,p_{n-1}(x_n)).
```

Every `V_L(X)` or `W_L(X)` detector factors through `D_n`.  If

```text
w != w',
w' in B_n.w,
D_n(w)=D_n(w'),
```

then no finite quotient of `V_L(X)` can separate `w` from `w'`, and the orbit
observer cannot help because the two words are in the same braid orbit.

A local one-generator obstruction occurs when, at prefix `p`,

```text
r_X(x,y)=(u,v),       (x,y) != (u,v),
p(x)=p(u)=pL_u(v).
```

Then the crossing changes the word but leaves the two normalized labels
unchanged; later normalized labels are also consistent because

```text
L_xL_y=L_uL_v.
```

Longer global `D_n` collisions may exist even when no single crossing is
locally `D`-null.

Such collisions do not automatically produce domination-reducing active
factors, because they are prefix-dependent rather than coordinatewise
YBE-compatible.

## State-Dependent Active Factor Criterion

A coherent state-dependent active factor consists of a finite YBE solution
`Z` and maps

```text
pi_p:X -> Z        (p in S)
```

such that, for every `p` and `r_X(x,y)=(u,v)`,

```text
r_Z(pi_p(x),pi_{pL_x}(y))
 =
(pi_p(u),pi_{pL_u}(v)).
```

Then

```text
Pi_n(x_1,...,x_n)
 =
(pi_{p_0}(x_1),...,pi_{p_{n-1}}(x_n))
```

is `B_n`-equivariant.  If there are inert observers `eta_n` such that

```text
(Pi_n,eta_n)
```

is injective for every `n`, then

```text
ker rho_n^Z <= ker rho_n^X
```

for all `n`.

If `Z` is itself a rack, the first-coordinate equality in the rack crossing
again forces a collapse analogous to `(V1)`.  To retain full arrow data, the
active state usually must be a non-rack YBE solution, or the rack label must
depend on more than the left prefix.

## Two-Sided Contextual Prefix Rack

Let `S=S_L^1`.  Define `C_L(X)` to be the rack generated by symbols

```text
c_{p,x,q}        (p,q in S, x in X)
```

with relations, for every `p,q in S` and `r_X(x,y)=(u,v)`,

```text
c_{p,u,L_v q} = c_{pL_x,y,q},                         (C1)
c_{pL_u,v,q} = c_{pL_x,y,q} triangleright c_{p,x,L_y q}.   (C2)
```

For a word

```text
w=(x_1,...,x_n),
```

define left prefixes and right suffixes

```text
p_i=L_{x_1}...L_{x_i},
q_i=L_{x_{i+1}}...L_{x_n},
```

with `p_0=1` and `q_n=1`.  Define

```text
Theta_n(w)
 =
(c_{p_0,x_1,q_1},
  c_{p_1,x_2,q_2},
  ...,
  c_{p_{n-1},x_n,q_n}).
```

## Equivariance

Consider a local segment `x,y` with left prefix `p` before `x` and right suffix
`q` after `y`.  Before the crossing, the labels are

```text
A=c_{p,x,L_y q},
B=c_{pL_x,y,q}.
```

After the crossing, with `r_X(x,y)=(u,v)`, the labels are

```text
A'=c_{p,u,L_v q},
B'=c_{pL_u,v,q}.
```

By `(C1)`,

```text
A'=B.
```

By `(C2)`,

```text
B'=B triangleright A.
```

Therefore

```text
(A',B')=(B,B triangleright A)=r_{C_L(X)}(A,B),
```

so `Theta_n` is `B_n`-equivariant.

Consequently, if `C_L(X)` has a finite rack quotient `Y` such that the induced
`Theta_n` labels separate distinct points inside every braid orbit, then

```text
ker rho_n^Y <= ker rho_n^X
```

for every `n`.

## Why It Is Stronger Than `W_L(X)`

The relation `(C1)` gives, for `r_X(z,x)=(L_z(x),R_x(z))`,

```text
c_{pL_z,x,q}=c_{p,L_z(x),L_{R_x(z)}q}.
```

Thus moving one generator from the prefix into the letter changes the right
context.  The prefix information is not simply discarded as in

```text
a_{pL_z,x}=a_{p,L_z(x)}.
```

This is the mechanism by which `C_L(X)` can retain more full-arrow data.

## Rees Sandwich Data

In a minimal ideal with Rees matrix form

```text
M(G_0;I_0,Lambda;P),
```

if

```text
p=(i,g,lambda),
L_x=(j_x,h_x,mu_x),
```

then

```text
pL_x=(i,g P_{lambda j_x} h_x, mu_x).
```

The full arrow

```text
p --x--> pL_x
```

remembers the source column `lambda`, the row `j_x`, and the sandwich entry
`P_{lambda j_x}`.  The normalized prefix label `p(x)` may lose this data.

The contextual rack `C_L(X)` is better suited to this issue because it keeps a
right context `q`; when prefix data is shifted across a crossing, the suffix
changes by the companion term `L_{R_x(z)}`.  This can carry data invisible in
`W_L(X)`.

## Current Reduced Theorems

The one-sided normalized route:

```text
If W_L(X) separates all normalized prefix labels needed inside braid orbits,
then X is rack-dominated.
```

Equivalently, one may assume normalized-prefix orbit faithfulness plus
profinite separability of the relevant stabilizers in `As(W_L(X))`.

The two-sided contextual route:

```text
If C_L(X) has a finite quotient whose Theta_n labels separate all distinct
points inside braid orbits, then X is rack-dominated.
```

This is currently the strongest rack-based modification of the prefix method
that still uses ordinary rack crossings.

The missing lemma is now the analogous finite separation statement for
`C_L(X)`, or an active-factor theorem explaining why failure of this
separation yields a proper domination-reducing active factor.
