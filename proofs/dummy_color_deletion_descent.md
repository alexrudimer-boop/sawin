# Dummy-color deletion descent

This note records the concrete progress from the latest same-chat Pro query on
the uniform rack-size endpoint.  The uniform bound is still open, but the
bounded rack kernels have a useful deletion descent: deleting strands lowers
the rack-size cutoff by one.

## Size-bounded rack kernels

For `s >= 1`, define

```text
D_s(n) = intersection_{|R| <= s} ker(rho^R_n),
```

where the intersection is over all finite racks of size at most `s`.  Equivalently,
if

```text
Q_s = product_{|R| <= s} R,
```

then

```text
D_s(n) = ker(rho^{Q_s}_n).
```

The two-point flip rack is included once `s >= 2`, so elements of `D_s(n)` are
pure for `s >= 2`.

## Theorem: Deletion Lowers The Cutoff

Let `T subset {1,...,n}` and let

```text
d_T:P_n -> B_|T|
```

be the standard pure-braid deletion map retaining only the strands in `T`.
For every `s >= 1`,

```text
beta in D_{s+1}(n)    =>    d_T(beta) in D_s(|T|).
```

Proof.  Fix a rack `R` with `|R| <= s`.  Form the dummy-color rack

```text
R^+ = R sqcup {*}
```

by using the original rack operation inside `R`, and setting all mixed
crossings with `*` to be flips:

```text
a * b       = a*b     for a,b in R,
a * *       = *,
* * a       = a,
* * *       = *.
```

This is the flip-across union of `R` with the one-point trivial rack, hence is
a rack of size at most `s+1`.

If `beta in D_{s+1}(n)`, then `beta` acts trivially on `(R^+)^n`.  Place
arbitrary `R`-colors on the retained strands `T`, and place the dummy color
`*` on all other strands.  Mixed crossings with dummy strands merely move the
dummy strands past the retained strands.  After deleting the dummy strands,
the retained-color history is exactly the `R`-rack action of `d_T(beta)`.
Since `beta` fixed the original `(R^+)^n` tuple, `d_T(beta)` fixes every
tuple in `R^|T|`.

This holds for every `R` with `|R| <= s`, so `d_T(beta) in D_s(|T|)`.

## Bounded Deletion Support Endpoint

For a finite YBE solution `X` and a pure braid `beta`, define the `X`-deletion
support by

```text
dsupp_X(beta)
  =
min { |T| : rho^X_|T|(d_T beta) != 1 },
```

with `dsupp_X(beta)=infinity` if no deletion is `X`-visible.

For each `h`, define `a_X(h)` to be the least size cutoff such that

```text
D_{a_X(h)}(k) <= ker rho^X_k      for every k <= h.
```

This number is finite because there are only finitely many `X`-visible braid
images in arities `k <= h`, and each visible braid is detected by some finite
rack by the pointwise conjugation-rack theorem in
`uniform_rack_size_endpoint.md`.

Now the deletion descent gives:

```text
beta in D_{a_X(h)+1}(n), rho^X_n(beta) != 1
  =>
dsupp_X(beta) > h.
```

Indeed, if some `|T| <= h` deletion were `X`-visible, then deletion descent
would give

```text
d_T(beta) in D_{a_X(h)}(|T|),
```

contradicting the definition of `a_X(h)`.

Thus a Sawin-negative sequence cannot merely be high-arity or Brunnian in the
ordinary braid group.  It must become deletion-essential for `X`: every
bounded-size deletion shadow is `X`-trivial.

## Positive Bounded-Support Lemma

The following single lemma would prove Sawin-positive.

```text
For every finite bijective YBE solution X, there exists h=h(X) such that
every beta in D_{a_X(h)+1}(n) with rho^X_n(beta) != 1 has an X-visible
deletion d_T(beta) with |T| <= h.
```

If this holds, then no `beta in D_{a_X(h)+1}(n)` can be `X`-visible: the
visible bounded deletion would contradict the definition of `a_X(h)` via the
dummy-color deletion descent.  Therefore

```text
D_{a_X(h)+1}(n) <= ker rho^X_n       for every n,
```

and the rack `Q_{a_X(h)+1}` dominates `X`.

## Finite Obstruction Group

For fixed `X,h,n`, set

```text
s = a_X(h)+1,
Q_s = product_{|R| <= s} R.
```

Since `Q_s` includes the two-point flip rack, `D_s(n)` is pure.  Use the
standard pure braid generators

```text
A_{ij}
  =
sigma_{j-1} ... sigma_{i+1} sigma_i^2
sigma_{i+1}^{-1} ... sigma_{j-1}^{-1},
1 <= i < j <= n.
```

For a subset `T`, deletion sends

```text
d_T(A_{ij}) =
  A_{rank_T(i),rank_T(j)}  if i,j in T,
  1                        otherwise.
```

Close the finite permutation group generated by

```text
(
  rho^{Q_s}_n(A_{ij}),
  rho^X_n(A_{ij}),
  (rho^X_|T|(d_T A_{ij}))_{|T| <= h}
).
```

Let `E_{X,h,n}` be the subgroup of `X^n`-permutations appearing in elements
whose `Q_s` coordinate and every bounded-deletion `X` coordinate are identity:

```text
E_{X,h,n}
  =
{ g_X : (1,g_X,(1)_T) occurs in the finite closure }.
```

Then

```text
E_{X,h,n} != 1
```

if and only if there is a braid

```text
beta in D_{a_X(h)+1}(n)
```

with `rho^X_n(beta) != 1`, but with every deletion to at most `h` strands
`X`-trivial.

The helper

```text
bounded_deletion_support_audit(X,h,n,s)
```

computes this finite obstruction with an explicit supplied rack cutoff `s`.
In the decisive application one takes `s=a_X(h)+1`; for small pressure tests,
the helper makes the obstruction group executable whenever the product rack
`Q_s` is small enough to build.

Thus:

```text
forall h exists n, E_{X,h,n} != 1
```

for one finite table `X` would give the normalized-law no-rack sequence.
Proving that `E_{X,h,n}=1` for all `n` once `h=h(X)` would give a finite rack
dominator.
