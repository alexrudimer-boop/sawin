# Universal corridor target

Date: 2026-05-28

This note refines the remaining branch after the coordinate-kernel closure
dichotomy.  It is a target statement, not a proof of the Master
Local-Minimal Residual Theorem.

## Setup

Let `pi : X -> Z` be a local-minimal interval with local maps

```text
T_{a,b}: A_a x A_b -> A_{a.b} x A_{a*b}.
```

Let `theta^ker` be the least admissible congruence family generated by the
nondegeneracy coordinate kernels

```text
y -> pr_1 T_{a,b}(x,y),
x -> pr_2 T_{a,b}(x,y).
```

The closure is generated by seed kernel pairs and their forward and inverse
transports through all local tables.  In a local-minimal interval,
`theta^ker` is equality or universal.

The equality case is the locally nondegenerate branch.  Hence the remaining
branch is:

```text
theta^ker = universal.
```

The companion elementary certificate is sharper than the aggregate closure:
`coordinate_kernel_pair_closure_audits(interval)` closes each distinct
nontrivial coordinate-kernel pair separately under every local table and
inverse local table.  In a local-minimal interval, any such elementary pair
has non-equality closure, hence its least admissible closure is universal.
Thus a universal corridor is not only generated by the set of all kernel
pairs together; every individual coordinate-kernel degeneracy already opens
an all-universal admissible corridor.

## Corridor Depth

The stable depth records how many transport rounds are needed after the seed
kernel graph is formed.

- Depth `0`: the seed coordinate-kernel graph already connects each fibre.
- Positive depth: some fibre connections require transporting seed pairs
  through local tables or inverse local tables.

The exhaustive size-2 and size-3 local-minimal congruence-cover scans show
only depth-`0` universal output-kernel corridors.  The translated affine
`F_2^2` audit shows that positive-depth corridors do occur: the `12`
local-minimal universal output-kernel affine rows have stable depth `1`.
All of those positive-depth rows are involutive.

These are finite diagnostics only.  They say that "positive corridor depth"
is not itself a counterexample signal.  A counterexample must carry residual
holonomy outside the known finite-G-measurable branches.

## A-Route Lemma Target

A complete proof can close this branch by proving the following symbolic
statement.

> Universal Corridor Residual Lemma.  Let `pi : X -> Z` be a local-minimal
> finite interval whose output coordinate-kernel closure is universal.  Then
> either the interval belongs to one of the known finite-G-measurable branches
> (involutive/permutation, an affine branch with a separate all-`n` detector
> proof, product-permutation, pairwise-linking, finite semidirect affine,
> coboundary, rack-type, or nondegenerate), or the
> two-sided symmetric Green kernel-block and Schutzenberger detector gives a
> finite group `G(pi,Q)`, independent of `n`, such that
>
> ```text
> Lambda_{G,n}(beta)=Lambda_{G,n}(1)  =>  Delta_n(beta)=1
> ```
>
> for every `n` and every `beta in ker rho_{Q,n}`.

The proof must be braid-action-level, not a fixed-degree image closure and not
a finite search.  In particular, the detector group must be constructed from
the finite interval data, not from `n`.
The `affine_cyclic` classifier by itself is not such a branch; it is only an
audit tag unless one of the symbolic detector mechanisms above also applies.
The semigroup version of the needed detector step is isolated in
`proofs/unit_section_detection_criterion.md`: after constructing one fixed
finite transition monoid, it is enough to prove that every residual section
word has unit labels in `V_beta(U(M))`.  This is still an all-`n` theorem
target, but it removes reset-like nonunit labels from the obstruction side.
The weaker endpoint form is
`proofs/unit_composite_longitude_criterion.md`: after the residual word is
composed, it is enough that the final unit lies in `V_beta(U(M))`.  This is
the natural target when corridor transports cancel internally.
The product companion `proofs/unit_section_product_detector.md` says that a
finite list of such monoids still supplies one fixed product detector group,
so factorwise corridor arguments remain compatible with the sharp obstruction
theorem.  In the telescoping endpoint form, the executable guardrail is
`unit_composite_product_detection_audit(...)`, which records the endpoint
tuple in the fixed product unit group and checks product-subgroup membership
when enumeration is feasible.
The non-enumerative certificate format is
`proofs/endpoint_longitude_expression_certificate.md`: display each endpoint
unit as a word in evaluated recursive longitudes for an input-dependent
assignment into the fixed unit group.  This proves membership in `V_beta`
directly and is the natural symbolic target for an all-`n` corridor proof.

## B-Route Search Target

A counterexample must now do more than produce a degenerate coordinate map.
It must supply an explicit finite local-minimal interval, or a full finite YBE
solution containing one, with all of the following properties:

- `theta^ker = universal`;
- every elementary coordinate-kernel pair closure is universal;
- the interval is not in any known finite-G-measurable branch;
- the residual braid action has nontrivial holonomy along the corridor graph;
- there is an explicit normalized-law sequence `beta_j in B_{q_j}` with
  `q_j -> infinity` whose finite-G longitude data is eventually trivial for
  every finite group `G`, but whose residual action moves an explicit tuple.

The current audits have not found such an example.  They have found only:

- depth-`0` universal corridors in the size-2 and size-3 local-minimal cover
  corpus, all known;
- depth-`0` universal corridors in the two-colour/fibre-2 all-base local
  corpus, all known after product/direct witnesses and branch tags;
- depth-`1` universal corridors in the translated affine `F_2^2` local-minimal
  corpus, all involutive.

Thus the open work is exactly the universal-corridor residual lemma above, or
an explicit normalized-law escape from it.
