# Ambient Factorial Holonomy Boundary

Date: 2026-06-05

This note records the outcome of testing the shift-rack/factorial transporter
obstruction against YBE contextual racks.  The obstruction is not forbidden by
the contextual rack presentation: it can occur in `As(C_M(X))` for a contextual
rack coming from a finite YBE solution.

However, the clean example is not orbit-relevant for Sawin.  It comes from the
one-point solution, so there are no distinct same-orbit pairs.  Thus it is an
ambient contextual-rack obstruction, not yet a harmful tower obstruction.

The sharp boundary is:

```text
YBE contextual racks can have factorial holonomy, but harmful orbit-relevant
factorial holonomy is not yet constructed.
```

## Associated Group Relations

Let

```text
R=C_M(X).
```

Under the right-rack associated group convention,

```text
As(R)=<g_r | g_{p triangleright q}=g_q^{-1} g_p g_q>.
```

Since `C_M(X)` is generated by symbols

```text
d_{a,x,b},  a,b in M, x in X,
```

the associated group has generators

```text
g_{a,x,b}=g_{d_{a,x,b}}.
```

The contextual rack relations impose:

```text
g_{a,u,lambda_v b}=g_{a lambda_x,y,b},

g_{a lambda_u,v,b}
=
g_{a,x,lambda_y b}^{-1}
g_{a lambda_x,y,b}
g_{a,x,lambda_y b},
```

whenever `r_X(x,y)=(u,v)`.

Thus `As(C_M(X))` is a finitely presented Wirtinger-type group: generators are
identified or conjugated by other generators.  These relations impose conjugacy
constraints, but do not force finite order, finite orbit, bounded period, or
uniform stabilizer separability.

## One-Point Contextual Rack

Take the one-point YBE solution

```text
X={*},
r(*,*)=(*,*).
```

Then

```text
L_X=<lambda>
```

is the free monoid on one generator.  Let

```text
M=C_m=<t | t^m=1>
```

be a finite cyclic quotient, with `lambda -> t`.

Write

```text
d_{i,j}=d_{t^i,*,t^j}.
```

The contextual rack relations become

```text
d_{i,j+1}=d_{i+1,j},
d_{i+1,j}=d_{i+1,j} triangleright d_{i,j+1}.
```

The first relation identifies all `d_{i,j}` with the same sum

```text
i+j mod m.
```

Let

```text
e_s=d_{i,j},  s=i+j mod m.
```

Then the second relation becomes

```text
e_s=e_s triangleright e_s.
```

Therefore `C_M(X)` is the free quandle on the `m` generators

```text
e_0,...,e_{m-1}.
```

For `m>=2`,

```text
As(C_M(X)) ~= F_m,
```

the free group on `m` generators.

## Factorial Nonuniformity In The Example

Take `m=2`, so

```text
As(C_M(X)) ~= F_2=<g_0,g_1>.
```

Let

```text
r=e_0,
h=g_1,
H=Stab(e_0)=<g_0>.
```

Define

```text
T={h^{n!}:n>=1}.
```

For every finite quotient

```text
q:F_2 -> F,
```

the element `q(h)` has finite order `o`.  For all `n>=o`,

```text
q(h^{n!})=1 in q(H).
```

Hence no single finite quotient separates all of `T` from `H`:

```text
closure(T) cap closure(H) != empty.
```

On the other hand, each individual `h^k` is separable from `H`.  For example,
choose a prime `p` not dividing `k` and map `F_2` to the dihedral group `D_p`,
sending

```text
g_1 -> rotation of order p,
g_0 -> reflection.
```

Then `h^k` maps outside the image of `<g_0>`.

Thus the factorial nonuniformity phenomenon occurs inside `As(C_M(X))` for a
YBE-origin contextual rack.

## Why This Is Not Harmful For Sawin

For the one-point solution,

```text
X^n={(*,...,*)}
```

for every `n`.  Hence

```text
Omega_n=empty
```

for every `n`: there are no distinct same-orbit pairs.

The one-point rack already satisfies

```text
ker rho_n^Y = ker rho_n^X
```

for every `n`.

Therefore the factorial transporter family is ambient contextual-rack
holonomy, but not harmful tower holonomy.  It does not produce a bad-pair
ultrafilter.

The guardrail is:

```text
Factorial holonomy in As(C_M(X)) is not enough; it must be orbit-relevant in
the actual braid dynamics of X^n.
```

## What Orbit Relevance Requires

A factorial transporter family in `As(C_M(X))` becomes relevant only if there
is a sequence of actual same-orbit pairs

```text
omega_n=(x^(n),x'^(n)) in Omega_{k_n}
```

and marked coordinates `i_n` such that:

```text
x'^(n)=rho_{k_n}^X(beta_n)x^(n)
```

for some braid `beta_n`, and the corresponding contextual labels differ by
transporters

```text
g_n in h^{n!}H
```

or by a family accumulating at a relevant stabilizer `H`.

In addition:

```text
1. every finite detector must fail on a cofinal subsequence;
2. no other coordinate may be separated by that detector;
3. the obstruction must survive finite state refinements M' of M.
```

An abstract transporter in `As(C_M(X))` is insufficient.

## Contextual Relations Do Not Force Uniformity

The one-point construction proves that contextual racks can have:

```text
free associated groups;
infinite-order elements;
infinite orbits on rack elements;
finite quotients with arbitrarily large periods;
factorial accumulation near stabilizers.
```

Therefore the missing theorem cannot be a pure group-theoretic theorem about
`As(C_M(X))`.  It must use the image of actual braid dynamics of `X` inside
the contextual or escape action groupoid.

## Does Orbit-Relevant Factorial Holonomy Give A Finite Active Factor?

Not automatically.  Factorial holonomy is an infinite-index phenomenon.  Any
finite active factor `Z` sees a transporter `h` through a finite permutation or
finite transformation.  If that finite action has period `o`, then

```text
h^{n!}
```

acts trivially for all `n>=o`.

Thus if the only difference between bad pairs is the transporter `h^{n!}`, a
finite `Z` eventually loses the difference.  To recover it uniformly, one
needs infinitely many states.

Even after forcing a finite quotient, active-factor extraction may fail
through:

```text
nonfunctionality;
partiality;
nonbijectivity;
YBE failure on unreached triples;
loss of orbit-injectivity;
failure of ker rho_n^Z <= ker rho_n^X.
```

Residual rigidity excludes only proper finite active factors with the correct
kernel direction.  It does not remove infinite-index holonomy by itself.

## Escape Holonomy

Escape holonomy records transporter cosets

```text
gH subset As(C_M(X))
```

or the analogous cosets in an escape action groupoid.  A harmful ultrafilter
can produce a profinite holonomy limit

```text
ghat in hat G.
```

Uniform finite separation from `H` is precisely

```text
ghat notin closure(H),
```

or for families,

```text
closure(T) cap closure(H)=empty.
```

Factorial accumulation gives the opposite.  Escape holonomy therefore detects
the obstruction, but it compresses to finite rack labels only when such
uniform coset separation holds.

## Strongest Current Theorems

The following ambient theorem is established:

```text
There exists a finite YBE solution X and finite state quotient M such that
As(C_M(X)) has a factorial transporter family pointwise separable from a
stabilizer but not uniformly separable.
```

Proof: take `X={*}` and `M=C_m` with `m>=2`; then `C_M(X)` is the free quandle
on `m` generators and `As(C_M(X)) ~= F_m`.

But this is not harmful because `Omega=empty`.

The remaining open obstruction is:

```text
Can factorial holonomy be realized by actual same-orbit bad pairs of X^n in a
way not finite-rack absorbed?
```

If yes, and if it is not finite-active-factor extractable, the contextual
tower route fails.  If no, the missing theorem is:

```text
Every orbit-relevant profinite/factorial holonomy in C_M(X) is either
uniformly separable, finite-rack absorbed, or finite-active-factor extractable.
```

This is the strongest precise lemma still smaller than Sawin.
