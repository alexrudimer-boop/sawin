# Product Observer Prefix-Path Factor

Date: 2026-06-05

This note upgrades the product-semigroup observer from an inert endpoint to an
injective finite-state path factor.

It still does not construct a finite rack detector.  Its value is that it
identifies the exact finite object that the product observer naturally gives:
a Yang-Baxter path groupoid over the finite left coordinate semigroup.

## Left prefix paths

Let `S_L^1` be the finite monoid generated by the left coordinate maps
`L_x`, with identity adjoined if needed.

For a word

```text
w=(x_1,...,x_n) in X^n,
```

define prefix states

```text
p_0=1,
p_i = L_{x_1} L_{x_2} ... L_{x_i}.
```

Equivalently,

```text
p_i = p_{i-1} L_{x_i}.
```

Define the left prefix-path code

```text
P^L_n(w)=((p_0,x_1),(p_1,x_2),...,(p_{n-1},x_n)).
```

This lies in the finite alphabet

```text
E_L = S_L^1 x X,
```

but not every element of `E_L^n` is allowed.  The valid words are exactly the
composable paths satisfying

```text
p_i = p_{i-1} L_{x_i}.
```

The code `P^L_n:X^n -> E_L^n` is injective, because the second component of
the `i`th edge is `x_i`.

The endpoint

```text
p_n=L_{x_1}...L_{x_n}
```

is the invariant observer `Lambda_n`.

## Local path rewrite

Suppose a valid path contains adjacent edges

```text
(p,x),(pL_x,y).
```

Let

```text
r(x,y)=(u,v).
```

The local braid rewrite sends the two-edge path to

```text
(p,u),(pL_u,v).
```

This is again composable.  Its endpoint is

```text
p L_u L_v = p L_x L_y
```

by the first coordinate YBE identity.

Thus the rewrite preserves the path source and endpoint.

## Equivariance theorem

The code `P^L_n` is equivariant from the original `X^n` braid action to the
path rewrite action on valid left prefix paths.

Proof.  The braid generator `sigma_i` acts on `X^n` by replacing

```text
(x_i,x_{i+1})
```

with

```text
(u,v)=r(x_i,x_{i+1}).
```

The prefix states before position `i` are unchanged.  If

```text
p=p_{i-1},
```

then the old two-edge segment is

```text
(p,x_i),(pL_{x_i},x_{i+1}),
```

and the new two-edge segment is

```text
(p,u),(pL_u,v).
```

All later prefix states are unchanged because

```text
pL_uL_v = pL_{x_i}L_{x_{i+1}}.
```

So applying `sigma_i` in `X^n` and then coding gives the same path as coding
first and applying the local path rewrite.  This proves equivariance.

## Yang-Baxter path groupoid

The local path rewrites satisfy the braid relation on composable three-edge
paths, because they are conjugate through the injective code `P^L_n` to the
original `X^n` braid action on every valid path starting at `1`.

More generally, the same formula gives a finite partial Yang-Baxter groupoid on
all composable paths in the Cayley graph of `S_L^1` with edge labels `x in X`.
The path groupoid is finite because `S_L^1` and `X` are finite.

## Why this is not yet a rack detector

The prefix-path factor is stronger than the endpoint observer:

- it is injective on `X^n`;
- it is finite-state;
- it is local on adjacent composable edges;
- it records the invariant product endpoint.

But it is not a rack factor for three reasons.

1. The allowed states form a path language, not all of `E_L^n`.
2. The local rewrite is only naturally defined on composable adjacent edge
   pairs `(p,x),(pL_x,y)`.
3. A finite rack detector requires a genuine rack `Y` acting on all of `Y^n`,
   not a partial path groupoid action on a constrained subset of `E_L^n`.

Therefore the exact rackification problem is:

> Given the finite left and right prefix-path Yang-Baxter groupoids, construct a
> finite rack `Y` and inert observers `I_n` such that the valid path action
> embeds equivariantly into `Y^n x I_n`, or prove that such an embedding need
> not exist.

This is sharper than asking about product observers alone.  The product
observer endpoint is the endpoint of an injective finite-state path action; the
remaining gap is rackifying that path action.
