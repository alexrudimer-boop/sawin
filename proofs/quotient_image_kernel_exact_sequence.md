# Quotient image-kernel exact sequence

## Purpose

This note records the fixed-degree algebra behind the quotient/residual
setup.  It is not an all-`n` proof of Sawin domination.  It identifies the
finite group that has to be killed at each braid degree and gives a precise
finite certificate for bounded audits.

## Exact fixed-degree sequence

Let `pi:X -> Z` be a finite braided-set quotient.  For each braid degree `n`,
the coordinatewise map

```text
pi^n : X^n -> Z^n
```

intertwines the braid actions.  Therefore the finite image of `B_n` on
`X^n` maps to the finite image of `B_n` on `Z^n`:

```text
Im_X(n) -> Im_Z(n).
```

Equivalently, close the joint image generated by the pairs

```text
(rho_Z,n(sigma_i), rho_X,n(sigma_i)).
```

Projection to the first coordinate is surjective onto `Im_Z(n)`, since both
groups are generated by the same braid generators.  Its kernel is

```text
K_pi(n) = { rho_X,n(beta) : rho_Z,n(beta)=1 }.
```

This is exactly the residual image of base-fixing braids.  If
`rho_Z,n(beta)=1`, then `beta` preserves every fibre `X_z`, and its action on
those fibres is the residual tuple `Delta_n(beta)`.  Thus `K_pi(n)` is the
finite image of all residual actions at degree `n`.

## Connection to the sharp detector criterion

For a quotient already dominated by a finite rack `Q`, the local theorem is
not merely the assertion that `K_pi(n)` is finite; it is finite for every
fixed `n` automatically.  The theorem needs one finite group `G=G(pi,Q)`,
independent of `n`, such that

```text
Lambda_G,n(beta)=Lambda_G,n(1)
```

kills every element of this residual kernel for every `n`.

The fixed-degree exact sequence is useful because it separates two tasks:

- compute or describe the finite residual kernel image `K_pi(n)`;
- prove that all elements of `K_pi(n)` are forced by finite-G Artin
  longitudes in one fixed detector group.

The Green/corridor and product-label programs are attempts to describe
`K_pi(n)` uniformly in `n` by fixed finite holonomy groups.

## Executable certificate

The helper

```text
quotient_image_kernel_summary(qmap,n)
```

closes the finite joint image for one degree and reports:

- joint image size;
- total image size;
- base image size;
- residual kernel size;
- whether the projection to the base image is surjective;
- whether the residual kernel contains a nonidentity action;
- a first braid word witnessing nonidentity kernel action, when present.

The tests verify two guardrails:

- over a one-point quotient, the joint image equals the residual kernel;
- for an identity cover with no fibre motion, the kernel is trivial.

These are exact fixed-degree certificates.  They do not prove the master
theorem unless supplemented by a symbolic uniform-in-`n` description of the
kernel images.

## B-route interpretation

Outcome B requires more than a nontrivial element of `K_pi(n)` at some fixed
degree.  It needs a sequence `beta_j in B_{q_j}`, with `q_j -> infinity`,
whose residual images in these kernels are nontrivial while every finite
group Artin-longitude detector is eventually trivial.  In the exact-sequence
language, B is a normalized-law sequence staying nontrivial in the moving
kernel images `K_pi(q_j)` but invisible in every fixed finite-G longitude
quotient.
