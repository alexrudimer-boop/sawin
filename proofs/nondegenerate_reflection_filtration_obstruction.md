# Nondegenerate Reflection Filtration Obstruction

This note refines the nondegenerate-reflection Brunnian obstruction by
keeping the whole finite construction chain for `E_nd`.  The obstruction does
not have to be studied in the full kernel of

```text
X -> X/E_nd.
```

If `X` is a counterexample, then one specific elementary degeneracy-pullback
layer must have cofinal relative all-meridian survival.

## The Reflection Filtration

Let `X` be a finite bijective YBE solution, and write

```text
R_X(x,y) = (lambda_x(y), rho_y(x)).
```

Define a finite increasing chain of braided congruences

```text
Delta_X = E_0 <= E_1 <= ... <= E_t = E_nd
```

as follows.  Given `E_i`, let `E_{i+1}` be the braided congruence generated by
`E_i` and all quotient-degeneracy pullbacks:

```text
y ~ y'       if lambda_x(y) E_i lambda_x(y') for some x in X,

x ~ x'       if rho_y(x) E_i rho_y(x') for some y in X.
```

The chain stabilizes because `X` is finite.  The final quotient

```text
X_t = X/E_t = X/E_nd
```

is two-sided nondegenerate, possibly the one-point solution.

For each layer, write

```text
X_i = X/E_i,
q_i:X_i -> X_{i+1}.
```

## Layer Notation

For arity `n`, let

```text
F_{n-1} = ker(d_n:P_n -> P_{n-1})
```

be the last-strand free group, with meridian generators

```text
x_j = A_{j,n},       1 <= j <= n-1.
```

For each layer `i`, define

```text
G^{(i)}_n = rho^{X_i}_n(F_{n-1}),
K^{(i)}_n = ker(G^{(i)}_n -> G^{(i+1)}_n).
```

For each meridian image, put

```text
M^{(i)}_{j,n}
  =
<< rho^{X_i}_n(x_j) >>_{G^{(i)}_n}.
```

Let

```text
C^{(i)}_n
  =
[M^{(i)}_{1,n},...,M^{(i)}_{n-1,n}]_Sigma.
```

This is the all-meridian symmetric commutator layer inside the `X_i`-image of
the last-strand group.

## Layer-Lifting Theorem

Suppose `X_{i+1}` is dominated by a finite rack.  If

```text
K^{(i)}_n cap C^{(i)}_n = 1
```

for all sufficiently large `n`, then `X_i` is dominated by a finite rack.

### Proof

Let `Y_{i+1}` be a finite rack dominating `X_{i+1}`:

```text
ker rho^{Y_{i+1}}_n <= ker rho^{X_{i+1}}_n
```

for every `n`.

Choose `N` such that

```text
K^{(i)}_n cap C^{(i)}_n = 1
```

for all `n > N`.

For each fixed arity `2 <= k <= N`, fixed-arity rack cofinality gives a
finite rack `Y_k` such that

```text
ker rho^{Y_k}_k <= ker rho^{X_i}_k.
```

Set

```text
Q = Y_{i+1}^0 x T_2 x product_{k=2}^N Y_k^0.
```

By the standard transparent Brunnian reduction, it is enough to show that
every

```text
beta in Brun_n cap ker rho^Q_n
```

acts trivially on `X_i^n`.

If `n <= N`, the transparent factor `Y_n^0`, with all strands colored
nontransparent, gives

```text
beta in ker rho^{Y_n}_n.
```

By the choice of `Y_n`, this implies

```text
beta in ker rho^{X_i}_n.
```

Now assume `n > N`.  The factor `Y_{i+1}^0`, again with all strands colored
nontransparent, gives

```text
beta in ker rho^{Y_{i+1}}_n.
```

Since `Y_{i+1}` dominates `X_{i+1}`,

```text
rho^{X_{i+1}}_n(beta)=1.
```

The `T_2` factor forces `beta` to be pure.  Because `beta` is Brunnian,
deleting the last strand gives the identity, so

```text
beta in F_{n-1}.
```

Therefore `rho^{X_i}_n(beta)` lies in `G^{(i)}_n`.  Since `beta` is trivial on
`X_{i+1}`, this image lies in the relative layer kernel `K^{(i)}_n`.

The standard finite-image Brunnian theorem for the last-strand free group
also gives

```text
rho^{X_i}_n(beta) in C^{(i)}_n.
```

Thus

```text
rho^{X_i}_n(beta) in K^{(i)}_n cap C^{(i)}_n = 1.
```

So every Brunnian `Q`-invisible braid is `X_i`-invisible, and the Brunnian
reduction implies that `Q` dominates `X_i`.

## Reflection-Filtration Theorem

If every layer satisfies eventual relative all-meridian triviality,

```text
K^{(i)}_n cap C^{(i)}_n = 1
```

for all sufficiently large `n` and every `i=0,...,t-1`, then `X` is dominated
by a finite rack.

### Proof

The top quotient

```text
X_t = X/E_nd
```

is nondegenerate, hence dominated by a finite rack.  This remains true if
`X_t` is the one-point solution.

Apply the layer-lifting theorem downward:

```text
X_t -> X_{t-1} -> ... -> X_0=X.
```

Thus `X` is finite-rack dominated.

## Counterexample Consequence

If `X` is a finite counterexample, then its nondegenerate-reflection
filtration has at least one layer `i` such that

```text
K^{(i)}_n cap C^{(i)}_n != 1
```

for unbounded `n`.

Equivalently, the obstruction is localized in one fixed layer

```text
X_i -> X_{i+1},
```

not merely in the full kernel of `X -> X/E_nd`.

This includes the degeneracy-perfect case `E_nd = X x X`: even when the only
nondegenerate quotient is the one-point solution, the finite reflection
filtration still exists, and a counterexample must have a bad elementary
layer inside it.

## New Target

The proper positive target is now:

```text
prove every elementary nondegenerate-reflection layer has eventually
trivial relative all-meridian kernel.
```

The proper negative target is:

```text
construct one finite X and one layer X_i -> X_{i+1}
such that K^{(i)}_n cap C^{(i)}_n survives cofinally
and yields rack-prefix-invisible Brunnian witnesses.
```

This is sharper than the single-quotient obstruction, because the bad layer
is fixed before taking `n` to infinity.
