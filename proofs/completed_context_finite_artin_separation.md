# Completed-context finite Artin separation

Date: 2026-06-03

This note refines `proofs/completed_context_artin_row_defect_gate.md`.  It
does not prove finite-rack domination and it does not produce a counterexample.
It records the exact finite separability statement left after recognizing that
raw completed-context row-defect vanishing is stronger than necessary.

## Universal Artin Row Group

Fix one finite completed-context local interval.  Let `E` be the finite set of
actual retained germs.  For every actual supported row

```text
e=(s,x),        f=(s tau_x,y)
```

with

```text
r(x,y)=(u,v),
```

write

```text
e'=(s,u),       f'=(s tau_u,v).
```

Define the universal Artin row group of the interval by generators

```text
A_e, L_e       for e in E
```

and relations, for every actual supported row,

```text
A_{e'} = A_e A_f A_e^-1,
L_{e'} = A_e L_f,
A_{f'} = A_e,
L_{f'} = L_e.
```

Call this group `Art_I`.  A finite group `H` with exact completed-context
Artin detector labels is exactly a finite quotient

```text
q: Art_I -> H
```

with labels

```text
A_e^H=q(A_e),      L_e^H=q(L_e).
```

Thus the question is no longer whether the original unit labels in `U(M)`
already satisfy the Artin row rule.  The universal row group forces that rule
by definition; the question is whether some finite quotient of this universal
rule still separates the original endpoint motion.

## Path Category And Endpoint Map

Let `P_I` be the actual completed-context path category generated by supported
rows, modulo only the actual YBE cube identifications.  A path `gamma` is the
formal shadow of one completed-context residual continuation branch.

The original unit branch gives a finite endpoint map

```text
Ept: P_I -> U(M),
Ept(gamma)=h_gamma.
```

YBE cube coherence says exactly that `Ept` is well-defined on `P_I`: the two
boundary paths of every actual supported cube have the same endpoint unit.

The universal Artin row group gives an Artin readout

```text
Art: P_I -> Art_I-data,
```

where `Art(gamma)` denotes the terminal tuple or endpoint word in the
universal labels obtained by sweeping the path through the exact Artin row
relations.  The precise target does not matter for the separation statement:
it may be a tuple of terminal `L`-labels or the endpoint word actually used by
the branch.  What matters is that every finite exact Artin detector sees
`gamma` only through `q Art(gamma)` for some finite quotient `q`.

## Finite Artin Separation Criterion

Finite defect absorption is equivalent to the following condition.

```text
There exists a finite quotient q: Art_I -> H such that

    q Art(gamma) = q Art(gamma')
        => Ept(gamma) = Ept(gamma')

for all actual completed-context paths gamma,gamma'.
```

For the kernel-killing form needed by the sharp obstruction theorem, this can
be stated as

```text
There exists a finite quotient q: Art_I -> H such that

    q Art(gamma) = 1
        => Ept(gamma) = 1

for every actual residual endpoint path gamma.
```

Equivalently,

```text
ker(q Art) <= ker(Ept).
```

This is the finite Artin-null endpoint separation identity.

If it holds, define the finite endpoint readout on the image of `q Art` by

```text
omega(q Art(gamma)) = Ept(gamma).
```

The separation implication makes `omega` well-defined.  The finite group `H`
then supplies exact Artin detector row labels, and `omega` recovers the
original endpoint unit.  Identity finite-`H` longitude data kills the terminal
Artin labels, hence kills the original endpoint.

Conversely, any finite defect-absorption package with exact Artin row labels
and endpoint recovery factors through a finite quotient of `Art_I`; endpoint
recovery is precisely the statement that `Ept` is constant on the fibres of
that quotient readout.  Thus finite defect absorption and finite Artin
separation are the same condition.

## What YBE Flatness Gives

The raw defects from `proofs/completed_context_artin_row_defect_gate.md`,

```text
delta_a(e,f)=a_{f'}^-1 a_e,
delta_l(e,f)=l_{e'}^-1 a_e l_f,
```

measure failure of the original `U(M)` labels to be exact Artin detector
labels.  YBE cube flatness makes the endpoint map `Ept` well-defined on the
actual path category.  It does not imply that `Ept` is constant on fibres of
`Art`, or on fibres of any finite quotient `q Art`.

Therefore the missing identity is not raw row-defect vanishing and not merely
flatness.  It is finite Artin-null endpoint separation:

```text
exists finite H with ker(q Art) <= ker(Ept).
```

## Relation To Outcome A

Proving this finite separation statement for every remaining local-minimal
completed-context interval gives the desired finite endpoint detector group.
Combining it with the already isolated Green, Schutzenberger, atom, quotient,
known-branch, and unit factors gives the fixed local product group `H(pi,Q)`.
Then the sharp obstruction theorem supplies the finite rack

```text
Q x A_{H(pi,Q)}.
```

Thus the positive endpoint target is now:

```text
Every actual endpoint map Ept of a remaining local interval is separated by
some finite quotient of its universal Artin row group Art_I.
```

## Relation To Outcome B

Failure of raw row-defect vanishing does not imply a no-rack obstruction.  It
only says that the original `U(M)` labels were too small or not in Artin row
form.

Failure of finite Artin separation is much stronger.  If no finite quotient
`q:Art_I -> H` satisfies `ker(q Art) <= ker(Ept)`, then one can diagonalize over
finite groups.  Enumerate finite groups as `G_1,G_2,...` and let

```text
K_j = G_1 x ... x G_j.
```

For each `j`, nonseparation gives an actual endpoint path `gamma_j` such that
`gamma_j` is invisible to the first `j` finite Artin detector groups but

```text
Ept(gamma_j) != 1.
```

If these `gamma_j` are realized by residual braid branches moving actual
tuples in `X^{n_j}` with `n_j -> infinity`, they are exactly the normalized-law
no-rack obstruction sequence: every fixed finite group eventually sees
identity longitude data, while the residual endpoint remains nontrivial.

Conversely, such a normalized-law endpoint sequence rules out any finite
separating quotient, because taking that quotient group as one of the finite
groups would eventually make its Artin-longitude data trivial while the
endpoint still moves.

Thus the final completed-context fork is:

```text
A: prove finite Artin-null endpoint separation for every actual remaining
   interval;

B: produce actual residual braid branches violating finite Artin separation
   for every finite group, hence a normalized-law no-rack sequence.
```
