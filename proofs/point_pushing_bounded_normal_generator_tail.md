# Point-Pushing Bounded Normal-Generator Tail

Date: 2026-05-30

This note refines the product-prefix first-failure tail after
`proofs/point_pushing_cyclic_tail_closure.md`.

It does not prove outcome A or B.  It records a uniform constraint on every
remaining monolithic first-failure quotient: the monolith is normally generated
by conjugates of one point-pushing element whose order is bounded only in terms
of `X`.

## Setup

Let `X` be a finite bijective set-theoretic YBE solution and set

```text
B_X = ord(rho_{X,2}(sigma_1^2)).
```

Use right-based point-pushing coordinates

```text
F_k=<a_1,...,a_k>,
```

where `a_k` is the newest far-left stationary strand in a first-failure row.
Let

```text
h_i = rho_{X,k+1}(a_i)
```

be the point-pushing action generators of `P_k(X)`.

Assume a product-prefix first failure has already been normalized by the
Brunnian jump theorem and monolithic compression.  Thus there are:

```text
w in ker(F_k -> F_{k-1}),
w = 1 in D_k(Pi_j),
w(h_1,...,h_k) != 1 in P_k(X),
```

and a smallest separating quotient

```text
phi:P_k(X)->H
```

with monolith `M` and

```text
m = phi(w(h_1,...,h_k)) in M \ {1}.
```

Write

```text
t = phi(h_k).
```

## Theorem

Every product-prefix first-failure monolithic quotient satisfies:

```text
ord(t) divides B_X,
M <= <<t>>_H.
```

Here `<<t>>_H` denotes the normal closure of `t` in `H`.

Consequently every remaining monolithic B tail is a bounded-order
normal-generator tail: the critical monolith must be contained in the normal
closure of a single element whose order divides the fixed integer `B_X`.

## Proof

The pure braid generator represented by `a_k` is one of the standard
last-strand point-pushing generators `A_{i,k+1}`.  Every `A_{i,k+1}` is
braid-conjugate to a crossing square `sigma_l^2`.  In the `X`-action on
`X^{k+1}`, `sigma_l^2` acts as `rho_{X,2}(sigma_1^2)` on the two active
coordinates and trivially on all other coordinates.  Therefore every
point-pushing generator image has order dividing `B_X`, and so its quotient
image `t=phi(h_k)` also has order dividing `B_X`.

Now use the first-failure Brunnian form.  The deletion kernel

```text
ker(F_k -> F_{k-1})
```

is the normal closure of the newest generator `a_k`.  Since `w` lies in this
kernel, its action value

```text
g = w(h_1,...,h_k)
```

lies in the normal closure of `h_k` inside `P_k(X)`.  Applying `phi`, the
moved value

```text
m = phi(g)
```

lies in `<<t>>_H`.

The subgroup `<<t>>_H` is normal in `H`, and `M` is the unique minimal
nontrivial normal subgroup of the monolithic quotient `H`.  Since

```text
m in M cap <<t>>_H
```

is nontrivial, the intersection `M cap <<t>>_H` is a nontrivial normal subgroup
of `H` contained in `M`.  Minimality of `M` gives

```text
M <= <<t>>_H.
```

This proves both claims.  QED.

## Consequence For B

The six remaining monolithic tail types are not arbitrary quotients.  In each
case the monolith must be normally generated by conjugates of one bounded-order
element:

1. central stem depth with bounded-order normal generator;
2. noncentral module prime escape with bounded-order normal generator;
3. noncentral module dimension escape with bounded-order normal generator;
4. noncentral bounded-module centralizer-layer escape with bounded-order
   normal generator;
5. nonabelian simple-factor escape with bounded-order normal generator;
6. nonabelian multiplicity escape with bounded-order normal generator.

This does not rule out those tails by itself.  Finite simple groups and large
p-groups can be normally generated by bounded-order elements.  The point of
the reduction is that a genuine B proof must now build the unbounded tail from
one transported endpoint generator rather than from an arbitrary large
quotient of the action image.

## Audit Hook

The helper

```text
point_pushing_bounded_normal_generator_audit(...)
```

records the same uniform bound `B_X` and checks, on a finite prefix of braid
indices, that all standard point-pushing generator orders divide it.  As with
the cyclic-tail helper, this finite prefix check is only a convention
guardrail; the theorem above supplies the all-arity normal-generator
constraint by braid conjugacy and Brunnian first-failure normalization.
