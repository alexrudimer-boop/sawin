# Product Label Group Detector

Date: 2026-05-28

This note fixes the finite group `H` used in the product-label
factorization target.  It is not the missing all-`n` factorization proof, but
it removes an ambiguity: the coloured product groupoid labels can always be
embedded in one ordinary finite permutation group built from the interval.

## Construction

For a local product interval, form the tagged fibre union

```text
U = disjoint union_a {a} x A_a.
```

In the swapped product branch

```text
T_{a,b}(x,y) = (L_{a,b}(y), R_{a,b}(x)),
```

each label is a bijection between two tagged fibres:

```text
L_{a,b}: {b} x A_b -> {a.b} x A_{a.b},
R_{a,b}: {a} x A_a -> {a*b} x A_{a*b}.
```

In the direct product branch

```text
T_{a,b}(x,y) = (L_{a,b}(x), R_{a,b}(y)),
```

the labels are

```text
L_{a,b}: {a} x A_a -> {a.b} x A_{a.b},
R_{a,b}: {b} x A_b -> {a*b} x A_{a*b}.
```

Extend each such partial bijection to a permutation of `U` as follows.  If
the source and target tagged fibres are distinct, swap those two fibres by
the label and its inverse, and fix every other tagged fibre.  If the source
and target tagged fibres are equal, use the given fibre permutation on that
block and fix the other blocks.

Let `H_prod` be the finite permutation group of `U` generated by these
totalized labels.  The implementation is

```text
swapped_product_label_group(interval)
direct_product_label_group(interval)
```

in `src/ybe_domination/label_detectors.py`.

## Verification

The totalization is faithful to the original product normal forms in the
following precise sense.  For every formal label word returned by

```text
swapped_product_label_word_action(interval,z,beta)
direct_product_label_word_action(interval,z,beta)
```

evaluation in `H_prod`, restricted to the tagged source fibre of that
coordinate, agrees with the original partial-fibre evaluator

```text
evaluate_swapped_product_label_word(...)
evaluate_direct_product_label_word(...).
```

The unit tests check this agreement for both positive and negative braid
generators and for both swapped and direct product branches.  The tests also
confirm that the one-colour pairwise-linking product branch gives the
expected cyclic label group.

## Consequence for the Master Gap

The product branch can now be stated with a completely explicit finite label
group:

> Product label-longitude target.  For a local-minimal product interval, set
> `H=H_prod`, possibly multiplied with the already-known cyclic, affine,
> coboundary, or known-branch factors.  Prove that every base-fixed product
> label word is a finite product of evaluations of recursive Artin
> longitudes in `H`.

If that target is proved, `proofs/label_longitude_factorization.md` applies
with this explicit `H`, so the rack `A_H` detects the product branch for all
braid degrees.

Conversely, a product-branch counterexample must now produce formal product
label words whose evaluations are nontrivial in this explicit finite group
`H_prod` while every finite-group Artin-longitude detector is eventually
trivial.  Merely saying that the coloured groupoid has nontrivial holonomy is
not enough; the holonomy must escape the `H_prod` finite-longitude quotient.

## Remaining Limitation

This construction embeds the label groupoid into a finite group, but it does
not by itself prove that label words are longitude evaluations.  The missing
symbolic assertion remains the all-`n` factorization of base-fixed product
label words through recursive Artin longitudes.
