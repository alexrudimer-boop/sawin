# Canonical strand-carrier subcase

Date: 2026-06-02

This note records the theorem-level meaning of the canonical strand-carrier
helpers added on the `codex/atom-inner-row-lift` branch.  It is a subcase
closure for the post-linear U/C/M endpoint observer problem.  It is not a
proof of Sawin finite-rack domination and it is not a counterexample.

## Canonical carrier relation

Let

```text
I = (C, (A_c), R_C, T)
```

be a finite local interval in the left rack base convention
`R_C(a,b)=(a*b,a)`.  For a local row

```text
T_{a,b}(x,y)=(u,v) in A_{a*b} x A_a
```

the physical right strand carries `(b,y)` to `(a*b,u)`, and the physical left
strand carries `(a,x)` to `(a,v)`.  The canonical strand-carrier relation is
the equivalence relation on tagged fibre points `(c,z)` generated by

```text
(b,y) ~ (a*b,u),
(a,x) ~ (a,v)
```

over all local rows.  The helper

```text
universal_k_canonical_strand_carrier_rows(I)
```

returns one label for each equivalence class.

## Admissible-family lemma

For each colour `c`, restrict the canonical carrier relation to the fibre
`A_c`:

```text
x theta_c x'  iff  (c,x) ~ (c,x').
```

Then `(theta_c)_{c in C}` is an admissible local congruence family.

Indeed, suppose `x theta_a x'` and `y theta_b y'`.  Write

```text
T_{a,b}(x,y)=(u,v),
T_{a,b}(x',y')=(u',v').
```

By the definition of the canonical carrier relation, `v ~ x`, `v' ~ x'`,
`u ~ y`, and `u' ~ y'`.  Hence `v ~ v'` and `u ~ u'`, so the product relation
is transported by `T_{a,b}` to the product relation on the output fibres.
The same argument applies to inverse rows because the rows are bijections.

Consequently, on a local-minimal interval the restricted carrier family is
either equality on every fibre or universal on every fibre.

## Closed subcase

If the canonical carrier family is equality on each fibre, equivalently the
canonical carrier labels are fibrewise injective, then an endpoint channel
that preserves canonical carrier labels is residual-faithful: the quotient
colour and the carrier label together recover the fibre point.  This is the
subcase checked by

```text
universal_k_interval_has_canonical_strand_carrier_action(I)
universal_k_canonical_strand_carrier_residual_faithfulness_audit(...)
```

and wired as the residual channel

```text
canonical_strand_carrier_residual_channel
```

in the U/C/M endpoint observer builders.

For fixed-carrier endpoint observers, the canonical labels are abstract
component names rather than endpoint-group elements.  The helper

```text
universal_k_canonical_strand_carrier_rows_with_values(I, component_values)
```

evaluates those component names in a supplied finite target, and the fixed
carrier monodromy constructor accepts the family-scoped ledger

```text
canonical_strand_carrier_values_by_family
```

to derive the concrete strand-carrier rows used by the certificate checker.
This is an executable supplied-certificate path, not an existence theorem for
the universal-carrier branch.

## Remaining open branch

The non-injective case is not a contradiction.  In a local-minimal interval it
means that the canonical carrier family is universal, so this carrier readout
contains no residual fibre information.  The examples in the regression suite
show this failure in standard residual-trivial or triangular rows, including
identity, coordinate-identity, fibre-label, rank-loss, and Latin triangular
fixtures.  Those examples may be closed by other branch-specific arguments,
but not by canonical strand carriers.

Thus the current remaining theorem is unchanged in scope:

```text
Every surviving post-linear U/C/M endpoint obligation with universal
canonical carrier family must either be residual-trivial by another fixed
readout, admit a nontrivial fixed-carrier or restricted-domain endpoint
observer, or yield a normalized-law/symmetric-tower counterexample.
```

The canonical strand-carrier subcase removes one equality-carrier branch from
that target.  It does not prove the uniform fixed-carrier positive
endpoint-observer existence lemma for arbitrary surviving intervals.
