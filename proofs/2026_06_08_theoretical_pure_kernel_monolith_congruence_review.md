# Theoretical Review: Pure-Kernel Monolith Congruence

Date: 2026-06-08.

## Verdict

This is a useful correction to the monolith obstruction.  Formal contextual
`J`-collisions are not enough for a counterexample.  A smallest nonsimple
counterexample must have its monolith generated by actual pure
detector-kernel monodromy.

It does not prove A or B, but it gives a sharper target for both:

```text
prove pure Q-invisible monodromy is trivial on monolith fibres,
or construct a fixed X where this monodromy congruence is nontrivial and
equals the monolith.
```

## Statement

Let `X` be a smallest nonsimple counterexample, let `mu` be its monolith, and
let

```text
Q=(Y_mu x Y_ctx)^0 x T_2
```

where `Y_mu` dominates `X/mu` and `Y_ctx` is a finite rack completion of
`P_X`.

Define `E_Q` on `X` by declaring `a E_Q b` if `a=b`, or if some pure braid

```text
beta in P_n cap ker rho^Q_n
```

moves some coordinate from `a` to `b` in the `X^n` action.  Take the
equivalence relation generated by all such pairs.

Then:

```text
E_Q is a braided congruence;
E_Q <= mu;
E_Q != Delta_X;
therefore E_Q = mu.
```

## Proof Check

The use of pure monodromy is essential.  Brunnian braids are not stable under
adding an idle strand: embedding a Brunnian braid into one more strand gives a
braid whose deletion of the new strand recovers the original braid, not the
identity.

Pure detector-kernel braids are stable under adding strands and conjugating by
crossings.  This gives closure of `E_Q` under `R_X` and `R_X^{-1}`: add a new
strand with colour `y`, conjugate the pure kernel braid across the relevant
crossing, and read off the moved output colours.

Since `Q` contains `Y_mu` and `Y_mu` dominates `X/mu`, every `Q`-invisible
pure braid acts trivially on the quotient, hence every moved pair lies inside
`mu`.

Nontriviality comes from the transparent Brunnian reduction: if `Q` dominated
`X`, `X` would not be a counterexample.  Therefore there is a Brunnian, hence
pure, `Q`-invisible braid acting nontrivially on `X`.

Minimality of the monolith then forces `E_Q=mu`.

## Consequence

The remaining nonsimple branch is not merely:

```text
there is a formal monolith J-collision.
```

It is:

```text
pure Q-invisible monodromy generates the monolith.
```

The next theoretical prompt should target this actual group-action statement,
not just formal reachability collisions in the contextual readout graph.
