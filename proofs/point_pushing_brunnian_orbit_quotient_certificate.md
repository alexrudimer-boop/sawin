# Point-Pushing Brunnian Orbit Quotient Certificate

Date: 2026-05-30

This note packages the post-stabilizer part of
`proofs/point_pushing_brunnian_relation_lift.md` as a finite graph/quotient
certificate.  After the stabilizer-centralizer gate and orbit-label
well-definedness hold, there is no further ambiguity: the remaining question
is exactly whether one finite paired orbit subgroup is the graph of a quotient
from the detector orbit subgroup.

This does not prove outcome A or B.  It gives the finite certificate format
for the second and final one-new-strand Brunnian extension gate.

## Setup

Assume the old suffix paired subgroup is already detected and the transported
new-generator orbit label is well-defined.  Let

```text
O_D={c d c^{-1}: c in C_D}
```

be the detector orbit of the new generator, and let

```text
O_X={q(c) h q(c)^{-1}: c in C_D}
```

be the transported action orbit.

Choose one action label `q_e(o)` for each `o in O_D`.  Define the paired orbit
subgroup

```text
B=< (o,q_e(o)) : o in O_D > <= <O_D> x <O_X>.
```

Let

```text
B_D=pr_D(B),     B_X=pr_X(B).
```

## Theorem

The remaining Brunnian relation-lift condition holds if and only if the
projection

```text
pr_D:B -> B_D
```

is injective.  Equivalently,

```text
B cap ({1} x B_X)={(1,1)}.
```

Since all groups are finite, this is also equivalent to the cardinality test

```text
|B|=|B_D|.
```

When these conditions hold, the map

```text
B_D -> B_X,
o |-> q_e(o)
```

is a well-defined marked quotient from the detector orbit subgroup to the
transported action orbit subgroup.

## Proof

The paired subgroup `B` is generated by the pairs `(o,q_e(o))`.  The projection
to `B_D` is surjective by definition.  Its kernel is exactly

```text
B cap ({1} x B_X).
```

If this kernel is trivial, then `pr_D` is an isomorphism from `B` onto `B_D`.
Composing the inverse with the action projection gives a homomorphism

```text
B_D -> B_X
```

sending each detector orbit generator `o` to its transported action label
`q_e(o)`.  Therefore every relation among detector orbit generators lifts to
the action orbit labels.

Conversely, if every detector-orbit relation lifts, then the assignment
`o |-> q_e(o)` induces such a homomorphism.  The paired subgroup lies in its
graph, and a graph intersects `{1} x B_X` only at `(1,1)`.  Hence the vertical
kernel is trivial.

For finite groups, a surjective homomorphism is injective exactly when source
and target have the same size, so the cardinality form `|B|=|B_D|` follows.
QED.

## Failure Classification

Combining this certificate with the stabilizer gate gives four finite row
statuses:

```text
truncated_old_suffix
stabilizer
orbit_label
orbit_relation
none
```

Only `none` is a successful one-new-strand extension row.  The three
nontruncated failures all produce explicit right-based Brunnian vertical
witnesses.

For a positive proof, the target is now:

```text
for one fixed m=m(X), every arity has status none.
```

For a negative proof, the target is an infinite symmetric-tail sequence whose
statuses are `stabilizer`, `orbit_label`, or `orbit_relation`, with explicit
witness words.

## Audit Hook

The helper

```text
point_pushing_brunnian_orbit_audit(...)
```

now records:

- `failure_kind`;
- `relative_subgroup_size=|B|`;
- `relative_detector_projection_size=|B_D|`;
- `relative_action_projection_size=|B_X|`.

When `failure_kind="none"`, the finite row has passed both the
stabilizer-centralizer gate and the post-stabilizer orbit-relation quotient
gate.  This remains a finite-row certificate only; an A proof still needs a
uniform all-arity argument for one fixed detector.
