# Universal continuation derivation certificate

Date: 2026-05-29

This note follows `proofs/elementary_continuation_closure.md`.  It does not
prove descent separation and does not prove the Master Local-Minimal Residual
Theorem.  It records the exact finite certificate carried by a single
continuation seed whose closure is universal.

## Setup

Let

```text
x ~ v
```

be one nontrivial continuation seed in a rack-base local interval.  Let

```text
Theta(x,v)
```

be the least admissible congruence family generated by this seed.

The closure engine builds `Theta(x,v)` by repeatedly transporting product
relations through every local table and inverse local table.  It also records,
for each new nontrivial fibre edge, the first derivation:

```text
GeneratedCongruenceDerivationRow(
  depth,
  color,
  left,
  right,
  source,
  crossing,
  source_pairs
).
```

Thus a universal closure is not opaque.  It comes with an explicit finite
derivation tree, edge by edge.

## Derivation certificate

For each continuation seed closure, define the audit

```text
continuation_seed_universal_derivation_audits(interval).
```

It records:

- the seed pair closure;
- the number of nontrivial undirected fibre edges in the generated family;
- the number of first-derivation rows recorded for those edges;
- the missing derivation count per colour.

The audit proves a single-seed universal derivation when:

```text
generated.kind = universal
```

and every nontrivial fibre edge has a derivation row.

The failure helper is:

```text
continuation_seed_universal_derivation_failures(interval).
```

## Lemma

If `continuation_seed_universal_derivation_audits(interval)` proves a seed's
universal derivation, then every fibre relation in the all-universal family is
obtained from that one seed by a finite chain of forward and inverse local
table transports.

Proof.  The generated-congruence algorithm starts with the seed edge, closes
under equivalence, then repeatedly applies every coloured local bijection and
its inverse to product-related pairs.  Whenever a new nontrivial undirected
edge first appears, it records the source row, the crossing, and the source
pairs that produced it.  If the final family is universal and no derivation
edge is missing, every nontrivial fibre edge in the universal relation has
such a finite first-derivation chain.  QED.

## Consequence for descent separation

The final unproved descent-separation target can now be stated with no hidden
collective closure language.

For each local-minimal bottleneck interval, each chart-conjugacy orbit of
nontrivial continuation seeds has a representative seed.  That representative
has:

1. a universal single-seed closure;
2. a finite derivation certificate for every fibre edge in that universal
   closure;
3. chart-transport collapse for all transported copies once one representative
   endpoint witness is supplied.

Therefore a positive proof can focus on the following finite symbolic task:

```text
For each representative continuation seed and for each derived edge in its
universal derivation certificate, prove that the transported endpoint motion
is visible in the fixed Green/Schutzenberger/atom detector factors.
```

If this seed-derived visibility is proved, then all continuation motion is
accounted for by the fixed interval-level detector product.  Transport-state
rackification handles the strand-continuing residue.

## B-route meaning

A negative proof can no longer appeal to an unspecified universal
continuation corridor.  It must choose:

```text
one continuation seed,
one derived edge in its finite universal derivation certificate,
```

and upgrade the associated residual motion to a normalized-law sequence
invisible to every finite group while still moving a tuple.

This is a sharper obstruction seed than a collective continuation closure, but
it is still not outcome B until the normalized-law sequence is constructed.
