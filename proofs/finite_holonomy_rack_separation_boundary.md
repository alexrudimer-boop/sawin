# Finite Holonomy-Rack Separation Boundary

Date: 2026-06-05

This note records the sharpened boundary after the active-factor /
vertexization audit.  The prefix-path vertexization theorem is valid, but it
does not by itself prove Sawin's problem.  The remaining gap is a finite
holonomy-rack separation lemma for the prefix path groupoid.

## Strengthened active factors

An ordinary solution quotient

```text
q:X -> Z
```

is `B_n`-equivariant in the sense that

```text
q^n rho_n^X(beta) = rho_n^Z(beta) q^n.
```

Therefore it gives

```text
ker rho_n^X <= ker rho_n^Z,
```

which is the wrong direction for Sawin domination.

The useful active-factor notion must be kernel-reflecting.  A finite solution
`Z` is a domination-reducing active factor of `X` if, for every `n`, there are
`B_n`-equivariant maps

```text
Pi_n:X^n -> Z^n
```

and inert maps

```text
eta_n:X^n -> I_n
```

such that

```text
(Pi_n,eta_n):X^n -> Z^n x I_n
```

is injective.  Then

```text
ker rho_n^Z <= ker rho_n^X
```

for all `n`: if `beta` acts trivially on `Z^n`, then `Pi_n` and `eta_n` both
take the same values on `w` and `rho_n^X(beta)w`, and injectivity forces
`rho_n^X(beta)w=w`.

With this strengthened definition, the induction scheme is clean:

```text
direct rack domination
or proper domination-reducing active factor
or finite prefix-path vertexization
    => Sawin, by minimal counterexample induction.
```

The product padding example `X=E x Z` is the model case.  The `E` coordinate is
inert, the `Z` coordinate is active, and

```text
ker rho_n^X = ker rho_n^Z.
```

## Prefix-Dependent Obstruction

Product-observer fibers do not automatically produce active factors.  A
coordinate active factor requires prefix-independent indistinguishability of
letters.  But product and prefix data can collapse letters after one prefix
and separate them after another.

For `S=S_L^1`, such a collapse has the form

```text
x ~_p y    iff    (p,x) and (p,y) are indistinguishable.
```

If the relations `~_p` are independent of `p`, one may hope to build a letter
congruence and a proper active quotient.  If the relations depend on `p`, the
phenomenon is holonomy rather than an active coordinate factor.  This is why
the prefix vertex state `(p,x)` is necessary.

Thus product-observer failure splits into two types:

```text
coordinate-uniform failure      possible active factor;
prefix-dependent failure        holonomy / vertexization problem.
```

## Universal Prefix Vertex Rack

Let

```text
S=S_L^1.
```

Define `V_L(X)` to be the rack generated by symbols

```text
a_{p,x}        (p in S, x in X)
```

with relations, for every `p,x,y` and `r_X(x,y)=(u,v)`,

```text
a_{p,u} = a_{pL_x,y},                              (VL1)
a_{pL_u,v} = a_{pL_x,y} triangleright a_{p,x}.     (VL2)
```

Equivalently,

```text
V_L(X)=FreeRack(S x X)/<(VL1),(VL2)>.
```

This is the universal rack for prefix vertexization: maps

```text
psi:S x X -> Y
```

to a rack `Y` satisfying `(V1),(V2)` are exactly rack homomorphisms

```text
V_L(X) -> Y
```

sending `a_{p,x}` to `psi(p,x)`.

For a word `w=(x_1,...,x_n)`, define

```text
p_0=1,
p_i=L_{x_1}...L_{x_i},
P_n(w)=(a_{p_0,x_1},a_{p_1,x_2},...,a_{p_{n-1},x_n}).
```

The relations `(VL1),(VL2)` say exactly that `P_n` is `B_n`-equivariant under
the rack convention

```text
r_Y(a,b)=(b,b triangleright a).
```

## Finite Residual Equivalence

On the finite generator set `S x X`, define

```text
(p,x) ==_fin (q,y)
```

if every homomorphism from `V_L(X)` to a finite rack identifies the two
generators:

```text
f(a_{p,x})=f(a_{q,y}).
```

Since `S x X` is finite, there is one finite product quotient of `V_L(X)` that
separates all generator pairs not identified by `==_fin`: for each separated
pair choose one finite rack quotient, and take their finite product.

If orbit observers are allowed, take

```text
iota_n(w)=B_n-orbit of w.
```

Then finite prefix vertexization is equivalent to orbitwise separation:
for every `n`, if `w != w'` lie in the same braid orbit, then for some
coordinate `i`,

```text
(p_{i-1}(w),w_i) not ==_fin (p_{i-1}(w'),w'_i).
```

Equivalently, finite vertexization fails exactly when there are `n`, a braid
`beta`, and a word `w` such that

```text
w' = rho_n^X(beta)w != w
```

but

```text
(p_{i-1}(w),w_i) ==_fin (p_{i-1}(w'),w'_i)
```

for every coordinate `i`.

This is the exact finite obstruction hidden inside the vertexization branch.

## Concrete Congruence Pressure

Any finite rack quotient of `V_L(X)` must respect the rack congruence rules
forced by `(VL1),(VL2)`.

Let

```text
A=(p,x),
B=(pL_x,y),
r_X(x,y)=(u,v).
```

Then the partial operation demanded by a prefix square is

```text
B triangleright A = (pL_u,v).
```

Thus any admissible finite quotient relation must satisfy:

```text
Functionality:
if B~B' and A~A', then B triangleright A ~ B' triangleright A'.

Injectivity of rack translations:
if B~B' and B triangleright A ~ B' triangleright A', then A~A'.

Self-distributive closure:
c triangleright (b triangleright a)
  ~ (c triangleright b) triangleright (c triangleright a)
whenever the terms are realized by YBE prefix squares.
```

A concrete obstruction to vertexization is therefore a finite residual
congruence collapse, closed under these rules, that identifies all prefix
labels of two distinct words in the same braid orbit.

## Relation To `U_L(X)`

The universal Hurwitz rack `U_L(X)` is a suffix object.  Its generators are

```text
[t,x]        (t in S_L^1, x in X)
```

and `t` is read as the product to the right of the current letter.  By
contrast, `V_L(X)` is a prefix object: `p` is the product to the left.

These are not generally the same rack.  They become formally related only
after reversing words and passing to an opposite solution with compatible
left/right semigroup data.  Finite transformation semigroups do not generally
carry an anti-isomorphism identifying

```text
p -> pL_x
```

with

```text
t -> L_x t.
```

Thus product-Hurwitz separability for `U_L(X)` does not automatically imply
prefix vertexization for `V_L(X)`.

## Holonomy And Rees Sandwich Data

Let `S=S_L^1`.  The local group method compresses minimal-ideal data to
`eSe`, where `e` is an idempotent in a minimal ideal.  The YBE product identity
gives

```text
eL_uL_v e = eL_xL_y e,
```

but this does not imply

```text
eL_u eL_v e = eL_x eL_y e.
```

In Rees matrix coordinates, the missing information is the intermediate row
and column data and the sandwich entry used between adjacent factors.  Prefix
vertexization keeps exactly this transition data by remembering arrows

```text
p --x--> pL_x.
```

Equivalently, let `H_L(X)` be the finite prefix path category with objects
`p in S` and generating arrows `(p,x):p -> pL_x`, modulo YBE square relations

```text
(p,x)(pL_x,y) = (p,u)(pL_u,v)
```

when `r_X(x,y)=(u,v)`.  Then `V_L(X)` is the universal rack-valued labelling
of the generating arrows of this holonomy category that sends each YBE square
to a rack crossing.

The local group `eSe` collapses this path groupoid to one object and loses the
intermediate sandwich coordinates.  `V_L(X)` retains them.

## Missing Lemma

The active-factor / vertexization route now reduces to the following finite
holonomy-rack separation lemma.

```text
For every residual rigid finite solution X with no proper domination-reducing
active factor, the finite-rack residual equivalence of V_L(X) is orbit-faithful:
if w != w' lie in the same B_n-orbit, then their prefix vertex words differ in
at least one coordinate modulo ==_fin.
```

Equivalently:

```text
Every finite-rack residual collapse of prefix vertices either descends to a
proper inert active factor, or is harmless for braid-orbit separation.
```

This is not a consequence of product observers or of the suffix Hurwitz rack
`U_L(X)`.  It is the distinct remaining problem.
