# Block-Core Finite-Image Obstruction

Date: 2026-06-06

This note records a C-type sharpening of the finite-image obstruction for
Sawin's finite-rack domination problem.  It does not prove domination for all
finite bijective set-theoretic Yang-Baxter solutions and does not produce a
cofinal counterexample.  Its contribution is to replace the previous
pairwise-core sufficient target by a strictly sharper triple/block-core
target.

## Setup

Let `G` be a group and let

```text
N_1,...,N_r triangleleft G.
```

For a nonempty subset `S subset {1,...,r}`, write

```text
N_S = product_{i in S} N_i,
```

the normal subgroup generated by the `N_i` with `i in S`.

For normal subgroups `H_1,...,H_s triangleleft G`, write

```text
[H_1,...,H_s]_Sigma
```

for the symmetric commutator subgroup generated by all fully parenthesized
iterated commutators with one input from each `H_i`, in arbitrary order.

For `3 <= s <= r`, let `Pi_s(r)` be the set of partitions

```text
P={S_1,...,S_s}
```

of `{1,...,r}` into `s` nonempty blocks.  Define the `s`-block core

```text
Theta_s(G;N_1,...,N_r)
  =
intersection_{P={S_1,...,S_s} in Pi_s(r)}
  [N_{S_1},...,N_{S_s}]_Sigma.
```

The all-meridian symmetric commutator is

```text
C=[N_1,...,N_r]_Sigma = Theta_r.
```

The previous pairwise core is

```text
D=intersection_{1<=i<j<=r} [N_i,N_j].
```

## Fat-Commutator Input

We use the standard fat-commutator theorem for normal subgroups.

Theorem.  Let `H_1,...,H_s triangleleft G`.  Let `F(H_1,...,H_s)` be the
subgroup generated by all fully parenthesized iterated commutators whose
entries are taken from the `H_i`, with the only requirement that every `H_i`
appears at least once.  Then

```text
F(H_1,...,H_s) = [H_1,...,H_s]_Sigma.
```

Proof sketch.  The inclusion from right to left is immediate.  For the other
direction, induct on the total number of entries in the commutator word.  The
identities

```text
[xy,z] = x[y,z]x^{-1} [x,z],
[x,yz] = [x,y] y[x,z]y^{-1},
```

together with the Hall-Witt collection consequence for normal subgroups,
allow repeated labels to be collected and removed modulo products of
commutators with the same set of labels and smaller total length.  Normality
keeps all conjugates in the same subgroup products.  Induction reduces every
fat commutator to a product of symmetric commutators with one occurrence of
each subgroup.

## Block-Core Interpolation

Theorem.  If `r>=3`, then

```text
C = Theta_r <= Theta_{r-1} <= ... <= Theta_3 <= D.
```

Proof.  Fix a partition

```text
P={S_1,...,S_s} in Pi_s(r).
```

Every generator of `C=[N_1,...,N_r]_Sigma` is a fully parenthesized
commutator with one input from each `N_i`.  If one forgets the individual
labels and remembers only the block `S_a` containing each label, the same
commutator is a fat commutator in

```text
N_{S_1},...,N_{S_s}
```

with every block appearing at least once.  By the fat-commutator theorem,

```text
C <= [N_{S_1},...,N_{S_s}]_Sigma.
```

Intersecting over all `s`-block partitions gives `C<=Theta_s`.

If a partition `Q` refines a partition `P`, then each block subgroup of `P`
is a product of block subgroups of `Q`.  A symmetric commutator for the
refined partition is therefore a fat commutator for the coarser partition, so
it lies in the coarser symmetric commutator subgroup.  Intersecting over
partitions gives

```text
Theta_{s+1} <= Theta_s.
```

Finally, fix a pair `i!=j` and choose a three-block partition

```text
P={{i},{j},R},
R={1,...,r}\{i,j}.
```

The pairwise-depth lemma for symmetric commutators gives

```text
[N_i,N_j,N_R]_Sigma <= [N_i,N_j].
```

Since `Theta_3` lies in this three-block commutator for every such pair,

```text
Theta_3 <= intersection_{i<j}[N_i,N_j] = D.
```

This proves the interpolation chain.

## Strictness

The inclusion `Theta_3<=D` can be strict.

Let `G` be a class-two `p`-group generated by `a,b,c,z`, with `z` central of
order `p`, and with

```text
[a,b]=[a,c]=[b,c]=z.
```

All triple commutators are trivial.  Put

```text
N_1=<a,z>,   N_2=<b,z>,   N_3=<c,z>.
```

Then

```text
[N_1,N_2]=[N_1,N_3]=[N_2,N_3]=<z>,
```

so `D=<z> != 1`.  But the group has nilpotency class two, hence

```text
Theta_3 = [N_1,N_2,N_3]_Sigma = 1.
```

Thus the pairwise core can contain class-two noise which is not an
all-meridian Brunnian obstruction.

## Finite-Image Consequence

Return to the finite-image obstruction setup.  For a finite rack detector
`Y`, put

```text
Q=Y^0 x T_2.
```

Let

```text
F_{n-1}=ker(d_n:P_n -> P_{n-1})
```

be the last-strand free group with generators `x_i=A_{in}`.  Let

```text
Phi_n:F_{n-1} -> Gamma_n <= Sym(Q^n) x Sym(X^n)
```

be the combined finite image and define

```text
K_n = ker(Gamma_n -> rho^Q_n(F_{n-1})),
L_n = ker(Gamma_n -> rho^X_n(F_{n-1})),
N_{i,n}=<<Phi_n(x_i)>>_{Gamma_n}.
```

The ordinary-Brunnian finite-image reduction gives

```text
Phi_n(Brun_n cap ker rho^Q_n)
  =
K_n cap C_n,

C_n=[N_{1,n},...,N_{n-1,n}]_Sigma.
```

Since `Gamma_n` is a subgroup of a direct product of the `Q` and `X` finite
images, `K_n cap L_n=1`.  Thus the detector `Q` dominates `X` if and only if

```text
K_n cap C_n = 1
```

for every `n`.

For `3 <= s <= n-1`, define

```text
Theta_{n,s}
  =
Theta_s(Gamma_n;N_{1,n},...,N_{n-1,n}).
```

The block-core interpolation gives

```text
C_n <= Theta_{n,s} <= Theta_{n,3} <= D_n,
```

where

```text
D_n=intersection_{1<=i<j<=n-1}[N_{i,n},N_{j,n}].
```

Therefore the large-arity sufficient condition can be sharpened from
`K_n cap D_n=1` to

```text
K_n cap Theta_{n,3} = 1
```

for every sufficiently large `n`, with fixed-arity rack cofinality handling
the finitely many remaining arities.

## Relative Block-Core Criterion

Let `Z` be a braided quotient of `X` already dominated by a finite rack
`Y_Z`, and put `Q=Y_Z^0 x T_2`.

For the last-strand `X` image write

```text
H_n=G^X_n=rho^X_n(F_{n-1}),
M_{i,n}=<<rho^X_n(x_i)>>_{H_n},
E_n=ker(G^X_n -> G^Z_n).
```

Define

```text
Theta^X_{n,s}
  =
Theta_s(H_n;M_{1,n},...,M_{n-1,n}).
```

Theorem.  If there is a fixed integer `s>=3` such that

```text
E_n cap Theta^X_{n,s} = 1
```

for every sufficiently large `n`, then `X` is dominated by one finite rack.
In particular, it is enough to prove the triple-block condition

```text
E_n cap Theta^X_{n,3} = 1
```

for all sufficiently large `n`.

Proof.  Let `gamma in K_n cap C_n`, and choose `beta in F_{n-1}` with
`Phi_n(beta)=gamma`.  Since `gamma in K_n`, the `Q` action of `beta` is
trivial.  Because `Q` contains a rack detector dominating `Z`, the `Z` action
of `beta` is trivial, hence

```text
rho^X_n(beta) in E_n.
```

Since `gamma in C_n`, its `X` projection lies in

```text
C^X_n=[M_{1,n},...,M_{n-1,n}]_Sigma.
```

By block-core interpolation, `C^X_n<=Theta^X_{n,s}`.  Hence

```text
rho^X_n(beta) in E_n cap Theta^X_{n,s}=1.
```

Thus `gamma in K_n cap L_n=1`.  Therefore `K_n cap C_n=1` in all sufficiently
large arities, and fixed-arity rack cofinality supplies finitely many racks
for the remaining arities.

## Comparison With the Gamma-2 Criterion

The earlier relative criterion asked for

```text
E_n cap gamma_2(G^X_n)=1.
```

The block-core criterion is weaker.  For `s=3`,

```text
Theta^X_{n,3} <= gamma_3(G^X_n) <= gamma_2(G^X_n).
```

Thus `E_n cap gamma_2(G^X_n)=1` implies the triple-block criterion, but not
conversely.  Class-two relative-kernel commutator noise may intersect
`gamma_2(G^X_n)` nontrivially without producing an all-meridian Brunnian
obstruction once `n>=4`.

## Chief-Factor Consequence

If a finite-image failure occurs, there is a nontrivial element in
`K_n cap C_n`.  Any chief factor `A/B` selected inside such a failure is
covered by `C_n`, and hence by every `Theta_{n,s}` for `3<=s<=n-1`.

In particular, a central Type C obstruction is not merely a prime-order
central factor covered by every pairwise commutator.  It must be a
prime-order central factor covered by every triple-block commutator

```text
[N_{A,n},N_{B,n},N_{C,n}]_Sigma
```

for every three-way partition `{A,B,C}` of the meridians.

## Remaining Boundary

To prove Sawin's statement through this finite-image route, it is enough to
prove:

```text
exists Q=Y^0 x T_2 such that for all sufficiently large n,
K_n cap Theta_{n,3}=1.
```

Equivalently, through a dominated quotient `Z`, it is enough to prove:

```text
E_n cap Theta^X_{n,3}=1
```

for all sufficiently large `n`.

A cofinal counterexample must do more than produce pairwise commutator noise.
For every finite rack prefix `P_m`, with `Q_m=P_m^0 x T_2`, it must produce
unbounded arities `n_m` and nontrivial elements

```text
1 != gamma_m in K_{n_m} cap C_{n_m},
```

and therefore automatically

```text
gamma_m in K_{n_m} cap Theta_{n_m,s}
```

for every fixed `3<=s<=n_m-1`, especially in the triple-block core
`Theta_{n_m,3}`.
