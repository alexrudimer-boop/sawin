# Triangular recovery unit observer

Date: 2026-05-31

This note follows `proofs/nonlinear_overlap_refined_obstruction.md` and
`proofs/triangular_bundle_recovery_inverse.md`.  It does not prove the
remaining all-`n` endpoint-longitude theorem.  It converts the final
triangular recovery labels into the same fixed finite unit-group format used
by the existing unit-composite longitude criterion.

## Setup

For a constant-section triangular row, the recovery inverse has the form:

```text
output state (u,v) -> source state (x,y).
```

The source and output states may live over different colour pairs, so this is
best viewed as a partial bijection between two tagged slices of one finite
state universe:

```text
(colour_left, colour_right, fibre_left, fibre_right).
```

Each triangular recovery row gives a finite partial bijection from its output
slice to its source slice.

## Fixed unit observer

[Proved] Every triangular recovery row with a bijective recovery formula can
be extended to a permutation of one fixed finite tagged universe.

Proof.  Let `D` be the output slice and `I` be the source slice.  The recovery
formula is a bijection `D -> I`.  Since `D` and `I` have equal size, their
complements in the finite universe also have equal size.  Pair the complement
of `D` with the complement of `I` in a fixed deterministic order.  Together
with the recovery bijection, this gives a permutation of the whole universe.
QED.

Let `U_tri` be the finite permutation group generated by these recovery-row
extensions.  It depends only on the local interval, not on braid index.

The executable object is:

```text
triangular_recovery_unit_observer_audit(interval)
```

It records the tagged universe, the recovery-row permutations, the finite
transition monoid they generate, and the unit group order.  Passing the audit
means:

```text
every recovery formula is bijective;
every recovery-row extension is a unit/permutation.
```

## Endpoint criterion

[Proved] If a residual triangular-recovery endpoint is represented by a word
in the recovery-row permutations and its resulting unit composite lies in

```text
V_beta(U_tri),
```

then identity finite-`U_tri` Artin-longitude data kills that endpoint.

Proof.  This is exactly `proofs/unit_composite_longitude_criterion.md`
applied to the fixed finite transformation monoid generated by the recovery
permutations.  If `Lambda_{U_tri,n}(beta)` is the identity signature, then
`V_beta(U_tri)={1}`.  Hence any endpoint composite in `V_beta(U_tri)` is the
identity permutation of the tagged recovery universe, and therefore fixes the
original triangular recovery state.  QED.

The executable fixed-word route check is:

```text
triangular_recovery_longitude_route_audit(
    interval, n, braid_word, factor_row_indices
)
```

It delegates the endpoint subgroup check to
`unit_composite_longitude_route_audit(...)`.

The bundled post-linear supplied-certificate checker is:

```text
triangular_recovery_endpoint_witness_audit(
    observer,
    routed_defects,
    endpoint_audits,
)
```

It keys endpoint certificates by

```text
(left_color, right_color, routed_defect_reason)
```

and accepts any of the existing recovery endpoint certificates which prove
membership in `V_beta(U_tri)`: subgroup-route, explicit longitude expression,
derived-series lift, or perfect-residual route.  The audit requires the same
fixed observer, exact coverage of the routed keys, no extra keys, and proved
endpoint visibility.  When supplied to the post-linear classifier, a matching
bundle closes System U as `closed_by_triangular_recovery_endpoint_witness`.

The coarser symmetric-detector supplied certificate is:

```text
triangular_recovery_symmetric_endpoint_fork_audit(
    observer,
    routed_defects,
    endpoint_family,
    covered_keys,
)
```

where `endpoint_family` is the finite endpoint-family symmetric fork for the
single fixed group `U_tri`.  It requires the endpoint-family group order list
to be exactly `(|U_tri|,)` and the covered keys to match the routed System U
keys.  A matching positive cutoff closes System U as
`closed_by_triangular_recovery_symmetric_endpoint_fork`; in a routed product
system it removes only U from `unclosed_routed_endpoint_systems`.

The all-`n` symbolic route is sharpened in
`proofs/triangular_recovery_detector_lift_fork.md`.  If the recovery observer
admits active Artin detector-lift local rows in `U_tri`, then terminal
recovery endpoints are literal recursive-longitude expressions and hence lie
in `V_beta(U_tri)` without subgroup enumeration.

## Final refined obstruction

[Open] The nonlinear survivor is now sharper than "triangular endpoint
recovery" alone.  It is:

```text
a triangular recovery endpoint composite in the fixed finite group U_tri
that is not yet proved to lie in V_beta(U_tri), uniformly in braid index,
and has not been upgraded to a normalized-law sequence.
```

Thus the A-route target is:

```text
Triangular recovery unit-longitude theorem.
For every local-minimal bi-free universal-corridor interval, every residual
triangular recovery endpoint composite lies in V_beta(U_tri), uniformly for
all beta in the quotient-kernel braid action.
```

The B-route target is:

```text
Construct one interval and a normalized-law sequence whose residual motion is
a nonidentity endpoint in U_tri while the sequence is eventually invisible to
every finite group.
```

A finite miss against one braid word and one `U_tri` is not `[Resolution: B]`;
it is only the first row of the normalized-law certificate.
