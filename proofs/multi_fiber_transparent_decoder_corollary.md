# Species-Indexed Multi-Fibre Transparent Decoder Corollary

Date: 2026-06-08

This note records the corrected multi-fibre transparent decoder corollary.
Transparent support follows physical strands, not arbitrary quotient colours.
Thus transparent hidden decoders are canonically indexed by strand species of
the quotient solution.

## Strand-Species Quotient

Let `Z` be a finite bijective YBE solution.  For

```text
R_Z(a,b)=(u,v),
```

define `E_sp` to be the equivalence relation on `Z` generated by

```text
u ~ b,
v ~ a
```

for every crossing.  Let

```text
Sp(Z)=Z/E_sp,
sigma:Z -> Sp(Z)
```

be the quotient map.

Then `R_Z` descends to the flip solution on `Sp(Z)`:

```text
R_{Sp(Z)}(sigma(a),sigma(b))=(sigma(b),sigma(a)).
```

Indeed, if `R_Z(a,b)=(u,v)`, then the defining relations give

```text
sigma(u)=sigma(b),
sigma(v)=sigma(a).
```

The quotient has the following universal property.  If `c:Z -> S` is any map
to a flip solution satisfying

```text
c(u)=c(b),
c(v)=c(a)
```

whenever `R_Z(a,b)=(u,v)`, then `c` factors uniquely through `sigma`.

Consequently, transparent decoders cannot generally be attached to arbitrary
quotient colours.  They can be attached canonically to species
`s in Sp(Z)`.  Colour-indexed transparent decoders are valid only in the
special case `Sp(Z)=Z`.

## Statement

Let `X` be a finite bijective YBE solution.  Suppose there is a braided
quotient

```text
pi:X -> Z,
```

and suppose `Z` is dominated by a finite rack `Y_Z`:

```text
ker rho^{Y_Z}_n <= ker rho^Z_n
```

for every `n`.

Let

```text
sigma:Z -> S=Sp(Z)
```

be the strand-species quotient.  For each species `s in S`, let `W_s` be a
finite bijective YBE solution dominated by a finite rack `Y_s`:

```text
ker rho^{Y_s}_n <= ker rho^{W_s}_n
```

for every `n`.

Let `W_s^0` denote the transparent YBE extension of `W_s`, obtained by adding
a color `0` with

```text
R(0,w)=(w,0),
R(w,0)=(0,w),
R(0,0)=(0,0).
```

Assume that for every `s in S` and every arity `n`, there is a readout

```text
Gamma^s_n:X^n -> (W_s^0)^n
```

satisfying braid equivariance:

```text
Gamma^s_n(rho^X_n(beta)(x))
  =
rho^{W_s^0}_n(beta)(Gamma^s_n(x))
```

for all `beta in B_n` and `x in X^n`, and satisfying species support:

```text
Gamma^s_n(x)_i = 0 whenever sigma(pi(x_i)) != s.
```

Finally assume the combined decoder

```text
D_n:X^n -> Z^n x product_{s in S} (W_s^0)^n
```

given by

```text
D_n(x) = (pi^n(x), (Gamma^s_n(x))_{s in S})
```

is injective for every `n`.

Then `X` is dominated by the finite rack

```text
Y = Y_Z x product_{s in S} Y_s^0.
```

That is,

```text
ker rho^Y_n <= ker rho^X_n
```

for every `n`.

## Proof

For each `s`, the rack transparent extension `Y_s^0` dominates the YBE
transparent extension `W_s^0`.  Indeed, if a braid is trivial on
`(Y_s^0)^n`, then for every subset of nontransparent strands the induced
deleted braid is trivial on the corresponding `Y_s` subword.  Since `Y_s`
dominates `W_s`, the deleted braid is trivial on the corresponding `W_s`
subword.  Hence the original braid is trivial on `(W_s^0)^n`.

Equivalently, the product

```text
U = product_{s in S} W_s^0
```

is dominated by

```text
Y_U = product_{s in S} Y_s^0.
```

Define

```text
Gamma_n:X^n -> U^n
```

coordinatewise by

```text
Gamma_n(x)_i = (Gamma^s_n(x)_i)_{s in S}.
```

Since each `Gamma^s_n` is braid-equivariant, `Gamma_n` is braid-equivariant
for the product solution `U`.  The assumed combined decoder is exactly

```text
(pi^n, Gamma_n):X^n -> Z^n x U^n.
```

It is injective by hypothesis.  The finite-state dominated-decoder theorem
therefore gives

```text
ker rho^{Y_Z x Y_U}_n <= ker rho^X_n
```

for every `n`, which is the claimed domination by
`Y_Z x product_s Y_s^0`.

## Local Certificate

The corollary is often certified by one shared finite context system.  Let
`L,R` be finite monoids, with updates

```text
lambda:X -> L,
rho:X -> R.
```

For `R_X(x,y)=(u,v)`, assume

```text
lambda(x) lambda(y)=lambda(u) lambda(v),
rho(y) rho(x)=rho(v) rho(u).
```

For each species `s in S`, let

```text
gamma_s:L x X x R -> W_s^0
```

be a finite local readout with

```text
gamma_s(A,x,B)=0 whenever sigma(pi(x)) != s.
```

Define contexts

```text
A_1=1_L,
A_{i+1}=A_i lambda(x_i),
B_n=1_R,
B_i=B_{i+1} rho(x_{i+1}),
```

and

```text
Gamma^s_n(x)_i = gamma_s(A_i,x_i,B_i).
```

The following local identity for all `A in L`, `B in R`, and `x,y in X`
with `R_X(x,y)=(u,v)` is a finite sufficient certificate for equivariance:

```text
R_{W_s^0}(
  gamma_s(A,x,B rho(y)),
  gamma_s(A lambda(x),y,B)
)
 =
(
  gamma_s(A,u,B rho(v)),
  gamma_s(A lambda(u),v,B)
).
```

The species support condition is compatible with transparent crossing
support because, writing `R_Z(pi(x),pi(y))=(pi(u),pi(v))`, the species
quotient gives

```text
sigma(pi(u)) = sigma(pi(y)),
sigma(pi(v)) = sigma(pi(x)).
```

The local identity is an exact necessary condition on all reachable context
pairs; requiring it for every `A,B` is the convenient finite global
certificate.

## Finite Injectivity Test

With the shared local context data above, all-arity injectivity of `D_n` is a
finite graph test.

Build a finite directed graph with vertices

```text
(A,A',B,B',x,x') in L^2 x R^2 x X^2
```

satisfying

```text
pi(x)=pi(x')
```

and

```text
gamma_s(A,x,B)=gamma_s(A',x',B')       for every s in S.
```

There is an edge

```text
(A,A',B,B',x,x') -> (bar A,bar A',bar B,bar B',y,y')
```

iff

```text
bar A  = A  lambda(x),
bar A' = A' lambda(x'),
B  = bar B  rho(y),
B' = bar B' rho(y').
```

Initial vertices have `A=A'=1_L`; terminal vertices have `B=B'=1_R`.
Then `D_n` fails to be injective for some `n` if and only if this graph has
an initial-to-terminal path containing at least one coordinate mismatch
`x_i != x_i'`.  If a collision exists, one exists with

```text
n <= 2 |L|^2 |R|^2 |X|^2.
```

## Use

This corollary packages multi-fibre hidden data into transparent dominated
channels indexed by physical strand species.  It strictly generalizes the
one-fibre gap-gauge mechanism when a solution has several nonsingleton
quotient fibres, provided the hidden data is separated by species and the
product of those readouts jointly decodes `X^n` with the quotient.

The remaining positive target is to construct such quotient and
species-indexed transparent decoder data for arbitrary finite degenerate
`X`, or to handle cases where several quotient colours in one species have
interacting nonsingleton fibres that cannot be separated by transparent
species channels.
