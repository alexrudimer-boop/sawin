# Continuation readout propagation criterion

Date: 2026-05-29

This note follows
`proofs/universal_continuation_derivation_certificate.md`.  It does not prove
descent separation and does not prove Sawin finite-rack domination.  It records
one exact monotonicity step: once a fixed detector readout relation is an
admissible local congruence and contains one continuation seed, it contains
the entire least admissible closure generated by that seed.

The point is to remove a possible source of duplicate work.  A positive proof
does not need to re-prove visibility for every derived edge separately after
it has proved that the fixed readout relation is admissible and contains the
representative seed.

## Setup

Let

```text
pi : X -> Z
```

be a local interval, with fibres `A_a` over colours `a in Z`.  Suppose a
non-strand-continuing row gives a continuation seed

```text
x ~ v in A_a.
```

Let

```text
Theta(x,v)
```

be the least admissible congruence family generated by this seed.  In code this
is the `generated` field of a
`ContinuationSeedPairClosureAudit`.

Let

```text
Phi = (Phi_a)_a
```

be a candidate fixed detector readout relation.  In the intended application,
`Phi` is the equality relation on the quotient by the fixed Green,
Schutzenberger, atom, and endpoint/unit detector factors.  Thus

```text
p Phi_a q
```

means that those fixed readout factors do not distinguish `p` and `q`.

## Lemma

Assume:

1. `Phi` is an admissible local congruence family;
2. the continuation seed is contained in `Phi`, i.e. `x Phi_a v`.

Then

```text
Theta(x,v) <= Phi.
```

Equivalently, every edge derived from the seed by forward and inverse local
table transport is also contained in the fixed readout relation.

Proof.  By definition, `Theta(x,v)` is the least admissible congruence family
containing the seed pair `x~v`.  Since `Phi` is also admissible and contains
that same seed pair, `Phi` is one of the admissible families over which the
least closure is taken.  Therefore `Theta(x,v)` is contained in `Phi`.  QED.

This is not a finite-search-only assertion.  The finite closure computation is
used only to expose the exact generated family and derivation rows for the
finite local interval.  The proof is the universal property of the generated
admissible congruence.

## Code certificate

The code helper

```text
continuation_seed_readout_propagation_audit(
    interval,
    seed_closure,
    readout_family,
)
```

records:

- whether `readout_family` is admissible;
- whether it contains the seed pair;
- whether it contains the whole generated seed closure;
- which generated nontrivial edges are missing, if any;
- whether a universal seed closure forces the readout itself to be universal.

The batch helper is

```text
continuation_seed_readout_propagation_audits(interval, readout_family).
```

The failure helper is

```text
continuation_seed_readout_propagation_failures(interval, readout_family).
```

## Consequence for descent separation

The previous reduction said that a positive A-route must route every edge in
the universal continuation derivation certificate through fixed Green,
Schutzenberger, atom, or endpoint/unit readouts.

The propagation lemma sharpens this target.  It is enough to prove, for each
representative continuation seed:

1. the fixed readout relation `Phi` is admissible;
2. the representative seed lies in `Phi`.

Then every derived edge in the seed's universal closure lies in `Phi`
automatically.  If the seed closure is universal, then `Phi` must itself be
universal; the fixed readout collapses the entire lower continuation fibre.

Thus the remaining positive theorem can be stated more tightly:

```text
Representative seed visibility.
For every local-minimal bottleneck interval and every chart-conjugacy orbit of
nontrivial continuation seeds, the fixed Green/Schutzenberger/atom/unit
readout relation is admissible and contains one representative seed.
```

Together with chart-transport collapse, this would propagate to all transported
copies and all derived edges.  Transport-state rackification would then handle
the strand-continuing residue.

## B-route meaning

A counterexample can no longer be a derived edge that escapes after its seed
is already known to lie in an admissible fixed readout relation.  Such escape
is impossible by the lemma.

A genuine B seed must instead be one of:

1. the fixed readout relation is not admissible;
2. a representative continuation seed is not contained in that relation;
3. the readout relation is not the actual equality relation of the claimed
   fixed detector factors;
4. the resulting finite failure can be upgraded to a normalized-law sequence
   invisible to every finite group while still moving a residual tuple.

The fourth item remains mandatory for outcome B; a bounded readout failure is
not enough.
