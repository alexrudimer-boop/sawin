# Pairwise-Or-Central Finite-Image Obstruction

Date: 2026-06-06

This note sharpens the chief-factor finite-image obstruction.  Once the
meridian normal closures generate the finite image, every nonabelian
obstruction and every noncentral abelian obstruction is already visible to a
two-meridian commutator.  The only obstruction that can genuinely require the
full all-meridian symmetric commutator is central elementary abelian.

This is still a C-type result.  It does not prove Sawin's statement and does
not construct a cofinal counterexample.

## Group-Theoretic Theorem

Let `G` be a finite group generated by normal subgroups

```text
N_1,...,N_r,        r>=2,
```

and let `K triangleleft G`.  Put

```text
C=[N_1,...,N_r]_Sigma.
```

Assume

```text
K cap C != 1.
```

Then there is a chief factor `A/B` of `G` lying inside `K` such that one of
the following alternatives holds.

Pairwise obstruction.  There exist distinct `i,j` such that

```text
[N_i,N_j] covers A/B,
```

equivalently,

```text
A <= [N_i,N_j] B.
```

Central abelian obstruction.  The chief factor `A/B` is elementary abelian and
central in `G/B`,

```text
A/B <= Z(G/B),
```

and it is covered by the full all-meridian commutator:

```text
A <= C B.
```

More sharply:

1. If `A/B` is nonabelian, then every pair `i!=j` satisfies

   ```text
   [N_i,N_j] covers A/B.
   ```

2. If `A/B` is abelian but noncentral in `G/B`, then there is some `j` such
   that `N_j` acts nontrivially on `A/B`, and for every `i!=j`,

   ```text
   [N_i,N_j] covers A/B.
   ```

Thus the only genuinely higher-meridian chief-factor obstruction is central
elementary abelian.

## Proof

By the chief-factor obstruction theorem, choose a chief factor `A/B` lying
inside `K` and covered by `C`.  Write

```text
V = A/B.
```

Since `C<=N_i` for every `i`, every `N_i` covers `V`.  Equivalently, in
`G/B`,

```text
V <= N_i B / B
```

for every `i`.

Suppose first that `V` is nonabelian.  Then `V` is a direct product of
isomorphic nonabelian simple groups, hence is perfect:

```text
V=[V,V].
```

For any distinct `i,j`, the inclusions `V<=N_iB/B` and `V<=N_jB/B` give

```text
V=[V,V] <= [N_iB/B,N_jB/B].
```

Thus `[N_i,N_j]` covers `A/B`.

Now suppose that `V` is abelian.  Then `V` is an elementary abelian
irreducible `F_p G`-module for some prime `p`.

If `V` is noncentral in `G/B`, some `N_jB/B` acts nontrivially on `V` because
the normal subgroups `N_i` generate `G`.  Therefore

```text
[V,N_jB/B] != 0.
```

The subgroup `[V,N_jB/B]` is `G`-invariant because `N_j` is normal in `G`.
Since `V` is an irreducible `G`-module,

```text
[V,N_jB/B] = V.
```

Choose any `i!=j`.  Since `V<=N_iB/B`,

```text
V=[V,N_jB/B] <= [N_iB/B,N_jB/B].
```

So `[N_i,N_j]` covers `A/B`.

The only remaining case is that every `N_iB/B` centralizes `V`.  Since the
`N_i` generate `G`, all of `G/B` centralizes `V`, so

```text
V <= Z(G/B).
```

This is the central abelian alternative.  The factor is covered by `C` by the
choice of `A/B`.

## Application To The Finite-Image Boundary

In the finite-image notation, take

```text
G = Gamma_n,
K = K_n,
N_i = N_{i,n},
r = n-1.
```

Here `Gamma_n` is the image of the last-strand free group `F_{n-1}` and the
subgroups `N_{i,n}` are the normal closures of the images of its free
generators.  Hence `N_{1,n},...,N_{n-1,n}` generate `Gamma_n`.

For `n>=3`, any finite-image failure

```text
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma != 1
```

has one of only two forms.

Pairwise form.  There exist `i!=j` and a chief factor `A/B<=K_n` such that

```text
A <= [N_{i,n},N_{j,n}] B.
```

This includes all nonabelian chief-factor obstructions and all noncentral
abelian chief-factor obstructions.

Central high-arity form.  There is an elementary abelian chief factor
`A/B<=K_n` such that

```text
A/B <= Z(Gamma_n/B)
```

and

```text
A <= [N_{1,n},...,N_{n-1,n}]_Sigma B.
```

This is the only obstruction that can genuinely require the full all-meridian
symmetric commutator.

## Sufficient Criterion

For a fixed finite rack detector `Q=Y^0 x T_2`, Sawin domination follows if,
for all sufficiently large `n`, both conditions hold:

```text
K_n cap [N_{i,n},N_{j,n}] = 1
```

for every `i!=j`, and there is no central elementary abelian chief factor

```text
A/B <= K_n,
A/B <= Z(Gamma_n/B),
```

covered by

```text
[N_{1,n},...,N_{n-1,n}]_Sigma.
```

Fixed-arity rack cofinality then handles the finitely many small arities.

Equivalently, a cofinal counterexample must do at least one of the following
against every finite rack prefix:

1. produce unbounded arities with a pairwise invisible obstruction

   ```text
   K_n cap [N_{i,n},N_{j,n}] != 1;
   ```

2. produce unbounded arities with a central elementary abelian high-Brunnian
   obstruction.

## Bounded Relative Lower-Central Depth Criterion

Let `Z` be a braided quotient of `X` already dominated by some finite rack.
For the last-strand images write

```text
G^X_n = rho^X_n(F_{n-1}),
G^Z_n = rho^Z_n(F_{n-1}),
E_n = ker(G^X_n -> G^Z_n).
```

If

```text
E_n cap gamma_{n-1}(G^X_n) = 1
```

for all sufficiently large `n`, then `X` is dominated by one finite rack.

In particular, it is enough that there is a uniform constant `c` such that

```text
E_n cap gamma_c(G^X_n) = 1
```

for every `n`.

Proof.  Let `Y_Z` be a finite rack dominating `Z`.  Use the detector

```text
Q = Y_Z^0 x T_2
```

and add finitely many fixed-arity rack detectors for the small arities not
covered by the eventual condition.

For large `n`, form the combined image using this `Q`.  If

```text
g in K_n,
```

then `g` is represented by a braid acting trivially on `Q^n`.  In particular,
that braid acts trivially on the subrack `Y_Z^n`, hence trivially on `Z^n`
because `Y_Z` dominates `Z`.  Therefore the `X`-projection of `g` lies in
`E_n`.

Also,

```text
[N_{1,n},...,N_{n-1,n}]_Sigma <= gamma_{n-1}(Gamma_n),
```

so its `X`-projection lies in `gamma_{n-1}(G^X_n)`.  Hence

```text
p_X(K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma)
  <= E_n cap gamma_{n-1}(G^X_n)
  = 1.
```

Since the two projection kernels in the combined image intersect trivially,
an element of `K_n` with trivial `X`-projection is itself trivial.  Thus

```text
K_n cap [N_{1,n},...,N_{n-1,n}]_Sigma = 1
```

in all sufficiently large arities.  The ordinary Brunnian and finite-image
reductions give domination in large arity, and the added fixed-arity
detectors handle the remaining arities.

## Remaining Boundary

To prove Sawin's statement from this boundary, it now suffices to prove that
for every finite bijective solution `X`, after adding one finite rack detector
`Q`, all sufficiently large `n` have neither

```text
K_n cap [N_{i,n},N_{j,n}] != 1        (i!=j),
```

nor a central elementary abelian chief factor

```text
A/B <= K_n,
A/B <= Z(Gamma_n/B),
```

covered by the all-meridian commutator.

Any explicit counterexample must now be cofinal in one of those two narrower
senses.
