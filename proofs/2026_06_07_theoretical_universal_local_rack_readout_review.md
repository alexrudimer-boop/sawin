# Theoretical Review: Universal Local Rack Readout

Date: 2026-06-07.

## Verdict

This is theorem-level progress on the positive contextual route.  It does not
prove A or B, but it closes one tempting escape: enriching the one-strand
local contextual state cannot evade the same-strand sliding quotient.  Any
local rack readout that follows a physical strand through rack crossings
factors through the two-sided contextual quotient `P_X`.

## Statement

Let `R_X(x,y)=(u,v)`.  Recall

```text
r_y(x) = pr_2 R_X(x,y),
m_u(v) = pr_1 R_X^{-1}(u,v).
```

A local one-strand contextual readout is a map

```text
c : M_L x X x M_R -> C
```

assigning a detector color to an `X`-strand of color `x` with left context
`A` and right context `B`.

If this readout is compatible with a rack detector whose crossing is

```text
R_Y(a,b) = (a*b,a),
```

then for every adjacent `X` crossing `R_X(x,y)=(u,v)` it must satisfy

```text
c(A,x,B r_y) = c(A m_u,v,B).
```

Consequently `c` factors uniquely through

```text
P_X = (M_L x X x M_R)/~
```

where `~` is generated by

```text
(A,x,B r_y) ~ (A m_u,v,B).
```

## Proof Check

Before the crossing, the old left physical strand has contextual state

```text
(A,x,B r_y).
```

After the crossing it is the right output strand with `X`-color `v` and
contextual state

```text
(A m_u,v,B).
```

In a rack crossing, the second detector output is exactly the old first
detector input.  Therefore any local detector color assigned to the same
physical strand must be equal on these two contextual states.  These are
exactly the generating relations defining `P_X`, so the readout factors
through the quotient.

The uniqueness of the factorization is just the universal property of a
quotient by the kernel congruence generated by those relations.

## Consequence

The positive route cannot be repaired by saying “add more one-strand local
context data” while still requiring that the detector color follows the same
physical strand through rack crossings.  Any such enriched local readout must
obey the same sliding relation and therefore descends to `P_X`.

The remaining positive options are therefore sharper:

```text
1. prove pure-loop faithfulness or all-arity orbit separation for P_X itself;
2. leave purely local one-strand readouts and build a genuinely multi-strand
   or stateful finite rack detector.
```

The remaining negative route also becomes sharper: a failure of `P_X` is not
fixed by local enrichment alone, but it is still not a Sawin counterexample
until it is converted into actual Brunnian detector-kernel braid witnesses for
one fixed finite target `X`.
