# Point-pushing suffix-shuttle normal form

Date: 2026-05-30

This note records the finite-state normal form for the point-pushing
generators used in the `mu_X(k)` formulation.  It does not prove outcome A or
B.  It shows that every generator `h_i=rho_X(A_{i,n})` is obtained from one
fixed reversible two-pass shuttle schema depending only on `X`.

## Statement

Let `X` be a finite bijective YBE solution with crossing `R`.  Fix

```text
1 <= i < n.
```

The standard pure braid generator is

```text
A_{i,n}
=
sigma_{n-1} ... sigma_{i+1}
sigma_i^2
sigma_{i+1}^{-1} ... sigma_{n-1}^{-1}.
```

Therefore the action of `A_{i,n}` on a tuple

```text
(x_1,...,x_n) in X^n
```

has the following suffix-shuttle form.

1. Left shuttle: sweep the last coordinate leftward through the suffix by
   applying

   ```text
   sigma_{n-1}, sigma_{n-2}, ..., sigma_{i+1}.
   ```

   Operationally, this is a one-state scan over adjacent pairs using the
   fixed table `R`.

2. Core interaction: apply `sigma_i^2` to the two coordinates now in positions
   `i,i+1`.

3. Right shuttle: undo the suffix sweep by applying

   ```text
   sigma_{i+1}^{-1}, sigma_{i+2}^{-1}, ..., sigma_{n-1}^{-1}.
   ```

   This is the inverse scan using the fixed table `R^{-1}`.

Thus every marked point-pushing generator is a reversible two-pass
finite-state transducer over the alphabet `X`, with state set contained in
`X` during each shuttle pass and with transition tables determined by `R` and
`R^{-1}`.

## Proof

The displayed word for `A_{i,n}` is the definition of the standard pure braid
generator in the repository convention.  The first block

```text
C_{i,n}=sigma_{n-1} ... sigma_{i+1}
```

only touches coordinates `i+1,...,n`; it is the left shuttle.  The middle block
is `sigma_i^2`.  The last block is

```text
C_{i,n}^{-1}=sigma_{i+1}^{-1} ... sigma_{n-1}^{-1},
```

which is the inverse right shuttle.

Because `R` is a bijection, every inverse crossing is computed by `R^{-1}`.
Hence the whole action is exactly the two-pass finite-state procedure above.
QED.

## Why This Matters

The preceding notes reduce Sawin's problem to boundedness of

```text
mu_X(k)=min { m : D_k(S_m) -> P_k(X) }.
```

The suffix-shuttle normal form says that the generators of every `P_k(X)` are
not arbitrary permutations of `X^{k+1}`.  They all come from the same fixed
two-pass reversible machine:

```text
left R-scan
then one local square
then right R^{-1}-scan.
```

So if `mu_X(k)` is unbounded, the escaping relations must arise in the group
generated by these uniformly finite-state suffix shuttles.  They cannot be
attributed to arbitrary finite marked quotients of `F_k`, since fixed arity is
already cofinal by `proofs/point_pushing_fixed_arity_cofinality.md`.

## Consequence For A

A possible positive route is now more concrete:

```text
prove that all finite marked quotients generated by these suffix-shuttle
transducers are detected by D_k(S_m) for one m=m(X).
```

Equivalently, prove that the fixed two-pass machine has bounded
`mu`-degree across all arities.

## Consequence For B

A negative route must produce an explicit finite solution `X` whose
suffix-shuttle transducers have unbounded `mu_X(k)`.  In the language of
`proofs/point_pushing_mu_boundedness_dichotomy.md`, this means explicit
vertical-witness words

```text
w_j=1 in D_{k_j}(S_j),
w_j!=1 in P_{k_j}(X),
```

where the nontrivial action in `P_{k_j}(X)` is generated by these fixed
two-pass shuttles.

## Audit Hook

The helper

```text
point_pushing_suffix_shuttle_audit(...)
```

checks the formula for one finite `n` and generator `i` by comparing the
suffix-shuttle computation with the direct braid action of `A_{i,n}` on every
tuple of `X^n`.

The helper

```text
point_pushing_suffix_shuttle_action(...)
```

applies the two-pass formula to one tuple.  These helpers are convention
guards; the theorem itself is the symbolic expansion of `A_{i,n}`.
