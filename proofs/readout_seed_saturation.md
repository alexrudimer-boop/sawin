# Readout seed-saturation audit

Date: 2026-05-29

This note follows `proofs/product_readout_descent_separation.md`.  It does not
prove the Master Local-Minimal Residual Theorem.  It records the exact
least-admissible coarsening forced when a fixed readout factor fails to kill a
continuation seed.

The point is to avoid an invalid proof move: one may not simply declare a
factor readout coarser until it kills the seed without checking what
admissible congruence that coarsening generates.  In a local-minimal interval,
that saturation often jumps all the way to the universal relation.

## Setup

Let `pi:X->Z` be a finite local interval in rack-side convention.  Let

```text
r_a : A_a -> E_a
```

be one finite readout label system, with kernel `Phi^r`.

Let `C` be the continuation seed relation generated by all pairs

```text
x ~ v
```

coming from local rows

```text
T_{a,b}(x,y) = (u,v)
```

whose base second output colour is `a` and whose second output satisfies
`v != x`.

Define the seed-saturation of `r` to be the least admissible congruence family

```text
Sat(r)
```

containing both `Phi^r` and `C`.

## Lemma 1: seed-saturation is the minimal admissible coarsening

If `Theta` is any admissible local congruence family such that

```text
Phi^r <= Theta
```

and every continuation seed satisfies

```text
x Theta_a v,
```

then

```text
Sat(r) <= Theta.
```

Proof.  The closure engine defining `Sat(r)` starts with all pairs in
`Phi^r` and all continuation seed pairs, then repeatedly transports product
relations through every local table and inverse local table until an
admissible family is reached.  Any admissible `Theta` containing the starting
pairs is closed under those same forward and inverse transports.  Therefore
every generated edge of `Sat(r)` lies in `Theta`.  QED.

## Lemma 2: saturated labels pass descent separation exactly when the base row is rack-side

Label each fibre point by its `Sat(r)`-block.  These block labels have kernel
exactly `Sat(r)`.  Since `Sat(r)` is admissible by construction and contains
all continuation seed pairs, the readout descent-separation certificate passes
precisely when the base row is in rack-side form.

In that case the quotient local row is strand-continuing.

Proof.  Admissibility of `Sat(r)` makes the quotient local table well-defined.
The continuation seed pairs are all identified, so the second output block is
the input block of the continuing strand.  The only remaining obstruction to
the certificate is a base row whose second output colour is not the input
left colour; such a row is outside rack-side convention and cannot be repaired
by fibrewise coarsening alone.  QED.

## Local-minimal corollary

Assume the interval is local-minimal and `Phi^r` is admissible.  Then `Phi^r`
is either equality or universal.  Therefore:

1. if `Phi^r` is universal, it already kills every continuation seed;
2. if `Phi^r` is equality and no seed survives, then `Sat(r)=Phi^r`;
3. if `Phi^r` is equality and some nontrivial seed survives, then `Sat(r)` is
   universal.

Thus there is no hidden proper seed-saturated middle layer in a local-minimal
interval.  A factor that fails to kill a nontrivial seed can only be made
seed-killing by collapsing to universal, unless the interval was not actually
local-minimal or the readout kernel was not admissible.

This corollary is a guardrail, not a positive proof of Sawin domination.
Universal saturation may destroy readout faithfulness; the lost endpoint
information must still be carried by some other fixed detector component or by
the transport-state rack quotient.

## Code certificate

The helper

```text
readout_seed_saturation_audit(interval, labels)
```

records:

- the original readout-kernel audit;
- the continuation congruence audit;
- the generated admissible saturation containing the readout kernel and all
  continuation seed pairs;
- block labels for the saturated family;
- the readout-kernel audit and descent-separation audit of those block labels;
- which original continuation seed rows survived before saturation;
- which saturation edges were new relative to the original readout kernel.

The property

```text
proves_admissible_seed_saturation
```

is true when the original readout kernel is admissible, the generated
saturation contains it, the saturated labels have exactly that generated
kernel, and all continuation seeds are killed after saturation.

The stronger property

```text
proves_saturated_descent_separation
```

also requires the saturated readout to pass the descent-separation audit.

## Updated target

For the A-route, each proposed Green, Schutzenberger, atom, known-branch, or
endpoint/unit factor must be audited in one of two ways:

1. it already kills every representative continuation seed; or
2. its seed-saturation is intentionally routed to a universal or quotient
   factor, with the lost information proved visible elsewhere.

A finite failure of this audit remains only a possible B seed.  It must still
be upgraded to a normalized-law sequence invisible to every finite group while
moving a residual tuple.
