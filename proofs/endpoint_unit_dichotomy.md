# Endpoint-unit dichotomy

Date: 2026-05-29

This note sharpens the semigroup endpoint branch into the exact local A/B
fork.  It is not a proof of the Master Local-Minimal Residual Theorem and it
does not construct a counterexample.

## Setup

Let `M` be a fixed finite transformation monoid attached to one residual
branch of a local interval.  Let

```text
U(M) = {units of M}
```

be the finite permutation group of its unit elements.  Suppose a braid
`beta in N_n` gives a residual branch endpoint

```text
h_beta = f_k ... f_1 in M.
```

Because residual braid actions are permutations, a successful endpoint branch
must have `h_beta in U(M)`.  The unit-factorization gate then prevents
nonunit/reset labels from being the final moving obstruction.

## A-Side Endpoint Criterion

The branch is killed by the fixed finite group `U(M)` whenever

```text
h_beta in V_beta(U(M)),
```

where `V_beta(U(M))` is the subgroup generated by all recursive Artin
longitude values in `U(M)`.  If the finite-`U(M)` longitude data of `beta` is
identity, then `V_beta(U(M))={1}`, so `h_beta=1`.

For finitely many branch monoids `M_1,...,M_r`, the same statement uses the
single product group

```text
G = U(M_1) x ... x U(M_r).
```

The endpoint tuple `(h_1(beta),...,h_r(beta))` must lie in `V_beta(G)`.  This
is the product endpoint condition already audited by
`unit_composite_product_detection_audit(...)`.

## B-Side Endpoint Shape

A finite endpoint failure occurs when

```text
Lambda_{U(M),n}(beta)=Lambda_{U(M),n}(1)
```

but `h_beta` is a nonidentity unit.  Equivalently, the braid is invisible to
this one unit detector while the residual endpoint still moves.

This is only a finite warning.  It is not outcome B.  To become B, such
failures must be upgraded to a normalized-law sequence

```text
beta_j in B_{q_j}, q_j -> infinity,
```

such that every finite group `G` eventually has identity finite-`G` longitude
data, while some residual endpoint unit remains nonidentity.  By the
fixed-variety barrier, this requires the moving endpoint unit groups to
escape the variety generated by every fixed finite group.

Thus the endpoint-unit branch has the same final dichotomy as the rest of the
program:

- prove every residual endpoint unit lies in the longitude-value subgroup of
  one fixed finite product unit group; or
- produce an explicit normalized-law sequence whose endpoint units defeat
  every finite group detector.

## Executable Flags

The helper `unit_composite_detection_audit(...)` now exposes

```text
is_finite_unit_detector_failure
```

for the one-monoid case.  The product helper
`unit_composite_product_detection_audit(...)` exposes

```text
is_finite_product_unit_detector_failure
```

for a finite list of monoids.

Both flags mean only "B-shaped against this fixed detector".  They must not
be cited as a counterexample unless a symbolic normalized-law diagonalization
defeats every finite group and supplies explicit moved residual tuples.

The route helper

```text
unit_composite_longitude_route_audit(...)
```

now separates three fixed-word proof routes for one endpoint: endpoint
identity, a single evaluated-longitude witness, and membership in the full
longitude-value subgroup `V_beta(U(M))`.  Only failure of the subgroup route
is a serious endpoint obstruction.  Lack of a single witness is not enough.
