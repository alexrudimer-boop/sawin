# Local-Minimality Pair-Closure Gate

Date: 2026-05-28

The master local theorem applies to local-minimal congruence intervals.  The
older audit guarded this point by refusing to route large-fibre intervals when
full partition enumeration was disabled.  That Bell-number enumeration is no
longer needed for the local-minimality question itself: local-minimality has an
exact single-pair generation criterion.

## Pair-Closure Criterion

For a finite local interval `pi:X->Z`, let

```text
< a:p~q >
```

denote the least admissible congruence family generated by identifying the two
distinct fibre points `p,q in A_a`.  The closure is computed by repeatedly
transporting product relations through every local bijection `T_{b,c}` and
through its inverse.

Lemma.  The interval is local-minimal if and only if, for every colour `a` and
every distinct pair `p,q in A_a`, the generated admissible family
`< a:p~q >` is the all-universal family.

Proof.  If some single-pair closure is neither all equality nor all universal,
then that closure is itself an admissible proper congruence family, so the
interval is not local-minimal.  Conversely, suppose every single-pair closure
is all universal, and let `theta` be an admissible family that is not all
equality.  Then `theta_a` contains a distinct pair `p~q` in some fibre.  Since
`< a:p~q >` is the least admissible family containing that pair, it is
contained in `theta`.  By hypothesis `< a:p~q >` is all universal, so `theta`
is all universal.  Hence the only admissible families are equality and
universal.

Singleton fibres cause no exception: they contain no distinct pair, and their
equality and universal partitions coincide.

## Executable Form

The implementation exposes this exact criterion as:

```text
LocalInterval.pair_generated_local_minimality_audits()
LocalInterval.pair_generated_local_minimality_failures()
LocalInterval.is_local_minimal()
```

The old `max_fibre_size` argument on `is_local_minimal()` is retained for
backward compatibility, but the current implementation no longer uses full
partition enumeration and no longer has a fibre-size guard.  The helper
`admissible_congruence_families()` remains available as a small-fibre
cross-check.

The branch router `local_master_bottleneck_summary()` therefore has exact
local-minimality evidence for arbitrary finite fibres in the input table.  If
a visible product or Green/corridor feature appears in a non-local-minimal
large-fibre interval, the router now reports `not_local_minimal` rather than
holding the row at `local_minimality_unchecked`.

The router also records three certificate counters:

```text
local_minimal_pair_count
local_minimal_pair_failure_count
local_minimal_pair_max_depth
```

These counters are not finite-search evidence for the global theorem; they
are the finite certificate for this particular local table.  A zero failure
count is the exact local-minimality proof for the interval, while a positive
failure count points to generated proper admissible families that refine the
congruence chain.

## Status

This closes only the proof-hygiene gap around arbitrary fibre size in the
local-minimality audit.  It does not prove the Master Local-Minimal Residual
Theorem.  After this gate, the remaining theorem burden is still the
finite-G residual detector for the product genuinely-coloured and bi-free
universal-corridor branches, or an explicit normalized-law escape from one of
those exact verdicts.
