# Point-pushing kernel-layer criterion

Date: 2026-05-30

This note repairs the last-strand reduction after
`proofs/last_strand_law_gap_audit.md`.  Ordinary laws are not enough.  The
right exact replacement is to keep the actual finite-longitude kernel
condition on each point-pushing layer.

## Setup

For a finite group `G`, write

```text
K_G(n) =
{ beta in B_n :
  Lambda_{G,n}(beta)=Lambda_{G,n}(1) }.
```

Let

```text
iota_r:F_{r-1}->P_r
```

be the standard last-strand point-pushing embedding.

## Theorem

For a finite bijective YBE solution `X` and a finite group `G`, the following
are equivalent.

1. The detector rack `A_G` dominates `X`:

   ```text
   K_G(n) subset ker rho_{X,n}
   ```

   for every `n`.

2. Every last-strand point-pushing layer that actually lies in the same
   finite-longitude kernel acts trivially:

   ```text
   rho_{X,r}(iota_r(w))=1
   ```

   for every `r>=2` and every `w in F_{r-1}` satisfying

   ```text
   iota_r(w) in K_G(r).
   ```

## Proof

Assume (1).  Then (2) is immediate because each `iota_r(w) in K_G(r)` is a
special case of a braid in the kernel.

Conversely assume (2), and suppose toward a contradiction that there are
`n` and

```text
beta in K_G(n)
```

with

```text
rho_{X,n}(beta) != 1.
```

Apply the Fadell-Neuwirth layer extraction guardrail.  Deleting the last
strand and splitting it back by the standard unused right strand preserve
`K_G`.  Hence the recursive decomposition of `beta` has layers

```text
lambda_r=iota_r(w_r) in K_G(r).
```

If every such layer acted trivially on its own `X^r`, then its standard
right-stabilized extension would act trivially on `X^n`, and their product
would make `beta` act trivially on `X^n`.  Since `beta` moves, some layer
must move:

```text
rho_{X,r}(iota_r(w_r)) != 1.
```

This contradicts (2).  Therefore (1) holds.

## Relation To Ordinary Laws

The necessary law condition remains true:

```text
iota_r(w) in K_G(r)  =>  w in Law_{r-1}(G).
```

It follows from the last recursive longitude, which is a triangular Nielsen
automorphism applied to `w`.

The converse is false.  The guardrail row in
`proofs/last_strand_law_gap_audit.md` gives an `S_3`-law word whose
last-strand point-pushing braid moves the three-element dihedral rack and has
nonidentity `S_3` longitude data.

## Derivative Detector Form

There is still a finite law-style sufficient condition, but it is a law on
the Artin derivative detector, not on `G` itself.

Fix `k>=1`.  Let `D_k(G)` be the finite permutation group on

```text
(G x G)^{k+1}
```

generated by the active Artin detector permutations induced by

```text
A_{1,k+1},...,A_{k,k+1}.
```

Equivalently, the `i`-th generator is the permutation obtained by sweeping the
pure braid `A_{i,k+1}` with arbitrary detector labels `(m_j,u_j) in G x G`.

If `w in F_k` is a law on `D_k(G)`, then the point-pushed braid
`iota_{k+1}(w)` fixes every detector state in `(G x G)^{k+1}`.  In
particular it fixes every initial longitude state

```text
((m_1,1),...,(m_{k+1},1)).
```

Thus

```text
w in Law_k(D_k(G))  =>  iota_{k+1}(w) in K_G(k+1).
```

The exact condition is not that `w` be a law on the whole group `D_k(G)`.
It is the marked-generator identity

```text
iota_{k+1}(w) in K_G(k+1)
  iff
w(d_1,...,d_k)=1 in D_k(G),
```

where `d_i` is the detector permutation induced by `A_{i,k+1}`.  Equivalently,
`w` fixes every endpoint-identity initial state
`((m_1,1),...,(m_{k+1},1))` under the generated detector action.  Since the
braid is pure, this endpoint-slice condition is the same as fixing the full
detector state space for the marked tuple.  The stronger sufficient condition
`w in Law_k(D_k(G))` is usually more than needed.  See
`proofs/point_pushing_marked_quotient_criterion.md` for the quotient form.

Thus the exact last-strand B certificate is:

```text
iota_{k_j+1}(w_j) in K_{S_j}(k_j+1),
rho_X(iota_{k_j+1}(w_j)) != 1,
```

not merely

```text
w_j in Law_{k_j}(S_j).
```

This keeps the useful point-pushing extraction while restoring the true
finite-longitude condition required by the sharp detector theorem.
