# Abelian longitude image criterion

Date: 2026-05-29

This note follows `proofs/green_defect_abelianization_split.md`.  It does not
prove the Master Local-Minimal Residual Theorem.  It gives the exact finite
abelian calculation needed for the projected defect endpoint in

```text
AbDef_C = Def_C / [Def_C,Def_C].
```

The point is to replace the vague phrase "ordinary abelian longitude
visibility" by a concrete all-`n` subgroup criterion.

## Setup

Let

```text
F_n=<x_1,...,x_n>
```

and let `beta in B_n`.  In the repo convention:

```text
beta(x_i)=L_i(beta) x_{p_beta(i)} L_i(beta)^-1.
```

For a finite group `G`, write

```text
V_beta(G)=< phi(L_i(beta)) : phi:F_n -> G, 1<=i<=n >.
```

Now assume that `A` is a finite abelian group.  Let

```text
M_beta=(m_ij)
```

be the integer matrix whose `i`-th row is the abelianized exponent vector of
the recursive longitude `L_i(beta)`, so `m_ij` is the exponent sum of `x_j` in
`L_i(beta)`.

## Theorem

For every finite abelian group `A`,

```text
V_beta(A)
= < a^{m_ij} : a in A, 1<=i,j<=n >.
```

Consequently finite-`A` longitude data is identity exactly when:

1. the Artin strand permutation `p_beta` is the identity; and
2. every matrix entry `m_ij` annihilates every element of `A`.

Equivalently, if `exp(A)` is the exponent of `A`, identity finite-`A`
longitude data is the same as `p_beta=1` and

```text
m_ij == 0 mod exp(A)
```

for every `i,j`.

## Proof

Use multiplicative notation for `A`.  A homomorphism `phi:F_n -> A` is
determined by arbitrary values

```text
a_j=phi(x_j).
```

Because `A` is abelian, evaluation of a free word depends only on its
abelianized exponent vector.  Therefore

```text
phi(L_i(beta)) = product_j a_j^{m_ij}.
```

For fixed `i,j` and `a in A`, choose the assignment with `a_j=a` and every
other generator sent to the identity.  This shows that every `a^{m_ij}` lies
in the generating set used to form `V_beta(A)`.

Conversely, every evaluated longitude value

```text
product_j a_j^{m_ij}
```

is a product of such single-coordinate values.  Thus the subgroup generated by
all evaluated longitude values is exactly the subgroup generated by all
`a^{m_ij}`.  This proves the formula.

The identity-data criterion follows immediately: the sharp detector also
records the strand permutation, and all abelian longitude values are trivial
exactly when the displayed subgroup is the identity subgroup.  Since a finite
abelian group has exponent `exp(A)`, the latter condition is equivalent to
every `m_ij` being divisible by `exp(A)`.  QED.

## Consequence for the Green defect split

For each Green/Schutzenberger defect kernel, the abelianized target

```text
AbDef_C = Def_C / [Def_C,Def_C]
```

is finite, fixed by the interval, and independent of braid index.  The
projected defect endpoint

```text
bar D_C(beta) in AbDef_C
```

is killed by identity finite-`AbDef_C` longitude data precisely when it lies
in the matrix subgroup

```text
< a^{m_ij} : a in AbDef_C, m_ij an entry of M_beta >.
```

Thus the abelian part of the remaining Green theorem has an exact target:
express the projected transported endpoint as an element of that matrix
subgroup, or prove that the endpoint cancels under the residual hypotheses.
This is stronger and more honest than an Artin-defect display, because Artin
permutation defects always vanish in abelian targets.
