# Triangular K-left partial-constant closure

Date: 2026-05-31

This note refines the remaining `partial_constant_hidden_rank_loss` line in
`proofs/triangular_k_left_missing_row_profile.md`.

It does not prove `[Resolution: A]` or construct `[Resolution: B]`.  It turns
the partial-constant mixed-unit phrase into explicit generated congruence
edges.

## Executable object

The helper

```text
missing_triangular_partial_constant_closure_audit(I)
```

inspects every missing triangular profile with explanation

```text
partial_constant_hidden_rank_loss
```

and records one row for each constant coordinate section and each nontrivial
kernel edge in that section:

```text
side
left_color
right_color
fixed_input
domain_color
collapsed_inputs
closure_kind
```

The post-linear finite-system wrapper reports the K-relevant part as:

```text
missing_triangular_partial_constant_closure_rows
missing_triangular_partial_constant_proper_closure_rows
missing_triangular_partial_constant_universal_closure_rows
```

## Lemma: partial-constant rows contain explicit kernel seeds

[Proved] Let a missing left triangular row have partial-constant hidden rank
loss.  Then for every constant section

```text
L_x^{a,b}: A_b -> A_{a*b}
```

and every distinct pair `y0,y1 in A_b`, the edge

```text
y0 ~ y1
```

is a literal coordinate-kernel seed.  The right-side statement is the
side-dual version with `R_y^{a,b}: A_a -> A_a`.

Proof.  A constant section sends every input in its domain to the same output.
Thus any two distinct domain inputs have the same coordinate output.  This is
exactly a coordinate-section kernel edge.  The helper records the least
admissible congruence generated by that one edge.  QED.

## Local-minimality split

[Proved] In a local-minimal remaining interval, every partial-constant
constant-section kernel edge has either universal generated closure or it is
impossible.

Proof.  The generated closure of one such edge is, by construction, an
admissible local congruence family.  The seed edge is nontrivial, so the
closure cannot be equality.  If the closure is proper, it is a proper
nontrivial admissible congruence, contradicting local minimality.  Therefore
the only surviving local-minimal case is universal closure.  QED.

## Consequence for System K

Partial-constant missing triangular rows no longer stand as an amorphous
mixed-unit obstruction.  Their finite subsystem is:

```text
for each constant-section kernel edge e,
compute the generated admissible closure <e>.
```

Then:

```text
proper closure:
  contradicts local minimality;

universal closure:
  identifies an exact universal coordinate-kernel seed that must be routed to
  a fixed endpoint detector/readout, or upgraded to a normalized-law B
  sequence.
```

This is still not the all-`n` endpoint theorem.  It is a sharper equivalence:
after proper-kernel, injective-nonsurjective, coordinate-unit, and side-dual
rows have been routed, a partial-constant K-left survivor is exactly a finite
family of universal generated seed edges coming from constant sections of the
missing row.  The follow-up
`proofs/triangular_k_left_partial_constant_continuation_route.md` routes these
seed edges into the continuation/descent channel by using companion-output
separation to find a nontrivial continuation seed in the same local row.
