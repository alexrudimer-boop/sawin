# Cofinal Monolith Chief-Factor Obstruction

This note upgrades the first-fold monolith obstruction to a finite-image
chief-factor obstruction.  In a smallest counterexample, the Brunnian
detector-invisible motion cannot merely move monolith fibres abstractly.  It
must occur through actual chief factors in the detector-invisible
all-meridian layer of the combined finite image.

## Setup

Let `X` be a smallest finite bijective YBE solution not dominated by any
finite rack.  Then `X` is degenerate.  Let

```text
mu = mu_X
```

be the unique first-fold atom, hence the global monolith, as in
`proofs/unique_first_fold_atom_monolith.md`.

Fix a finite rack prefix `P_m`.  By minimality of `X`, the proper quotient
`X/mu` is dominated by a finite rack.  Choose such a rack and call it
`Y_mu`.  Define

```text
Q_m = (P_m x Y_mu)^0 x T_2.
```

For arity `n`, let

```text
F_{n-1} = ker(d_n:P_n -> P_{n-1})
```

be the last-strand free group, with meridian generators

```text
x_i=A_{i,n},       1 <= i <= n-1.
```

Define the combined finite image

```text
Phi_{m,n}:F_{n-1} -> Gamma_{m,n}
  <= Sym(Q_m^n) x Sym(X^n).
```

Let

```text
K_{m,n}=ker(Gamma_{m,n} -> rho^{Q_m}_n(F_{n-1})),
L_{m,n}=ker(Gamma_{m,n} -> rho^X_n(F_{n-1})).
```

For each meridian, set

```text
N_{i,m,n}
  =
<< Phi_{m,n}(x_i) >>_{Gamma_{m,n}},
```

and define the exact all-meridian symmetric commutator layer

```text
C_{m,n}
  =
[N_{1,m,n},...,N_{n-1,m,n}]_Sigma.
```

The two projection kernels satisfy

```text
K_{m,n} cap L_{m,n}=1,
```

because `Gamma_{m,n}` is a subgroup of the direct product of the two finite
images.

## Theorem

For every finite rack prefix `P_m` and every integer `N`, there exists
`n>N` such that

```text
K_{m,n} cap C_{m,n} != 1.
```

Moreover, for such an `n`, there is a chief factor

```text
A/B
```

of `Gamma_{m,n}` such that:

```text
B=1,
A <= K_{m,n} cap C_{m,n},
```

so the factor lies inside the detector kernel and inside the exact
all-meridian layer.  Consequently `C_{m,n}` covers the factor.

The `X`-projection of `A` generates the monolith by coordinate mismatches:

```text
<
  (a,b):
  exists g in A, exists x in X^n, exists j,
  x_j=a, (p_X(g)x)_j=b, a != b
>_br
= mu,
```

where

```text
p_X:Gamma_{m,n}->rho^X_n(F_{n-1})
```

is the `X`-projection.

## Proof

Since `X` is a counterexample, no finite rack `Q_m` dominates `X`.  By the
standard transparent Brunnian reduction, for every prefix `P_m` there are
Brunnian witnesses

```text
beta in Brun_n cap ker rho^{Q_m}_n
```

with

```text
rho^X_n(beta) != 1.
```

The arities of such witnesses are unbounded.  If all witnesses for this
fixed `P_m` occurred in arities `n <= N`, fixed-arity rack cofinality would
provide finitely many rack factors killing those bounded arities; multiplying
them into `Q_m` would give one finite rack detector dominating `X`, a
contradiction.

Fix `n>N` and such a witness.  The `T_2` factor in `Q_m` forces `beta` to be
pure.  Since `beta` is Brunnian, deleting the last strand gives the identity;
therefore it lies in

```text
F_{n-1}.
```

Its combined image satisfies

```text
Phi_{m,n}(beta) in K_{m,n}.
```

The finite-image Brunnian theorem for the last-strand free group gives

```text
Phi_{m,n}(Brun_n cap ker rho^{Q_m}_n)
  =
K_{m,n} cap C_{m,n}.
```

Since `rho^X_n(beta) != 1`, the element `Phi_{m,n}(beta)` is nontrivial:
otherwise it would be trivial in both projections.  Equivalently, using
`K_{m,n} cap L_{m,n}=1`, a nontrivial `X`-projection cannot come from the
identity in `Gamma_{m,n}`.  Therefore

```text
K_{m,n} cap C_{m,n} != 1.
```

Set

```text
H = K_{m,n} cap C_{m,n}.
```

This is a nontrivial normal subgroup of the finite group `Gamma_{m,n}`.
Choose a minimal nontrivial normal subgroup

```text
A <= H
```

of `Gamma_{m,n}`.  Then `A/1` is a chief factor of `Gamma_{m,n}`.  Thus the
theorem's chief factor can be taken with `B=1`, and

```text
A <= K_{m,n} cap C_{m,n}.
```

In particular, `C_{m,n}` covers this chief factor.

It remains to identify the monolith action.  Because `A <= K_{m,n}`, every
element of `A` is invisible to `Q_m`.  In particular, it is invisible to the
`Y_mu^0` factor.  Coloring all strands nontransparent, and using that
`Y_mu` dominates `X/mu`, the `X`-projection of every element of `A` acts
trivially on

```text
(X/mu)^n.
```

Therefore every coordinate color change produced by `p_X(A)` lies inside a
`mu`-class.

Also `A` is nontrivial and `A <= K_{m,n}`.  If `p_X(A)=1`, then
`A <= L_{m,n}`, so

```text
A <= K_{m,n} cap L_{m,n}=1,
```

contradiction.  Hence `p_X(A)` is nontrivial.  Some element of `A` moves some
state of `X^n`, producing at least one nontrivial coordinate mismatch.

Let `nu` be the braided congruence generated by all coordinate mismatches
produced by elements of `p_X(A)`.  Then

```text
Delta_X != nu <= mu.
```

Since `mu` is the global monolith, it is contained in every nontrivial
braided congruence.  Hence

```text
mu <= nu.
```

Together with `nu <= mu`, this gives

```text
nu = mu.
```

This proves the theorem.

## Chief-Factor Dichotomy

Applying the finite chief-factor obstruction from the ledger to a chief
factor covered by `K_{m,n} cap C_{m,n}`, the monolith-generating obstruction
has one of two finite-image forms.

### Nonabelian Monolith-Chief Obstruction

There is a nonabelian chief factor covered by the detector kernel such that
every meridian normal closure covers it:

```text
N_{i,m,n} covers A/B        for every i.
```

The `X`-projection of this factor generates the monolith `mu`.

### Abelian Monolith-Chief Obstruction

There is an elementary abelian chief factor inside the detector kernel and
covered by the exact all-meridian subgroup

```text
C_{m,n}.
```

Again, its `X`-projection generates `mu`.  In the central abelian case, this
is a high-Brunnian elementary `p`-layer acting nontrivially and
monolith-generatingly inside `mu`-fibres.

## Consequence

A smallest counterexample must have the following finite-image shape:

```text
for every finite rack prefix P_m,
unbounded arities contain a detector-invisible all-meridian chief factor
whose X-projection generates the unique first-fold monolith.
```

Thus the current target is not merely to find a degenerate quotient-rigid
solution.  It is to find or rule out a first-fold monolith `mu` generated
cofinally by detector-invisible all-meridian chief factors.
