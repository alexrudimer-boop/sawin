# Probe-Central Motion Congruence

This note repairs the actual-mismatch probe-visibility gap.  The fix is not to
extract an immediate first-fold pair from a moved pair.  The correct object is
the braided congruence generated by all detector-kernel, all-meridian,
conjugated-probe-central motions in a fixed finite image.

## Setup

Let `X` be a smallest finite bijective YBE solution not dominated by a finite
rack, and let

```text
mu=mu_X
```

be its unique first-fold monolith.

Fix a rack prefix `P_m` and a support cutoff `s`.  Let

```text
Q=(P_m x Y_mu)^0 x T_2 x B_s(X),
```

where `Y_mu` dominates `X/mu` and `B_s(X)` is the bounded-support detector.

For arity `n`, keep the finite image notation

```text
Phi_n:F_{n-1}->Gamma_n
  <= Sym(Q^n) x Sym(X^n).
```

Let

```text
K_n=ker(Gamma_n->rho^Q_n(F_{n-1})),
C_n=[N_{1,n},...,N_{n-1,n}]_Sigma,
```

and let

```text
CPC^Gamma_n=p_X^{-1}(CPC_n(X))
```

be the conjugated-probe centralizer core from
`conjugated_probe_core_obstruction.md`.

Define

```text
H_n=K_n cap C_n cap CPC^Gamma_n.
```

## Definition: Probe-Central Motion Congruence

Define `Pi_{Q,n}` to be the braided congruence on `X` generated by all
coordinate color changes caused by elements of `H_n`.

Equivalently, `Pi_{Q,n}` is generated as a braided congruence by all pairs
`(a,b)` for which there exist

```text
h in H_n,
mathbf{x} in X^n,
j in {1,...,n}
```

such that

```text
x_j=a,
(p_X(h)mathbf{x})_j=b,
a != b.
```

Thus

```text
Pi_{Q,n}
  =
< (a,b) :
    exists h in H_n, exists word in X^n, exists j,
    word_j=a, (p_X(h)word)_j=b, a != b
>_br.
```

This is finite and computable from the finite permutation image `Gamma_n`.

## Theorem: Probe-Central Branch Regenerates The Monolith

If the conjugated-derivative-visible branch fails cofinally, then for every
`m,s,N` there exists `n>N` such that

```text
Pi_{Q,n}=mu.
```

Equivalently, in the conjugated-probe core branch, the first-fold monolith is
generated exactly by actual all-meridian, detector-invisible,
conjugated-probe-central motions.

## Proof

Assume the conjugated-derivative-visible branch fails cofinally.  Fix
`m,s,N`.  By the deletion-null monolith-chief obstruction, there are
unbounded arities with a chief factor

```text
A/B
```

such that

```text
B < A <= K_n cap C_n.
```

Choose such an arity `n>N` in the cofinal range where all conjugated
derivatives of the obstruction factor vanish.  By
`conjugated_probe_core_obstruction.md`, this gives

```text
A <= CPC^Gamma_n.
```

Hence

```text
A <= H_n.
```

Because `H_n <= K_n`, every element of `H_n` is invisible to the detector
`Q`.  In particular it is invisible to the `Y_mu^0` factor.  Since `Y_mu`
dominates `X/mu`, the `X`-motion of every element of `H_n` is trivial on

```text
(X/mu)^n.
```

Therefore every coordinate mismatch generated by `H_n` lies inside a
`mu`-class.  Hence

```text
Pi_{Q,n} <= mu.
```

On the other hand, `A` is nontrivial and lies in `K_n`.  The two projection
kernels in

```text
Gamma_n <= Sym(Q^n) x Sym(X^n)
```

intersect trivially:

```text
K_n cap L_n=1.
```

Thus `p_X(A)` is nontrivial.  Some element of `A` moves some `X^n`-state and
produces at least one nontrivial coordinate mismatch.  Since `A <= H_n`, this
pair appears among the generators of `Pi_{Q,n}`.  Therefore

```text
Pi_{Q,n} != Delta_X.
```

Since `mu` is the monolith, it is the least nontrivial braided congruence.
The inequalities

```text
Delta_X != Pi_{Q,n} <= mu
```

force

```text
Pi_{Q,n}=mu.
```

This proves the theorem.

## What This Fixes

The previous endpoint tried to extract an immediate first-fold pair from the
actual moved pairs of a Brunnian chief element.  That extraction is not
available.

The motion congruence avoids that false step:

```text
actual moved pairs need not be first-fold pairs,
```

but in the conjugated-probe core branch their braided congruence closure,
computed from `H_n`, is exactly the first-fold monolith.

So the central branch has a finite arity-`n` certificate:

```text
Pi_{Q,n}=mu,
```

where `Pi_{Q,n}` is computed from

```text
K_n cap C_n cap CPC^Gamma_n.
```

## Updated Obstruction Split

A smallest counterexample must support one of two cofinal mechanisms.

### Conjugated-Derivative Tower

For every rack prefix and support cutoff, there are arbitrarily large arities
where some deletion-null Brunnian obstruction has a nontrivial conjugated
derivative:

```text
[iota_n(p_X(a)),T_{i,h}] != 1.
```

This produces a new all-meridian detector-invisible obstruction in arity
`n+1`.

### Probe-Central Monolith Regeneration

For every rack prefix and support cutoff, there are arbitrarily large arities
with

```text
Pi_{Q,n}=mu.
```

That is, the monolith is regenerated by actual motions lying in

```text
K_n cap C_n cap CPC^Gamma_n.
```

## Current Exact Targets

To prove A from this boundary, it is enough to prove both:

```text
no infinite conjugated-derivative tower can persist;
```

and, for some finite detector `Q`,

```text
Pi_{Q,n} != mu eventually.
```

To prove B, one must construct one fixed finite `X` with first-fold monolith
`mu` such that, against every rack prefix, either nontrivial conjugated
derivatives persist cofinally or

```text
Pi_{Q,n}=mu
```

for unbounded `n`.
