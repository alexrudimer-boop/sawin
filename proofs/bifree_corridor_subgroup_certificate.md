# Bi-free corridor subgroup certificate

Date: 2026-05-28

This note records the executable certificate layer attached to
`proofs/bifree_universal_corridor_factorization_target.md`.  It is finite
diagnostic infrastructure, not theorem evidence.

## Purpose

The target theorem says that, in the remaining
`bi_free_universal_corridor_bottleneck` branch, every residual holonomy
element should be forced by recursive Artin-longitude values in one fixed
finite detector group `H(pi,Q)`.  Equivalently, for a braid `beta`, every
residual holonomy element attached to `beta` should lie in the subgroup
`V_beta(H(pi,Q))` generated by all finite-group values of all recursive
Artin longitudes.

The code now exposes this as a uniform finite certificate:

```text
bifree_corridor_detector_target(interval)
bifree_corridor_detector_groups(interval)
bifree_corridor_word_certificate(interval,n,beta)
bifree_corridor_exact_image_audit(interval,n)
bifree_corridor_product_subgroup_audit(interval,n,beta)
```

The helper constructs the two-sided Green detector factor list for the local
interval, records the factor orders and total detector order, checks whether
the interval is actually routed to the bi-free universal-corridor verdict,
and profiles a braid word against each listed factor.  The factor list now
contains every currently named finite Green source: symmetric kernel-block
groups, Schutzenberger action groups, and atom-quotient inner groups whenever
the atom quotient is already certified as a right-rack-like YBE layer.
Concrete duplicate group tables are deduplicated before forming the product.
The exact-image helper uses the same factor list and closes the finite joint
image at one braid index.  A nontruncated exact audit with no failures proves
the sharp detector implication only for that fixed index and interval; it is
not the all-degree corridor theorem.

The product-subgroup helper is the bridge from the displayed factor list to
the single finite group required by the sharp obstruction theorem.  For small
products it explicitly enumerates the direct product detector and verifies

```text
V_beta(product_i H_i) = product_i V_beta(H_i).
```

For large products it marks the finite enumeration as truncated; the symbolic
direct-product lemma in `proofs/longitude_subgroup_products.md` is the
theorem-level justification.

## Certificate Fields

For a finite word `beta`, the word certificate records:

- whether `beta` fixes the quotient action;
- the first moved residual tuple, if one exists;
- the longitude-value subgroup profile for every listed detector factor;
- whether all listed factors are longitude-invisible;
- whether this finite word has the finite B-shape against the listed factors.

The last flag is deliberately named only as a listed-factor diagnostic.  A
true value would still not be outcome B.  Outcome B requires a normalized-law
sequence `beta_j` defeating every finite group, with explicit moved residual
tuples and symbolic YBE/local-minimality proofs.

## Current Guardrail

The test `tests/test_bifree_corridor.py` verifies the expected behavior on
the standard size-three affine commutator fixture.  Its two-sided detector
factors have orders `2`, `3`, and `6`, so the fixed detector product has order
`36`.  The order-`6` factor is now recorded both as the full symmetric
kernel-block factor and as the atom quotient inner group, then deduplicated
to one concrete group in the product.  The commutator law braid moves the
solution and is invisible to the
actual cyclic kernel-image factor, but the symmetric order-`6` factor is
visible.  Therefore the helper rejects it as a B-shape failure against the
listed corridor factors.

This matches the existing lesson from the Green audits: actual image groups
can be too small, while full symmetric kernel-block groups are needed in the
candidate detector.

The generated audit `proofs/bifree_corridor_exact_audit.md` applies the
exact-image helper to the same affine stress row at braid index `2`.  The
joint image closes with `12` states, no kernel failure, and no detector versus
residual collision.  The same report records that the degree-`3` commutator
mover is visible to the order-`6` symmetric factor.  This keeps exact
fixed-index checks and finite-word subgroup profiles tied to one corridor
detector list.

The same generated audit now also includes a direct-product subgroup check on
the degree-`2` pure braid `sigma_1^2`.  For the affine stress row the listed
factor orders are `2`, `3`, and `6`, the product detector order is `36`, and
the computed longitude-value subgroup equals the Cartesian product of the
three factor subgroups.  This is still a finite guardrail, but it confirms
that the code path for the corridor factor list is compatible with one fixed
finite group.

The generated audit `proofs/bifree_corridor_certificate_audit.md` applies the
same certificate to the exhaustive size-2 and size-3 local-minimal
congruence-cover corpus.  In size `2`, all `5` local-minimal covers route to
closed product finite-G subbranches and no interval reaches the target
verdict.  In size `3`, all `116` product rows route to
`product_finite_g_branch`, while the `6` intervals that previously reached
the corridor target verdict are tagged involutive and now route to
`known_total_branch`.  Thus the size-2/3 local-minimal cover corpus has no
remaining `product_genuinely_coloured_bottleneck` or
`bi_free_universal_corridor_bottleneck` rows.

This is still bounded candidate-search evidence only.  Its role is to keep a
future counterexample honest about the target verdict and fixed detector
factors, not to prove that no counterexample exists.

## Use In A Or B

For an A proof, the finite certificate suggests the exact symbolic lemma to
prove: every residual corridor holonomy element must lie in
`V_beta(H(pi,Q))`, with input-dependent homomorphisms allowed.
The product-subgroup check means it is enough to prove this factor by factor:
`proofs/longitude_subgroup_products.md` then combines the factors into the
single finite group `H(pi,Q)`.

For a B construction, the certificate says what each finite stage must look
like before diagonalization: quotient-fixed, detector-invisible for the
chosen finite factor list, and still moving an explicit residual tuple.  The
final proof must then upgrade this from a listed finite factor set to every
finite group by a normalized-law argument.
