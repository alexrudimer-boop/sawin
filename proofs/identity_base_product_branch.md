# Identity-base product-permutation branch

Date: 2026-05-28

This note records a symbolic subcase of the product-permutation branch.  It is
not the Master Local-Minimal Residual Theorem, but it eliminates a tempting
source of coloured product holonomy with arbitrary finite fibre size.

## Setup

Assume the quotient colour solution is the identity table

```text
R_Z(a,b) = (a,b)
```

and the local table is in swapped product form

```text
T_{a,b}(x,y) = (L_{a,b}(y), R_{a,b}(x)),
```

where

```text
L_{a,b}: A_b -> A_a,
R_{a,b}: A_a -> A_b
```

are bijections.

For the direct product form

```text
T_{a,b}(x,y) = (L_{a,b}(x), R_{a,b}(y)),
```

the identity-base direct cocycle equations force every `L_{a,b}` and
`R_{a,b}` to be idempotent.  Since they are bijections, all are identities.
Thus the direct identity-base product branch is coboundary/trivial.
The helper

```text
identity_base_direct_reduction(interval)
```

records this exact conclusion and returns explicit failures for any
identity-base direct product table whose labels are not all identities.  Such
a failure is necessarily a failure of the direct product YBE equations, not a
new local-minimal branch.

## Central Label Family

For the swapped form, the coloured YBE on colours `a,b,c` gives, in the
middle coordinate,

```text
R_{a,b} L_{a,b} = L_{b,c} R_{b,c}: A_b -> A_b.
```

The left side is independent of `c`, and the right side is independent of
`a`.  Therefore for every colour `b` there is a single permutation

```text
K_b in Sym(A_b)
```

such that

```text
R_{a,b} L_{a,b} = K_b
L_{a,b} R_{a,b} = K_a
```

for all colours `a,b`.  Equivalently,

```text
L_{a,b} K_b = K_a L_{a,b}
R_{a,b} K_a = K_b R_{a,b}.
```

So the product labels do not carry arbitrary noncommuting coloured holonomy:
all residual non-coboundary holonomy is transported among the conjugate
central permutations `K_a`.

The helper

```text
identity_base_swapped_reduction(interval)
```

computes this exact normal form.  It records the `K_a`, their cycle lengths,
and any failures of the displayed equations.  It is a proof-audit helper, not
a finite-search proof.

## Local-Minimal Consequence

In a product-permutation interval, admissible congruence families are exactly
the partition families invariant under all transported `L` and `R` labels.
For the identity base, every `L_{a,b}` conjugates `K_b` to `K_a`, so all
`K_a` have the same cycle type.

If every `K_a` is the identity, then

```text
R_{a,b} = L_{a,b}^{-1}
```

and every local map is involutive:

```text
T_{a,b}^2 = 1.
```

This branch is already in the known finite-G-measurable involutive/permutation
list.

Suppose some `K_a` is nonidentity.  If the common cycle type of the `K_a` is
not a single cycle of prime length, then the cycles of `K_a`, or the cosets of
a nontrivial proper subgroup of the cyclic group generated by `K_a`, give a
nontrivial invariant block system on each fibre.  Transporting those block
systems by the `L` labels gives a proper admissible congruence family.  Hence
local-minimality rules this out.

Therefore the genuinely nontrivial local-minimal identity-base swapped
product branch has

```text
K_a
```

a single `p`-cycle on every fibre, for one prime `p`.  After choosing one
fibre coordinate system and transporting it by the labels, the branch is the
cyclic pairwise-linking product branch with detector `C_p`.

## Detector

Let `p` be the prime cycle length.  In the identity-base swapped product
branch, a pure residual braid with trivial Artin permutation acts on each
fibre coordinate by a power of the corresponding `K_a`.  The exponent is a
linear combination of the abelianized recursive Artin-longitude matrix, as in
the one-colour product note:

```text
one_color_swapped_label_exponent_action(n,beta)
artin_longitude_row_column_sums(n,beta)
```

record the model formula.  The coloured identity-base case is the same
formula transported between fibres by the `L` labels; only the common cyclic
power of `K_a` remains as closed holonomy.

The cyclic group `C_p` detects these exponents.  If

```text
Lambda_{C_p,n}(beta) = Lambda_{C_p,n}(1),
```

then the abelianized exponent vector of every recursive Artin longitude
vanishes modulo `p`.  Hence every closed `K_a` power is trivial, so every
closed product label is identity.  The detector `C_p` depends only on the
finite interval, not on the braid degree `n`.

Thus the identity-base product-permutation branch is finite-G measurable:
it is either involutive/coboundary, or it is detected by the fixed cyclic
group `C_p`.

## Audit Role

This closes the cleanest degenerate quotient-colour stress test.  A genuine
product-permutation obstruction must therefore use a non-identity colour
solution whose cocycle equations do not collapse closed holonomy to the
cyclic family `K_a`, or it must already fall into the known nondegenerate,
involutive, coboundary, or pairwise-linking branches.
