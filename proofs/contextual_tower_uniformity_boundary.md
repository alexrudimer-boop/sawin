# Contextual Tower Uniformity Boundary

Date: 2026-06-05

This note records the audit of the finite-state contextual tower.  The tower is
the right strengthening of the two-sided contextual rack `C_L(X)`, but it still
does not close Sawin without a new uniform finite/profinite lemma.

The missing statement is:

```text
There exists one finite state quotient M such that C_M(X) is orbitwise
residually separating on all contextual labels in every arity.
```

Pointwise separation by finer and finer finite state quotients is not enough:
Sawin requires one finite rack detector working for all `n`.

## Left Structure Monoid

Let `L_X` be the positive left structure monoid

```text
L_X =
< lambda_x, x in X
  | lambda_x lambda_y = lambda_u lambda_v
    whenever r_X(x,y)=(u,v) >.
```

There is a natural homomorphism

```text
ell:L_X -> S_L^1,
lambda_x -> L_x.
```

A finite state quotient is a finite quotient monoid

```text
theta:L_X -> M.
```

One may harmlessly assume `M` refines `S_L^1`: if not, replace `M` by
`M x S_L^1`, so that `ell` factors through `M`.

Write

```text
lambda_x^M=theta(lambda_x).
```

## Finite-State Contextual Rack

For a finite quotient `M`, define `C_M(X)` as the rack generated by

```text
d_{a,x,b}        (a,b in M, x in X)
```

with relations, for `r_X(x,y)=(u,v)`,

```text
d_{a,u,lambda_v^M b}=d_{a lambda_x^M,y,b},                       (M1)
d_{a lambda_u^M,v,b}
 =
d_{a lambda_x^M,y,b} triangleright d_{a,x,lambda_y^M b}.          (M2)
```

For a word `w=(x_1,...,x_n)`, define

```text
P_i^M=theta(lambda_{x_1}...lambda_{x_i}),       P_0^M=1,
Q_i^M=theta(lambda_{x_{i+1}}...lambda_{x_n}),   Q_n^M=1.
```

Then

```text
Theta_n^M(w)=
(d_{P_0^M,x_1,Q_1^M}, ..., d_{P_{n-1}^M,x_n,Q_n^M}).
```

The same local proof as for `C_L(X)` gives braid equivariance:

```text
Theta_n^M(rho_n^X(beta)w)
=
rho_n^{C_M(X)}(beta) Theta_n^M(w).
```

The only required identity is

```text
lambda_x lambda_y=lambda_u lambda_v
```

in `L_X`, hence in `M`.

Taking `M=S_L^1` recovers `C_L(X)`.

## Fixed-M Domination Theorem

For a fixed finite `M`, define finite-rack residual equivalence on contextual
generators by

```text
(a,x,b) ==_{M,fin} (a',x',b')
```

if every homomorphism from `C_M(X)` to a finite rack identifies the two
generators.

If there is a finite quotient `M` such that, for every `n`, whenever

```text
w != w'
```

lie in the same braid orbit in `X^n`, some coordinate `i` satisfies

```text
(P_{i-1}^M(w),w_i,Q_i^M(w))
not ==_{M,fin}
(P_{i-1}^M(w'),w'_i,Q_i^M(w')),
```

then `X` is dominated by a finite rack.

Proof: `M x X x M` is finite.  For every pair of contextual generators not
identified by `==_{M,fin}`, choose a finite rack quotient separating them.
The finite product of these quotients gives one finite rack `Y`.  Then
`Theta_n^Y` separates distinct points inside every braid orbit.  If
`beta in ker rho_n^Y`, equivariance gives

```text
Theta_n^Y(rho_n^X(beta)w)=Theta_n^Y(w),
```

and orbitwise separation forces `rho_n^X(beta)w=w`.  Thus

```text
ker rho_n^Y <= ker rho_n^X
```

for every `n`.

## Profinite Obstruction For Fixed `M`

Let

```text
R_M=C_M(X),
G_M=As(R_M).
```

Then `G_M` has finite Wirtinger-type presentation with generators
`g_{a,x,b}` and relations

```text
g_{a,u,lambda_v b}=g_{a lambda_x,y,b},
g_{a lambda_u,v,b}
 =
g_{a lambda_x,y,b} g_{a,x,lambda_y b} g_{a lambda_x,y,b}^{-1}.
```

For `alpha=(a,x,b)`, write

```text
bar alpha=d_{a,x,b},
H_alpha=Stab_{G_M}(bar alpha).
```

If `bar beta=g.bar alpha`, then

```text
alpha ==_{M,fin} beta
iff
g in closure_prof(H_alpha)
iff
g in intersection_{N normal finite index in G_M} H_alpha N.
```

If `bar alpha` and `bar beta` lie in different `G_M`-orbits, they are
separated by a finite trivial rack.

Thus fixed-`M` separation requires subgroup separability of orbit-relevant
stabilizer cosets in `As(C_M(X))`.  Residual rigidity as currently stated does
not imply this.

## Uniformity Barrier

For finite quotients `M' -> M`, there is a natural rack map

```text
C_{M'}(X) -> C_M(X),
d_{a',x,b'} -> d_{pi(a'),x,pi(b')}.
```

Thus finer state quotients can only improve separation.  Let `B_M` be the set
of same-orbit bad pairs not separated by `C_M(X)` after finite-rack residual
equivalence.  Then

```text
M' refines M  =>  B_{M'} subset B_M.
```

The tower closes only if

```text
there exists finite M with B_M empty.
```

Pointwise separation gives only

```text
intersection_M B_M empty,
```

which is weaker.  The analogy is `Z`: every nonzero integer is separated from
`0` by some finite quotient `Z/mZ`, but no single finite quotient separates
`0` from every nonzero integer.

Because Sawin requires one finite rack `Y` for all arities, pointwise tower
separation is insufficient.

## Tower Residual Equivalence

For full contexts `A,B in L_X`, define

```text
(A,x,B) ==_tower (A',x',B')
```

if for every finite quotient `theta:L_X -> M`,

```text
(theta(A),x,theta(B)) ==_{M,fin}
(theta(A'),x',theta(B')).
```

No finite-state contextual rack separates a same-orbit pair `w,w'` if every
coordinate of their full contextual labels is tower-equivalent.

Tower-equivalence can arise from:

```text
monoid profinite collapse in L_X;
universal collapse in the full marked-word contextual rack;
rack profinite collapse in every finite state quotient C_M(X).
```

Therefore failure of `C_L(X)` separation does not imply that some finer
finite `C_M(X)` succeeds.  It succeeds exactly when the bad pair is not
tower-equivalent.

## Scattering Normalization In `C_M(X)`

For a word `A` in the generators `lambda_x`, define recursively

```text
sigma_empty(x)=x,        Delta_empty(x)=1,
sigma_{Az}(x)=sigma_A(L_z(x)),
Delta_{Az}(x)=Delta_A(L_z(x)) lambda_{R_x(z)}.
```

Then in `C_M(X)`,

```text
d_{theta(A),x,b}
=
d_{1,L_A(x),theta(Delta_A(x))b}.
```

If `theta(A)=theta(A')` and `M` refines `S_L^1`, then `L_A=L_{A'}` and

```text
d_{1,L_A(x),theta(Delta_A(x))b}
=
d_{1,L_A(x),theta(Delta_{A'}(x))b}.
```

Thus `C_M(X)` loses precisely the escape data not seen by `M`.  Finer `M` can
remove this collapse only if the escape words are separated in some finite
quotient of `L_X`.  If they agree in the profinite completion of `L_X`, no
finite `M` separates them.

## Finite Local Tower Obstruction

For a fixed `M`, a local crossing `r_X(x,y)=(u,v) != (x,y)` at context
`(a,b)` is invisible to `C_M(X)` if

```text
d_{a,x,lambda_y b}
==_{M,fin}
d_{a lambda_x,y,b}
==_{M,fin}
d_{a lambda_u,v,b}.
```

A purely finite equality obstruction is generated by the `M1` scattering
relation

```text
(a,u,lambda_v b) ~_{sc,M} (a lambda_x,y,b).
```

If

```text
(a,x,lambda_y b)
~_{sc,M}
(a lambda_x,y,b)
~_{sc,M}
(a lambda_u,v,b),
```

then the local braid generator gives a same-`Theta^M` collision.

A concrete pattern is

```text
r_X(s,y)=(x,y),
r_X(x,y)=(u,y),
u != x,
a lambda_s=a lambda_x=a lambda_u in M.
```

This obstruction survives every finite `M` if the corresponding elements have
the same image in the profinite completion of `L_X`.  Residual rigidity does
not currently rule this out.

## Full Marked-Word Contextual Rack

Define the full marked-word contextual rack `C_Lword(X)` with generators

```text
e_{A,x,B}        (A,B in L_X, x in X)
```

and relations

```text
e_{A,u,lambda_vB}=e_{A lambda_x,y,B},
e_{A lambda_u,v,B}
 =
e_{A lambda_x,y,B} triangleright e_{A,x,lambda_yB}.
```

Every finite quotient `theta:L_X -> M` induces a rack quotient

```text
C_Lword(X) -> C_M(X).
```

The full rack avoids collapse caused by any fixed finite `M`, but it introduces
two issues:

```text
pointwise residual finiteness is not enough for Sawin;
a finite rack quotient of the full rack need not factor through a finite state
quotient C_M(X).
```

It factors through some finite `M` exactly when the finite label function is
determined by a finite-index monoid congruence on the left and right contexts.

## Active Factors Are Still Not Automatic

A contextual scattering collapse gives relations among triples `(A,x,B)` or
`(a,x,b)`.  It does not give a coordinate relation on `X` or a YBE congruence.

The most general state-dependent active factor considered here requires a
finite YBE solution `Z` and maps

```text
pi_{a,b}:X -> Z
```

satisfying

```text
r_Z(pi_{a,lambda_y b}(x), pi_{a lambda_x,b}(y))
=
(pi_{a,lambda_v b}(u), pi_{a lambda_u,b}(v))
```

for every `r_X(x,y)=(u,v)`.

Then the induced maps to `Z^n` are braid-equivariant.  If they become
injective after adding inert observers, then `Z` is domination-reducing:

```text
ker rho_n^Z <= ker rho_n^X.
```

But completing the contextual partial dynamics to a finite bijective YBE
solution is an additional problem.  A scattering cycle gives no reason for
such a `Z` to exist.

## Escape Holonomy And Finite Automata

Escape-holonomy separation implies finite contextual rack separation exactly
under finite rack determinacy by states:

```text
epsilon:M x X x M -> E
```

must satisfy the `M1/M2` rack equations.  Then `epsilon` factors through
`C_M(X) -> E`.

If escape holonomy distinguishes paths with the same finite state triple, or
uses a crossing law other than the rack law, it does not factor through
`C_M(X)`.

More generally, finite monoid quotients are not the most general finite-state
construction.  One may take finite sets `P,Q` with a right action of `L_X` on
`P` and a left action on `Q`, and define a rack `C_{P,Q}(X)` with generators

```text
e_{p,x,q}.
```

The same contextual relations and equivariance proof apply.  This can encode
finite escape-holonomy states not literally coming from a monoid quotient, but
it still requires a finite rack quotient separating all orbit-relevant labels.

## Current Missing Lemma

To close the residual branch through the contextual tower, one must prove:

```text
If X is residual rigid and has no proper domination-reducing active factor,
then there exists a finite quotient M of L_X such that C_M(X) is orbitwise
residually finite on Theta^M labels.
```

Equivalently:

```text
there exists finite M such that every orbit-relevant stabilizer coset in
As(C_M(X)) is finitely separated.
```

This is stronger than pointwise tower separation and stronger than escape
holonomy unless escape labels satisfy finite rack determinacy.

## Strongest Valid Endpoint

The strongest valid theorem is conditional:

```text
contextual tower finite separation => Sawin domination.
```

The unresolved obstruction is the possible nonexistence of one uniform finite
state quotient `M` plus one finite rack quotient separating all braid-orbit
points in all arities.  This obstruction may arise from finite scattering
cycles, profinite collapse in `L_X`, nonclosed stabilizer cosets, or failure
of contextual collapses to form domination-reducing active factors.
