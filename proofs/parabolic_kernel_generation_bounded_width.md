# Parabolic kernel generation and bounded-width domination

This note records the bounded-width theorem obtained from the latest Pro
bounded-width query.  It does not prove Sawin, but it gives a genuine
non-tautological route for collapsing the all-arity quantifier for a fixed
detector rack.

## Fixed detector notation

Let `X` be a finite bijective YBE solution and `Y` a finite rack.  Write

```text
K^Y_n = ker(B_n -> Sym(Y^n)),
H^X_n = ker(B_n -> Sym(X^n)).
```

The fixed-detector obstruction `N_{Y,n}(X)` vanishes exactly when

```text
K^Y_n <= H^X_n.
```

Equivalently, the finite joint image

```text
< (rho^X_n(sigma_i), rho^Y_n(sigma_i)) : 1 <= i < n >
<= Sym(X^n) x Sym(Y^n)
```

contains no nonidentity element of the form `(g_X,1)`.

## Computable cutoff versus decidability

For fixed sizes `|X|=a` and `|Y|=b`, a non-effective size-only cutoff exists
for trivial finite-enumeration reasons: there are only finitely many tables of
those sizes, so one can take the maximum first failing width among all
non-dominated pairs.

The meaningful question is computability.  A computable size-only cutoff
`B(a,b)` is equivalent to decidability of the fixed-detector domination
problem:

```text
given finite tables X,Y, decide whether K^Y_n <= H^X_n for every n.
```

Indeed, a computable cutoff gives the decision algorithm by checking
`n <= B(a,b)`.  Conversely, if fixed-detector domination is decidable, enumerate
all table pairs of sizes `a,b`; for each non-dominated pair, enumerate arities
until the first failure appears; the maximum first failure is a computable
cutoff.

Thus a computable bounded-width theorem is a real decision theorem, not a
formal consequence of finite locality.

## Parabolic normal-generation criterion

For `k <= n`, let

```text
iota_{j,k}:B_k -> B_n
```

be the standard parabolic inclusion onto the consecutive block
`{j+1,...,j+k}`.  For a bound `B`, define

```text
J^Y_{B,n}
  =
<< iota_{j,k}(K^Y_k) : 1 <= k <= B, 0 <= j <= n-k >>_{B_n}.
```

This is the normal closure in `B_n` of all detector-blind relations supported
on at most `B` consecutive strands.  Always

```text
J^Y_{B,n} <= K^Y_n.
```

### Theorem

Assume that for some `B`,

```text
K^Y_n = J^Y_{B,n}     for every n > B.
```

Then `B` is a bounded-width domination cutoff for `Y` against every finite YBE
solution `X`:

```text
[ K^Y_k <= H^X_k for every k <= B ]
  =>
[ K^Y_n <= H^X_n for every n ].
```

Proof.  If `K^Y_k <= H^X_k` for `k <= B`, then every parabolic copy
`iota_{j,k}(K^Y_k)` acts trivially on `X^n`.  Since `H^X_n` is normal in
`B_n`, the normal closure `J^Y_{B,n}` acts trivially on `X^n`.  If
`K^Y_n=J^Y_{B,n}`, then `K^Y_n <= H^X_n`.

This is the cleanest currently available bounded-width mechanism.

## Flip-rack example

For the two-point flip rack, the braid action is the standard projection

```text
B_n -> S_n.
```

The detector kernel is the pure braid group `P_n`.  The normal closure of the
adjacent squares `sigma_i^2` is `P_n`, since quotienting `B_n` by
`sigma_i^2=1` gives the Coxeter presentation of `S_n`.  Hence

```text
K^Y_n = J^Y_{2,n}.
```

The bounded test is just width `2`: `sigma_1^2` acts trivially on `X^2`, i.e.
`r_X^2=id`.  This recovers the involutive branch.

## High-arity cross-effects

The obstruction to bounded width for a detector `Y` is

```text
Q^Y_{B,n} = K^Y_n / J^Y_{B,n}.
```

This is the group of genuinely new `n`-strand detector relations not normally
generated by detector relations on at most `B` strands.

For a specific target `X`, the realized finite obstruction is

```text
C^{X,Y}_{B,n}
  =
rho^X_n(K^Y_n) / rho^X_n(J^Y_{B,n}).
```

If all widths `<= B` pass, then `rho^X_n(J^Y_{B,n})=1`, so any later failure
is exactly a nontrivial high-arity cross-effect

```text
C^{X,Y}_{B,n} != 1.
```

## Minimal first-failure theorem

Suppose `n_0` is the first arity where `Y` fails to dominate `X`:

```text
K^Y_k <= H^X_k for every k < n_0,
K^Y_{n_0} not <= H^X_{n_0}.
```

Then every witness `beta in K^Y_{n_0}` with `rho^X_{n_0}(beta) != 1` has
nontrivial image in

```text
K^Y_{n_0} / J^Y_{n_0-1,n_0}.
```

If `beta` lay in `J^Y_{n_0-1,n_0}`, it would be a product of conjugates of
lower-width detector-kernel elements.  By minimality those lower-width
relations act trivially on `X`, and normality of `H^X_{n_0}` would force
`beta` to act trivially on `X^{n_0}`, a contradiction.

## Remaining theorem

The fixed-detector all-arity problem would be solved by:

```text
Finite parabolic kernel-generation theorem.
For every finite rack Y, there exists a computable B(Y) such that
K^Y_n = J^Y_{B(Y),n} for all n>B(Y).
```

This is known in the flip and one-point cases above, but not for arbitrary
finite racks.  The surviving obstruction is the family of cross-effects
`Q^Y_{B,n}` and their realized images `C^{X,Y}_{B,n}`.

## Fixed-arity realized audit

The helper `realized_parabolic_cross_effect_audit(X,Y,B,n)` implements the
finite fixed-arity version of `C^{X,Y}_{B,n}`.

The algorithm is:

1. Close the finite joint image

   ```text
   G_n=< (rho^Y_n(sigma_i),rho^X_n(sigma_i)) >
       <= Sym(Y^n) x Sym(X^n),
   ```

   while retaining one braid-word representative for each joint image element.

2. Extract

   ```text
   K_image = { (1,g_X) in G_n }.
   ```

   This is the finite image of `K^Y_n` in the joint action, equivalently
   `rho^X_n(K^Y_n)`.

3. For each `k<=B`, close the lower joint image in arity `k`, retain one word
   for each element of its detector kernel, parabolically shift that word into
   every consecutive block of length `k` inside `B_n`, and evaluate the shifted
   word in the full joint action.

4. Take the normal closure of these shifted lower-kernel images inside the
   finite group `G_n`.  Since the seeds lie in the detector kernel and the
   detector kernel is normal in `G_n`, this normal closure lies in `K_image`.
   It is the realized image of `J^Y_{B,n}`.

5. The quotient size is `|K_image|/|J_image|`.  A nontrivial coset gives a braid
   word `beta in K^Y_n` whose `X`-action is not generated by lower-width
   detector-kernel relations.

This audit is finite for fixed `X,Y,B,n`.  It still leaves the all-`n`
vanishing problem untouched.  Current regressions check that the one-point
detector has a nontrivial cross-effect at bound `1`, while the two-point flip
detector has vanishing cross-effect at bound `2` in arity `3`.

For Sawin-negative output, a fixed-detector high-arity cross-effect is not
enough.  One must find a single finite `X` such that these obstructions survive
for the product prefixes of all finite racks, producing

```text
rho^{P_m}_{n_m}(beta_m)=1,
rho^X_{n_m}(beta_m) != 1,
n_m -> infinity.
```
