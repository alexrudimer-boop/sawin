# Green branch-choice audit

Date: 2026-05-28

This note records proof-code for the local branch-choice obstruction mentioned
in the current master gap.

For a finite braided set with

```text
R(x,y) = (u,v),
```

define the first-coordinate transformations

```text
tau_x(y) = pr_1 R(x,y).
```

The YBE implies the structure-monoid relation

```text
tau_x tau_y = tau_u tau_v.
```

The new module `src/ybe_domination/green_branch.py` audits the finite
transformation monoid generated by the `tau_x`.  For a regular Green `R`-class
`C`, it forms the retained edge-germs

```text
E_C = { (s,x) : s in C and s tau_x in C }.
```

For composable retained edges

```text
a = (s,x),        q = (s tau_x, y),
R(x,y) = (u,v),
```

the completed YBE row gives

```text
q^a = (s,u),      a^q = (s tau_u, v).
```

The atom quotient is generated by the relations

```text
p(q^a) = p(q).
```

The audit then checks the direct branch-choice condition: for fixed `a`, if
two choices `q,q'` lie in the same atom, then `a^q` and `a^{q'}` should also
lie in the same atom.  A failure here would be a concrete finite local
branch-choice obstruction candidate.

The audit now also checks the stronger atom-action descent that is needed by
the Green rigidity formulation.  It asks whether the completed-row operation

```text
p(a) triangleright p(q) = p(a^q)
```

depends only on the two saturated atoms `p(a),p(q)`, not on the chosen edge
representatives.  It simultaneously checks the inverse bookkeeping operation

```text
p(a^q) triangleleft p(q) = p(a).
```

The helper

```text
atom_action_summary(audit)
```

records supported atom pairs, undefined atom pairs, and conflicts for both
operations.  A conflict would be sharper than the older fixed-edge
branch-choice failure: it would show that the saturated atom quotient still
remembers section data not carried by the two input atoms.  In that case a B
route could try to turn this hidden section dependence into normalized-law
holonomy.  If the operation descends, the A route may treat the atom quotient
as a finite partial branch-action layer before passing to Schutzenberger and
unit-group detectors.

When this atom action is conflict-free and total, the helper

```text
atom_quotient_solution(audit)
```

constructs the finite atom crossing

```text
R_atom(A,Q) = (Q, A triangleright Q).
```

The companion note `proofs/green_atom_quotient_layer.md` records the
conditional theorem: a total descended atom layer is a finite right-rack-like
YBE solution.  The report now checks this through
`atom_quotient_rack_audit()`, which records right-translation bijectivity and
right self-distributivity in addition to the generic finite YBE check.
Therefore the atom quotient itself is not the remaining B obstruction; a
genuine Green/corridor obstruction must survive in the section or unit
holonomy below this rack-like atom layer.

## Schutzenberger refinement

The audit now also records two stronger finite invariants for each regular
Green `R`-class.

First, it records a kernel-block action.  In the full transformation monoid,
Green `R`-classes are kernel classes.  Since an `R`-class in the coordinate
submonoid refines a full transformation `R`-class, every `s in C` has the same
kernel partition `K_C`.  If `(s,x)` is retained, then `s tau_x` lies in the
same coordinate-monoid `R`-class and hence has the same kernel.  Therefore
`tau_x` preserves `K_C` and induces a permutation of the finite block set
`Omega / K_C`.  This is a symbolic kernel-level globalization lemma, not a
finite-search observation.  The report records the finite group generated by
these induced block permutations.

Second, it projects the atom relation sourcewise: for each `s in C`, the
retained labels `x` with `(s,x) in E_C` are partitioned by the atom of
`(s,x)`.  Equality source projections are group-like; universal or mixed
source projections indicate collapsed local information that must be assigned
to a known finite-G-measurable branch or explained by local-minimality.

Third, it computes the right stabilizer of `C` in the coordinate-action
monoid.  The stabilizer acts on `C` by permutations: this is the finite
Schutzenberger group action.  The new counter
`local_only_edge_germ_count` measures retained edge-germs `(s,x)` for which
`s tau_x` stays in `C` but `tau_x` does not globally stabilize all of `C`.
Such a local-only edge would be a sharper hidden-branch candidate than a
bounded context loop, because it cannot be explained directly by the finite
Schutzenberger group.

The same audit now has a right-handed copy.  The side-opposite solution
`R^op=P R P` has first-coordinate maps equal to the right-coordinate maps
`rho_x(y)=pr_2 R(y,x)` of the original solution.  Therefore all kernel-block
and Schutzenberger data can be computed on both `X` and `X^op`; the helper
`two_sided_kernel_symmetric_groups(X)` records the resulting full symmetric
kernel-block detector factors with duplicates removed.

The Schutzenberger data is no longer only a counted summary.  The helper
`schutzenberger_action_groups(X)` returns the finite permutation groups
themselves.  The atom layer now contributes executable detector factors too:
`atom_quotient_inner_groups(X)` returns the inner groups of all proved
atom-rack quotient layers, and `two_sided_atom_quotient_inner_groups(X)` adds
the opposite-side layers.  Thus `two_sided_green_detector_groups(X)` combines
the full symmetric kernel-block factors, two-sided Schutzenberger factors,
and two-sided atom-quotient inner groups, with duplicate concrete group
tables removed.  The direct-product helper
`two_sided_green_detector_product(X)` then gives one finite group for the
sharp detector rack.  The size-three affine commutator fixture has concrete
factor orders `2`, `3`, and `6`, with product order `36`; its order-`6` atom
inner group is already represented by the symmetric kernel-block factor and
is deduplicated.

The bounded completed-context category now also has a group-part extractor:

```text
bounded_atom_trivial_loop_group_summaries(audit, max_depth)
```

It keeps only total bijective atom-trivial loops on the finite context word
sets and forms their generated permutation groups.  This separates genuine
finite-depth group holonomy from reset-like atom-trivial context collapse.
The two-point identity table has raw hidden atom-trivial loops, but the new
summary sees only the trivial group; such collapses cannot by themselves be
residual braid motions because residual actions are permutations.

## Candidate lemma isolated

The new data suggests the following symbolic lemma as the next A-route target:

> In the coordinate-action monoid of a finite bijective YBE solution, the
> kernel-block permutation groups attached to regular Green `R`-classes,
> together with the Schutzenberger actions when local-only splitting is absent,
> control all recurrent branch choices; any mixed source atom projection is
> forced into the known finite-G-measurable cases.

This lemma is stronger than the bounded hidden-loop audit and would directly
feed the Master Local-Minimal Residual Theorem: the detector group candidate
for the Green branch would be a finite product of the relevant
kernel-block and Schutzenberger groups, plus the already-bookkept known-branch
detectors.  The kernel-block permutation part is proved by the Green
`R`-kernel argument above; the remaining unproved step is showing that this
finite group data detects the full braid-action residual for arbitrary finite
fibres and quotient colours.

This is not a proof of the Master Local-Minimal Residual Theorem.  It is a
repeatable finite local obstruction microscope: any B-style construction
following the hidden-holonomy route should produce a symbolic family whose
finite stages eventually show nontrivial behavior here after the recurrence
and local-group filters, while an A proof must turn the absence of genuine
branch-choice holonomy into an all-`n` residual detection theorem.
