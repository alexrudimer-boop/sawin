# Point-pushing mu functoriality

Date: 2026-05-30

This note records structural rules for the growth invariant

```text
mu_X(k)=min { m : D_k(S_m) -> P_k(X) is a marked quotient }.
```

It does not prove outcome A or B.  It says that the remaining unbounded-growth
obstruction cannot be manufactured by quotients, already dominated covers, or
direct products.  Any B example must be primitive with respect to these
operations.

## Quotient Monotonicity

Let

```text
f:X -> Z
```

be a surjective morphism of finite bijective YBE solutions.  Then for every
`k>=1`,

```text
mu_Z(k) <= mu_X(k).
```

Proof.  The coordinatewise map

```text
f^{k+1}:X^{k+1}->Z^{k+1}
```

intertwines the braid actions.  In particular, it intertwines the
point-pushing generators:

```text
f^{k+1} h_i^X = h_i^Z f^{k+1}.
```

Therefore every marked relation among the generators `h_i^X` is also a marked
relation among the generators `h_i^Z`, and `P_k(Z)` is a marked quotient of
`P_k(X)`.

If `D_k(S_m)->P_k(X)` exists, composing with `P_k(X)->P_k(Z)` gives
`D_k(S_m)->P_k(Z)`.  Hence `mu_Z(k)<=mu_X(k)`.  QED.

## Domination Monotonicity

If a finite solution `Y` dominates `X`, meaning

```text
ker rho_{Y,n} subset ker rho_{X,n}
```

for every `n`, then

```text
mu_X(k) <= mu_Y(k)
```

for every `k`.

Proof.  Restrict the kernel inclusion to the last-strand point-pushing
subgroup `iota_{k+1}(F_k)`.  Any word acting trivially in `P_k(Y)` acts
trivially in `P_k(X)`.  Thus `P_k(X)` is a marked quotient of `P_k(Y)`.
The same composition argument as above gives the inequality.  QED.

In particular, once a solution is known to be dominated by a fixed rack, its
`mu` sequence is automatically bounded.

## Product Formula

Let `X` and `Y` be finite bijective YBE solutions, and let `X x Y` be their
Cartesian product solution.  Then

```text
mu_{X x Y}(k) = max(mu_X(k), mu_Y(k))
```

for every `k`.

Proof.  The point-pushing action on `(X x Y)^{k+1}` is the coordinatewise
product of the point-pushing actions on `X^{k+1}` and `Y^{k+1}`.  Therefore

```text
P_k(X x Y)
```

is the marked subgroup of

```text
P_k(X) x P_k(Y)
```

generated by

```text
(h_i^X,h_i^Y).
```

First suppose

```text
m >= max(mu_X(k), mu_Y(k)).
```

Then there are marked quotients

```text
D_k(S_m)->P_k(X),
D_k(S_m)->P_k(Y).
```

The product map sends each detector generator to

```text
(h_i^X,h_i^Y),
```

so its image is exactly `P_k(X x Y)`.  Hence

```text
mu_{X x Y}(k) <= max(mu_X(k),mu_Y(k)).
```

Conversely, both coordinate projections

```text
X x Y -> X,
X x Y -> Y
```

are surjective YBE morphisms.  Quotient monotonicity gives

```text
mu_X(k) <= mu_{X x Y}(k),
mu_Y(k) <= mu_{X x Y}(k).
```

Thus equality holds.  QED.

The same proof gives, for any finite product,

```text
mu_{\prod_s X_s}(k)=max_s mu_{X_s}(k).
```

## Consequence For The A Route

The boundedness statement

```text
sup_k mu_X(k)<infinity
```

is inherited by quotients and by solutions dominated by bounded-`mu`
solutions.  It is also preserved under finite products.

So product/permutation assemblies cannot create a new unbounded `mu`
obstruction if all factors have bounded `mu`.  This matches the repository's
closed product-detector and direct-product longitude calculus.

## Consequence For The B Route

An unbounded-`mu` counterexample cannot be explained by taking a quotient of
an already bounded solution, nor by taking a finite product of bounded
solutions.  If `X` is a product and `mu_X(k)` is unbounded, then at least one
factor already has unbounded `mu`.

Thus the exact B seed remains:

```text
an explicit primitive finite solution X
with sup_k mu_X(k)=infinity,
```

together with explicit vertical-witness words for the symmetric-tail failures.

Finite product constructions and quotient shadows are therefore false leads
for the final obstruction.
