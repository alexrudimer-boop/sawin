# Point-Pushing Active Module Generator Split

Date: 2026-05-30

This note refines the noncentral irreducible relation-module branch after
`proofs/point_pushing_module_prime_characteristic_split.md`.

It does not prove outcome A or B.  It separates the remaining module
obstruction according to whether the bounded newest point-pushing generator
actually acts on the irreducible module.

## Setup

Let a noncentral abelian-chief first failure have monolith

```text
M ~= F_p^r
```

and let

```text
A = H/C_H(M) <= GL(M)
```

be the faithful irreducible action shadow.  Let `t in H` be the image of the
newest point-pushing generator from
`proofs/point_pushing_bounded_normal_generator_tail.md`, so

```text
ord(t) | B_X,
M <= <<t>>_H.
```

Write

```text
a = image(t) in A.
```

Then `ord(a)` also divides `B_X`.

## Theorem

Exactly one of the following holds.

1. **Centralizer-layer generator.**

   ```text
   a=1.
   ```

   Then `t in C_H(M)`, and the first-failure normal generation of `M` occurs
   inside the centralizer layer `C_H(M)/M`.

2. **Active bounded-order linear generator.**

   ```text
   a != 1.
   ```

   Then the irreducible module is generated by the commutator images of the
   conjugates of this bounded-order linear operator:

   ```text
   M = sum_{g in H} (a^g - 1)M.
   ```

   In a module-prime escape tail, after finitely many terms this is
   cross-characteristic: `p` does not divide `ord(a)`.

## Proof

If `a=1`, then `t in C_H(M)`.  Since `C_H(M)` is normal in `H`, every
conjugate of `t` also lies in `C_H(M)`, and therefore the normal closure
`<<t>>_H` lies in `C_H(M)`.  But `M<=<<t>>_H`, so the obstruction is carried by
the centralizer layer over `M`.  This is precisely the bounded-module
centralizer-layer branch from `proofs/point_pushing_noncentral_module_tail.md`.

Assume now that `a!=1`.  Let

```text
N = <<t>>_H.
```

By the bounded normal-generator theorem, `M<=N`.  Hence

```text
[M,N]=[M,<<t>>_H].
```

This subgroup is generated, additively in the elementary abelian group `M`, by
the commutator images

```text
(a^g - 1)M
```

as `g` ranges over `H`.  It is also an `H`-stable subgroup of `M`.  Since the
module is noncentral and irreducible, `[H,M]=M`; because `M<=N`, this gives

```text
[M,N]=M.
```

Therefore

```text
M = sum_{g in H} (a^g - 1)M.
```

Finally, in a module-prime escape tail,
`proofs/point_pushing_module_prime_characteristic_split.md` shows that
eventually `p` does not divide `B_X`.  Since `ord(a)|ord(t)|B_X`, eventually
`p` does not divide `ord(a)`.  Thus the active linear generator is a bounded
order `p'`-element acting on the `F_p`-module.  QED.

## Consequence For The Fork

The noncentral irreducible module branch now has two exact subbranches:

1. **Centralizer-layer generator tails.**  The newest generator is invisible in
   the action shadow `A<=GL(M)`, so any remaining obstruction lives in the
   centralizer extension over the module.

2. **Active bounded-order linear-generator tails.**  A nontrivial linear
   operator `a` of order dividing `B_X` has conjugate commutator images that
   generate the irreducible module.  Prime escape is necessarily
   cross-characteristic for this operator.

Thus a genuine noncentral module B tail cannot be a vague large module
quotient.  It must either be a centralizer-layer extension tail or an
irreducible module quotient generated by commutators with a bounded-order
linear operator.

The follow-up `proofs/point_pushing_centralizer_layer_commutator_split.md`
further divides the centralizer-layer extension tail: if `N=<<t>>_H` is the
normal closure of the bounded generator in the centralizer of `M`, then
minimality forces either `[N,N]=1` or `M<=Z(N) cap [N,N]`.
The abelian side is sharpened in
`proofs/point_pushing_abelian_centralizer_layer_prime_bound.md`: there `N` is
`p`-primary and `exp(N)|ord(t)|B_X`, so that subcase has no module-prime
escape.

## Audit Hook

The helper

```text
point_pushing_active_module_generator_audit(...)
```

records whether the image of the bounded generator in the action shadow has
order `1` or greater than `1`.  It labels finite rows as

```text
centralizer_layer_generator
active_bounded_order_linear_generator.
```

This is finite bookkeeping only; the theorem above supplies the symbolic
tail-level split.
