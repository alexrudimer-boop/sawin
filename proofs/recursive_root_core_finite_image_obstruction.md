# Recursive Root-Core Finite-Image Obstruction

Date: 2026-06-06

This note records a C-type sharpening of the weighted block-core obstruction
for Sawin's finite-rack domination problem.  It does not prove Sawin's
statement and does not provide a cofinal counterexample.  Its contribution is
to retain the binary root-split structure of genuine all-meridian commutators.

Update.  The recursive root-core target recorded here has now been sharpened
again by exact small-support, or q-skeletal, root cores.  The q-skeletal note
proves

```text
C_S <= Sk_{S,q}^{(d)} <= R_S^(d),
Sk_{S,q}^{(d)}=C_S for d>=max(0, |S|-q).
```

Thus the large-arity target can be sharpened from `K_n cap R_n^(d)=1` to
`K_n cap Sk_{n,q}^{(d)}=1` for fixed `q>=3` and fixed `d>=0`.  See
`proofs/q_skeletal_root_core_finite_image_obstruction.md`.

The weighted block core records all-meridian multiplicity after collapsing
labels into blocks.  A genuine all-meridian commutator has more structure:
the root of its binary commutator tree splits the support into two nonempty
parts, and each side is itself an all-support commutator on its own labels.
The recursive root cores below enforce this coherence to fixed depth.

## Root-Split Factorization

Let `G` be a group and let

```text
N_1,...,N_r triangleleft G.
```

For every nonempty subset `S subset {1,...,r}`, define

```text
C_S = [N_i | i in S]_Sigma,
```

with the convention `C_{ {i} }=N_i`.  Let `Bip(S)` be the set of unordered
bipartitions

```text
S=A sqcup B,       A,B nonempty.
```

Theorem.  For every `|S|>=2`,

```text
C_S =
product_{ {A,B} in Bip(S) } [C_A,C_B].
```

The product is a product of normal subgroups, so the order of the factors is
irrelevant.

Proof.  First, take `u in C_A` and `v in C_B`.  The subgroup `C_A` is
generated by all-support commutators using every label in `A`, and `C_B` is
generated by all-support commutators using every label in `B`.  Commutator
identities reduce `[u,v]` to products of conjugates of commutators between
such generators.  Each such commutator is a fat commutator in which every
label in `S=A sqcup B` appears at least once.  By the fat-commutator theorem,
it lies in `C_S`.  Hence

```text
product_{ {A,B} in Bip(S) } [C_A,C_B] <= C_S.
```

Conversely, a generator of `C_S` is a fully parenthesized commutator with one
input from each `N_i`, `i in S`.  Its top bracket has form `[u,v]`, where the
leaves of `u` are indexed by some nonempty proper subset `A subset S`, and the
leaves of `v` are indexed by `B=S\A`.  Then `u in C_A` and `v in C_B`, so
`[u,v] in [C_A,C_B]`.  Taking all bracketings gives the reverse inclusion.

## Recursive Weighted Root Cores

For `|S|=1`, set

```text
R_S^(d)=N_i      (S={i}).
```

For `|S|=2`, set

```text
R_S^(0)=C_S=[N_i,N_j].
```

For `|S|>=3`, set

```text
R_S^(0)
  =
Omega_2(G;(N_i)_{i in S}) cap Omega_3(G;(N_i)_{i in S}),
```

where `Omega_s` is the multiplicity-preserving weighted block core from
`proofs/weighted_block_core_finite_image_obstruction.md`.

For `d>=0`, define recursively

```text
R_S^(d+1)
  =
R_S^(d) cap
product_{ {A,B} in Bip(S) } [R_A^(d), R_B^(d)].
```

Call `R_S^(d)` the depth-`d` recursive weighted root core.

## Root-Core Containment and Eventual Exactness

Theorem.  For every nonempty `S` and every `d>=0`,

```text
C_S <= R_S^(d+1) <= R_S^(d).
```

Moreover,

```text
R_S^(d)=C_S       whenever d>=|S|-3.
```

In particular, for `S={1,...,r}`,

```text
C <= R_S^(d) <= R_S^(0)
  =
Omega_2(G;N_1,...,N_r) cap Omega_3(G;N_1,...,N_r).
```

Proof.  The descending inclusion `R_S^(d+1)<=R_S^(d)` is immediate from the
definition.

We prove `C_S<=R_S^(d)` by induction on `d`.  For `d=0`, this is the weighted
block-core containment for `|S|>=3`, and it is equality for `|S|<=2`.  For
`|S|=3`, the three-block weighted core is the singleton partition, so
`Omega_3=C_S`, and hence `R_S^(0)=C_S`.

Assume `C_T<=R_T^(d)` for every nonempty `T subseteq S`.  By root-split
factorization,

```text
C_S =
product_{ {A,B} in Bip(S) } [C_A,C_B].
```

Since `C_A<=R_A^(d)` and `C_B<=R_B^(d)`, every factor `[C_A,C_B]` lies in
`[R_A^(d),R_B^(d)]`.  Hence `C_S` lies in the product of these root-split
commutator subgroups.  Also `C_S<=R_S^(d)`, so `C_S<=R_S^(d+1)`.

For eventual exactness, induct on `m=|S|`.  For `m<=3`, the base core is
already exact.  Let `m>=4`, put `d=m-3`, and assume the claim for all proper
nonempty subsets of `S`.  Then `d-1=m-4>=|A|-3` for every proper nonempty
`A subsetneq S`, so

```text
R_A^(d-1)=C_A,
R_{S\A}^(d-1)=C_{S\A}.
```

Therefore

```text
product_{ {A,B} in Bip(S) } [R_A^(d-1),R_B^(d-1)]
  =
product_{ {A,B} in Bip(S) } [C_A,C_B]
  =
C_S.
```

Thus

```text
R_S^(d)=R_S^(d-1) cap C_S.
```

Since `C_S<=R_S^(d-1)`, this gives `R_S^(d)=C_S`.

## Finite-Image Consequence

Return to the finite-image setup.  Let

```text
R_n={1,...,n-1}.
```

For every nonempty `S subset R_n`, define

```text
R_{n,S}^(d)
  =
R_S^(d)(Gamma_n;(N_{i,n})_{i in S}),
```

and define the full depth-`d` root core

```text
R_n^(d)=R_{n,R_n}^(d).
```

Then

```text
C_n <= R_n^(d)
  <= Omega_{n,2}^wt cap Omega_{n,3}^wt
```

for every fixed `d>=0`, and

```text
R_n^(d+1) <= R_n^(d).
```

Moreover,

```text
R_n^(d)=C_n       whenever d>=n-4.
```

Corollary.  A detector `Q=Y^0 x T_2` dominates `X` if there exists a fixed
integer `d>=0` such that

```text
K_n cap R_n^(d)=1
```

for all sufficiently large `n`, together with fixed-arity rack detectors for
the remaining small arities.

Proof.  Since `C_n<=R_n^(d)`, the assumed vanishing gives
`K_n cap C_n=1` in all sufficiently large arities.  The finite-image
Brunnian theorem identifies this with the large-arity domination condition,
and fixed-arity rack cofinality handles the finitely many remaining arities.

## Relative Quotient Version

Let `Z` be a braided quotient of `X` already dominated by a finite rack
`Y_Z`, and put

```text
Q=Y_Z^0 x T_2.
```

Recall

```text
G^X_n = rho^X_n(F_{n-1}),
E_n = ker(G^X_n -> G^Z_n),
M_{i,n}=<<rho^X_n(x_i)>>_{G^X_n}.
```

Define

```text
R_{n,S}^{X,(d)}
  =
R_S^(d)(G^X_n;(M_{i,n})_{i in S}),
```

and

```text
R_n^{X,(d)}=R_{n,{1,...,n-1}}^{X,(d)}.
```

Corollary.  If there is a dominated braided quotient `Z` of `X` and a fixed
integer `d>=0` such that

```text
E_n cap R_n^{X,(d)}=1
```

for all sufficiently large `n`, then one finite rack dominates `X`.

Proof.  Let `gamma in K_n cap C_n`, and choose `beta in F_{n-1}` with
`Phi_n(beta)=gamma`.  Since `gamma in K_n`, the `Q` action of `beta` is
trivial.  Since `Q` contains a rack detector dominating `Z`, the `Z` action is
trivial.  Hence `rho^X_n(beta) in E_n`.  Also `gamma in C_n`, so its
`X`-projection lies in

```text
C^X_n=[M_{1,n},...,M_{n-1,n}]_Sigma.
```

By the root-core containment theorem, `C^X_n<=R_n^{X,(d)}`.  Therefore the
`X`-projection lies in `E_n cap R_n^{X,(d)}=1`.  Thus
`gamma in K_n cap L_n=1`, because `Gamma_n<=Sym(Q^n) x Sym(X^n)` has
trivially intersecting projection kernels.  Hence `K_n cap C_n=1` in all
sufficiently large arities, and fixed-arity rack cofinality handles the rest.

## Remaining Boundary

The current finite-image positive target is:

```text
exists Q=Y^0 x T_2 and fixed d>=0 such that
K_n cap R_n^(d)=1
for all sufficiently large n.
```

The quotient target is:

```text
exists dominated quotient Z and fixed d>=0 such that
E_n cap R_n^{X,(d)}=1
for all sufficiently large n.
```

A cofinal counterexample must produce, for every finite rack prefix, unbounded
arities `n_m` and nontrivial elements in

```text
K_{n_m} cap C_{n_m}.
```

Such elements automatically lie in every fixed-depth recursive root core:

```text
K_{n_m} cap R_{n_m}^(d)
```

for each fixed `d`, while `n_m -> infinity`.  Defeating only the weighted
block core remains insufficient unless membership in the exact all-meridian
subgroup `C_n` is proved.
