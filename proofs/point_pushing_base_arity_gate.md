# Point-Pushing Base-Arity Gate

Date: 2026-05-30

This note closes the base arity in the point-pushing Brunnian gate induction.
It is a small but useful cleanup: base failures cannot contribute to the
asymptotic B tail, and the detector needed for arity `1` is completely
explicit.

It does not prove outcome A or B.  It removes the arity-`1` case from the
remaining all-arity extension problem.

## Setup

At point-pushing arity `1`, the free group is

```text
F_1=<x_1>,
```

and the last-strand point-pushing generator is

```text
iota_2(x_1)=A_{1,2}=sigma_1^2.
```

For a finite solution `X`, let

```text
s_X = ord(rho_{X,2}(A_{1,2})).
```

Equivalently, `s_X` is the order of the pure two-strand action `R_X^2` on
`X^2`.

Define the minimal symmetric base cutoff

```text
b_X = min { m>=1 : s_X divides lcm(1,...,m) }.
```

## Theorem

The arity-`1` marked quotient

```text
D_1(G) -> P_1(X)
```

exists whenever

```text
s_X divides exp(G).
```

In particular, it exists for the cyclic group `C_{s_X}` and for the symmetric
group `S_{b_X}`.  The older choice `S_{s_X}` is always safe, but `S_{b_X}` is
the minimal symmetric cutoff for the base gate.

## Proof

The group `F_1` is infinite cyclic, generated by `x_1`.  The point-pushing
image `P_1(X)` is therefore cyclic, generated by the action of
`A_{1,2}=sigma_1^2`, and has order `s_X`.

For a finite group `G`, the exact two-strand Artin-longitude period says that
finite-`G` longitude data is trivial on `sigma_1^N` exactly when

```text
N in 2 exp(G) Z.
```

Restricting to pure powers `A_{1,2}^r=sigma_1^{2r}`, this means

```text
A_{1,2}^r in K_G(2)
iff
r in exp(G) Z.
```

Thus the derivative detector image `D_1(G)` is cyclic of exponent dividing
`exp(G)` and has kernel on `F_1` contained in the kernel of `P_1(X)` exactly
when `s_X` divides `exp(G)`.  This is precisely the marked quotient condition
`D_1(G)->P_1(X)`.

For `G=C_{s_X}`, the exponent is `s_X`.  For `G=S_m`, the exponent is
`lcm(1,...,m)`.  Therefore `S_m` detects arity `1` exactly when

```text
s_X divides lcm(1,...,m).
```

By definition, the least such symmetric degree is `b_X`.  QED.

## Consequence For The Brunnian Induction

The exact all-arity criterion from
`proofs/point_pushing_brunnian_gate_induction.md` now has a closed base case.
For any finite solution `X`, choose

```text
m_0=b_X.
```

Then every symmetric detector `S_m` with `m>=m_0` passes the arity-`1` marked
quotient gate.  Hence an asymptotic negative tail cannot be made of base
failures.  Any eventual B tail must occur in the one-new-strand Brunnian
extension rows:

```text
stabilizer,
orbit_label,
orbit_relation.
```

This is consistent with, and slightly sharpens, the first-failure
stratification note: base failures vanish after an explicit finite cutoff.
