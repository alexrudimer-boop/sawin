# Unit-continuation abelian-kernel lift

Date: 2026-05-29

This note follows `proofs/unit_continuation_final_obstruction.md`.  It does not
prove the unit-continuation longitude theorem.  It splits the final unit
endpoint problem into an abelian quotient calculation and a commutator-kernel
correction.

## Setup

Let `U=U(M_cont)` be the fixed finite unit group from the constant-observer
universal-continuation case.  The remaining endpoint is

```text
S_beta in U.
```

The desired certificate is

```text
S_beta in V_beta(U).
```

Let

```text
C=[U,U]
```

be the commutator subgroup, and let

```text
q:U -> U_ab = U/C
```

be the finite abelianization quotient.

## Lift criterion

Suppose the following data are supplied:

1. a longitude witness in `U_ab` for `q(S_beta)`;
2. a lifted longitude witness in `U` whose projection to `U_ab` has the same
   value;
3. a longitude witness in `U`, using only assignments into `C`, for the kernel
   correction

```text
K_beta = S_beta * v_beta^-1,
```

where `v_beta` is the value of the lifted witness.

Then

```text
S_beta in V_beta(U).
```

Proof.  The lifted witness value `v_beta` is in `V_beta(U)`.  Since it projects
to the same abelianized value as `S_beta`, the correction

```text
K_beta = S_beta * v_beta^-1
```

lies in `ker(q)=C`.  The third witness proves `K_beta in V_beta(C)`, and after
including `C` in `U` this is also an element of `V_beta(U)`.  Because
`V_beta(U)` is a subgroup, the product

```text
K_beta * v_beta = S_beta
```

lies in `V_beta(U)`.  QED.

## Abelian quotient part

The quotient group `U_ab` is finite abelian, so
`proofs/abelian_longitude_image_criterion.md` applies.  The image
`V_beta(U_ab)` is generated by the entries of the abelianized Artin-longitude
matrix:

```text
M_beta = (exp_j L_i(beta)).
```

Thus the abelian part of the unit-continuation theorem is an explicit finite
matrix witness problem:

```text
q(S_beta) in V_beta(U_ab).
```

This part is allowed to use the abelian matrix witness certificate; it is not
an Artin-permutation-defect display, and it may detect abelian endpoint
information that Artin defects alone cannot see.

## Remaining theorem after the split

The final unit-continuation theorem is reduced to:

1. prove the abelianized endpoint `q(S_beta)` has the matrix witness above;
2. choose a lift of that abelian witness to `U`;
3. prove the commutator correction `K_beta` has a longitude witness using
   assignments into `[U,U]`.

Equivalently, after the abelian endpoint is handled, any remaining obstruction
must live in the commutator subgroup of the fixed unit group.

This is a strict reduction of the final obstruction:

```text
S_beta in V_beta(U)
```

is replaced by

```text
q(S_beta) in V_beta(U_ab)
```

plus

```text
K_beta in V_beta([U,U]).
```

## Executable certificate

The helper

```text
normal_quotient_longitude_lift_audit(q,n,beta,S_beta,
                                     quotient_witness,
                                     lifted_witness,
                                     kernel_witness)
```

checks this certificate for any finite quotient homomorphism `q:G->H`.  For
the abelian-kernel split, take `q` to be the projection

```text
U -> U/[U,U].
```

The audit records:

- the quotient endpoint and quotient witness value;
- the lifted witness value in `U` and its quotient projection;
- the kernel correction `S_beta*v_beta^-1`;
- whether the kernel witness uses only assignments in `ker(q)`;
- the combined witness value in `U`.

It proves endpoint membership exactly when the quotient witness, lift, and
kernel correction all match.

## B-route consequence

A future B construction in the constant-observer continuation channel must now
say where the normalized-law movement lives:

1. in the abelianized unit endpoint, by defeating the finite abelian matrix
   witness criterion; or
2. in the commutator-kernel correction after the abelianized endpoint is
   accounted for.

A bounded failure in one finite unit group is still not B.  It must still be
upgraded to a normalized-law sequence invisible to every finite group while
moving an explicit residual tuple.
