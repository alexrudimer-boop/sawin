# Actual Mismatch Probe-Visibility Gap

This note records the current failed endpoint after the conjugated-probe core
obstruction.  It is not a resolution.  It identifies the precise implication
missing from the positive route and the precise construction missing from the
negative route.

## Positive Attempt

Assume `X` is a smallest finite bijective YBE solution not dominated by any
finite rack.  In the nonsimple branch, `X` has a unique first-fold monolith

```text
mu=mu_X <= F_1(X).
```

For a rack prefix `P_m`, choose a rack `Y_mu` dominating `X/mu`, and use the
strengthened detector

```text
Q=(P_m x Y_mu)^0 x T_2 x B_s(X).
```

The earlier reductions force, in unbounded arities, deletion-null Brunnian
chief factors

```text
A/B <= K_n cap C_n
```

such that every nontrivial element has a `Q`-invisible Brunnian representative
and its `X`-motion generates `mu` by coordinate mismatches.

The tempting final positive step is:

1. `mu <= F_1(X)`, so `mu` is generated by immediate degeneracy folds such as

```text
lambda_a(b)=lambda_a(c),       b != c,
```

or

```text
rho_a(b)=rho_a(c),             b != c.
```

2. If a Brunnian chief element moves a coordinate from `b` to `c`, then adding
a probe strand colored `a` should make a conjugated Brunnian derivative
visible.

3. Therefore the conjugated-probe core branch should be impossible.

4. If derivatives remain visible forever, repeated derivatives should
eventually contradict bounded-support annihilation.

This would close the minimal-counterexample branch and prove A.

## Fatal Gap In A

Step 2 is not justified.

The chief-factor obstruction proves only that the actual coordinate mismatches
produced by `p_X(A)` generate `mu` as a braided congruence:

```text
<actual moved pairs>_br = mu.
```

It does not prove that any actual moved pair is itself an immediate first-fold
pair, or even one-strand-probe visible.  The actual moved pairs may generate
an immediate fold only after closing under `R_X`, `R_X^{-1}`, and transitivity.

Brunnian derivatives probe the pairs that are actually moved by the finite
image element.  They do not automatically probe every pair appearing later in
the braided congruence closure.

Thus the missing implication is

```text
<actual moved pairs>_br = mu
and mu <= F_1(X)
  =>
some actual moved pair is conjugated-probe visible.
```

No proof of this implication is currently known in the ledger.

Equivalently:

```text
Brunnian derivatives see actual coordinate mismatches,
not the whole congruence generated by those mismatches.
```

The derivative-propagating branch also does not collapse from the existing
bounded-support detector argument.  Repeated derivatives remain Brunnian and
detector-invisible, but their support can grow with arity.  The
bounded-support detectors kill fixed-support representatives, not a cofinal
tower whose image support grows at every derivative step.

So the positive proof is blocked exactly by the absence of a theorem forcing a
first-fold monolith-generating Brunnian chief factor to have an actually
probe-visible moved pair.

## Negative Attempt

The natural negative strategy is the known powered Brunnian construction

```text
w_r=[...[ [x_1^e,x_2^e],x_3^e],...,x_r^e],
```

where `e` kills the detector's two-strand pure action.

This works when the target is allowed to vary with the detector, for example
by choosing a fresh alternating-group conjugation rack `Conj(A_l)` with `l`
not dividing the relevant detector exponent.

To prove B, one needs one fixed finite degenerate target `X` such that for
every finite rack prefix `P_m` there are unbounded arities and Brunnian braids
with

```text
rho^{P_m^0 x T_2}_n(beta)=1,
rho^X_n(beta) != 1.
```

Equivalently, in the current finite-image language, one needs a fixed finite
`X` whose first-fold monolith supports cofinal deletion-null Brunnian chief
factors

```text
K_n cap C_n
```

against every rack prefix.

## Fatal Gap In B

No such fixed finite `X` is currently known.

The existing alternating-group construction does not supply one, because the
target changes with the detector.  For one fixed finite `X`, the relevant
finite pure orders in the `X`-action are fixed, and a sufficiently rich rack
prefix can absorb those fixed orders.  The powered-commutator trick can then
become `X`-invisible as well.

The six-point linear `F_3` skew-over-flip family was the first serious
degenerate test, but the ledger closes that family by quotient, gauge, and
contextual mechanisms.  It does not provide the required fixed target.

The missing construction is:

```text
one fixed finite X with cofinal K_n cap C_n chief factors generating
its first-fold monolith against every finite rack prefix.
```

## Current Exact Status

The problem is not resolved.

A positive resolution must prove that first-fold monoliths cannot be generated
cofinally by actual deletion-null detector-invisible Brunnian chief factors,
or at least prove enough probe visibility or derivative collapse to rule out
the conjugated-probe core and derivative-propagating branches.

A negative resolution must exhibit one fixed finite `X` where such cofinal
first-fold-monolith chief factors really occur against every finite rack
prefix.

Anything weaker is another obstruction framework, not a proof of A or B.
