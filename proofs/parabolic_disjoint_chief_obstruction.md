# Parabolic-Disjoint Chief Obstruction

This note strengthens bounded-support elimination.  After adding the
bounded-support detector `B_s(X)`, a surviving obstruction chief factor is
not merely represented by elements of image support width greater than `s`.
It is disjoint, modulo its lower chief subgroup, from every bounded parabolic
image.

Thus the obstruction must be globally generated by conjugation while locally
absent from every bounded last-strand parabolic subgroup.

## Setup

Let `X` be a smallest finite bijective YBE solution not dominated by any
finite rack.  Let

```text
mu=mu_X
```

be its unique first-fold monolith.

Fix a finite rack prefix `P_m`, and choose a finite rack `Y_mu` dominating the
proper quotient `X/mu`.  For a support bound `s`, let

```text
B_s(X)=product_{k=2}^{s+1} Z_k^0,
```

where each `Z_k` is a fixed-arity rack detector satisfying

```text
ker rho^{Z_k}_k <= ker rho^X_k.
```

Set

```text
Q_{m,s}=(P_m x Y_mu)^0 x T_2 x B_s(X).
```

For arity `n`, let

```text
F_{n-1}=ker(d_n:P_n->P_{n-1})
```

be the last-strand free group, with meridian generators

```text
x_i=A_{i,n},        1 <= i <= n-1.
```

Let

```text
Phi_n:F_{n-1}->Gamma_n
  <= Sym(Q_{m,s}^n) x Sym(X^n)
```

be the combined finite image.  Define

```text
K_n=ker(Gamma_n->rho^{Q_{m,s}}_n(F_{n-1})),
L_n=ker(Gamma_n->rho^X_n(F_{n-1})).
```

For each meridian, put

```text
N_{i,n}=<<Phi_n(x_i)>>_{Gamma_n},
```

and define the exact all-meridian layer

```text
C_n=[N_{1,n},...,N_{n-1,n}]_Sigma.
```

For a subset

```text
T subset {1,...,n-1},
```

write

```text
F_T=<x_i:i in T>,
H_T=Phi_n(F_T)<=Gamma_n.
```

Here `H_T` is the finite-image subgroup supported on the last strand and the
meridians in `T`.

## Theorem

For every `m,s,N`, there exists `n>N` and a chief factor

```text
A/B
```

of `Gamma_n` such that:

```text
B < A <= K_n cap C_n,
```

the `X`-projection of `A` is nontrivial and generates the monolith `mu`, and
for every subset `T` with `|T|<=s`,

```text
A cap H_T B = B.
```

Equivalently, no bounded parabolic image `H_T` covers `A/B`.

## Proof

Since `X` is a counterexample, the finite rack `Q_{m,s}` cannot dominate
`X`.  By the transparent Brunnian reduction, there are unbounded arities `n`
with

```text
Brun_n cap ker rho^{Q_{m,s}}_n
  not subset
ker rho^X_n.
```

For such `n`, the finite-image Brunnian theorem gives

```text
K_n cap C_n != 1.
```

Choose a chief series of the finite group `Gamma_n` refining

```text
1 <= K_n cap C_n <= Gamma_n.
```

Then some chief factor `A/B` lies inside `K_n cap C_n`, so

```text
B < A <= K_n cap C_n.
```

The projection kernels of `Gamma_n<=Sym(Q_{m,s}^n)xSym(X^n)` satisfy

```text
K_n cap L_n=1.
```

Since `A` is nontrivial and `A<=K_n`, its `X`-projection is nontrivial.

Also, since `A<=K_n`, every element of `A` is invisible to `Q_{m,s}`.  In
particular it is invisible to the `Y_mu^0` factor.  Coloring all strands
nontransparent and using that `Y_mu` dominates `X/mu`, the `X`-projection of
`A` acts trivially on

```text
(X/mu)^n.
```

Therefore every coordinate mismatch produced by `p_X(A)` lies inside a
`mu`-class.

The `X`-projection is nontrivial, so at least one nontrivial coordinate
mismatch occurs.  The braided congruence generated by all mismatches produced
by `p_X(A)` is nontrivial and contained in `mu`.  Since `mu` is the global
monolith, that congruence equals `mu`.

It remains to prove parabolic-disjointness.  Let `T` satisfy `|T|<=s`.
Because `Q_{m,s}` contains the bounded-support detector `B_s(X)`, the
bounded-support annihilation theorem gives

```text
K_n cap H_T = 1.
```

Now suppose

```text
a in A cap H_T B.
```

Then `a=hb` for some

```text
h in H_T,
b in B.
```

Since

```text
A <= K_n,
B <= A <= K_n,
```

we have

```text
h=ab^{-1} in K_n.
```

But also `h in H_T`, so

```text
h in K_n cap H_T = 1.
```

Thus `h=1`, and hence `a=b in B`.  Therefore

```text
A cap H_T B = B.
```

This holds for every `|T|<=s`.

## Consequence

A smallest counterexample must have obstruction chief factors with all of the
following simultaneous properties:

```text
A/B lies inside the detector kernel K_n;
A/B is covered by the exact all-meridian subgroup C_n;
p_X(A) generates the first-fold monolith mu;
A/B is disjoint from every bounded parabolic image H_T.
```

This is stronger than large image support.  It says bounded parabolic
subgroups do not even meet the obstruction chief factor nontrivially modulo
`B`.

## Branch Refinements

### Pairwise Branch

If a pairwise or pairwise-core branch occurs, then pairwise commutator
subgroups cover `A/B`, but every bounded parabolic `H_T` fails to cover it.

Thus the pairwise obstruction has the form:

```text
normal closures of meridians cover A/B only after conjugation by
unboundedly many other meridians.
```

It is a global conjugation ghost, not a genuine bounded-strand obstruction.

### Central Abelian Branch

If a central elementary abelian branch occurs, then `A/B` is a central
elementary `p`-factor covered by `C_n`, while still satisfying

```text
A cap H_T B = B        for every |T|<=s.
```

So it is not a bounded-support `p`-module phenomenon.  It is a high-Brunnian
module class whose every bounded parabolic restriction vanishes.

## New Target

The current obstruction is:

```text
a detector-invisible all-meridian chief factor that is globally generated
but locally absent.
```

To prove domination, it is enough to rule out such parabolic-disjoint
monolith-generating chief factors for first-fold atoms.

To construct a counterexample, one must construct one fixed finite `X` whose
first-fold monolith is generated cofinally by these parabolic-disjoint
all-meridian chief factors.
