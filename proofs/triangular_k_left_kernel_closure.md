# Triangular K-left kernel-closure ledger

Date: 2026-05-31

This note refines `proofs/triangular_k_left_defect_ledger.md`.  It does not
prove `[Resolution: A]` or construct `[Resolution: B]`.  It closes one more
ambiguity in System K: when a non-Latin triangular row contains an actual
kernel edge, the edge now has an explicit admissible-congruence closure.

## Executable object

The helper

```text
triangular_latin_defect_closure_audit(I)
```

collects kernel edges from non-Latin triangular rows:

```text
constant_map_kernel
companion_section_kernel
opposite_section_kernel
```

For each edge it computes the least admissible congruence family generated by
that one collapsed pair.  Each row records:

```text
side
defect
left_color
right_color
domain_color
fixed_input
collapsed_inputs
closure_kind
```

where `closure_kind` is one of the existing generated-congruence kinds, in
particular `proper` or `universal`.

The post-linear finite-system wrapper includes the summaries:

```text
triangular_latin_defect_closure_rows
triangular_latin_defect_proper_closure_rows
triangular_latin_defect_universal_closure_rows
triangular_latin_defect_duplicate_closure_keys
```

whenever the wrapper is built from an actual interval.

[Proved, audit-side] The closure ledger is keyed by:

```text
(side, defect, left_color, right_color, domain_color, fixed_input,
 collapsed_inputs).
```

This keyed ledger must be duplicate-free.  If two supplied closure rows share
the same key, even with different generated-congruence kinds, the post-linear
wrapper refuses to use that ledger either as a proper-closure terminal or as a
universal-closure route.  This prevents conflicting closure rows from closing
System K or creating downstream U endpoint obligations.

## Local-minimal consequence

[Proved] In a local-minimal interval, no kernel edge in a remaining K-left
triangular defect can have proper generated closure.

Proof.  The closure computed by
`generated_admissible_congruence_audit(I,{c:(p,q)})` is, by construction, an
admissible congruence family containing the nontrivial pair `p~q`.  In a
local-minimal interval every nontrivial generated admissible congruence is
universal.  Therefore a proper closure row would contradict local minimality.
QED.

Thus every surviving kernel edge in K-left has exactly one of two outcomes:

```text
proper closure: impossible in the local-minimal branch;
universal closure: an exact universal seed edge that still needs fixed
                   detector routing.
```

## What remains after this ledger

The kernel-closure ledger removes a false middle possibility.  A K-left
survivor cannot hide in a proper intermediate quotient generated by a
constant-map, companion-section, or opposite-section kernel edge.

The live kernel side of K-left is therefore:

```text
all nontrivial kernel edges force universal closure,
and the proof must route those universal seed edges through fixed detector
data or construct a normalized-law sequence from them.
```

The post-linear wrapper now makes the proper-closure alternative terminal:
if a supplied triangular-Latin defect closure contains a proper generated
congruence row and the closure-key ledger is duplicate-free, it reports
`closed_by_triangular_latin_proper_closure`, empties the live K ledger, and
does not create any routed endpoint obligation.  This keeps the
local-minimality contradiction separate from the universal-closure endpoint
route.

For constant-map kernel edges, the companion note
`proofs/triangular_k_left_recovery_routing.md` supplies the next routing
layer: the triangular recovery table separates the collapsed constant-map
inputs, so those universal seed edges are System U recovery endpoints rather
than independent K-left branches.

Rows with no kernel edge, such as injective-nonsurjective companion sections
or a complete absence of a triangular row, remain separate finite defects.
They are not closed by this note.
