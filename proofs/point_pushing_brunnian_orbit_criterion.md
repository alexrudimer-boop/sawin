# Point-Pushing Brunnian Orbit Criterion

Date: 2026-05-30

This note refines `proofs/point_pushing_jump_normalization.md`.  Once a
detector degree works at arity `k`, a failure at arity `k+1` is not only
deletion-trivial; it is detected by a finite normal-closure subgroup generated
by the orbit of the new far-left point-pushing generator under the old suffix
paired action.

It does not prove outcome A or B.  It gives the exact finite group-theoretic
criterion for the one-new-strand extension step.

## Setup

Use right-based point-pushing coordinates at arity `k+1`:

```text
F_{k+1}=<a_1,...,a_k,a_{k+1}>.
```

Here `a_1,...,a_k` are the old suffix generators and `a_{k+1}` is the newly
added far-left stationary strand.  The deletion retraction is

```text
r_k:F_{k+1}->F_k,
r_k(a_i)=a_i for i<=k,
r_k(a_{k+1})=1.
```

Fix a symmetric detector `S_m` and a finite YBE solution `X`.  Let

```text
E_i=(d_i,h_i) in D_{k+1}(S_m) x P_{k+1}(X)
```

be the paired detector/action image of the right-based generator `a_i`.

Let

```text
C_k=<E_1,...,E_k>
```

be the old suffix paired subgroup, and let

```text
e=E_{k+1}
```

be the new-generator pair.  Define the relative Brunnian orbit subgroup

```text
B_{m,k+1}(X)
=
<<e>>_{C_k}
=
< c e c^{-1} : c in C_k >.
```

This is finite because `C_k` is finite and the ambient product permutation
group is finite.

## Theorem

There exists a one-new-strand Brunnian vertical witness

```text
w in ker(r_k),
w in R_{m,k+1},
w notin N_{X,k+1}
```

if and only if

```text
B_{m,k+1}(X) cap ({1} x P_{k+1}(X))
```

contains an element `(1,p)` with `p!=1`.

Equivalently, the relative extension step has no Brunnian obstruction exactly
when this finite orbit-normal-closure subgroup has trivial vertical kernel.

## Proof

The subgroup `ker(r_k)` is the normal closure of `a_{k+1}` in `F_{k+1}`.
Since `F_{k+1}=F_k * <a_{k+1}>`, the free-product normal form gives the
standard Schreier basis for this kernel: it is generated by conjugates of the
new generator by words from the old free factor `F_k`.  Thus every element of
`ker(r_k)` is a product of conjugates

```text
u_t a_{k+1}^{epsilon_t} u_t^{-1},
epsilon_t in {+1,-1},
u_t in F_k.
```

Evaluating the paired detector/action map sends each conjugate to

```text
E(u_t) e^{epsilon_t} E(u_t)^{-1},
```

where `E(u_t)` lies in `C_k`.  Hence every Brunnian word evaluates inside

```text
B_{m,k+1}(X).
```

If such a word also lies in `R_{m,k+1}` and not in `N_{X,k+1}`, its paired
value is `(1,p)` with `p!=1`, giving a nontrivial vertical element of `B`.

Conversely, every generator `c e c^{-1}` of `B` is represented by a word

```text
u a_{k+1} u^{-1}
```

with `u in F_k` and paired value `c=E(u)`.  Products and inverses of these
generators are represented by products of such conjugates, hence by words in
`ker(r_k)`.  Therefore any nontrivial vertical element `(1,p)` in `B` is
represented by a word `w in ker(r_k)` with detector value `1` and action value
`p!=1`.  This is exactly a one-new-strand Brunnian vertical witness.  QED.

## Relation To Jump Normalization

If `S_m` detects arity `k`,

```text
R_{m,k} <= N_{X,k},
```

then `proofs/point_pushing_jump_normalization.md` says that arity `k+1` fails
if and only if a one-new-strand Brunnian vertical witness exists.  By the
criterion above, this is equivalent to a nontrivial vertical element in

```text
B_{m,k+1}(X).
```

Thus the A-side extension theorem can be stated as:

```text
exists m=m(X) such that
B_{m,k+1}(X) has trivial vertical kernel for every k.
```

If this holds, induction gives `R_{m,k}<=N_{X,k}` for all `k`, and the sharp
rack `A_{S_m}` dominates `X`.

The B-side target becomes:

```text
for every j, find k_j and a nontrivial vertical element
in B_{j,k_j}(X).
```

Representing these elements by words gives Brunnian point-pushing braids in
`K_{S_j}` which move `X`; right stabilization then gives the normalized-law
obstruction sequence.

## Audit Hook

The helper

```text
point_pushing_brunnian_orbit_audit(...)
```

performs the finite check in one arity:

1. build the old suffix paired subgroup `C_k`;
2. conjugate the new-generator pair through all elements of `C_k`;
3. generate the relative orbit-normal-closure subgroup;
4. report a right-based Brunnian witness word if a nontrivial vertical element
   appears.

This helper is a certificate checker for finite rows.  The theorem above is
the symbolic reduction that makes those rows the exact one-new-strand
extension obstruction.
