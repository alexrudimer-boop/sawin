# Powered-Meridian No-Freezing Theorem

This note rules out the known powered-meridian Brunnian construction as a
fixed-target counterexample strategy.  The construction works only because the
target is allowed to vary with the detector.

## Theorem

Let `X` be a fixed finite bijective YBE solution, and define

```text
d_X=ord(rho^X_2(sigma_1^2)).
```

Let

```text
P_m=R_1 x ... x R_m
```

be a rack prefix whose enumeration eventually contains every finite rack up
to isomorphism, and set

```text
e_m=ord(rho^{P_m}_2(sigma_1^2)).
```

Then, for all sufficiently large `m`,

```text
d_X divides e_m.
```

Consequently, for all sufficiently large `m`, every braid in the normal
subgroup of `P_n` generated by the powered meridians

```text
A_{ij}^{e_m}
```

acts trivially on `X^n`.

In particular, no fixed-target counterexample can be built from Brunnian
words of the form

```text
W(A_{1,n}^{e_m},A_{2,n}^{e_m},...,A_{n-1,n}^{e_m}),
```

including the standard powered commutators

```text
[...[ [A_{1,n}^{e_m},A_{2,n}^{e_m}],A_{3,n}^{e_m}],...,A_{n-1,n}^{e_m}].
```

## Proof

First, every pure meridian `A_{ij}` is conjugate in `B_n` to an adjacent
square braid, hence to `sigma_1^2` after relabelling.  Under the braid
representation coming from `X`, the adjacent square acts on two coordinates by
`rho^X_2(sigma_1^2)` and leaves all other coordinates as spectators.
Therefore

```text
ord(rho^X_n(A_{ij})) divides d_X.
```

Now show that eventually `d_X` divides `e_m`.  For every positive integer
`d`, there is a finite rack whose two-strand pure order is exactly `d`.  Take

```text
Y_d=Z/dZ,
```

with rack operation

```text
a*b=b+1.
```

Then the rack braid map is

```text
R(a,b)=(a*b,a)=(b+1,a),
```

so

```text
R^2(a,b)=(a+1,b+1),
```

which has order `d`.  Hence

```text
ord(rho^{Y_d}_2(sigma_1^2))=d.
```

Since the rack prefix eventually contains `Y_{d_X}`, the product rack `P_m`
eventually has two-strand pure order divisible by `d_X`.  Equivalently,

```text
d_X divides e_m
```

for all sufficiently large `m`.

For such `m`,

```text
rho^X_n(A_{ij}^{e_m})=1
```

for every meridian `A_{ij}`.  Since kernels are normal, every conjugate of
`A_{ij}^{e_m}` also acts trivially on `X^n`.  Therefore the entire normal
subgroup generated by the powered meridians acts trivially on `X^n`.

This proves the theorem.

## Consequence

The known detector-survival construction works by choosing the target after
the detector, for instance

```text
X_Q=Conj(A_l),
```

with `l` chosen not to divide the detector's relevant pure order.  That makes
the powered meridians detector-invisible but still target-visible.

For one fixed finite target `X`, this cannot work.  Once the rack prefix
contains a rack with two-strand pure order divisible by `d_X`, the same
powered-meridian subgroup is also `X`-trivial.

Thus a genuine negative solution must use Brunnian witnesses whose
detector-invisibility is a global finite-rack law, not a consequence of each
meridian becoming individually trivial.

Equivalently, a fixed-target counterexample sequence must have

```text
n_m -> infinity,
rho^{P_m^0 x T_2}_{n_m}(beta_m)=1,
rho^X_{n_m}(beta_m) != 1,
```

and, for large `m`,

```text
beta_m notin << A_{ij}^{e_m} >>.
```

So the remaining negative route requires global Brunnian laws for finite
racks, not powered-meridian laws.
