# Contextual Scattering And Escape Boundary

Date: 2026-06-05

This note records the next audit of the contextual prefix rack route.  The
two-sided contextual rack `C_L(X)` is valid and genuinely stronger than
`W_L(X)`, but it does not close Sawin.  Its exact missing lemma is contextual
orbitwise residual finiteness:

```text
For residual rigid X with no proper domination-reducing active factor,
C_L(X) separates distinct braid-orbit points through finite rack quotients of
the Theta_n labels.
```

Equivalently, there must be no distinct same-orbit words whose contextual
coordinates are identified in every finite rack quotient of `C_L(X)`.

## Scattering Normalization

The one-sided rack `V_L(X)` collapses to `W_L(X)` because moving a left-prefix
letter through the marked letter simply evaluates the prefix on that letter.
For `C_L(X)`, the analogous relation is

```text
c_{pL_z,x,q}=c_{p,L_z(x),L_{R_x(z)}q},
```

for `r_X(z,x)=(L_z(x),R_x(z))`.  Thus prefix data is transported into the
right context.

Let `a=z_1...z_k` be a word in `X`, and write

```text
L_a=L_{z_1}...L_{z_k} in S_L^1.
```

Define recursively

```text
sigma_empty(x)=x,        Delta_empty(x)=1,
sigma_{az}(x)=sigma_a(L_z(x)),
Delta_{az}(x)=Delta_a(L_z(x)) L_{R_x(z)}.
```

Then iterating the contextual relation gives

```text
c_{L_a,x,q}=c_{1,sigma_a(x),Delta_a(x)q},
```

and `sigma_a(x)=L_a(x)`.

However, `C_L(X)` indexes the left context by the transformation `L_a`, not by
the word `a`.  Thus if two words `a,a'` have the same transformation

```text
L_a=L_{a'},
```

then the same generator `c_{L_a,x,q}` gives the relation

```text
c_{1,L_a(x),Delta_a(x)q}
=
c_{1,L_a(x),Delta_{a'}(x)q}.
```

This is the scattering collapse.  It is weaker than the `W_L(X)` collapse but
still loses word-level escape data.

The hierarchy is therefore

```text
full marked word/path data -> C_L(X) -> W_L(X).
```

The first map forgets word representatives with the same left transformation
and imposes the rack-forced crossing identification.  The second forgets the
right context entirely.

## Finite Contextual Collision

At context `(p,q)`, a local crossing `r_X(x,y)=(u,v)` has labels

```text
A=c_{p,x,L_yq},
B=c_{pL_x,y,q},
```

and sends `(A,B)` to

```text
(B,B triangleright A).
```

Thus the crossing is invisible in `C_L(X)` if

```text
A=B
and
B triangleright A=B.
```

Since `(C2)` identifies `B triangleright A` with `c_{pL_u,v,q}`, a sufficient
universal-level local obstruction is

```text
c_{p,x,L_yq}=c_{pL_x,y,q}=c_{pL_u,v,q}
```

for a nontrivial crossing.

Let `~_sc` be the equivalence relation on `S x X x S` generated by the
`C1` moves

```text
(p,u,L_vq) ~_sc (pL_x,y,q).
```

If

```text
(p,x,L_yq) ~_sc (pL_x,y,q) ~_sc (pL_u,v,q),
```

then the local braid generator gives a same-`Theta` collision.

A concrete finite table/semigroup pattern forcing this is:

```text
r_X(a,y)=(x,y),
r_X(x,y)=(u,y),
u != x,
pL_a=pL_x=pL_u.
```

Then for every `q`,

```text
c_{p,x,L_yq}=c_{pL_a,y,q}=c_{pL_x,y,q}=c_{pL_u,y,q},
```

so the crossing `(x,y)->(u,y)` is invisible to contextual labels at context
`(p,q)`.

Residual rigidity as currently stated does not exclude such a contextual
scattering cycle.

## Profinite Obstruction

Let

```text
R=C_L(X),
G_C(X)=As(R).
```

Since `R` is generated by `A_C=S x X x S`, `G_C(X)` has generators
`g_{p,x,q}` and relations

```text
g_{p,u,L_vq}=g_{pL_x,y,q},
g_{pL_u,v,q}=g_{pL_x,y,q} g_{p,x,L_yq} g_{pL_x,y,q}^{-1}.
```

For `alpha=(p,x,q)`, let

```text
H_alpha=Stab_{G_C(X)}(c_alpha).
```

Contextual finite-rack residual equivalence is

```text
alpha ==_{C,fin} beta
```

if every finite rack quotient of `C_L(X)` identifies `c_alpha` and `c_beta`.
If `c_beta=g.c_alpha`, then

```text
alpha ==_{C,fin} beta
iff
g in closure_prof(H_alpha)
iff
g in intersection_{N normal finite index in G_C(X)} H_alpha N.
```

Thus the profinite obstruction is an orbit-relevant coset

```text
g notin H_alpha
but
g in closure_prof(H_alpha).
```

This criterion requires no residual finiteness of `G_C(X)`.

## Active Factors Are Not Automatic

Contextual collapse gives relations among triples

```text
(p,x,q).
```

For each context pair, it induces relations

```text
x ~_{p,q} y
iff
(p,x,q) ==_{C,fin} (p,y,q).
```

A coordinate active factor would require a context-independent relation on
`X`, compatible with the YBE.  Contextual collapse does not provide this.

Inside one braid orbit, inert observers cannot help because they are constant
on the orbit.  A contextual collapse yields active coordinates only if it can
be promoted to a coherent finite state-dependent YBE factor.

The correct state-dependent condition is: a finite bijective YBE solution `Z`
and maps

```text
pi_{p,q}:X -> Z
```

such that, for every `r_X(x,y)=(u,v)`,

```text
r_Z(pi_{p,L_yq}(x), pi_{pL_x,q}(y))
=
(pi_{p,L_vq}(u), pi_{pL_u,q}(v)).
```

Then the induced maps

```text
Pi_n(w)=(pi_{p_0,q_1}(x_1),...,pi_{p_{n-1},q_n}(x_n))
```

are `B_n`-equivariant.  If they become injective after adding inert observers,
then

```text
ker rho_n^Z <= ker rho_n^X.
```

But existence of such a `Z` is an extra coherent finite YBE extension
condition and does not follow from contextual rack separation failure.

## Escape Holonomy Determinacy

The escape-rack/minimal-ideal holonomy construction can retain row, column,
and sandwich data.  A contextual generator `c_{p,x,q}` with Rees coordinates

```text
p=(i,g,lambda),
L_x=(j_x,h_x,mu_x),
q=(j_q,k,nu)
```

sees sandwich entries such as

```text
P_{lambda j_x},      P_{mu_x j_q}.
```

Thus `C_L(X)` is closer to escape holonomy than `W_L(X)`.

However, an escape-rack label factors through `C_L(X)` only under a precise
rack-determinacy condition.  There must be a finite rack `E` and a label map

```text
epsilon:S x X x S -> E
```

satisfying the contextual relations

```text
epsilon(p,u,L_vq)=epsilon(pL_x,y,q),
epsilon(pL_u,v,q)=epsilon(pL_x,y,q) triangleright epsilon(p,x,L_yq).
```

Then `epsilon` factors through a rack homomorphism

```text
C_L(X) -> E.
```

If escape labels distinguish marked paths with the same triple `(p,x,q)`, or
if their crossing law is not the rack crossing `(a,b)->(b,b triangleright a)`,
then escape holonomy does not factor through `C_L(X)`.

## Stronger Detectors

The contextual construction can be refined.

Let `M` be a finite quotient of the left structure monoid generated by symbols
`lambda_x` with relations

```text
lambda_x lambda_y = lambda_u lambda_v
```

for `r_X(x,y)=(u,v)`.  Define `C_M(X)` with generators

```text
d_{a,x,b}        (a,b in M, x in X)
```

and relations

```text
d_{a,u,lambda_v b}=d_{a lambda_x,y,b},
d_{a lambda_u,v,b}
 =
d_{a lambda_x,y,b} triangleright d_{a,x,lambda_y b}.
```

The same local proof gives braid-equivariant labels.  Taking `M=S_L^1`
recovers `C_L(X)`.  Finer finite monoid quotients may retain word-level escape
data that `S_L^1` loses.

At the limit, one may use an infinite full marked-word rack with generators

```text
d_{a,x,b}        (a,b in X^*, x in X),
```

but Sawin still requires a finite rack quotient separating orbit points.

## Current Endpoint

The strongest clean theorem remains:

```text
If for every n and every distinct same-orbit pair w,w' in X^n, some contextual
coordinate alpha_i(w) is not ==_{C,fin} alpha_i(w'), then X is dominated by a
finite rack.
```

The exact missing lemma is:

```text
For residual rigid X with no proper domination-reducing active factor, every
orbit-relevant contextual collapse is either finite-rack separable or yields a
proper active factor.
```

Equivalently:

```text
Every orbit-relevant stabilizer coset in As(C_L(X)) is profinitely separated,
unless it descends to an active factor.
```

The contextual route is stronger than the normalized prefix route, but it is
still conditional.  The next possible moves are a finite-state contextual
tower, an escape-holonomy determinacy theorem, or a concrete obstruction.
