# Unique First-Fold Atom And The Monolith

This note refines the first-fold atom obstruction for a smallest
counterexample.  It shows that a smallest counterexample cannot have two
independent immediate degeneracy directions.  Its first-fold atom is unique,
and that atom is the global monolith.

## First-Fold Congruence

Let `X` be a finite bijective YBE solution, and write

```text
R_X(x,y) = (lambda_x(y), rho_y(x)).
```

Define `F_1(X)` to be the braided congruence generated by all immediate
left- and right-degeneracy folds:

```text
y ~ y'       whenever lambda_x(y)=lambda_x(y') for some x in X,

x ~ x'       whenever rho_y(x)=rho_y(x') for some y in X.
```

If `X` is degenerate, then `F_1(X) != Delta_X`.

A first-fold atom is a minimal nontrivial braided congruence

```text
mu <= F_1(X).
```

## Theorem 1: A Smallest Counterexample Has A Unique First-Fold Atom

Let `X` be a smallest finite bijective YBE solution, by cardinality, not
dominated by any finite rack.  Then `X` is degenerate and `F_1(X)` has exactly
one first-fold atom.

### Proof

Since one-sided nondegenerate solutions are already finite-rack dominated by
the known derived-rack/guitar theorem, `X` must be degenerate.  Thus
`F_1(X)` is nontrivial and has at least one atom.

Suppose `F_1(X)` had two distinct first-fold atoms

```text
mu_1 != mu_2.
```

Their intersection is a braided congruence contained in both atoms and still
contained in `F_1(X)`.  If it were nontrivial, atom-minimality would force

```text
mu_1 cap mu_2 = mu_1 = mu_2,
```

contradiction.  Hence

```text
mu_1 cap mu_2 = Delta_X.
```

The diagonal quotient map

```text
X -> X/mu_1 x X/mu_2
```

is therefore injective and braided.

Neither atom is universal.  Indeed, if one were universal, it could not be
distinct from another nontrivial congruence contained in `F_1(X)`.  Hence
both quotients `X/mu_1` and `X/mu_2` are proper.  By minimality of `X`, each
proper quotient is finite-rack dominated.

Product closure of domination gives a finite rack dominating

```text
X/mu_1 x X/mu_2.
```

Since `X` embeds braid-equivariantly into this dominated product, the same
rack dominates `X`: if a braid fixes the product quotient in every arity, it
fixes the injective image of every `X`-word, hence fixes the `X`-word itself.

This contradicts that `X` is a counterexample.  Therefore `F_1(X)` has
exactly one first-fold atom.

## Theorem 2: The Unique First-Fold Atom Is The Global Monolith

Let `mu` be the unique first-fold atom of a smallest counterexample `X`.  Then
every nontrivial braided congruence on `X` contains `mu`.  Thus `mu` is the
global monolith:

```text
mu = mu_X.
```

### Proof

Let `nu` be a nontrivial braided congruence on `X`.

If `nu = X x X`, then `mu <= nu` is immediate.

Now suppose `nu` is proper.  If

```text
mu cap nu = Delta_X,
```

then the diagonal map

```text
X -> X/mu x X/nu
```

is injective and braided.  Both quotients are proper: `X/mu` is proper
because `mu` is nontrivial and not universal unless `X` is braided-simple,
and `X/nu` is proper by assumption.  More directly, if `mu` were universal,
then `mu cap nu = nu`, not `Delta_X`, since `nu` is nontrivial.

Thus, under the displayed assumption, both quotients are proper and hence
finite-rack dominated by minimality of `X`.  Their product is dominated, and
the injective diagonal embedding pulls domination back to `X`.  This is a
contradiction.

Therefore

```text
mu cap nu != Delta_X.
```

But `mu cap nu` is a nontrivial braided congruence contained in
`mu <= F_1(X)`.  Atom-minimality of `mu` forces

```text
mu cap nu = mu,
```

so `mu <= nu`.

Hence every nontrivial braided congruence contains `mu`, which is exactly the
definition of the monolith in the finite congruence lattice.

## Consequence

A smallest counterexample has exactly one of the following first-fold forms.

### Simple Branch

The unique first-fold atom is universal:

```text
mu = F_1(X) = X x X.
```

Since `mu` is the monolith, every nontrivial congruence contains the universal
congruence and therefore is universal.  Thus `X` is braided-simple.  It is
also degeneracy-perfect.

### Monolithic Branch

The unique first-fold atom is proper:

```text
mu = mu_X <= F_1(X).
```

Then `X` is subdirectly irreducible, and its monolith is generated by
immediate degeneracy folds.

By `proofs/first_fold_atom_brunnian_obstruction.md`, this same `mu` is
generated cofinally by actual Brunnian rack-prefix-invisible coordinate
mismatches.  More precisely, for every finite rack prefix `P_m`, if `Y_mu`
dominates `X/mu` and

```text
Q_m=(P_m x Y_mu)^0 x T_2,
```

then there are unbounded arities `n`, braids

```text
beta in Brun_n cap ker rho^{Q_m}_n,
```

and moved words `x in X^n` whose coordinate mismatches lie inside `mu` and
generate `mu`.

Thus a true minimal counterexample cannot have several independent immediate
degeneracy directions.  The next search target is:

```text
braided-simple degeneracy-perfect solutions,
```

or

```text
subdirectly irreducible solutions whose monolith is the unique first-fold
atom and is generated cofinally by Brunnian detector-kernel monodromy.
```
