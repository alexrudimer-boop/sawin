# Unit composite longitude route audit

Date: 2026-05-29

This note records the endpoint-unit analogue of the product closed-label route
audit.  It is a fixed-word diagnostic, not a proof of the Master
Local-Minimal Residual Theorem.

## Route Ladder

Let `M` be a fixed finite transformation monoid and `U(M)` its unit group.
For a braid `beta in B_n` and a residual endpoint word

```text
h_beta = f_k ... f_1 in M,
```

the endpoint criterion in `proofs/unit_composite_longitude_criterion.md`
requires only

```text
h_beta in V_beta(U(M)).
```

There are three increasingly flexible ways a proof attempt may see this:

1. the endpoint is the identity unit;
2. the endpoint is one evaluated recursive longitude
   `phi(L_i(beta))` for some assignment `phi:F_n -> U(M)`;
3. the endpoint lies in the subgroup generated by all such evaluated
   recursive longitudes.

Only the third condition is theorem-level.  A missing single-longitude
witness is not a counterexample signal if subgroup membership still holds.
Conversely, an endpoint unit outside this subgroup is the fixed-word failure
shape that can feed the normalized-law B route.

## Executable Audit

The helper

```text
unit_composite_longitude_route_audit(monoid,n,beta,factors)
```

computes:

- the final composite endpoint;
- whether the endpoint is a unit/permutation;
- the size of `V_beta(U(M))`;
- whether the endpoint lies in that subgroup;
- whether a single-longitude witness exists;
- the witness longitude index and assignment, when present;
- whether identity finite-`U(M)` longitude data kills this endpoint;
- whether the word is a finite-unit detector failure.

The helper deliberately treats subgroup membership as the decisive fixed-word
criterion.  The single witness is only an explanatory convenience.

## Consequence For A And B

For outcome A, a semigroup or corridor branch may prove endpoint detection by
showing subgroup membership directly, without choosing a common assignment or
a single evaluated longitude for each endpoint.

For outcome B, the obstruction must start with endpoint units outside the
longitude-value subgroup and then upgrade them to a normalized-law sequence
defeating every finite group.  The route audit can identify the finite-word
failure shape, but it cannot by itself prove such a sequence.

Regression tests cover both sides:

- a `C_2` endpoint where the nonidentity unit is hit by a single longitude
  value and lies in `V_beta(C_2)`;
- a `C_3` endpoint with identity finite-longitude signature where the
  nonidentity endpoint lies outside `V_beta(C_3)`, correctly marked as a
  finite detector failure only.
